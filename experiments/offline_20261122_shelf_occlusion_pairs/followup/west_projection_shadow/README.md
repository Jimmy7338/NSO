# 西侧遮挡仿真中的障碍端点落格

第 61 步的 44 个深度端点和第 51 步的 3 个激光端点都由 x=2.9 m 一侧观测到 x≈3.4 m。第 13 步的反例由 x=2.5 m 一侧观测到 x≈2.0 m。固定向高索引取整在前两处选择了射线越过边界的一侧，却在后一处落回传感器一侧。该规则在旧轨迹上曾丢失真实占据中心，并使一些真实无效车体中心通过栅格检查。

仿真候选只改有效障碍端点的索引。端点必须只在一个坐标轴上落入预先固定的单精度单 ULP 边界区间。根据首个命中点与传感器起点推断射线越过该面的方向。仅当边界两側的数值扰动仍处于同一横向格时才采用该方向。角点、擦边、落在传感器自身格和超出地图的修正均沿用原索引。自由空间扫描线、传感器原始数据、三维融合、评分、保护和返航预算继续使用原代码。源几何仅在回放评价时用于核验，不参与选边。

四项静态测试已通过。其中固定见证检查了上述 48 个实际端点，合成检查包括反向边界、原始值回退和有向扫掠。静态测试尚未证明整段地图和闭环行为。两个固定观测回放应逐帧复现各自原栅格，并对两种模式分别检查此前真实占据中心未丢失、没有新增真实无效中心或有向扫掠。返航路径中的每个平移和转向也作独立核对，终点另按连续几何重验。回放保持实际动作顺序，结果中的可用回程由保护器重算。
