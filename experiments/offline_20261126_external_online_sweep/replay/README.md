# HM3D 00770 起点 1 固定观测回放

在已归档的第 0–38 步真实记录位姿上，调用原传感器渲染例程重建 RGB、深度和激光验证帧。每步均核对三个传感数据的 SHA-256、完整传感包 SHA-256 和实际占用图。回放按日志直接设置观测位姿，只渲染原轨迹曾访问的位置。回放不会实例化运动模拟器、推进底盘、读取预计算可达图或评价真值。传感渲染器只将当前观测返回给适配器，适配器不会接触源网格。

第 17 步为提前检查，第 38 步为实际重规划节点。在每个节点使用冻结的原生候选生成和区域认证代码，区域提案池由已实测历史固定。给这段代码分别传入原足迹膨胀图和观测扫掠适配图，重新核对两条定向路线、预算和每条边的一致性。第 38 步的原安全栅格、所有原生候选路线、区域提案及认证与存档完全一致。
