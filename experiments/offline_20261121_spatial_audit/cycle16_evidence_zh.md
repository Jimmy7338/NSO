# Cycle16 的轨迹与重建空间核查

Cycle16 的原始场景由四个房间组成，尺寸为 16.0 × 14.4 m。场景坐标以左下角为原点，横轴为东向，纵轴为北向。按冻结图纸上的 `x=8.2 m`、`y=7.8 m` 分为西南 A、东南 B、东北 C 和西北 D 四个房间。轨迹房间来自记录位姿的栅格中心换算。相机所在房间和朝向可以按记录计数，表面点则按自身坐标归入房间。两种记录之间没有逐帧可见性归因。

第 256–512 步的每个已付费动作后，两组二维正确空闲覆盖率均为 100%。第 256–320 步之间，S 的整场景召回增加 3.572 个百分点，精度下降 0.025 个百分点。此时主要变化是东北 C 房间内已有几何表面召回差距收窄。G 在第 202 步进入东北 C，第 250 步已退出至东南 B。S 到第 241 步才进入东北 C，并在第 257–320 步的 64 次观测中有 31 次位于该房间，其中 21 次朝南。同一时段，G 的 64 次观测全部发生在南侧的两个房间。该时窗内两组轨迹的空间差异与东北 C 匹配差逆转同时出现。

西北 D 占终点匹配面积优势的大部分。G 在第 160–201 步于西北 D 记录了 42 个观测位姿，轨迹横坐标为 5.9–8.1 m。S 在第 162–240 步记录了 79 个观测位姿，向西到达 `x=3.9 m`，并在第 207 步到达 `(3.9, 13.5) m`。S 的 +7.399 m² 匹配优势在第 256 步已经出现。第 256 步的西北 D 中，源实例 ID `0` 且 `z=0` 的 S 独占匹配点占 6.910 m²。按水平距离，这些点离 S 和 G 各自第 256 步前最近的西北相机记录位姿的距离中位数分别为 2.852 m 和 4.841 m。该距离描述空间邻近，任何单帧是否看到这些点仍未知。第 257 步以后，两组均未再进入西北 D。终点西北 D 的差值为 +7.583 m²。末端两组货架与柜体匹配面积合计的 S−G 为 −0.065 m²，按独立的整场景参考采样和同一固定权重估计。其他源几何使用准确源实例 ID `0`，该 ID 未分开标注墙体、地面或其他构件。

两组在第 51 步首次出现动作、位姿及 RGB、深度与激光原始内容差异。最后 22 个动作的动作、位姿与传感器数据逐步相同，终点网格差异仍存在。当前证据支持轨迹差异和累计表面匹配结果的时空对应关系。窗口、房间和子样本均依赖同一对轨迹，各项面积是固定参考表面的匹配估计，单一房间或单个观测的因果贡献仍待独立验证。
