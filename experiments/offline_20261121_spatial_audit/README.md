# 四栋建筑的终点表面空间核验

本次只读核验沿用冷启动实验的参考可见表面、固定采样点和面积权重。按 5 cm 参考点到原生三角网格的距离，将每个点标为两者均匹配、仅 S 匹配、仅 G 匹配或均未匹配。精确率从各自原生网格独立采样，沿用每臂 12,000 个点和原种子。四栋楼终点的正确自由空间覆盖率均为 100%，复算的场景精确率、召回率、F1 与 (J) 均与封存值一致。两个环式 16 终点网格分别与同臂第 512 步网格逐字节一致。 [原实验归档](https://github.com/Jimmy7338/NSO/tree/4c388a5c06d51e53251a9c901bbefd511d5b2a95/experiments/offline_20261121_same_goal_cold_holdout) · [复算 CSV](spatial_pairs.csv) · [终点与冻结来源哈希](source_hashes.json)

## 四栋建筑的终点结果

精确率、召回率和 F1 以百分数表示，单格顺序为 G／S。最后四列为同一整场景参考上的估计面积。

| 建筑 | 精确率 | 召回率 | 整场景 F1 | 两者均匹配（m²） | 仅 S（m²） | 仅 G（m²） | 均未匹配（m²） |
|---|---:|---:|---:|---:|---:|---:|---:|
| 链式 13 | 99.725／99.825 | 99.763／99.744 | 99.744／99.784 | 368.460 | 0.043 | 0.114 | 0.833 |
| 环式 14 | 99.717／99.683 | 96.110／96.110 | 97.880／97.864 | 382.024 | 0.008 | 0.008 | 15.457 |
| 链式 15 | 99.733／99.733 | 96.399／96.399 | 98.038／98.038 | 428.215 | 0.000 | 0.000 | 15.996 |
| 环式 16 | 99.617／99.792 | 97.886／99.626 | 98.744／99.709 | 468.685 | 8.626 | 0.286 | 1.504 |

- 链式 13 的 G 独有匹配点主要在西南区。S 的匹配面积净差为 −0.071 m²，精确率提高 0.100 个百分点，使终点 F1 略升。
- 环式 14 的西南区各有一个仅 S 和仅 G 匹配的参考点，两个点的原权重相同。总体召回持平，S 的精确率低 0.033 个百分点。
- 链式 15 两个终点网格的 SHA-256 相同，所有参考点的匹配状态一致。
- 环式 16 的匹配净增为 8.340 m²。西北区净增 7.583 m²，其中 7.085 m² 位于 `z=0` 截面。整场景召回提高 1.741 个百分点，终点 F1 提高 0.965 个百分点。

## 环式 16 的事后时序核验

| 计费动作 | 整场景 F1 差（百分点） | 整场景匹配净差（m²） | 东北区净差（m²） | 西北区净差（m²） |
|---:|---:|---:|---:|---:|
| 256 | −1.012 | −9.244 | −14.936 | +7.399 |
| 320 | +0.727 | +6.919 | +0.572 | +7.472 |
| 512 | +0.965 | +8.340 | +0.673 | +7.583 |

第 256–320 步的整体反转主要对应东北区缺口缩小。S 在第 257–320 步记录了 31 个东北区相机位姿，其中 21 个朝南。G 在这段时间的计费位姿均位于南侧两个房间。西北区的大部分优势在第 256 步已出现。此前 S 和 G 分别在西北记录了 79 和 42 个相机位姿，S 的轨迹向西多深入 2.0 m。相机轨迹记录提供观测时序，无法把每个匹配点的变化归因到某一帧。 [分区定量与坐标](regional_surface_audit.json) · [位姿日志核验](cycle16_evidence_zh.md)

整场景参考点的来源 ID 由原采样三角面恢复。这些点与封存可见点逐行对应，使用同一整场景权重。环式 16 的终点净差可分解为其余建筑表面 +8.404 m² 和目标设施 −0.065 m²。独立高密度设施参考点的净差为 −0.072 m²，分别来自货架 −0.049 m² 和柜体 −0.023 m²。独立设施点的面积单列，整场景加和只使用同一参考点集。图中的 `z=0` 和 `z≠0` 是世界高度截面。 [逐点及精确率复算证据](spatial_measurement_sources.json)

## 复算顺序

在归档的原实验工作站，以原 `science312` Python 环境运行以下命令。脚本默认查找相邻的冷启动和冻结场景目录。

```sh
python verify_sources.py
python measure_spatial.py
python audit_regions.py
python cycle16_spatial.py
python plot_spatial.py
python audit_spatial_release.py
```

`spatial_pairs.csv` 为主表，包含两臂指标、配对面积、计数及引用哈希。`spatial_pairs.npz` 保存固定参考 XYZ、逐点匹配状态、权重和来源 ID，也保留两臂用于复算精确率的网格采样。原始 PLY 在此处保持原位，索引列出原路径和哈希。
