# Runner verification recovery

The first sealed runner rejected the two archive formats before a native action.
Its direct-inspection support audit used integer category keys in memory and
the published JSON stores those keys as strings. Both no-motion probes
reproduced the raw packet, prefix chain, occupancy, mesh, candidate scores,
rankings and selected routes. The sole Python equality failure was the direct
support record. Its canonical JSON digest agreed in both probes.

The recovered actor changes the two affected archive comparisons to canonical
JSON digests. Numeric contents remain exact. The original actor, route bank,
setup, scorer, candidate admission, guard, native continuation and scientific
evaluation are preserved. The recovered actor is recorded under
`runtime/run_recovery.py`. Its command-line arguments match the original actor.

The diagnostic script and the two receipts are in `runtime/preflight/`.
Each probe ends at the fork verifier before a native world step.
