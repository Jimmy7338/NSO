# HM3D 00770 地面支撑复核

冻结的 0.20 m 足迹与源扫描保持不变。在两个失败扫掠范围内对原始三角面投影与向下射线独立复算。每个扫掠均有 32,871 个 2.5 mm 规则采样点，所有上层回波落在同一近水平地面。随后在规则栅格未击中的狭小闭合区域内额外采样 129 次。

高程以仿真层参考地面为零。两处投影缝内部的原始射线均有回波，没有检测到低于原地面带的下层表面。缝内主要的低垂直法线余弦分别约为 0.670 和 0.057。两侧距缝 3 mm 的网格采样均近水平，支撑边高程变化分别不超过 4.27 和 1.24 mm。这些量测支持扫描三角面的亚毫米接缝和原法线筛选共同造成的支撑断裂。真实建筑物的原始测量现场未重新调查。

验证仅接合满足内切直径、面积、边缘共面性及缝内原始量测约束的闭合多边形。两个原失败扫掠的欠支撑面积都变为零，车体高度带的净空保持原值。原地面高度带扩大或仅对输入三角面做高度裁剪均未改变这两处失败。修复只应用于仿真网格支撑检查。
