# Retrospective frontier guard audit

This replays the four existing frontier prefixes to the guard-rejected forward action; it adds no experimental samples or policy rollouts. The observed-map search uses the same safe graph and return contract with a camera-only predicted unknown-cell proxy, not measured future gain or an exhaustive physical safety claim. At all four rejections remaining budget equaled the shortest recorded return cost, with no positive predicted-gain target under this model. This does not prove permanent return is optimal or fully equate this baseline with another method.

Run `python audit.py` with the parent package requirements; the sibling `source` and `frontier_baseline/matrix` are required. The frozen `audit.json` remains untouched, and the replay writes `audit_recomputed.json`.
