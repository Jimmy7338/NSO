# Same-goal runtime contract review

The development driver binds both arms to the inherited B11 neutral global scorer. It wraps the component's selected-option accessor after native target selection. The accessor returns a copy. The runner checks that the backend's authoritative selected option has the same digest after local scoring, and the replacement is restricted to outbound path/action and paid-cost fields. Goal cell, goal heading, return actions, return states, anchor, parent region and original choice identifiers remain identical for that decision.

The local comparison keeps the native outbound route. It uses the native known-free circular footprint graph, searches via one oriented waypoint, checks the remaining budget against original return reservation and applies the additional-action bound. A route enters comparison only if it adds an estimated viewing sector on a measured modeled object and retains 95% of the native route's predicted unknown-cell union. The simulator's true free mask and evaluation mesh are absent from the chooser. The coverage floor estimates visibility of currently unknown cells in the observed occupancy map. It establishes neither free-space acquisition nor realized coverage.

The runtime commits the chosen outbound actions exactly as it commits an original macro-action. It re-evaluates the latest measured footprint and the successor's observed return availability before each charged action. The original observation loop validates action index, discrete pose, timestamps and packet uniqueness before map fusion. A rejected action can still cause the inherited fresh global replan or observed return. Global goals can diverge later when the two local paths produce different measurements.

Class conditioning is isolated at the local scoring switch given a fixed acquired map, measured instance support and shared geometric bank. The inherited synthetic frontend uses ideal visible category masks to associate RGB-D support. The geometry pool is independent of which structural posterior ranks it, conditional on those shared inputs. This experiment does not remove semantic segmentation from G or test a natural detector.

The audit separates three questions. Candidate availability measures passage from bounded graph states to new sectors, distinct traces and the coverage floor. Selected-route effectiveness checks whether an alternative diverges from the native commands on a charged action. Paired causal divergence checks the earliest charged G/S difference against matched initial and pre-divergence observations, the exact original global option, the pool, scores, remaining budget and chosen action index. Each recorded local decision is a diagnostic observation nested within its run and parent, so the audit makes no independence assumption over these decisions.
