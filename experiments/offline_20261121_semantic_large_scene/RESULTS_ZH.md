# 设施类别线索对未知场景探索的受控验证

本实验将终点正确自由覆盖 (C_{\mathrm{free}}) 与整场景重建 (F1_{5\,\mathrm{cm}}) 相乘，得到联合指标 (J=C_{\mathrm{free}}F1_{5\,\mathrm{cm}})。四房间 E1 的同状态分支复现了前 198 个动作的传感器记录及第 6 次规划的 12 个候选。只交换该次所选路线，随后使用同一策略续行。覆盖候选 3 到达初始目标时新增表面毛估计为 58.95 m²，设施入口候选 5 为 46.85 m²。候选 5 在续行中较早到达其随后选中的覆盖目标，但在第 498 步因下一动作足迹无法确认安全而停止。其终点覆盖和 F1 分别为 94.59% 和 93.19%，(J=0.88153)，未返航。候选 3 以 512 步返航，终点覆盖和 F1 分别为 95.30% 和 93.87%，(J=0.89452)。两轮零碰撞。该个案的退化同时反映了实际新增表面较少以及终点覆盖和返航的差异。

两组程序化父布局分别具有 100.04 和 124.88 m² 的可达自由区域。每组将同一开放货架与封闭柜体换位，保持扫掠可达图、非语义首帧和总源表面积一致。对每个摆位，从同一首帧分别以正确类别（S）、中性先验（G）和互换评分标签（X）触发一次原生岔口决策，随后继续同一中性策略。四个摆位各自的三条执行轨迹和终点网格均完全一致，12 轮均执行 256 动作、返航且零碰撞。两组换位都使 S 与 X 的分数向量逐项对调，但首选没有随货架换边。因此，S 相对于 G 和 X 的终点覆盖、F1 和 (J) 差值均为零。

库房的原生候选在诊断门之前结束，但有供观察货架内部的门前位姿。展厅的原生候选则覆盖门两侧，并存在光学表面收益不同的路线。在展厅左摆位中，有利于观察货架的左侧候选 0 在 S 的模板收益项上比右侧候选 1 高 0.01653，而公共分数低 0.43853，因此总分仍落后 0.42200。诊断门外的视线接触以光学首击记录核验，首击格数仅用于核查可观察性，不能用作实测重建面积。

按预先约定的判定，两个父布局均未支持类别驱动的换边及联合指标提升，达到停止扩展条件。四个普通独立大布局尚无确认性结果。已有四个较小的链形和环形布局可用相同指标复算，但属于此前已检查的历史比较。当前结论适用于精确位姿、理想可见类别和一次类别先验干预的仿真条件，不能扩展到自然识别、持续使用类别的普通大场景策略或实车。最值得优先检查的是候选之间的收益排序。可固定覆盖与路径代价的计算，先用独立短回放检查类别项是否正确预测同成本候选的实测重建差，再判断应改预测还是改排序尺度。
