# E1 历史决策反事实

试验对应四房间归档中 `20261120/S/attempt_001`。第 6 次规划前已付 198 动作，预算余 314。历史资产入口候选 5 的计划去程与返航为 79 和 89 动作。预先指定的覆盖候选 3 为 78 和 40 动作。两个分支从归档传感器配置冷启动，由原 S 耗费实际 198 动作复现首帧和观测历史。分叉点核对原 12 候选、完整评分、位姿、地图哈希和反馈版本。候选 3 只替换一次选中的完整路线，从第一个动作起仍由原运行时逐步授权。候选 5 保留原决策，并校验完整历史轨迹和终点原生网格。

两条路线完成后续行同一 S 策略，返航计入 512 动作上限，提前停止保留实际动作数。`protocol.json` 和 `freeze.json` 在运行前固定了参考与评价口径。`intervention.json` 保存 12 个原候选、原始分数、替换记录及相同起始状态的哈希。`route_end.json` 表明是否在未切换目标的情况下抵达指定路线终点。

`evaluate_e1.py` 将重建的原环境参考与归档固定参考逐点核对，并重算终点正确自由覆盖、场景 F1@5cm 及乘积。表面面积采用固定参考点逐点同权，权值等于外表面总面积除以 100,000 个初始抽样点。所报毛增量只含由超过 5 cm 变为不超过 5 cm 的参考点，净增量另扣除反方向变化。所得数值是固定可见参考上的估计，不能当作精确几何积分。

路线后前沿代价有两个观测定义。第一是之后首次到达截至当时地图中已知空闲且四邻接未知的车体中心格，第二是续行策略之后首次抵达已选覆盖候选的目标位姿。它们分别测量观测前沿接触与覆盖选项到达，任何未抵达均保存空值。

执行与评价环境为 `/home/ouc/nso_robot/envs/science312/bin/python -s -B`。新运行只创建新输出，归档原文件不变。初次启动器退出时未生成运行目录或动作记录，进程信息见 `launcher_001.json`。
