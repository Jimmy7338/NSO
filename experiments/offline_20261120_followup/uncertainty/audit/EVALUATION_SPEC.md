# B9 interval evaluation, frozen before new calibration or test outcomes

The independent unit is one of 48 newly drawn objects. The first 24 objects calibrate and the other 24 test; every object retains front, front_side, around, and occluded observations. Both splits follow the same frozen IID mixture. No redraw, successful-case selection, or use of new test geometry is allowed during method or calibration fitting. Clean exact-pose first-hit RGB-D and ideal masks/classes delimit external validity.

The base predictor is the frozen B8 neutral structure prior (0.5/0.5), sigma=0.01 joint particle posterior. Source geometry is available only to separate generation/evaluation processes. Actor predictions, candidate scoring, and navigation are not modified. Independently recompute exported posteriors from frozen energies, prior, and sigma. A declared inference failure, unusable/multiple track, or invalid conditional distribution retains the B8 evaluator fallback: unconditional uniform-density depth [0.2,1.4], Voronoi masses, fixed world-y axis. All 96 cases stay in each split denominator. Hash mismatches invalidate evidence rather than trigger statistical fallback.

Targets are extents of actual object vertices projected onto the inferred depth axis (world-y for fallback). Yaw/axis error, swapped axes, prior support violations, and failures are separately reported. No target-dependent axis matching or best-track selection is permitted.

Only frozen B8 training-object predictions determine s0: median over objects of the median absolute posterior-median residual over their four conditions. B9 calibration alone determines q using the already frozen standard object-group split-conformal method. Each object contributes the maximum of its four normalized interval residuals, s=max(raw 95% halfwidth,s0). At n=24, alpha=0.05 the finite-sample order statistic is the 24th of 24 scores. The correction clips the lower endpoint at zero and does not clip the upper endpoint to the old 1.4 m support. With insufficient calibration objects the interval is [0,infinity), never an arbitrary finite approximation.

The two evaluator phases run in separate processes. Calibration installs a provenance guard that rejects new test truth and the full generator parameter specification, writes calibration rows/configuration/receipt, and records opened truth paths. Evaluation requires that frozen receipt and the root's release referencing frozen parallel protocols before opening test geometry. This guard is trusted-code source auditing, not an operating-system sandbox. All failed attempts are retained; an evaluation output directory cannot be overwritten.

Primary test metrics are original versus corrected 95% case coverage, all-four-condition object coverage, width, and the standard alpha=0.05 interval score (width + 2/alpha times any endpoint exceedance). Equal weight is given to objects and then their four conditions. Per-condition, closed/open family, regular/part-mismatch, and valid-only statistics are descriptive secondary views. No independent-sample claims are made for the 96 dependent cases. Unbounded intervals have null aggregate width/interval score plus explicit count, never a reduced-denominator finite mean.

Original PMF CRPS, median error, nominal interval coverage, prior-only and fixed-0.65 baselines are reported separately using the unchanged B8 evaluator. There is no CRPS for the corrected set and no navigation, reconstruction, or policy-benefit claim. Finite-sample coverage applies marginally to exchangeable new objects under the same frozen mixture, not separately to every geometry/family. Test results do not select s0, q, sigma, mixture, or model variants.
