# 同目标路线的局部巡检对照

我们在两个独立的合成房间布局中固定四处设施摆位，分别保留可通行的侧窗观察与放置遮挡板的情形。分叉时，四臂使用同一批观测、同一个全局目标及同一完整合法路线池，随后分别采集与融合深度。直接巡检与类别条件结构推断共享仿真可见理想类别。直接巡检按已测点的视角欠覆盖、距离和入射角评估各路线。验收 14/16 轮完整回执，有效局部配对 2/4 处。有效配对中，类别条件结构推断相对直接巡检的净新增货架表面积在共同第 96 步和终点分别为 east_visible -0.1031/-0.0458 m²、west_visible -0.1960/-0.1287 m²。共 7 轮按初选路线到达，11 轮实际返航，记录 0 次模拟碰撞。预算 192 个计费动作包含转向和返航。同一合成父布局的两处摆位为相关对照。
