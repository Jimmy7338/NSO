# 独立核验单回合主动观测

`audit_gate.py` 读取已经结束的原生运行目录。它核对单一 `region_S` 回合从计费第 0 步启动，冻结输入在运行前后保持一致。派发、到达新视点、根据观测重规划及实际前进均对应原生动作和控制授权记录。

在归档的实际位姿重建传感包和观测图后，脚本重新计算两次规划的测量图哈希、每条定向边、保留返程和目标扫掠证书。新视点必须提供以前未见过的深度或激光测量。正式动作须沿 `(52,26,2)→(53,26,2)` 无碰撞前进。覆盖评价只在独立核验末尾读取固定的 V1 掩膜，终点正确自由格须大于 522/1,640，计费预算 192 步。

```sh
python validation/audit_gate.py --run "$NATIVE_RUN_DIRECTORY" --freeze "$FROZEN_GATE_FILE"
```

结果写入 `validation/GATE_AUDIT.json`。任一条件不成立时保留失败原因并以非零状态退出。核验程序不运行探索策略。
