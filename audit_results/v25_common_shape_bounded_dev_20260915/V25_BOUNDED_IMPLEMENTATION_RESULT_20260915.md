本轮有界开发已停止，**预声明的整套解析门仍未全过，两个结果 JSON 均保留 `status=failed`**。V25 尚未接规划器、未重放四条真实历史、未计算 Q 或语义收益。当前交付只能说明：一项已定位的共同几何估计错误有可运行的修复方向，且对缺失边缘证据的失败能明确保留。

## 实现边界

原版位于本目录 `observed_shape_v25.py`，唯一修复版位于 `v2/observed_shape_v25.py`，各自有原始测试源码、执行前 freeze 和执行后结果；不能把根目录首版误当最终候选。全部开发在 RAM。冻结 V24 源 SHA 在两次运行前后均相同；最终源 `_edges` 与 `_free_ray_conflicts` 直接继承原函数，返回支持/拒绝的旧阈值保留。

新估计器在实际组件支持上按帧拟合仿射视差平面：对归一化像素坐标有 `disp=a*u+b*v+c`，使 `.25px` 传感噪声成为同尺度残差。固定64个确定性三点假设分面，3σ内点、2.5σ稳健损失迭代6次；面块连续拟合正交方向，不用原5°法向bin及全点极端分位。面法向位置由校正后的面块估计，面内边界由有效背景相邻射线与面求交的区间估计。参数只有公共视差噪声/标定及声明的几何稳健设置，没有任务尺寸、类别、GT窗口、Q或free-ray通过率输入。

原 observe、地面、组件和清理接口继承不变，推断仍是cuboid先验；snapshot只额外标记新版本。测试实际走 observe→ground→component→enclosure，没有用GT组件或GT地面。GT尺寸仅在测试侧计算误差。没有创建世界或运行新 sense/step，也没有融合TSDF。两轮各9条件、140幅解析深度；不把这些数组当新付费动作或环境样本。

## 首版失败与唯一修复

首版结果：`analytic_result_v1.json`，耗时8.096秒。4个预声明尺寸/方向正例中前三个达到一个4cm体素的边界精度及1°方向精度，第四个2×1×1.8m高柜失败：估计高度约1.009m，却被旧门放行。

这里是实质错误，不能用“推断只是可选”淡化。该样本前视1.3m的竖直视野顶部只到约1.761m，未看到1.8m柜顶；外侧背景离相机5.2m，超出5m范围；远视也缺真实上边缘背景。首版将零星远距噪声深度差当作上边界。自由射线门检查假设侵占free，不能单独发现一个过小盒漏掉了已测上半面。

唯一修复保留原门，在**参数估计的边缘候选**中增加两个可解释条件：背景像素须比同一拟合面预测视差小3σ以上，且具备至少3个相邻像素连续支持。未改尺寸目标、相机路线、传感噪声或原free-ray阈值。另补齐snapshot版本标记。没有第二轮调参。

## 剩余风险与下一证据门

- 第4正例的原精度门失败保留。修复消除了错误获准，没有凭不存在的观测恢复尺寸；不能将其事后重分类后宣布全通过。
- 仅三个有足够边界支持的简单解析盒达到预设参数门，不能推及真实双对象全部前缀、复杂外露附件或任意视角。正交cuboid仍是显式先验。
- 分面上限、稳健采样、面块权重及连续3像素是有限原型规则，尚无自然相机噪声或复杂组件验证；单个条件一个噪声种子，不构成区间估计或泛化证明。
- 保留raw/实测/推断的完整snapshot接口本轮只作继承/不变性检查，未对真实历史做完整输出与指标审计。新的面拟合不得删去实际附件；这个承诺仍需后续真实已付历史验证。
- 参数估计没有最小化free-ray通过率，但其原门仍无法单独保证整体外壳足够大。新增边界检查减少了本次假证据，不能被表述成完备证明。
