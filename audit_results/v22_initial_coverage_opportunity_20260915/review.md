# V22 初始覆盖候选机会审查

本次只消费四个动作 0 的已保存 packet、初始模块记录及参考 metadata 中的公开配置；没有读取 case 的未来质量结果，没有新动作、训练或矩阵实验。A/B 为两个带标记观测实例按 x 坐标从左到右命名，不使用模拟资产编号。四个初始观测各有 8 个共同覆盖候选；同父两排列的深度/雷达、观测几何、地图、候选及以下机会指标完全相同，类别票正负互换。

## 已有路线有早期 A/B 取舍，但不是三处都独立

以下 A/B 关联使用既有观测精度代理在各设施上的最大值；不使用未来 F1。点帧数是“当前观测网格推算的已观测点 × 路线帧次数”，不是新采集数据或真实可见面积。

|父布局|A 关联候选：A/B 点帧数|B 关联候选：A/B 点帧数|A/B 首次动作不同|去+返动作|原未知格并集|
|---|---|---|---|---|---|
|P00|2：555 / 279|0：283 / 474|第 8 步（前 7 步相同）|A 27+29；B 28+30|A 999；B 1209|
|P01|2：457 / 255|1：192 / 506|第 7 步（前 6 步相同）|A 27+29；B 29+31|A 1009；B 1234|

P00 纯覆盖 N 首选就是候选 0，**与 B 关联候选是完全相同的 option、端点朝向和完整去返路径**；这里只有两个不同首选，不得把 N/A/B 当成三个独立干预。P01 的 N=0、A=2、B=1 是三个不同候选；N0 与 B1 到第 10 个动作才分岔。

两父的 A/B 路线在第 7/8 步分岔，因而在设计文档指出的动作 0—19 配对几何共同窗口内存在改变付费动作的机会。类别已可见，故值得保留为下一版的优先检查入口。但较多的点帧数只证明观察机会不同，普通接近/多看也会产生这种差异；当前还没有证明类别能预报哪条路线具有更高真实外形收益。

## 朝向缺口与一个不能过度解释的备选

全部原始覆盖候选对 A/B 的“已观测后边界假设平面”支持均为 0。最强 A/B 接近路线的末端朝向均为北，末端对两目标的已观测点投影数也均为 0：途中看到了前表面，到终点时朝向却未面向目标。该支持使用既有观测网格遮挡修正，不能等同完整侧后结构可见性。

在原候选 0 相同终点补一个真实计费的左转/右转，A/B 假设平面支持分别成为 P00 的 0.751/0.860、P01 的 0.690/0.798；去程均 29、返程均 29，原 1209/1213 未知格并集不变。新增去程转向替代了一步返程转向，总去返仍为 58。这是路径几何诊断，并未把转向作为免费动作。

然而左右分支到第 29 步才出现不同动作，晚于已知的共同几何窗口；**仅补这个末端朝向，不能证明早期类别信息有因果价值**。未命中已观测网格的射线仍是未知，非可见证书；非零假设平面支持也不是质量改善。所有检查只证明当前观测地图上的路线/返航可规划；并未验证新增联合意图的覆盖余量门或最终 80% 覆盖资格。

## 最小下一步

优先复用候选 2/0（P00）及 2/1（P01）的早期分岔，冻结观测侧关联、类别条件选择、完整预算和共同回退规则；先确认语义改变了可保留的有意义路线，再决定是否运行完整矩阵。保留 P00 N/B 重合这一事实，不人为制造第三组来凑设计。

若任务必须在路线终点安排侧后观察，保留原 8 个覆盖候选，在新版本增加面向观测设施的末端朝向，或增加同支路、已有安全路径上的覆盖终点；每次平移/转向均计费，原覆盖并集与设施观察意图随重规划保留。仅末端左右转是晚分岔备选，不能替代早期路线关联。

本次证据尚不要求更换场景。如果上述早期覆盖路线仍不能提供有用的目标观察，再在回报前新建版本，把任务朝向的观察位置前移到支路取舍附近，或以遮挡延后结构揭示，使早期选择有实际成本与信息价值。保留旧结果与 80% 门槛，不以降低基础方法成绩为目标。
