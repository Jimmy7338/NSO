## 内容与证据保全

每对替换前均核验路径白名单、无符号链接、同设备、完成状态、权限/所有者、大小和 SHA256，并检查可写句柄及非阻塞文件锁。保留原 inode 的临时备份后，使用同目录临时硬链接加原子替换；替换后再次核验 inode、大小及 SHA256，再移除冗余临时备份。读取中的旧文件描述符仍可继续读相同内容。

`actions.jsonl.gz` 保存每个 canonical/duplicate 路径、预期 SHA256、原 inode/mtime/权限信息、替换后 inode 与核验状态；`summary.json` 保存源清单和操作日志哈希。19 份冻结源码归档中未发现 mtime 完整性依赖，原 run_metadata 字节全部保持不变。硬链接路径采用 canonical 的文件时间；原时间留存在操作日志中。

原 30.57 MiB 输入估计已无损压缩为 `audit_results/completed_sensor_duplicate_estimate_20260910.json.gz`，约 1.85 MiB；解压后 SHA256 与原文件一致：`d63fca9275efea03ebe0e7a6dd87c9c17e92305c5d278ad04488c8a1e2018781`。仅删除了它冗余的未压缩表示。

这是存储去重，不是删除实验或改写指标。硬链接共享 inode，后续应继续把这些已完成实验文件视为不可变输入；如需修改内容，应写入新实验目录或先建立独立副本。
