## 观测与共同主表示

每条主任务按真实时间顺序保存帧 0 至终点的完整 SensorPacket，含 RGB、深度、semantic 原始通道、内参、相机位姿、扫描、动作及机器人位姿。调用既有 QualityMapperV2；每步保存包/非语义摘要、belief/visible SHA、碰撞、done、规定状态一致性、实际 C。C 仅由评价侧可达网格统计，固定采集控制不消费该真值。

两个 ObservedShapeBackendV24 槽从帧 0 接收全部真实深度；发现前 seed=None。实际 RGB 两种标记颜色先取并集，按冻结 16 像素阈值、0.75 m 观测中心关联建立槽。首次有效 seed 是实际深度像素，之后不改、不按 GT 中心或最高 Q 重选。首次像素的实际颜色代码单独记录，供预声明类别规则核验；它不进入几何后端。额外轨迹、未发现实例和错误关联均保留。

唯一轻适配器继承 V24，仅将 `_enclosure` 返回设为空和“推断禁用”；地面、连通分量、清理及实测网格算法/阈值均不改，V25 推断后端不导入。分别在公共前缀帧 234 和真实返航终点 snapshot 两槽，保存原始 TSDF SHA、各槽 measured/ground/cleaned/unassigned 数组数量与 SHA、地面参数、observed 网格及 SHA。只有终点原始 TSDF 网格保存一份；前缀原网格只在内存用于固定评价。推断始终为空，completed 必须与 observed 相同。缺失表面继续未知，不用 GT 补全。

所有可用阶段的两实例输出及 pre-GT snapshot/checkpoint 先写入，之后才构造禁用 sense/scan/step 的评价参考。主分数仅为两槽 observed mesh 联集，原始 TSDF 固定旁报；不得按成绩改选表示。冻结 V23 外形评价：三投影各 min(F1@5 cm, IoU) 的均值、所有两个对象等权、漏建零、J=CQ；2/10 cm 仅旁报。尺寸/完成门保留，但不是选择主 Q 的额外条件。

评价侧将首次真实 seed 对固定 GT 窗口作唯一匹配，零/多匹配不纠正。每槽也对全部窗口独立评分，记录落入其他设施窗口的几何；空间联集 Q 不认证实例归属。非空且不是同一完整 cleaned 分量只叫 minimum separation，不声称自然语义实例分割得到验证。运行结束的严重实例失败是 seed 唯一关联、最低分离或其他设施窗口污染检查失败。前缀同样保留这些门及标记支持证据，类别规则是否可用由固定分析单独判断。

## 独立回放、资格与失败

回放必须不同 PID，先核物理 case 全部文件 SHA 和冻结来源；从帧 0 构造新世界/mapper/两槽，每动作再执行真实 world.step，将新传感包与已保存包逐字段哈希比较，然后用保存包更新后端。它不写第二份 raw/mesh。逐步元数据、阶段点数组/地面/实测网格、终点原 TSDF 三数组和冻结评价均必须相同。阶段先对照已保存 pre-GT snapshot，最终对照评价后的完整 result，不能丢掉不匹配字段自称通过。

终点资格固定：付费不超 400、C≥0.8、零碰撞、回到规定格及朝向、没有执行失败。保留未合格和低 Q；不靠中途最好阶段替换终点。碰撞、提前 done、路线状态不一致时，先保存当前包及逐步回执，再报告实际终止与可用阶段。程序/I/O 失败保留 failure receipt、已保存 raw 和最后进度；停止未开始任务，不覆盖失败。结构/安全/严重实例失败允许完成其独立回放，然后阻止未开始任务。单纯 Q 低或 C 未达 0.8 不删除、不调预算、不换路线重采。

四条都完成后，核同排列跨臂及同臂跨排列的完整 235 帧非语义前缀，包括深度/位姿/扫描/去类别 RGB/标记二值及观测关联。完整前缀相同不代表四个独立环境。任一信息窗口、资格或回放门失败，按冻结分析如实限制语义结论。
