# V35 保存观测与四模块接线准入协议

2026-09-18。在任何V35新World、TSDF或终点Q成绩之前冻结。V34已结束，主任务19/36；本准入不增加物理主任务。不修改既有几何、相机／雷达、42动作总预算、18动作前缀、主指标或旧代码。

## 信息合同与在线实现

两种方法共享两个公开CAD构型、保守共同合法导航图、两个模板在全部有限姿态的clean深度／雷达预测库，以及相同的名义面片与覆盖潜在收益。模板库取已保存V33/V34数据，同时加载两者；不根据实际hypothesis挑模板，不加载policy/witness或既有终点Q。它是具有结构模板和任务域先验的设施建档，不是未知地图自主探索。

实际控制器只接收当前已付动作号、动作、位姿、RGB、深度、扫描、碰撞和可选实测地图摘要；episode/scene身份、真值标签、实际构型、未来包、GT参考和评分不可读。相机／雷达似然同用于G/S，类别只由当前RGB解码。两个不同XY处读到至少16像素同类别才给一次0.9可靠度先验，重复观看不继续加权，出现矛盾类别清空该先验。G保持无类别；未知类别回退共同先验。

几何反馈在每个新姿态只计一次，深度使用固定双目视差尺度fb=57.6、sigma=.25px，雷达尺度.02m；截断残差损失12.5，每姿态log-odds最多±6、总几何log-odds最多±24。这是鲁棒伪似然，不称校准概率。错误类别对照只交换RGB解释；关闭反馈对照同时禁用实际几何后验更新与规划中的未来纠错预期。

OV-SDF分开记录实测地图／传感与类别／模板状态；IGCR依据实际残差更新后验和已访问模板曝光；STGHP按当前概率和剩余预算在线重新计算完整视界选择；RPN-UQ核局部动作合法性与返航余量。二者共用代码、能力和资源门。公共图检查属于确定性先验安全检查，不称学习或概率安全保证。

## 有界规划近似

规划器不调用V33的`witness(actual,...)`。新递归在每次滚动规划中最多预测一次未来信息事件：只有两个公开clean模板均能以固定似然阈值log(99)区分对方的姿态，才允许一个预设正确率.99的二值观测分支；按Bayes公式更新概率，两分支均保留误判可能。到达未来节点前不能获取信息，已实际访问节点不再次作为免费信息来源。

该.99是固定设计假定，不是实测识别率。单次信息分支后，后续规划不再预测更多新信息；实际执行仍每步用新测量更新并重新规划。因此它是单次预期信息分支的滚动有限规划近似，不是精确带噪POMDP。双方采用相同边顺序的确定性择优、1e-12比较容差、每次最多1,500,000个memo状态和20秒资源门，触限保留失败。

收益仍是两个公开模板的预计可见竖面比例×理想整数中心覆盖，不能称实测Q。终点规划门要求两个模板均满足中心覆盖80%和精确返航，极小先验不豁免该门；未来实际任务仍须额外通过外部C_map≥80%及TSDF测量。重复访问的曝光集合用OR去重，不因为重复观测凭空增加模板面积。

## 本次零新物理准入内容

先完成独立toy穷举规划合同、实际保存带噪包的后验测试、四模块顺序／边界测试。然后执行唯一正式保存观测批：P00两构型×G、S、swapped、swapped_no_feedback共8条缓存观测闭环。外层夹具按构型提供V34已保存clean数组中当前姿态的一帧，控制器只见这一帧；下一姿态完全由刚输出的动作在公共图上转移。每条最多42个名义动作，预定18步公共前缀相同；不构造World、不调用renderer、不重建、不计算新Q。缓存数组重复读取另计，不能称真实付费传感、带噪闭环或独立物理任务。

同时在同一前缀状态做无类别／颜色干预，核G与S去类别后状态及动作一致、更换类别可能改变方向；在实际V34保存带噪后缀核错误类别后验能由新几何纠正。另预先指定两次配对规划干预：每个构型的swapped缓存轨迹首次被非零几何更新纠正到真实模板概率>0.5时，固定当前节点、曝光、剩余预算、已访问节点和启用未来几何的设定，仅将后验换回错误语义先验，比较立即动作。每构型只取这个首状态，不搜索更有利的后续状态；另计最多2次select。它隔离实际后验的作用，避免把关闭未来信息预期引起的提前分叉冒充已发生反馈的效应。

若缓存闭环中错误类别反馈与去反馈始终同动作，或上述同状态干预没有任何动作改变，明确报告行为门未过，不能仅凭后验改变宣布反馈有效。读取完整未来数组是夹具职责，控制器仅持两模板公开深度／扫描，不能读取未来实际RGB或实际构型。

正式批在首次控制器执行前封存源码、固定参数、协议、测试receipt及全部输入哈希；上限600秒、2MiB新证据、实际空闲至少64MiB。8条缓存轨迹全部保留，计实际控制器调用、后验更新、规划次数与memo状态；相同轨迹不当独立样本。失败／超时立即保留，不默默换参数重试。现阶段没有新主任务，后续自主任务须另行冻结最多8条的采集协议。

通过条件：全部8缓存轨迹不越预算且精确返航、双模板中心覆盖合格；四模块实际调用；至少一个构型正确类别改变动作；去类别输入后与G相同；错误类别的实际带噪后验可纠正；反馈两臂在缓存任务中至少一个构型改变动作，并且首纠正状态的同状态后验干预至少一例改变动作。即使全部通过，也只获得实现准入，不能据此宣称实测在线语义或完整架构优势。
