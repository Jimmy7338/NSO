# V25 两周判定的最小任务契约

2026-09-15。本文规定本轮实现和验证的边界；具体世界、传感运行和策略协议须各自记录版本。当前既有负结果不变，本契约不是有效性报告。总目标仍包含ANS层次、四模块、可验证语义创新、独立确认、ROS1实车和论文。

## 任务与物理动机

机器人在未知工位区域内完成二维地图覆盖，并登记所有任务设施的外轮廓、位置和占用尺寸。前部通道支持基本建档，进入侧后检修通道可补足实际外露附件。任务对象事先定义，简单与复杂设施等权；类别不直接控制噪声、权重或评分。

语义的候选作用是预测尚未看见的附件和需要观察的方向。普通几何方法同样知道一般的遮挡、测距不确定性、规则外壳先验与未见结构可能性，并可主动探看、随时改选。需要验证的差别是类别条件知识能否提前改变有用的行动选择，而不是是否添加一个语义分数。

首个家族只含两个任务设施和两个父布局，类别及隐藏外露结构成对交换。该规模用于机制去留，不代替大规模适用性结论。实际类别识别与人工可见标记分层验收，人工提示不能作为自然语义网络成功的证据。

## 共同感知和建图

沿用现有米制深度、标定和位姿契约、0.2m平移/90°转向离散动作、CPU开源TSDF及通用双目视差误差。具体原参数记录在运行冻结清单，不能为某一类别或方法改变。理想位姿阶段只验证规划机制，不称真实SLAM闭环定位结果。

所有对照采用同一共同表示。V24结果继续冻结；V25外壳原型只能经过一次已保存case00完整观测验证后决定是否作为候选后端，不能因三个解析盒通过就接入默认规划。原型总解析门failed的事实保留。本轮不继续优化估计器参数。

上述case00检查现已完成：235帧下，两个实例的自由射线冲突降至0.854%/0.246%，但均超过冻结拒绝门；推断均拒绝，Q仍为0.465218。故本轮不授权将V25接入默认后端，也不把拟合改善记作外形得分改善。详见[保存历史结果](V25_CASE00_SAVED_HISTORY_RESULT_20260915.md)。

表示输出必须同时保留实测、推断和未知。有效的规则外壳先验可以推断未直接测量的表面，但必须满足实际平面/边缘支持并接受自由射线检验；隐藏附件不能凭类别直接写入地图获得几何分数。补看出现真实附件后，实测附件不得因为模型偏好规则盒而被删掉。观察次数不作为精度奖励。

公开基本观察不要求所有物体达到理想满分，但应尽可能保留普通本体外形的真实边缘支持。需要检查：顶部处于实际视场内且背景在有限量程内；侧向深度的后缘有背景夹持；无效深度不等价于自由空间。物理可观测性由尺度、视距、遮挡和相机共同决定，不能事后只排除低分对象。

## 新隔板必须满足的工程条件

- 所有障碍来自实体几何，类交换的工位墙完全一致；不在渲染器中屏蔽特定附件。
- 圆形足迹安全地面连通，公共路线和返航真实可行；检查所有合法原地转向。
- 外侧隔板不能无意遮死普通本体的后缘；关键附件最终至少能从一个机器人可达视点被真实射线看到。
- 柜体与隔板保持可观测分离。当前实例组件使用0.08m体素和26邻接，实体接触或窄缝可能把整面墙误合并成设施；不能靠GT owner修正运行时分割。
- 保留真实可达面积作为覆盖评价分母，不能因新支路尚未探索而排除它。原P01前缀76.958%的负结果保留，新世界的静态路线不是80%在线覆盖成功证据。

只实现一个明确机制版本，允许一次有具体反例的修正并保留首版结果。若失败，应说明哪项物理/表示条件不满足，不循环扫描隔板参数直至出现有利成绩。

## 评价与比较

沿用冻结V23主外形Q：每设施的XY/XZ/YZ投影分别计算`min(边界F1@5cm, 投影IoU)`，取三向均值，再对全部任务设施等权；漏建设施记零。主要联合值为`J=C_2D×Q_outline`，并分别报告C和Q。全部方法必须满足同一覆盖门、零碰撞及返航资格。多投影轮廓不唯一确定三维几何，因此另列连续外表面误差、尺寸与位置，不将Q称作完整三维精度。

所有比较使用同一任务终点、总付费动作预算和共同后续；前缀、转弯、信息探看及返航均收费。曾经到达但未返航的中间高分不能代替终点成绩。相同质量下动作成本为预先声明的辅助结果，不能临时取代失败的主指标。

第一批至多12条去重A/B/公共选项任务用于检查类别条件信息上限；该上限是事后开发诊断，不是已学习策略。第二批在上限支持时执行强几何G和冻结语义S，至多24条，加对应独立回放。强G的主动获取信息/改选策略必须实际执行，不能只用最佳固定A/B假装强G。

几何信息成本先给予保守审查：可以在评价侧使用所有真实可达状态和理想深度，给G更乐观的信息获取能力。真实可达图、未付未来射线、类别排列和未来Q不得进入运行时。如果只检查有限路线，结果只能是路径见证，不能宣称信息获取的全局下界或不可行。

后续训练同容量G/S收益头时，未来Q改善可作为离线标签；在线IGCR只能使用可观测残差、支持和置信变化，评价器不可回传真值。最终还须验收自然前端、类别置换、错误先验、低置信、去反馈及未见布局，不能用人工类别上限替代完整系统贡献。

文献核查增加了必要的算法对照：[SPP直接重叠核查](SEMANTIC_DOCUMENTATION_SPP_OVERLAP_REVIEW_20260915.md)确认，语义预测未见结构、预测观察收益与观测纠错已有实现。这一宽泛链条不再作为原创主张。除强G及固定类别规则外，后续完整验证须包含“结构模板预测可见收益＋实测纠错”机制基线；模板仅来自合法历史或共同训练集，不能利用原方法的冷启动限制故意削弱它。该适配器不称作者完整SPP复现。候选差别限于类别条件的付费、定向外形质量改善预测是否超过上述基线；其新颖性、必要性和实测收益均待验证。两周内36条上限不因增加对照要求而自动放大，正式分配在成绩前另行固定。
