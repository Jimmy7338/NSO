# V32：外轮廓支持带的有界适用性协议

2026-09-17。在任何正式夹具评分与保存网格新评分前冻结。本轮仅一个新候选；若出现有明确代码缺陷依据的问题可另封存一次修正，不能为通过门调阈值、夹具或分母。主任务仍16/36，2026-09-29去留日期不变。

## 问题与任务边界

V31准确竖面Q=1，但1mm断环仍Q=2/3。V32只检验能否消除**精确闭合引起的微小缺口跳变**，同时惩罚超容差外部预测和大块缺失。它不是新建图方法，不承诺几何位置误差下处处连续，更不能仅凭支持吻合认证实际空间封闭。保留全部V30/V31数据和分数，不把新旧任务函数之差写成性能改善。

唯一候选由预测网格独立提取冻结V31支持S，参考外边界为R。分别计算半径τ的距离带：

`B_tau = area(buffer(S,tau) intersection buffer(R,tau)) / area(buffer(S,tau) union buffer(R,tau))`

`Q_support_tau = output_instance_precision × fixed_asset_macro(mean_xyz_projections(min(F1_tau,B_tau)))`

τ沿用2/5/10cm（主诊断5cm），边界采样间距1cm。round cap、round join、每四分之一圆16段。buffer内部孔保留，不填整个区域、不再做收缩/闭运算；预测距离带不接收参考、类别或访问次数。带的重叠可以跨窄间隙，但不回写表面/占用，不修改网格、归属或支持S。V31有效三维面验证、固定seed归属、缺失记零和额外非空输出precision惩罚沿用。

Q_support是**外轮廓支持吻合度**，不是原实体区域IoU或完整三维精度。完整预测、尺寸、Hausdorff界、每投影P/R/F1、按长度计算的缺失/额外支持、距离带交并面积及组件数、原面积IoU、V31区域Q全部并列保存。无真值裁预测/对齐，既有C80/返航/预算资格保持。`completion_fraction=null`、`connectivity_certified=false`、`candidate_ready_as_sole_training_target=false`；绝不由高分推导完成/占用认证。硬F1阈值仍可能使位置偏移跨τ时跳变。

字段约定：projection的`iou`/`legacy_region_iou`和`missing_projection`仍指V31区域面积；支持为空应读`missing_support`。新每阈值统计使用`band_iou`与`quality=min(f1,band_iou)`，不能沿旧区域IoU重算新Q。`v31_region_outline_quality`只作并列旧定义诊断。

## 固定输入与执行数量

1. V32噪声夹具协议中的33案：8缺口、7平移、3旋转、1缺面、6近邻/错误桥、1非凸L、3共享噪声实现的面扰动、2观测歧义、2薄壁。几何定义由独立模块冻结，不按评分改动。
2. V31原17几何夹具、4归属夹具、额外非空输出与额外空输出2案，共23个回归锚点。前缀使用`anchor_`。
3. 合计56次合法候选评价。每次同时从同一投影统计保留V31区域Q，不单独重跑旧评价器。另2次非法三维退化面输入应拒绝，分别位于匹配槽和未匹配槽。数组前后哈希必须相同。
4. 同预测、不同真值的歧义pair额外核验三个预测支持/面积WKB和全部容差距离带WKB相同，不能要求最终分数相同（参考不同）。它只说明给定网格不能辨别真实通口；不声称额外深度射线历史也相同。
