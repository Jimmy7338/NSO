# V9.1 结果、语义贡献与 F1 上限

本批保留 ANS 双层与 OV-SDF、STGHP、RPN-UQ、IGCR 四模块接口约束，检验其中的类别条件观测选择机制。当前不是完整四模块调用链实验。

**44/44 条实际路线及 1328 个分支动作通过独立回放，零碰撞、零失败，全部达到原目标并返回原位置和朝向。冻结效果判定为 `failed_prospective_gates`，无待核验项。** 只有相对 N 的终点 F1 和 C×F1 幅度未达到各 +0.005；其余效果及安全门槛通过。

## 未达标的根因：当前完整候选池的 F1 上限

对每个历史 h，完整候选池中任意选择器的 F1 不超过 max_a F1(h,a)。用已执行全部路线计算上界，仅用于诊断，不作为在线输入或新选择器：

\[\bar F_{\rm oracle}=\frac18\sum_{h=1}^8\max_{a\in A(h)}F(h,a).\]

S 在八个历史中都取得当前候选池的最高终点 F1，F1 regret 为零。因此，即使提前知道所有未来结果，相对 N 的平均最高 F1 增幅也只有 0.003704645981，低于预定0.005。

|父场景|S−N 新增面积 m²|S−N F1|全池最佳−S F1|
|---|---:|---:|---:|
|Q0|1.716909075|0.003552869714|0.000000000000|
|Q1|1.960906388|0.003082116556|0.000000000000|
|Q2|1.976193362|0.004338032319|0.000000000000|
|Q3|2.114803775|0.003845565337|0.000000000000|

这个上界说明，仅重新排列本批既有路线无法通过原 F1 幅度门槛。它不允许撤销原门槛，也不保证新的候选、连续观察或完整系统一定更好。后续研究应检验真实可行的更多观察序列和完整预算闭环，另行冻结新协议。

## 为什么仍是有用的语义证据

总收益目标在新世界构造前固定；可变候选数量规则在已知前缀可达性失败后、未来结果揭示前修订。全部原候选、分数、物理输入和四父场景都保留，评分器没有根据结果再训练或调参。G/O/N 获得相同几何与候选；S/X 只交换类别解释、M去掉语义并回退。因而可描述本有限人工资产域中类别信息的实际增量，但完整预设进阶条件仍未通过。

原 V9 的强制六候选失败、V8.1 的原终点质量/排他性失败及其事后目标诊断均保留。V9.1 不是自然开放词汇识别、学习后验校准、主流方法原系统或实车 SLAM 的证明。
