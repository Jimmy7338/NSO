# V27 自主效果分析冻结协议（2026-09-16）

分析器只读取封存证据，不创建世界、不运行策略、不融合 TSDF、不重新提取网格、不重新计算 Q。它必须逐 SHA 核验采集根目录、四个 case、来源归档和独立回放收据。

固定输出包括：

- 四条任务的 `C/Q/J`、动作数、返航、碰撞、缺失设施、合格状态；
- 两组 `S-S_no_feedback` 的反馈增量及平均值；
- 修复后两条 `S` 与 V26 同排列 `G` 的完整方案差异；
- 反馈更新状态、更新次数、反馈表终值、第一次动作分叉和候选/规划开销；
- 每实例 Q，防止总体均值掩盖复杂设施与简单设施方向相反；
- 主任务、成功回放、失败尝试和离线等价审计的实际计算成本；
- 预先冻结的两个判断门是否通过，以及未通过时的停止结论。

任何不合格、未完成或未独立回放的成员都保留原始数值，但不得进入合格优势结论。缺失设施按冻结评价计零，不以任务失格代替。墙钟时间只作诊断，不称算法速度基准。

历史 V26 G 仅在 `V27_GEOMETRY_REFERENCE_EQUIVALENCE` 审计通过后使用；历史 V26 S 只用于描述修复前结果，不进入 `S-S_no_feedback` 的反馈因果对照。一个 seed、一个父场景和确定性回放不提供置信区间或泛化证明。
