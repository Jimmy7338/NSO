## 内部优化分工

| 保留模块 | 下一阶段内部改进 | 验证依据 |
|---|---|---|
| OV-SDF | 分离实测几何与类别先验，增加实例观察方向、置信度和缺口状态 | 输入只来自当前及过去传感记录；无类别时仍能表示地图 |
| STGHP | 按剩余预算比较探索与设施观察的延续收益 | 同一候选池、同一预算、共同延续策略，单独归因候选生成与语义评分 |
| RPN-UQ | 保留逐动作安全检查及返航储备，记录完整路线成本 | 碰撞、返回、实际付费动作及拒绝原因；当前确定性检查不冒充已校准概率 |
| IGCR | 逐动作保留预测、实际观测和更新历史，为后续实例／方向条件反馈提供输入 | 完整历史恢复一致；另做关闭反馈对照，调用成功不等于反馈有效 |

不新增替代四模块的主架构。CPU 后端是机制原型，开放词汇感知、原 ANS 神经策略、学习型 UQ 和定位漂移收益仍需分别验证。

## 已实现：从零时刻恢复决策状态

入口：`scripts/collect_semantic_gain_v13_history.py`；传感持久化和恢复工具：`nso/decision_replay_v13.py`；冻结配置：`configs/virtual3d/semantic_gain_v13_history_smoke.json`。

本次固定 Q0 / shelf_east，一个开发父场景，96 个动作预算，几何 G 评分和本地 v10_3_1 四模块后端。没有人工真值导航前缀。该后端是轨迹采集基线，并非缺失的 9 月 13 日 V12 实现，也不是新训练的 V13 算法。

采样规则在执行前固定：保留自然决策序号 1、2、4、8；不根据事后收益筛选检查点。这是小规模恢复检查，不能声称已覆盖所有探索阶段或统计独立场景。

每帧保存完整 RGB-D、扫描、标定、位姿、动作和来源信息，禁止 pickle。每个检查点保存决策前传感哈希、地图数组和导出网格哈希、预算与反馈审计状态、执行状态、候选池及下一动作。源码、配置、软件版本和全部输出另行记录哈希。

恢复时创建独立地图，从第零帧开始逐一重做策略授权和实际传感更新。仅重融全部帧再调用一次 bootstrap 不能自动恢复中间 IGCR 状态，因此不能作为此处恢复实现。禁止用 TSDF 的 Python 深拷贝替代独立融合。

验收范围：传感包磁盘往返精确一致；4 个检查点的记录状态、候选池和下一动作精确一致；四模块有实际调用；完整轨迹无碰撞且返回起点。这里只验证持久化传感重放与记录状态一致，未独立重生成物理传感器数据，也不声称序列化了 Open3D 内部全部状态。

## 后续待实现与冻结

1. **多阶段采样。** 将采集扩展到 Q0–Q3 全部开发父场景。按已支付预算比例预定采样区间，取区间内首个自然决策点；缺失区间也记录。设施接近与细节阶段由可观测条件标注，不能借用隐藏场景真值或事后回报筛选状态。
2. **共同候选与预算。** 先用几何观测产生并冻结候选池。每个候选恢复同一决策前历史，执行首选路线，再由共同几何策略延续。预算从任务起点统一计费，包含首选、转向、延续和返航；记录提前停止和失败，不将不同预算的回报混合。
3. **特征与标签分离。** 剩余预算、往返成本、已观测网格内未知比例、预计新增相机覆盖、方向缺口、置信度、几何不确定性与历史反馈作为候选输入。未知比例的分母不能使用真值可达面积。实际覆盖与三维 F1 只在离线计算标签。特征维度、归一化、门控及零资产行为需先写进新配置再采集正式训练数据。
4. **先检验可用信息。** 比较配对真实延续回报中类别信息是否改变优选动作。理想选择差距只描述该候选集合与延续策略；物理排列若改变可观测几何或候选池，就不能将差距单独归因为语义，需额外做同一物理历史的标签干预。零价值状态与失败状态全部保留。
5. **再训练与闭环。** 父场景的全部排列、阶段和延续在同一折；归一化、门控拟合及调参均隔离验证父场景。同容量比较几何、正确语义、固定类别先验、打乱语义、零置信度及反馈关闭；通过开发筛选后再冻结新的独立确认集。

主指标继续记录二维覆盖与三维 F1 的联合表现，同时分开报告覆盖、precision/recall/F1、表面误差、动作／时间／路程与返航。当前继承历史开发诊断的面积乘 F1 标签；跨不同大小父场景还须报告归一化覆盖乘 F1，不能仅靠面积差扩大平均收益。

本次不设“必须得到正结果”的实验筛选条件。完整方案优势仍需语义增量、反馈贡献边界、强几何／主流方法对照和独立确认支持。
