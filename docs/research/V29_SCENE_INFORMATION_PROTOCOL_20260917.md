# V29：双工位类别额外信息的有限解析预检协议

2026-09-17。只建立一个冻结的解析版本，不新增世界、SensorPacket、mapper、TSDF、网格、Q 或主任务。配置为 `configs/virtual3d/v29_information_scene_20260917.json`，运行器为 `scripts/preflight_scene_information_v29.py`，独立输出为 `audit_results/v29_scene_information_20260917`。配置、协议、脚本必须在第一次完整解析求解前封存 SHA；本协议和配置先交主线程审查。一次运行，失败或零信息增益原样保留，不调整场景、预算或权重追门。

## 问题与唯一场景

任务故事是工位外部垂直面巡检：公共前廊已完成相同的初始观察，两侧设备可能分别具有简单柜壳或被柜体遮挡的后部外露结构。类别标签可能提前提示结构位置；几何方法也可以主动绕行、发现实际结构、立即改选。这里检查的只是**提前知道哪侧存在该结构是否具有额外决策价值**，不是人为规定复杂类必须优先。

公开平面为 1 米间隔、x=-5..5、y=0..7 的离散地面，机器人半径 0.2 米；前廊在 y=0/1 连通两工位，中间有实体隔板。柜体中心 x=-3/+3，占地 x相对[-1,1]、y=[2,5]、高1.6米。复杂型在后部接一块 x相对[-.6,.6]、y=[5,5.7]、z=[.4,1.2] 的实体附件。附件只交换所在工位，柜体、墙、导航尺度不变。它形成向后及侧向的实际外露面，前方会被共同本体遮挡；这些性质必须由解析检查证实，不能靠故事直接宣布通过。

两种排列先验各 1/2。公共前缀 18 个付费动作，从 `(0,0,北)` 沿前廊访问两柜前方，再回到完全相同的起始姿态。**总预算固定48，余量30**，包含前缀、所有移动、原地转向和最终返回同一位置与朝向。预算是本次解析资源假设，不是 V25 的旧服务成本或真实电池标定。

## 几何、可见性及奖励契约

地面图使用所有合法前进/左右转向，每次成本1。安全检查采用实体矩形与机器人半径，不删孤立格；检查全部安全格连通。两排列若导航图不同，则本次主信息比较判为不适用，不能默默用交集禁掉几何策略的合法动作。

所有柜体、附件及墙的垂直面按配置的最大0.5米水平/垂直间距分成等面积小矩形，以中心为有限代表点。接触内表面剔除。相机高0.9米，水平/垂直视角90°，4米距离；可见性要求面朝向相机、在视锥和距离内、到该点的线段不被任何实体长方体先截断。只做数值几何运算，不导入项目世界或传感器代码。该离散代表点模型不包含真实像素、噪声、SLAM误差或表面重建。

观测签名只包含**可见物理坐标及外法向**，规范排序去重；包括可见背景墙，不仅筛出任务设施。不得含隐藏表面ID、设施role、类别、面积权重或每设施总面积。同一可见表面在不同假设下的内部编号不同，不能制造首差。类别仅是另给语义政策的初始信息。前缀两排列签名逐步严格一致才能进入主比较。

奖励为已观察代表小面的面积并集 / 对应设施全部参考垂直外表面积，再对两设施等权平均；重复观察不重复计分，没有复杂类奖励系数。分母及所有未见面积只存在于解析模型和评价侧。它是**参考几何潜在可见表面积代理**，不是外形Q、三维精度或真实任务性能。顶面/底面不是本轮巡检目标；平面采样与有限朝向限制必须随结果报告。可达视点是否能观察每个目标代表点由全图检查，不能假定全部可见。

## 强几何对照与信息价值

G 获得完整共同导航图、两种可能几何模型及正确1/2先验，但不知道实际排列；这是比现实未知地图规划更有利的几何信息条件。在每个动作后立即得到理想有限几何观测，按观测签名更新信念。求解遍历**所有合法动作**，不限于预定服务路径，不强制长选项，不禁止补看，也不禁止首差后返回并改选。

精确有限时域 belief-state 动态规划同时维护当前姿态、剩余动作、可能排列及各排列条件下已观察面积并集。只有能在余量内返回精确锚点姿态的状态可取；允许提前返回停止。每次观测分支的概率来自当前信念，不把真实排列偷偷传给决策。记录 memo 状态数与是否穷尽；若触及时间/状态上限，标为删失，不将近似值冒充最优界。

正确类别政策从初始就知道排列，求各排列下同图、同预算的最优动作值。它是**类别信息充分且使用最优时的 oracle 信息价值**，不是 V28 r1 方向先验政策或当前 ANS 的成绩。主量为 `mean(V_class_optimal) - V_G_Bayes_optimal`，另列相对量、逐排列值、完整动作与返回资格。Bayes最优G允许主动取信息；有限期望奖励是策略随机混合的线性函数，故最佳随机政策的期望上界等于该确定性 belief-policy 最优值，不能用一个任意随机游走作为弱对照。

所有最优并列按动作次序 `forward,left,right`，可停止且不损失价值时优先停止。输出首信息动作层、最短返回、各已求得完整观察动作串和首差后是否实际改变路线。若某种“必须完成工位”的服务选项不能在预算内完成，照报；不能把一像素/一点首差替代完整采集或重建。

同一精确 DP 同时计算两个单设施面积目标，用来查询“该设施全部参考代表点已观察并返回”的最小成本。只在固定余量30以内查其可行最短成本，超出则给严格下界>30；内部最短成本查询不改变主任务总48，不按这些结果挑预算。面积是有限代表点积分：接触边界切过小矩形时，以其代表点是否属于外表面判定，故该面积也只是声明分辨率下的近似，不冒称连续实体的精确表面积。

## 预声明控制与停止规则

1. **普通同结构**：两侧都是简单柜，两假设物理几何完全相同。正确类与G最优值必须相等；不得仅因内部ID不同产生假信息。
2. **几何提前揭示**：主场景在决策开始免费提供可区分两模型的真实几何签名，相当于给G同等排列知识。它是信息条件干预，非本场景实际可获得的免费观测；G必须达到正确类 oracle。
3. **交换类别**：执行依据相反初始类别而生成的最优政策，但在真实几何首次反驳时立即切换为真实模型的最优后续，付费返回和剩余预算不变。报告真实回报，不强迫错误政策一直走错；该控制未必严格更差。
4. **不相关类别**：类别提示与真实排列独立。知道此关系的 Bayes 最优政策忽略它，最优值与G相同；另给沿提示行动的四种配对回报，不能据其失败否定理性语义融合。

开发门依次为导航/连通、前缀同几何、关键目标可达可见、精确求解完成、同结构和提前揭示控制、主绝对信息增益>1e-9。门用于判断一个解析设计是否值得进一步传感验证，没有将旧5%性能或20%短名单门移植过来。零增益、正确类别最优反而优先简单柜、G能廉价首差改选追平、不可观测目标、超时均完整保留，不能展开预算/几何搜索。

一进程单线程，最多300秒、1,500,000 memo状态，产物小于1MiB，保留64MiB磁盘。开始后不重启；异常也封存配置、源码和失败收据。输出不授权实际采集、学习或新主任务。成功至多说明这个有限解析模型有可用的类别信息，下一步仍需独立验证真实传感首差、噪声、完整观察质量与当前策略能否兑现。
