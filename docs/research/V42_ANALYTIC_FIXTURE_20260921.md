# V42 双帧解析观测夹具

本夹具只用于检查接口、观测归属、语义先验激活和实际 TSDF 融合，不是 DEV 场景，不是规划性能实验。

`nso/analytic_fixture_v42.py` 中的 `analytic_forward_sequence_v42()` 返回两个严格的 `PaidRGBDObservationV40` 数据包。相机从 `(0.75, 0.75, 0.9)` 沿世界 `+X` 平移 0.25 m，偏航均为 0。初始数据包 step 为 0，动作后的数据包 step 为 1，符合 V41 公共运动图。

两帧分别用相机射线与同一组固定有限矩形作解析求交：主体平面 `x=1.85 m`，标签平面 `x=1.83 m`，标签尺寸 `0.32 × 0.30 m`。每个像素均重新计算交点，深度采用相机光轴 z 距离；并非复制图像后只修改相机位姿。无返回深度为 0，不提供空闲空间证明。在线模块只接收 RGB、深度、内参、相机位姿、frame ID 与 paid step，不接收夹具几何、实例真值或隐藏结构。

使用 V41 默认关联参数，两个数据包均关联同一实例，当前像素残差均有效。S 与 G 的几何观测、关联和几何反馈完全相同，S 仅在第二帧后满足两次类别支持条件；G 始终使用几何先验。**第二帧的新增支持主要来自实例台账对初始 0.6 m 自举子集的扩展，不代表第一帧图像中被遮挡表面的揭露**。因此本夹具不能证明重复观测带来的独立信息增益、语义性能优势或泛化能力。

五项针对性测试验证固定世界平面、真实运动与深度变化、共享几何与先验激活、公共动作状态兼容、转动射线重新求交，以及无效输入拒绝。运行命令：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 .venv-3d/bin/python -B -m unittest discover -s tests -p test_analytic_fixture_v42.py -v
```
