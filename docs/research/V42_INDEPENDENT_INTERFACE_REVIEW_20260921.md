# V42 独立接口复核

复核范围是新建的解析夹具、观测视角预测器、实测 TSDF／占据图适配器和接线验证脚本。未运行 DEV World，未访问保留场景种子，也不据此判断方法性能。

## 解析输入与证据边界

双帧夹具从同一固定世界平面重新求交，0.25 m 位移后的深度变化与相机位姿一致。其第二帧可激活语义先验，但新增实例支持主要来自台账自举支持范围的扩展，不能写成“新揭露的遮挡表面”或独立精度收益。5 项夹具测试通过。

预测器只接受绑定当前数据包 SHA 的已观测像素支持，重新反投影并核对点集，再独立拟合标签平面。G／S 使用同一观测状态与固定名义结构库；后验仅用于混合各结构的预测表面积。未知扩展字段被拒绝；未发现在线读取实际场景几何、实例包围盒、所有者 ID 或未执行视角传感结果的路径。

## 面积与可见性核验

独立使用单位立方体作为闭式参考，检查预测器的表面采样、外法向和首次交点判定：总面积为 `6.000000000000002 m²`，正面可见面积为 `1.0000000000000002 m²`，最小法向与“表面点减中心”的内积为 `0.4999999999999999`。面积权重和外表面方向与理论值一致。该验证使用显式小数组，不构造开发场景。

坐标变换使用相机光轴 z 作为射线参数；原型自身遮挡采用固体并集的首次交点。新表面积不超过可见表面积，可见面积不超过原型总面积。可见性、测得支持覆盖判定和结构后验是不同环节，不把结构原型作为已经重建的表面。

预测值仍是名义结构上的代理量：未建模外部障碍遮挡、未边缘化标签位姿不确定性、尺度权重未经校准，也未预测重复观测的噪声降低收益。不能将候选预测面积变化写成真实重建质量提升。

## 实测融合边界

新建图适配器只融合实测 RGB-D；深度按光轴 `[0.1, 4.0] m` 裁剪。Open3D 的严格上界用 float32 的下一可表示值处理，使 `4.0 m` 有效深度不被误删。相机采用连续刚体位姿，不吸附到网格。

相同 frame ID 或跳号 paid step 在融合前拒绝；重新付费的新数据包允许融合，已知面积不会因重复次数重复累计。错误输入在修改地图前拒绝，后端融合异常则将适配器标记为不可继续使用。占据图保留相机所在格的已观测障碍，未沿用旧实现强制清空原点的行为。

激光扫描检查合法范围、刚体姿态、世界平面约束和时间单调性；receipt 将扫描 SHA 与 RGB-D SHA 绑定。**同一次采集的同步关系仍由调用端提供，时间单调不证明同步**。解析接线夹具未提供扫描，因此此轮的占据图不能被写成已测得完整二维覆盖率。记录的已知面积是被传感器触及格子的并集，分母及覆盖率保持为空。

## 审计记录

初次复核发现预测器以不带类型／形状信息的原始数组字节计算重复数据包摘要，与 V41 台账的约定不一致。已反馈实现者修正并加入回归检查；此问题不影响固定 `96 × 72` 主夹具，但修正对统一接口语义有必要。

第一次接线验证的 37 项测试通过，但随后独立摘要复核发现预测器与测试文件在运行结束后发生了并行清理修改。原证据包没有被覆盖；差异与当时文件副本另存于 `audit_results/v42_verification_drift_20260921`。该包被明确标记为最终版本的前序记录，不用于声称当前源码已通过最终封存验证。

第一次接线结果还暴露了方法层面的问题：名义原型与已测表面不一致时，已经付费采集的同一视角仍可能保留正的“新表面积”预测，四个条件都再次选择当前位置 `observe`。主任务据此要求修正视角资格判定。对当前**仅预测新视角面积、未建模重复噪声平均收益**的目标，应将已付费相同相机视角的有效新面积设为零，同时保留原始几何预测量；此规则不能将无返回深度解释为已测表面，也不能据此否认其他任务中重复观测的价值。

修正版用内参、刚体相机位姿、图像尺寸匹配已付费相机视角，浮点绝对容差为 `1e-9`。匹配的数据包 SHA 和相机历史 SHA 均进入预测记录，原始预测面积与资格判定后的有效面积分别保留。该规则对整张已采集图像生效，即使当时未关联目标，也保守排除相同视角；它适用于当前静态、新视角面积目标，不适用于将随机漏检重试或重复噪声平均作为收益来源的目标。旋转、平移或改变内参的候选仍可获得预测收益。

最终 r1 运行通过 40 项测试。独立复核通过 32 项产物摘要、17 份当前／归档源码摘要、171 项旧冻结文件摘要；重新核验两个数据包身份及两次实际 CPU TSDF 融合绑定，检查 768 个原型组件的面积界限、后验混合计算、12 项重复视角零收益条件及相机历史摘要。地图包含 1,131 个顶点、2,128 个三角面，原型未进入 TSDF，真实覆盖率分母仍为空。

修正后四个条件都提出 `left`，目标均为 `north / heading 11`；均未执行。语义改变了候选预测值，但此夹具没有产生 G／S 选点差异，更没有建立重建性能优势。最终收据为 `audit_results/v42_independent_review_20260921/result.json`，审计对应 `audit_results/v42_observed_planning_r1_20260921/result.json`。本复核不将解析夹具、单次未执行选点或 TSDF 平面重建等同于完整四模块规划实验。
