# V42 实测 RGB-D／扫描建图接口

2026-09-21。本文件描述 `nso/observed_mapper_v42.py` 的接口与解析验证边界。该接口使用 Open3D 0.19.0 的 CPU TSDF；新增测试确实执行小型解析深度平面的融合，但不创建 DEV World，不构成场景性能结果。

## 输入与 API

```python
mapper = ObservedMapperV42(
    shape=(140, 200), resolution_m=0.1, origin_xy_m=(0., 0.),
    voxel_m=0.04, sdf_trunc_m=0.12, near_m=0.1, far_m=4.)
receipt = mapper.update(paid_rgbd, measured_scan)  # scan 可以为 None
state = mapper.snapshot()
belief, observed_this_frame = mapper.occupancy_arrays()
mesh = mapper.mesh_arrays()  # vertices / triangles / vertex_colors
```

`paid_rgbd` 必须为严格的 `PaidRGBDObservationV40` 六字段实例。接口重新检查并复制数据，拒绝混入场景／实例所有权字段的旧传感对象或任意字典。`PlanarScan` 必须为原始类型，检查一维有限非负量测、范围上界、有限时间戳、单圈以内非零角增量、正交齐次位姿与竖直雷达平面。零距离代表无效射线；到达 `range_max_m` 的有效射线代表量程内未命中。浮点量程上界允许源精度对应的四倍机器精度误差，并以此区分饱和量测。

相机内参必须为零偏斜标准针孔模型，因为 Open3D 的本接口不支持一般 3×3 内参。相机位姿保持连续，不将其吸附到占据栅格中心或离散航向。

## 帧计费、来源与失败处理

第一帧 `paid_step=0`，以后严格连续；已出现的 `frame_id` 或跳步在融合前拒绝。静态视角下一次真实付费产生的相同像素仍是新帧，可融合一次；它本身不会额外增加已知栅格面积。全无有效深度的付费帧仍入账，但 TSDF 融合计数不增加，合法雷达数据仍可更新占据图。

回执绑定 RGB-D SHA、扫描 SHA、扫描时间戳、裁剪后 float32 深度 SHA、原始位姿、有效像素数、扫描射线类别、融合次数、新增已知格数和相机所在格的占据冲突。扫描与 RGB-D 的同次采集关系由传感适配器提供；该接口检查扫描时间严格递增，不把整数 `paid_step` 冒充为传感时钟，也不声称散列本身可证明硬件同步。

所有输入验证和占据图预计算先于 TSDF 修改。非法输入不会改变 TSDF、占据图、计数、帧 ID 集或上次扫描时间。Open3D 若在 `integrate()` 内部失败，没有可用的事务回滚；本适配器立即标记 `backend_poisoned`，拒绝继续融合或导出网格，调用方必须丢弃该映射器。不能把内部错误后的重试描述为干净的一次融合。

## 三维融合

只有原始测得 RGB、轴向深度、内参和位姿进入 TSDF。类别、结构后验、结构原型与预测补全面完全不进入融合。无实例 ROI、所有权或 GT 网格。

先在原始深度精度中应用闭区间 `0.1 ≤ z ≤ 4.0 m`，再转成 float32。无效零值、过近或过远值写为零。Open3D 的深度截断是严格上界，实际传入 `nextafter(float32(4.0), +∞)`，从而保留恰好 4 m 的量测；这是 float32 的下一个可表示数，避免 float64 的极小调整在内部转换后失效。筛选依据光学轴 z，不以斜射线的欧氏距离错误删去角落像素。

默认 TSDF 体素 0.04 m、截断距离 0.12 m；导出完整网格，不按已知实例裁剪。每次查询返回独立数组副本。

## 二维占据与面积

`origin_xy_m` 为地图最小 x/y 边界，行号随世界 y 增大，列号随世界 x 增大。该约定与部分旧图像行倒序接口不同；接入导航时必须显式适配。状态为 `-1` 未知、`0` 测得空闲、`1` 测得占据。

雷达采用连续世界坐标线段与格边界的交点来决定经过格，先裁剪到地图范围，不将射线起终点替换为格中心。仅触碰角点不声称两侧格空闲；命中端点标占据，边界外命中不生成虚假边界障碍。深度点仅把默认世界高度 `[0.15, 1.2] m` 的端点标为占据，不把三维投影射线直接当作可通行地面。

占据格在静态保守策略下不被后续空闲射线抹去；相机／雷达起点不自动强制设为空闲，保留短距命中与原点格冲突。该规则不提供动态障碍清除能力。

`snapshot()` 分开报告传感器触及格的已知、空闲、占据面积。它们是栅格分辨率下的测量面积代理，不表示整格内所有点均被观察，也不等于真值自由空间覆盖率。`coverage_fraction` 与 `coverage_denominator` 固定为 `None`；正式 `C_map` 需要独立离线评估器持有预先冻结的可达自由空间分母，不能以本接口地图边界面积冒充。

## 解析检查与当前限制

测试文件 `tests/test_observed_mapper_v42.py` 覆盖实际 CPU 平面重建、0.1／4 m 边界保留、近远裁剪、连续倾斜位姿、重复 ID／跳步拒绝、新付费重复像素、扫描非法值与时间倒退的融合前拒绝、原点障碍不被清除、非零地图原点、连续斜射线、地图外裁剪、无效／量程射线、哈希及副本隔离、偏斜内参拒绝、后端失败停止。

这些是测量与接口正确性测试；不是完整四模块闭环、独立场景重建指标、语义增益或自然传感器性能。当前位姿来自提供的精确位姿，没有加入真实 SLAM 位姿漂移。实际 DEV 场景批次仍须满足既定持久存储门槛。
