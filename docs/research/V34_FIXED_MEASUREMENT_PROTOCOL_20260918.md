# V34 P00固定路线：像素噪声与TSDF实测协议

2026-09-18。像素信息门已完成两父416视点：公共前缀几何相同，类别标记每构型在7个不同XY位置可读；最短几何首差仍8/6动作，潜在信息价值仍11.798%/10.468%。它没有测重建。本协议在任何新路线融合/质量成绩之前确定固定测量批；必须先通过像素独立保存证据复核、测量夹具与source完整性门才prepare。

## 唯一场景、矩阵、预算

使用已冻结V33 r1原几何和V34像素世界，不改变前护板、肋、导航域、传感范围、前缀或预算。首批固定词典序父P00；矩阵为h0/h1 × G/class_oracle，取V34像素信息复核保存的两类最优见证，不根据物理收益选择路线。P01不在此批，不宣称两父已经实测验证。

每个比较单元的动作串均为同一18动作公共前缀加其保存后缀，上限42动作，返航须原位置和heading一致。G这里是离线有限策略的真实假设分支轨迹，执行时顺序回放已冻结动作，没有在线读取GT后分支；它不是实际主动G、ANS或学得语义策略。oracle亦是条件路径上界。两者的目的仅是检测有限模型预期收益能否经真实像素与公共融合兑现。

执行前按同父、同真实构型、完全相同行动串和采集参数作精确alias。当前P00 h0两路线相同，可共用一条轨迹；四个声明格预计三个唯一采集，alias不算独立样本、不重复计数。若实际prepare不能证明一致则保留四条。次序为h0/G、h0/oracle（若alias不执行）、h1/G、h1/oracle。

历史主任务已用16/36；每个唯一case目录一创建就计一次，失败保留，不重置，不自动重试。最多4新主任务；独立进程回放另记真实World、packet、动作、融合与评价次数。任何终点覆盖/返航/碰撞/预算资格失败、采集异常或回放失败，都停止剩余新主任务；prefix低覆盖是预期诊断，不单独阻止继续。

## 同一真实传感与融合

相机/单线/位置与V34像素协议一致：96×72，fx=fy=48，相机高.9米、Euclidean4米；单线高.25米、180束、8米；精确模拟位置，1米前进或90度转向每次付费1，所有转向付费。切向安全继承V33 EPS，并单列其不能保证实车正余量；没有动作中间免费帧。

本批唯一预声明深度噪声为现有 `iid_025px`、seed1901、parent_index=0、step=真实付费动作号，reference_fx=480px、baseline=.12米。相机像素内参仍48，噪声公式的参考分辨率参数另列；这是既有双目误差敏感性模型，不是ZED物理标定。构型/政策不输入随机噪声生成；同父同动作号同规则。保存clean-depth hash与实际noisy-depth原始数组。深度截断不改变独立激光量程。

使用 `ObservedRuntimeMapperV10` 的同一Open3D CPU ScalableTSDFVolume作为主重建，voxel=.04米、truncation=.12米、depth_trunc=4米；全帧深度按测量融合，marker类别不给几何加权、补全或奖励，frame.semantic为零。只用公开输入和已付观测，不在后端输入实际假设、参考网格、owner真值或Q。原V24实测面清理器不参与主预测，避免看到分数后挑后端。

初帧和每个实际动作后保存原packet，旧IO读出后用独立量程新版validator；初始＋42动作应为43包。每步记录动作、pose、packet/clean与非类别字段hash、RGB解码、碰撞和观测footprint冲突；冲突是单列诊断，实际执行碰撞资格由冻结真实扫掠合同判断，不能隐藏。这个固定轨迹系统未验证基于噪声地图的自主安全决策。

## 快照、公共ROI与评价隔离

在已付18动作和真实终点各提取一次raw TSDF mesh、复制belief，再按冻结测量合同从raw提取单设施mesh；保存全部数组、公共ROI及面积去除账本、哈希。所有两阶段预测快照均在读取GT参考和计算质量之前冻结。prefix快照不改变融合状态、不重新初始化TSDF，后续融合继续使用同一已付历史。

公共设施bounds由P00两hyp配置的全部设备AABB取并集并施同一公开坐标平移，prepare即冻结。两构型/两政策完全相同，不用实际真值bounds替换。API的 `.20m` padding、`.02m`/10度近地水平面去除、无封口/配准/吸附等均按[V34表面合同](V34_SURFACE_MEASUREMENT_CONTRACT_20260918.md)。所有ROI外裁去的预测面积和面数单列；主precision只在公共ROI内，不能称无裁剪完整实例或全地图precision。

冻结后评价侧构造准确设备并集全表面和全部外露竖面。precision为预测面到完整GT表面的距离比例，recall为全部竖面到预测mesh的距离比例，固定32768面积样本和seed340918/340919。漏建为空时P/R/F1=0。主量 `J5=C_map×F1@5cm`；2cm和10cm同时报告，不按成绩选阈值。误差mean/RMSE/P95、P与R分开，recall不叫坐标精度。

`C_map` 固定为本父完整公共域、.2米栅格全部真实安全可达格上 `belief!=-1` 的比例；分母由world的完整swept-safe栅格和连通检查取得，不按路线裁剪。24个声明整数中心上的同belief覆盖另列为`C_grid_measured`，V33的理想中心覆盖只作来源诊断。实际主资格只能用C_map≥.80，加真实精确返航、零执行碰撞、未失败、实际动作≤42，不能用高J抵消失败。
