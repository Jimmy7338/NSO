# V16.3 可达视点候选与七条后续观察执行

2026-09-14。**新候选生成、三状态预检查及全部七条第二视点执行与独立进程重放完成。七条均到达、安全返航、零碰撞。** 四条标记封闭设施分支有原观测面深度支持，三条未标记墙面分支没有；复杂设施召回和新增复杂表面积均无增量。因此这仍是公共候选与观察执行验证，尚未证明语义创新或完整方案优势。

## 1. 修改内容与冻结条件

上一轮发现实际侧角到达后，安全视点会因偏离预设中心 0.35 m 而被原进入／深入候选拒绝。新 `hierarchical_options_v16_3` 保留全部 V16.2 候选，并为每个观测几何簇增加最多一个 `aperture_view`：

1. 枚举已观测安全地图上可达且可预留返航的相机位置和四个离散朝向。
2. 使用已有观测几何定义的假设观察面支持，选取支持最大的未占用候选；依次用去程代价、总预留代价和姿态打破平局。
3. 不要求逼近预设中心点，不改变原进入／深入角色的 0.35 m 限制，不把新角色重新命名为原角色。
4. 对所有几何／语义对照共用 `5+5N` 容量，类别不参与候选筛选。N 是观测几何簇数，可能包括墙面。

除了位置规则，新角色允许四个离散朝向参与比较；原进入目标指定的正面朝向规则仍保留。因此不能将新旧差别全归给一个距离阈值。

`CPUFourModulesV16_3` 保留既有四模块接口和全局目标—局部付费动作层次。此次诊断在已声明的第一次到达动作数才启用新候选，之前的侧角接近使用原公共候选。这是明确的两阶段诊断条件，不是已经运行的新版本完整冷启动策略。

规则在执行前写入 `configs/virtual3d/feasible_aperture_v16_3.json`。假设观察面投影没有真实遮挡证书，不能自动解释为新增面积或已经看到了隐藏表面。

## 4. 本轮能证明和不能证明的内容

四条有正的原目标面深度支持的分支，对应实际观测中的封闭类别：canonical vote 为 +1，均有 8 个标记支持点。三个零支持分支的目标均未标记，vote=0，不应把它们当成已知封闭类别。分支类别信息来自第二段出发前的真实 OV-SDF 调用记录。

四个标记目标的连续观察有实际几何支撑；到达后分别新增 2、4、2、2 个原进入／深入候选。三个未标记墙面目标虽然到达并产生地图增长，但第二帧没有原观测面深度一致支持，后续仍无原进入／深入候选。不能把它们全部称为成功观察了目标背面。

全部七条的复杂设施 recall 增量和参考 2026 的新增复杂设施可见表面积均为零。本批目标没有已观测的开放类别，主要验证封闭设施及墙面附近的几何执行。既不能用它证明复杂设施补看收益，也不能以此否定其他结构中的语义条件价值。

三个无目标面支持的分支仍有较大的全局地图增量，提示必须把“对目标的观察支持”和“沿途覆盖收益”分开归因。不能仅凭是否带语义标记删掉候选，或将一般覆盖增长计为语义反馈的成功。

## 5. 下一步进入语义验证的必要工作

1. 增加公共的已观测遮挡检查与观测区域关联诊断，解释三个无目标面支持案例。假设观察面可作为预测量，但真实观测反馈应区分目标关联成功、失败和无法关联；几何与语义模型共享这套信息。
2. 将本轮几何规则用于此前已冻结的几何匹配、类别不同结构，验证开放设施是否真的存在额外可观测表面和有效路线。不能另挑正回报结构，不能只测试封闭类别，也不能借用隐藏物体编号维持目标关联。
3. 冻结第一接近后如何选择同一观测区域的第二视点；区域重分割或没有可靠关联时明确回退。然后以相同总剩余预算和公共后续策略，采集覆盖、直接观察和连续观察候选的完整回报，计算可观测语义信息价值。
4. 门槛通过后才进入跨父布局的等容量几何、正确语义、置换、零置信度和残差模型训练；之后再进行完整闭环、反馈归因、全新独立确认和外部基线比较。V15 的零信息结论继续冻结，当前七条不授权训练。

ROS1 真实运行、自然语义感知、原神经 ANS、学习型 UQ 和实车有效性仍分别待验证；本轮没有开展这些实验。
