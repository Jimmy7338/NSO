**结论：当前 S 的数学更新没有发现“把贝叶斯公式写错”的证据，但它表达的是一个很窄、信号偏弱的共享类别可靠性模型。它既不学习类别的四构型频率，也不假设同类设备长得一样。固定两个分位的场景设计不能直接检验该层次模型的分布适应优势；旧闭环中又存在“共享改变的实例没有可用观察收益”这一实际阻断。三者应分开解释，不能把尚未知的 Ground 效果直接判成失败。**

## 1. 当前“类别信息”实际代表什么

| 层次 | 已执行实现 | 不能由此声称 |
|---|---|---|
| 观测类别 | 付费RGB-D中的精确颜色标签，经唯一深度支撑关联、多个有效观测和无类别冲突条件取得资格。 | 已验证自然图像分割、开放词汇网络或类别识别泛化。 |
| 类别语义 | cabinet、rack、machine、workstation 对四个公开构型原型的固定设计权重 `q_c`。公开规格明确为 `uncalibrated_design_prior`，训练清单尚未给出。 | 从当前场景训练得到的经验频率，或类别本身就是构型真值。 |
| 规划作用 | 类别改变构型后验，后验改变各可执行视角的预计新表面积及一次诊断的未来作用。 | 给高语义类别直接乘重要性奖励；当前评价没有按类别偏好加权。 |
| 共享范围 | 同一次运行中、当前仍具有合格同类标签的已观测实例共享可靠性；无标签、冲突或关联不确定时退出该类的共享。 | 未发现对象的位置/构型已知，或跨场景累计学习得到新的类别分布。 |

每次控制器重新构造信念，场景之间没有累计学习类先验。增加不同布局不等于给某一运行的类别增加了更多同伴样本。

## 2. S 学习的是二选一的模型权重，不是四构型分布

记四构型为 `planar/recessed/louvered/open_frame`，几何先验 `g=(.25,.25,.25,.25)`，类别表为 `q_c`，实例自身累计几何分数为 `L_i(h)`。G在规划信念中不给类别条件；B使用固定混合先验

\[
 b_c(h)=\tfrac12g(h)+\tfrac12q_c(h).
\]

S假定每个类别共享一个隐藏域变量 `Z_c∈{g,q}`，初始权重各半；在给定 `Z_c` 后，同类对象的构型独立服从该域的分布。对目标 i，代码先排除自身，再用同伴的累计消息

\[
 m_j(z)=\sum_h q_{c,z}(h)e^{L_j(h)},\qquad
 \rho_i=\frac{\prod_{j\ne i}m_j(q)}{\prod_{j\ne i}m_j(g)+\prod_{j\ne i}m_j(q)},
\]

得到活跃先验及后验

\[
 \pi_i(h)=(1-\rho_i)g(h)+\rho_iq_c(h),\qquad
 p_i(h)\propto\pi_i(h)e^{L_i(h)}.
\]

这里的乘积仅遍历**当前合格同类同伴**，自身证据只施加一次；历史消息是替换累计值，不是每次读取再乘一次。没有同伴，或同伴四构型证据相同，就严格回到B的 `rho=.5`。这是一种标准层次广义贝叶斯构造；CPU残差不是校准过的真实传感似然，不能无条件套用其统计最优性。

`rho` 只在两张固定表之间插值。它没有更新 `q_c` 的四个参数，更不会把目标构型复制成同伴的构型。因为g均匀，所有正rho的活跃先验仍保持q原有的构型排序；看到q不偏好的构型，只会向均匀分布退回，不会把该构型学成新的类别主模式。若论文说“观察一台设备就学习同类设备的具体构型分布”，超出了当前实现。

因此同类两台设备**不应被假定为同构型**。在该模型中，它们只共享“类别表是否可信”的域变量；边缘相关性为

\[
 P(H_i=h,H_j=k)-b_c(h)b_c(k)
 =\tfrac14[q_c(h)-g(h)][q_c(k)-g(k)].
\]

相关性的符号由两个构型分别受到q增权还是减权决定，并非所有同类构型都正相关。

## 3. 当前场景使用固定分位；T0/T1没有新增关系分布

`article_scene_assets_v1.py` 对每个类别强制两台设备的分位数恰为 `.25` 与 `.75`，再按q的累积分布确定构型。它不是给定共享 `Z_c` 后的独立分类抽样，也没有在场景之间抽取可靠域/无信息域。

九份已封存类别/构型元数据核验如下；同一行的DEV、T0、T1多重集合完全相同：

| 场景族 | DEV/T0/T1始终共有的类别—构型组合 |
|---|---|
| AISLE | cabinet：planar、louvered；rack：recessed、open_frame |
| CELL | machine：recessed、louvered；workstation：planar、louvered |
| LOOP | cabinet：planar、louvered；machine：recessed、louvered |

T0/T1具有不同空间布局，设计检查也拒绝简单重命名相同房间/设施姿态/遮挡配置；它们可以验证**固定对象组合下的空间布局外推**。它们没有带来新的类别—构型抽样分布、共享可靠性域或类别关系偏移。不能仅凭六个测试布局将结论扩展为“适应变化的类别关系分布”。

固定分位用于覆盖不同构型有其工程价值；问题是它对应的联合分布与S假设不同。若规划器知道每类恰有这两个固定分位，观察第一台会约束另一台剩余构型，但当前S既没有接收也没有利用这个设计规则，不能在论文解释中暗中赋予它这种能力。

### 一个揭示方向的纯代数极限

假定同类物理对象已正确关联、同伴的真实构型被完全识别、目标尚无自身几何证据。此时 `rho=q_c(h_peer)/(q_c(h_peer)+g(h_peer))`。将上述固定分位对应的两台互换作为目标/同伴，结果是：

| 类别 | 目标构型 ← 已知同伴构型 | B对目标真实构型的先验权重 | S相应权重 |
|---|---|---:|---:|
| cabinet | planar ← louvered | .325000 | .316667 |
| cabinet | louvered ← planar | .225000 | .219231 |
| rack | recessed ← open_frame | .225000 | .219231 |
| rack | open_frame ← recessed | .325000 | .316667 |
| workstation | planar ← louvered | .300000 | .287500 |
| workstation | louvered ← planar | .200000 | .191667 |
| machine | recessed ← louvered | .250000 | .250000 |
| machine | louvered ← recessed | .325000 | .325000 |

前三类的固定配对是一项q高于g、一项q低于g。因此看到其中一项后，S对另一项真实构型的先验权重略降；machine对应权重不变。**这是当前设计与模型之间的方向性事实，不是执行得到的后验准确率、行动效果或F1下降。** 自身证据、候选收益、其他实例和路线成本都会改变实际结果，不可据此预判Ground终点。

## 4. 即便分布完全匹配，一名同伴能提供的共享信号也很小

对一名合格同伴，令 `r=Σq_h exp(L_h)/Σg_h exp(L_h)`，则

\[
 \min_h(q_h/g_h)\le r\le\max_h(q_h/g_h),\quad \rho=r/(1+r),\quad
 \operatorname{TV}(\pi_S,b)=|\rho-.5|\operatorname{TV}(q,g).
\]

已有 `shared_prior_capacity.json` 给出的上界是：cabinet活跃先验TV≤.042857，machine/rack/workstation≤.01875；支持语义表的正向上界通常更小。上界只约束**活跃先验**，不约束施加自身证据之后的后验。

完美知道一名同伴H_j=h时，还可直接写出

\[
 \pi_S(k\mid H_j=h)-b(k)
 =\frac{[q(h)-g(h)][q(k)-g(k)]}{2[q(h)+g(h)]}.
\]

所以在q接近g时，S相对B的这一步变化是类别偏离量的二阶效应；B相对G的初始类别作用则是一阶。累计很多帧把**同一同伴**看得更清楚，只能趋近这些一同伴边界，不能把一台设备重复当成许多独立同伴去放大可靠性。真正增加独立同类实例数才会改变这一统计容量；当前物理每类仅两台，且本次旧保存状态最大合格peer数确为1。

为了量化“即使模型正确也有多强”，对理想的 `P(Z=q)=P(Z=g)=.5`、条件独立抽样和完美同伴观测，离线穷举四构型联合概率得到：

| 类别 | 期望活跃先验TV变化 | 期望多类Brier风险下降 |
|---|---:|---:|
| cabinet | .020000 | .000681263 |
| machine | .011250 | .000285123 |
| rack | .011250 | .000285123 |
| workstation | .011250 | .000161774 |

后列使用 `E||P(H_i|H_j)-b||²` 的标准平方概率误差恒等式；它是模型内、概率预测层的纯代数结果，不是机器人质量增益。这些微小值说明一同伴可靠性学习本来就弱；但微小概率变化在候选接近打平时仍可能改变行动，不能推导为“完全没有可行增益”。

对固定候选a、成本c_a及构型面积向量A_ai，单实例变化满足

\[
 |\Delta s_a|\le \frac{w_I}{c_a}\operatorname{osc}(A_{ai})\operatorname{TV}(p_i^S,p_i^B).
\]

若竞争分差大于两候选各自最大变化之和，就不会改向；若构型面积全零或所有构型一样，换后验也没有直接作用。必须用含自身证据的实际后验TV检查这个式子，不能直接把先验TV上界当作后验上界。

| S轨迹 | 已保存共享变化 | 与返航前实际可规划实例的交集 |
|---|---|---|
| AISLE | 相对固定B第一次非零变化在step136；首次返航指令为126。全程最大后验TV约.010080。 | 返航前10次选中direct/diagnostic的重规划均无共享后验变化。 |
| CELL | 从step26出现变化；首次返航136。全程最大TV约.012320，返航前选中重规划最大约.012140。 | 13次选中重规划中3次（32/51/131）有变化，但被改变的实例与正预测面积实例交集均为空。 |
| LOOP | 全程无合格同类peer，rho=.5，与固定B相同。 | 18次选中重规划无共享后验变化。 |

CELL的具体断点：step32/51/131中，`instance_0001`收到workstation同伴的共享消息，却没有可靠标签平面，各分配视角的构型面积全零；有正预测面积的`instance_0000`仍为rho=.5。step60前者又因关联不确定退出类别条件。**“有信念转移”和“有方向性候选”分别成立，并不意味着两者作用在同一时刻的同一实例。**

完整保存的B/S动作序列在AISLE、CELL、LOOP均相同；可比G/B在AISLE、LOOP也相同。分析文件中的付费观测整体SHA跨运行不同，包含各自运行/帧标识，因此本稿不把整体SHA不同解释成传感数组物理内容不同，也不据此声称输入像素完全一致。

此前单实例one-hot目标后验反事实已显示AISLE有2次、CELL B有12次直接目标改向机会。但这允许把**目标构型直接变成确定真值**，远强于S从一名同伴获得的有限rho变化。它证明候选池不是完全无方向性，不能当作当前S必能实现这些改向的证据。

## 6. 与当前S相匹配的最小验证问题

应将问题写成：**当同类设备共享一个未知的类别先验可靠性域时，来自已付费同伴的几何证据，是否能通过可靠性更新改变另一个可规划实例的预算可行视角选择？其收益在何种候选分差、观测资格和成本下出现？**

最小模型对照必须保留相同几何证据和候选权限：G无类别先验，B固定混合先验，S只多同类可靠性共享。可依次验证：

1. **纯代数层，先明确可检验量。** 在 `Z_c∈{q,g}` 共享域下，构型在给定Z后独立抽样；四构型、两对象仅需每域16个联合状态即可精确求期望。应按其原概率加权完整状态，不强制一高分位一低分位，也不只取S有利配对。本稿已给出一同伴概率层容量，未生成场景。
2. **保存候选层，限定到S实际能到达的变化。** 对已保存的自身证据，考察一同伴允许的rho区间，而不是任意one-hot目标后验；固定其他对象、候选和成本，判断能否跨越实际选择分差。诊断宏动作还需同时支付诊断、后续观察及返航成本，不能用无代价信息收益取代完整动作评分。
3. **本轮Ground层，完成已有12项再判。** 核查共享后验变化、可靠平面/正预测面积、预算可行候选在返航前是否相交；检查实际B/S分数或宏动作差异是否可归因于共享。技术流程和共同指标必须通过，科学释放门不要求正的端点差异。Ground仅改善关联入口，不会改变两表混合模型、弱先验或固定分位的联合分布。
4. **若后续需要验证分布适应，另行预声明。** 在同一公开q/g及固定几何条件下，引入按共享Z条件分布生成的完整、概率加权配对验证；要检验“学习类内结构频率”则必须另建相应模型，不能把它归入现有S。此处仅提出可审阅下一步，不修改当前场景、不加强先验、不新增设备、不启动该设计。

当前固定分位场景依然可以展示空间布局下的联合覆盖/重建机制、前端修复和特定候选上的语义调节。它不能单独提供共享域分布适应的完整证据。是否继续主48，应待Ground全部12项与实际机制交集检查完成；本次分析不提前替代这一门槛，也不根据未知端点决定成功或失败。
