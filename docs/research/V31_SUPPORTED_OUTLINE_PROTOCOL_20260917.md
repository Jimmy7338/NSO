# V31：保留线段支持的外轮廓评价适用性实验

2026-09-17，首次新评分运行前声明。基于已知V30失败提出的开发修正，不是独立效果确认。0个新世界、传感、mapper、TSDF或主任务；两周主任务仍16/36。旧V23/V30源、协议、Q/J与失败保持原样。

## 问题与范围

用户任务是设施的外轮廓、位置和占用尺寸；不能把未观察顶面声称为已重建的三维表面。V23把退化三角投影删除，准确竖面在XY成为空预测。V31候选仅修正预测的投影表示，并检查整份输出的多余实例；不使用类别、访问次数、真值边界或轨迹来修复预测。

外轮廓不唯一决定完整3D。三个投影完全相同的内部多余面或缺面，本指标无法辨别；不能声称所有3D错误均受罚。只对可投影辨识的缺边、外扩、错误凹口桥接和多余输出设置反例门。

## 唯一候选算法，参数不搜索

每个预测实例完整输入，不GT裁剪、不对齐、不做凸包。三投影保持XY/XZ/YZ；所有数值单位米；阈值仍2/5/10cm，边界积分步长1cm。

数值退化阈值固定为二倍三角面积≤`1e-14`平方米，3D使用叉积范数，2D使用叉积绝对值。3D退化输入报错并留档，不能静默清理旧TSDF。唯一归属只统计非空输出，空输出携带的seed忽略，空extra不会使真实实例重复失配；全空时输出precision按0约定、Q为0。保留原C80等任务资格与新增输出gate两套字段。输出计数精度受实例切分粒度影响，不称表面几何精度或自然分割准确率。

1. 非退化投影三角形形成原始面集合。退化但长度非零的投影保留精确线段（最远顶点对），按几何集合去重。3D本身零面积的三角形拒绝为非法测量输入，不将点扩大成面或按顶点数量奖励。
2. 只对原始面集合的边界与退化线段作精确noding和polygonize；只闭合的已提交线环贡献二维面积。与原始面集合合并后，仅填有界内部孔，沿用外轮廓任务定义，保留非凸性和分離组件。不开闭运算、不snap、不增加连接线，绝不跨未观察缺口补边。重三角化的内部对角线不作为多余外边界。
3. 评价支持为最后二维外边界，加位于该二维面积以外的退化线段。未闭合的外部线段仍进入按长度加权的precision，参考边界对全部支持计算recall。面积IoU仍保留，Q仍取每投影min(F1,IoU)，三投影等权；没有闭合面积的投影IoU=0。精确几何与采样间距/数值误差界分开报告。
4. 参考构造和seed唯一归属沿用V30：仅评价端读取固定参考窗，预测没有真值裁剪。漏实例、重复或歧义seed对应的参考记0，固定任务数不变。新候选额外报告输出实例precision：唯一归属且非空的输出数/全部非空输出数（全部空时0）。候选Q/J为固定任务macro乘该precision，base macro同时保存。未归属的非空输出不能被丢掉，还使候选任务资格失败；不能把这个显式新惩罚冒称原V23定义。

## 预先规定的解析门

解析几何目录由 `V31_ANALYTIC_FIXTURES_PROTOCOL_20260917.md` 另行冻结，使用2×3×1.6米盒子和非凸L形、固定变形幅度，不按结果挑选。

- 闭合参考、准确全部竖面、同体重三角化和重复三角形：同任务Q5应≥.99，差≤1e-8；既不需要实测顶面，也不把补出的2D面积称实测顶面。
- 2mm测量薄壁：相同外轮廓Q5应≥.98，不按case选择数值容差。
- 非凸L的完整/竖面预测应≥.99；其凸包shortcut、凹口填桥、缺单侧开环、.3米偏移/外扩、多余分离box及外部open strip须比各自正确几何Q5至少低.01。此门检查可见的外形错误，不要求它们分数都为0。
- 全漏为0，漏一个固定两实例的base macro≤.5，duplicate关联的对应实例0；附加未归属非空输出必须降低最终候选macro并不合格。单纯边界F1不能绕过IoU或输出precision门。
- 非法3D退化面拒绝；输入数组不变；禁止新world/mapper/传感构造。图形和测试只为解析几何，不占主任务，也不当仿真轨迹。

正式主审计包含夹具目录17个几何+4个归属例；另固定增加绕z轴37度旋转并平移(4.25,-2.75,.3)的闭合/竖面成对例（都应≥.99且差≤1e-8）、原柜竖面一个角留1mm开口（XY面积应为0，不能自动补线）、一个x平移10米的未归属非空柜（应精确乘2/3且新增输出gate不通过）、空extra携带重复seed（不罚）、3D共线三角分别在已归属/未归属槽中的非法输入（两者必须拒绝）。因此26个合法候选评价和26个旧V30伴随评价，另2次预期非法输入拒绝。只读对照旧评分用于说明表示差异，不改门或算法。

解析主审计只运行一遍，先封存源码、目录、配置和本协议。失败结果保留且不因已知数值换阈值；实现错误需单独版本说明，不能覆盖第一次运行。预先定义的基本函数合同测试用于实现正确性，另记于主审计。
