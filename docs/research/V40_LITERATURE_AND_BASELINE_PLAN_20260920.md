# V40 文献、比较对象与证据呈现计划

日期：2026-09-20。范围：下一阶段虚拟实验与论文的方案设计。本轮新实验 **0 次**，未启动原作者系统安装、数据集下载或参数搜索。本文不修改已封存 V39 代码、结果和图，也不把拟实施内容写成已取得结果。

## 1. 当前证据起点与下一阶段问题

V39 的共同 CPU 比较包含 16 次主轨迹及 16 次完整重放，但独立布局只有 **2 个已在开发中使用的布局**。S/G 的平均 J5 分别为 0.745881/0.702576，相对增幅 6.16%；这个受控差异可以支持当前条件下类别信息的增量作用。SWAP-I/VISTA-I 是明确删改表示与动作空间后的机制适配，不能据此宣布击败 SWAP/VISTA 原版系统。来源：[V39 共同 CPU 结果审查](V39_EXTERNAL_CPU_RESULTS_20260920.md)。

原始 TARE 节点已完成四个迁移条件，但内部 360°×24° 可见模型、窄视场 RGB-D、平地 terrain 近似、路点投影及 adapter 返航存在实质差别；固定轨迹复核也未重执行原生策略。这组证据证明迁移链已运行，不构成完整系统公平排名。来源：[V39 TARE 迁移结果](V39_TARE_TRANSFER_RESULT_20260920.md)。

下一阶段应回答三个相互衔接的问题：

1. **任务价值**：在多个未用于开发的布局、设施类型和遮挡条件下，有限预算的探索能否同时形成足够大的地图与足够完整、准确的设施表面？
2. **语义机制**：语义是否提高对尚未看见结构和未来视角价值的预测，并通过实际动作改变产生重建收益？类别相关分数非零、动作改变和重建收益须分别测量。
3. **系统比较**：在信息、预算和后端一致的条件下，完整方案相对几何探索、几何补看、固定语义、语义巡检、结构预测等不同策略有什么收益和代价？哪些收益来自语义，哪些来自规划器与表示选择？

保留 ANS 层次结构与 OV-SDF、STGHP、RPN-UQ、IGCR 四模块接口。论文应区分接口、实际 CPU 实现和未来神经实现；不能通过引用原始方法的论文来补足本项目尚未运行的模块证据。

## 3. SPP 必须作为有实际竞争能力的结构语义比较

SPP 不只是给语义点更高权重。它从已观测语义场景图中挖掘重复/近似重复子图，预测未见部分，并以 PP-AE 辅助探索、PP-OI 复用检查视角序列。预测与实测的重合比例会调节预测作用，原文还专门测试缺失重复结构。因此，对本项目最有价值的比较是**同样允许结构预测，但预测、纠错和预算分配方式不同**。[SPP 原论文第 5 节及第 7 节](https://arxiv.org/html/2506.06560v1)

当前 V39 的单设施、双构型观测不足以直接建立 SPP 所需的重复多实例场景图。下一阶段的 SPP-I 先决条件如下，均须在开发集完成后冻结：

1. 从所有方法同等取得的已付 RGB-D 与已观测类别/实例关联构建图。节点是已检测实例，边是由已观测几何支持的空间关系；未见实例与边只能来自公开预测模型，不能从实际 GT 场景图复制。
2. 场景提供足够的可观测重复结构，也提供无重复、局部缺件、尺寸变化和错误类别等反例。可以预注册“至少两个已观测重复单元”作为本适配的启动条件，但须明确它是本项目决定，不能冒充原文固定阈值。
3. 分别记录检测误差、图匹配支持、预测位置/类别、不确定性、后续确认/否定和对应付费动作。观测不足时允许正常几何探索；预测错误后应降权或撤回。
4. 保留原机制的两个用途：预测位置帮助未知区探索；确认重复对象后减少冗余巡检设计。若只实现其中一个，名称和方法段应明确限定，不把类别 bonus 命名为 SPP。
5. 公共先验或训练数据在 S 与 SPP-I 之间列成信息权限表。S 使用的结构模板若同样有助于 SPP-I，应允许对照使用或另设信息匹配版本；不能把“不给对照结构知识”当作算法优势。
6. 对几何 NBV 保留基于当前测量的法向、距离、遮挡、视角多样性及质量欠缺信息。它不知道未观测类别不代表不能识别已经测到的缺口或欠采样表面。

第一周冻结选择：优先确认官方 SPP 的场景图、重复匹配与预测模块可在 CPU 开发例中工作，再决定是否采用完整核心适配或 SPP-I。若本地输入或源码依赖不足，只能选择事先定义的能力匹配结构语义替代，并公开原因；不能先看留出胜负，再更换一个更弱基线。官方仓库已经提供非预测基线、PP-AE、PP-OI 三类入口，可用于核验所保留机制。[官方启动方式](https://github.com/ntnu-arl/predictive_planning_ros)

## 4. 比较层级与信息公平性

### L1：本机共同 CPU 主矩阵及预冻结收缩方案

主计划拟采用 **8 种方法**：S、G、Frontier、几何质量 NBV、固定语义、SWAP-I、VISTA-I、SPP-I（或第一周冻结的能力匹配结构语义替代）。这是覆盖不同决策机制的矩阵，不是七篇论文各自完整系统的排行榜。

其中 S/G/几何质量 NBV/固定语义 NBV 为四种必做核。八方法为完整目标；仅能依据试点的接口及资源条件在打开独立测试之前缩减范围，未执行最接近结构语义对照时相应新颖性与优势主张也必须收窄。总计数以 [总计划](../thesis/V40_TOP_TIER_PAPER_PLAN_20260920.md) 为准。

|方法角色|需要保证的能力|需要回答的问题|
|---|---|---|
|S / G|相同公共几何、规划容量、质量账本及预算；明确仅改变哪些语义输入/利用机制|受控语义增量能否在未见布局复现？|
|Frontier|可用的探索与安全返航，不人为禁止进入设施附近|联合目标相对主要追求未知空间的代价/收益是什么？|
|几何质量 NBV|合法的几何补看、方向覆盖及距离/法向质量预测|收益是否只是“任何补看都会有”的效果？|
|固定语义|已见类别相关性 + 与主方法相同的公共几何质量能力|结构预测与纠错是否超过固定类别优先级？|
|SWAP-I|已观测目标表面检查、正确距离/角度条件及探索回退|相对语义巡检机制的规划差异是什么？|
|VISTA-I|真实正相关性、视角覆盖与重复抑制、共同公共支持|相对几何/任务相关联合视角评分的差异是什么？|
|SPP-I / 强结构语义替代|多实例结构预测、确认/失配纠错、完整几何回退|是否超过一个也利用结构语义推断的对照？|

所有方法共用候选可达性、付费传感、地图与表面后端、相机与雷达信息、初始观测、姿态噪声模型、碰撞和返航约束。共同候选或安全图如果是已知地图先验，应明确写为“已知可达结构下的观测规划”；若声称未知环境主动探索，就需要另设逐步发现的地图条件，不允许只对主方法隐藏这一区别。

原始预算须包括实际移动、转向、观测与返回；不能只数设施附近的有利动作。累计传感次数和真实墙钟时间分别报告。决策时间、账本/建图时间与系统总耗时采用相同分母；预处理、训练/模板构造和离线调参另列一次性成本。固定路线重放核验属于复现成本，不增加独立样本数。

### L2：有界原作者核心/系统迁移

沿用主计划的 **最多 48 条 L2 任务预算**，具体分配由统一冻结清单确定。优先评估原版 SPP 核心是否满足当前观测输入；SWAP 原版取决于完整代码是否可得。TARE 的可见性、尺度与执行接口问题在进入其新批次前解决。此处不启动任何任务。

进入 L2 公平比较前必须通过开发场景的接口门槛：真实相机 FOV/range 与内部收益模型一致；地面可达域和高度一致；传感采样密度与原版阈值关系明确；原生路点/停止与 adapter 投影/等待/返航分别记录；不以无限等待、额外扫描或预算外旋转补偿接口问题。不能满足时，结果只保留“迁移压力测试”身份，不混入 L1 排名。

原始 TARE、SPP 与 FALCON 任务能力和依赖不同，不预先承诺三者同时纳入完整系统比较。优先把一个几何原版与一个语义原版的可比性做好；若原版语义系统只能使用受控类别输入，需在原版、S 及其他方法上统一输入层，并如实写为感知适配。

### L3：GPU 资源可用时的条件扩展

ActiveSplat / ActiveGS 中优先选择一个与最终运动、传感和重建任务更吻合的完整系统；VISTA 原版用于开放词汇任务扩展；HERE 用于不确定性估计和辐射场探索研究对照。选择在开发兼容性与资源核验后冻结，不按留出结果选择。

本层不属于无显卡环境的必做项，也不以预计得分填补表格。若采用不同重建表示，应同时报告“共同轨迹、共同后端”的规划效应和“各自后端”的系统效应，不能将 3DGS 渲染指标与测量深度 TSDF 的表面指标混成同一优越性结论。

## 5. 从原论文具体借鉴哪些实验

### 5.1 多场景与失败条件：借鉴 SPP、FALCON 和 VISTA

- SPP 第 7 节与 Fig. 17/Table 3 对重复结构逐步缺失进行控制，并呈现预测和后续确认。可借鉴为“规律完整—局部缺件—关系变化—无规律”的轴，检查结构先验在失效时的代价。对本项目应保留几何、固定语义与预测语义三类对照，不能只在预测确实正确的样本上计分。[SPP 原论文](https://arxiv.org/html/2506.06560v1)
- FALCON 官方示例包含办公室、复杂办公室、隧道、复式办公室、迷宫和电厂，可借鉴其按空间组织而非仅按纹理区分环境的方式。本项目应按语义实例密度、房间/通道结构、遮挡、可达视角和规模进行独立分层；地图换色或重复旋转不算新的独立场景家族。[FALCON 官方示例](https://github.com/HKUST-Aerial-Robotics/FALCON)
- VISTA 的搜索实验区分遮挡程度与目标相对距离，并提供几何与语义对照。可借鉴为跨遮挡/距离分组，避免主方法只在目标接近且容易识别时获益；其 SR/TTR/SPL 是搜索指标，不能直接代替设施重建质量。[VISTA 原论文 Fig. 4/Table I](https://arxiv.org/html/2507.01125v1)

**建议的公平场景原则**：可以围绕语义结构有价值的真实任务假设构建场景，但必须在实验前声明假设、构造规则和适用范围，配套结构不匹配/弱语义/无语义负对照，并将真正未使用的布局与实例留出。场景难度通过几何遮挡、重复结构歧义、视角受限和预算竞争产生；不能通过评价器只奖励主方法偏好的标签制造优势。

### 5.2 补看价值：借鉴 SWAP、ActiveGS 与 ActiveSplat

- SWAP 的 Fig. 1/Fig. 5 同时给出全局路线和对象网格，网格颜色反映实际观看距离；这使“去过目标附近”和“得到足够好检查视角”区别可见。应借鉴 **已付观测的距离、入射角与视角支持图**，并增加最终真实表面误差/完整度图。[SWAP 原论文](https://arxiv.org/html/2303.07236v1)
- ActiveGS 比较基于观测方向分布的置信度与单纯观测次数，并按包含建图、规划和动作的总任务时间绘制结果。应加入“重复同视角”与“改变遮挡/法向覆盖的互补视角”开发验证，让几何 NBV 具备真实质量判断能力，再测结构语义能多做什么。[ActiveGS 原论文](https://arxiv.org/html/2412.17769v2)
- ActiveSplat 报告层次规划与可见性/几何边界组成的消融，并区分在线结果与额外优化后的显示。应将全局层、局部补看和质量门控的作用分别验证；所有展示图需标明是否额外离线优化，不能把不同优化预算的图片作为规划收益证据。[ActiveSplat 原论文](https://arxiv.org/html/2410.21955v2)、[作者展示说明](https://li-yuetao.github.io/ActiveSplat/)

一个地方是否值得补看应是待验证预测：由当前合法观测估计的收益，与之后真实执行该视角得到的增量对应。语义可预测尚未观测的结构和任务价值，几何可识别已经观测的欠缺；两者可相互补充，不需要人为规定无语义方法绝不能补看。

### 5.3 代理正确性：借鉴 HERE 的校准证据

HERE 比較不确定性与实际误差并使用 AUSE 等校准指标，而不是只给高亮热图。可借鉴“固定观测轨迹下的质量代理评估”与“自由规划的最终任务评估”分开：前者验证语义/结构预测和 RPN-UQ 的误差相关性，后者验证规划闭环是否兑现收益。[HERE 原论文 v2](https://arxiv.org/html/2601.07242v2)

建议测量的对应关系包括：预测未来表面增益与实际 ΔF1 的排序关系；预测可见性与实测支持是否一致；缺件/错误类别下置信度是否下降；同等距离与视角条件下语义还能带来多少增量。若代理预测无效，先修代理或适用假设，再扩大矩阵；不应靠更大规模重复无效机制的实验。

HERE 的 mesh culling 会剔除一些未观察区域；这一做法不能直接用于本项目的设施完整性主指标，否则漏看的表面可能从分母消失。主指标应按实验前声明的可达目标外表面固定 GT 分母，分别报告不可达/内部表面的排除规则。[HERE 评价设置](https://arxiv.org/html/2601.07242v2)

## 6. 指标与统计：避免“分数很高但任务没完成”

主表保留 **C_map、F1@5cm、J5=C_map×F1@5cm、成本和运行时**，并给出 C 和 F1 分开随预算的轨迹。面积与精度的乘积不能替代两个分量，也不能把单个终点 J5 当成足够的完整系统证据。

建议在开发集冻结以下附加输出，数量由主计划统一裁剪：

- **阈值敏感性**：以 5 cm 为主，使用固定较紧/较松阈值检验是否只在某一个阈值下获胜，不以测试结果挑阈值。
- **多实例质量**：同时报告按面积汇总和设施等权质量，给出最差若干设施或低分位，防止大而简单的表面掩盖关键小设施漏建。若有任务权重，必须来自预先任务定义并对所有方法共同适用。
- **预算效率**：覆盖—质量轨迹、预算内达到预注册 C/F1 双阈值的比例、首次达到阈值的成本；未达到的情况按删失/未完成报告，不把它们删掉后只平均成功例时间。
- **系统可靠性**：碰撞、无法返航、非法动作、超时和运行失败的数量与原因。连续质量统计与完成率分列，失败不可在主表里隐去，也不擅自把未知 F1 填成 0。
- **运行成本**：每步规划、感知/类别推理、账本与建图、总耗时和峰值内存；并列离线模板/训练和源适配的成本，CPU/GPU 原版分别报告。

统计独立单位为未见的布局/场景实例，不是帧、每步决策、重复重放、同一布局多个噪声种子。随机种子用来估计布局内波动；配对分析先按布局汇总，再做分层或按布局重采样的区间。场景族、布局、条件、种子和失败分母需在冻结清单中显式区分。旧 V36/V39 数据用于开发复现和历史证据，不重新命名为留出测试。

“整体系统表现更好”和“语义模块有增量”分别采用完整对照与控制变量消融。预算曲线面积、终点 J5、最差设施质量等若同时分析，应事先指定主终点，其他为次要结果；不事后选择最有利的一列代表总优势。

## 8. 优先级与停止条件

1. **第一周：机制与可比性冻结。** 核查 SPP 原核心、完成合法观测场景图开发例、确定强结构语义比较名义；检查 TARE 的 FOV/阈值/执行模型差异；冻结矩阵、指标、场景分层和算法调参权限。门槛是输入合法、机制真实激活、信息可比，不能要求主方法先赢才通过。
2. **随后：先完成多场景 L1，再扩大原版适配。** 在未进入留出前验证记录、失败计入与存储上限；所有方法按冻结设置进入完整计划。L2 受 48 条任务总预算约束，GPU 只作条件扩展。
3. **每阶段先判断机制，再判断规模。** 若结构预测在正确规律场景仍不能预测实际收益，优先修正模型或目标；若在正确规律中有效但失配场景退化，增加校准/回退并用开发集验证；若平均获益但成本不可接受，优化候选缓存、图规模和触发频率，保留质量约束。
4. **负结果保留。** 若强结构语义基线更好，应报告优势条件，分析模块设计，并在开发阶段据此优化主方案；不能从正式比较表移除该基线。任何改变留出协议的修订都生成新版本，保留原结果。

本阶段完成的标志是得到可复核的研究计划与资源可行的比较选择，不是承诺“顶刊接收”或保证某个增幅。接下来最有判别力的工作是让 SPP 类结构语义对照具备真实预测能力，并把主方案放到多个独立布局、规律失配和合法几何补看对照中检验。
