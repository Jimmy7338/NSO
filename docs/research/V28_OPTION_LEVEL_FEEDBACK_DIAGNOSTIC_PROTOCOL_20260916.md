# V28 选项级语义反馈诊断协议（冻结于 2026-09-16）

## 1. 目的与边界

本阶段只回答一个机制问题：V27 的 IGCR 在语义观测选项到达时使用的“最后一帧相邻观测改进面片数 / 16”是否能预测该选项期间真实取得的设施外形质量变化。

本诊断只读取已经封存的 V27 自主实验 case 01 与 case 03 传感包、规划记录和模块调用。不得产生新的自主动作、传感调用或主任务额度；不得把评价真值送回规划器；不得据结果改变样本、场景、阈值或标签定义。

评价真值仅用于回放结束后的离线标签和论文中的机制诊断，不构成在线方法输入，也不构成 V27 效果证明。

## 2. 冻结样本

- 输入批次：`audit_results/observed_autonomous_v27_20260916`，且必须先通过封存清单校验。
- 只分析反馈启用的自主 case 01、case 03。
- 纳入所有满足以下条件的 IGCR 调用：`selected_endpoint_reached=true`、`directional_updates` 非空且更新状态为 `updated`。
- 每一条方向更新是一条样本；预计 case 01 为 13 条、case 03 为 11 条，共 24 条。实际数量不符则停止，不补样、不删样。
- `option_id` 必须严格映射到自主运行中第 N 个非空全局规划结果；选项开始时刻是该规划的 `audit.action_id`，结束时刻是方向更新的 `action_id`。

## 3. 冻结标签与代理

对每个样本，在保存传感包的一次顺序回放中，于开始和结束动作的观测已融合后提取 V24 measured-only 实例网格。`cue-XXXX` 的序号映射到同序号观测实例槽；槽到参考设施的固定种子映射只在离线评价中使用。

主要标签为：

`delta_Q05 = Q05_end - Q05_start`

其中 Q05 是既有 OutlineEvaluatorV23 在 5 cm 阈值下、与该 cue 对应设施的 `outline_quality`。同时记录 F1 和终点网格哈希用于审计。标签表示整个选项时段的实现净变化，包含沿途观测贡献，不能解释成终点最后一步的因果效应。首次失败运行后的执行成本修正见 `V28_OPTION_DIAGNOSTIC_RECOVERY_20260916.md`；该修正未改变本主要标签。

冻结比较量：

1. `endpoint_proxy`：V27 实际在线值 `min(1, endpoint_improved_common_patches / 16)`；
2. `option_proxy_16`：用选项开始与结束的完整观测支持计算 `min(1, option_improved_common_patches / 16)`；
3. `option_improved_fraction`：`option_improved_common_patches / option_comparable_patches`；
4. 原始改进面片数、可比较面片数、选项动作长度、cue 类别与方向扇区。

所有完整支持仍只由观测白名单几何生成；评价 Q 不参与这些代理的计算。

## 4. 预先固定的诊断统计

分别对 `endpoint_proxy`、`option_proxy_16`、`option_improved_fraction` 报告：样本数、均值、标准差、取值数、饱和率，以及与 `delta_Q05` 的 Spearman 相关。仅在两变量均有方差时报告相关系数，否则明确标为不可识别。另报告 Pearson 相关作为尺度诊断，不替代 Spearman 主统计。

方向一致率定义为：代理高于其中位数时 `delta_Q05 > 0` 的比例；若不存在严格高于中位数的样本则不可识别。按 cue 类别（2/3）、case、cue 和扇区报告样本覆盖，暴露语义类别是否实际获得反馈，禁止用总体均值掩盖类别缺失。

当前在线代理只有在同时满足以下预设条件时才可称为“具备继续使用的最低校准证据”：

- 至少 20 个有效样本；
- 取值数至少 4；
- 饱和率低于 50%；
- Spearman 相关至少 0.30；
- 高代理组的正向 Q 一致率至少 60%。

任一条件失败，只能得出“当前代理缺少最低校准证据”，不能据此否定语义信息本身。类别 3 若少于 6 个样本，则复杂设施的语义反馈机制判为不可验证，不能用类别 2 的结果外推。

## 5. 完整性与停止条件

- 每个保存包只映射一次；回放不调用规划器、不驱动仿真世界、不产生动作。
- 允许构造两个只读参考 world 以建立既有评价器；传感调用和 world step 必须为零。
- 回放终点的 mapper/实例网格哈希和 Q 必须与 V27 封存终值一致，否则诊断无效并停止。
- 输出只保存 JSON 指标、清单和报告，不保存重复网格或传感包。
- 输出目录上限 2 MiB，并保留至少 64 MiB 实际空闲空间。

## 6. 冻结决策解释

- 若 endpoint 代理通过门槛，V28 优先保留代理，下一阶段只修正其在全局规划中的权重和类别覆盖。
- 若 endpoint 代理失败而选项级比例代理显示正相关，只允许设计“选项级、实例/方向条件化的残差反馈”，随后必须在新自主配对实验中验证。
- 若两类代理均无正相关，则停止继续调节 `/16` 或反馈平均公式，转向直接由观测网格不确定性构造可验证的语义视角价值；仍保留四模块与层次结构。
- 本诊断不能证明整体方案优越，只用于决定下一次有限主实验是否值得执行。
