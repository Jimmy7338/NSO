# V26 观测边界与自主候选接口结果

2026-09-16。已完成可运行代码、31项专项测试和235个既有传感包的离线决策检查；没有启动新物理任务。结论是信息边界和决策接口已打通，不是语义或整体方案优势已经成立。

## 根因定位的精确修正

旧固定A/B四任务确实从GT附件可见性和GT安全图预先取得整条路线，因此不测试自主目标发现。

另外审查旧V21在线原型发现：V20覆盖候选只用belief，V16.3设施候选先按几何聚类，不能声称它们直接使用标记定位候选。真正泄漏任务目标识别信息的是V19质量评分的`marked_points > 0`筛选，V21 G继承该评分。只去掉类别数值而保留这个筛选，仍让G提前知道哪些几何簇属于设施。详见`V26_OLD_CANDIDATE_BOUNDARY_REVIEW_20260916.md`。本轮首次进度消息中“补看候选先由标记定位”的表述已经纠正。

## 已实现的代码

- `nso/observed_state_v26.py`：独立几何白名单、不可写快照、语义记忆。G输入不含RGB、类别、标记中心、场景/排列字符串或GT目标。所有实测patch按相同几何规则取样。语义线索只从实际RGB与同像素深度生成；不采信`frame.semantic`作为识别结果。
- `nso/observed_planner_v26.py`：覆盖/几何补看/类别方向假设候选、来源日志、G/GP/GR/S/去反馈模式。G与GR在同一快照共享最终几何候选；主G/S允许候选不同。候选≤4覆盖＋8其他，另报预筛选查询量和CPU时间。轨迹只用已观测安全格，成本包含转向与返航。
- `nso/observed_runtime_v26.py`：动作0冷启动、ANS全局/局部交互、连续动作—观测核对、所有模式一致的帧ID防重、四模块调用日志、碰撞停止。局部每步刷新路线，不接受预定GT路线或付费前缀。
- `scripts/preflight_observed_decisions_v26.py`：只读取既有传感包及公开配置白名单的离线来源检查。打开旧result文件提取传感配置与地图shape，但没有把其GT/评价/路线字段传给规划器。

OV-SDF和STGHP此处为实际观测表示与CPU规划实现，RPN-UQ为确定性观测门，IGCR为实际局部支持反馈。接口调用不等于原训练网络已恢复或四模块净贡献已证明。

## 不能据此推出的结论

当前S仍用公开但未训练的稀疏模板/类别权重；颜色一致性不是自然语义网络置信度，IGCR局部方向/距离支持不是实际外形Q，也不是整条option的累计收益。几何补看代理尚未通过自主强基准验收。语义现在能改变决策，只满足“信息进入决策”的必要条件；没有证明所选动作更好，更没有证明相对模板纠错方法的创新性。
