# V24 保存深度上的共同外形后端开发协议

日期：2026-09-15。在读取新后端的 V23 阶段质量结果前声明。此协议不改 V23 原协议、数据或分数，不采集新传感、不重新执行机器人动作、不训练语义模型。

只使用 V23 两条完整记录的0—96包，按原顺序输入 `ObservedShapeBackendV24`。阶段固定为粗扫23、补看73、返航96，不增加最佳阶段选择。每阶段以旧保存的原始TSDF网格为实测网格输入，后端根据已有深度识别地面和单个设施，再给出可撤回的规则外壳推断。新的结果仅属于已看过的开发记录。

设施种子来自已观测RGB人工标记的二值位置，不传递类别值。第一个有标记且有有效深度的帧中，选择最接近标记命中点中位数的实际命中点，后续只靠几何关联；两类标记颜色不同但二值位置相同。读取RGB标记的前端对所有几何与语义方法共同提供这一关联；它尚未实现自然实例分割。后台不接收类别、模拟实例ID、世界、真值窗口、参考或隐藏尺寸。

主交付表示预定为 `completed_mesh = observed_mesh + inferred_mesh`。后者只有在支持条件成立时非空；否则保留清理后的实测网格。两种来源必须分开保存，不把推断面计为实测证据。原始TSDF的旧分数及清理后实测表示作为并列诊断，不能逐结果挑最高分。沿用已冻结V23外形评价的三个投影、Q、J、5厘米完成门和评价侧对象参考；原始V19外表面F1和连续误差保留于V23原证据，不用推断面冒充实测表面精度。

算法固定参数写入冻结源码：重力方向默认世界z上（需实车标定）；法向约束25度、平面支持至少40点及候选池15%、地面不确定带2.2厘米、实例连通网格8厘米、网格局部支持10厘米、三角边不超过25厘米、边界夹持8厘米、有效背景深度差超过 `0.12+0.005*z²` 米、自由射线冲突余量 `0.08+0.005*z²` 米。超过2‰且至少3条有冲突射线即拒绝规则外壳；至少3条有效边缘射线支持每个外形端点，底面须有观测近地支撑。外壳是带假设的规则矩形推断，不表示两面已唯一确定隐藏几何。存在非规则附件时可拒绝补全并保留实测，不强行做凸包。

地面选择在有足够支持的平面候选中优先最低实测高度，避免把大平台顶面当地面。仅靠近地面的不确定点不参与实例连通，但仍保留原始/未归属证据，不能声称2.2厘米以内细节可靠分离。低位真实附件、倾斜地面、单前板、截断边缘、自由射线冲突、重复帧、未知种子、较大平台和远离实测支持的三角形先用独立解析夹具检查。

运行前冻结本协议、后端、驱动、测试和依赖版本，以及V23原始证据清单。独立新进程重复同一保存数据处理，比较种子、几何摘要、全部六个阶段网格和新分数；这属于共同后端开发数值复核，既不是新的物理回放，也不是新增独立场景。执行中失败保留失败回执，禁止改冻结算法再接着旧进程。

本次只进行这一版共同后端开发回放。保留未完成和拒绝原因；不把简单柜全部5厘米完成作为语义选择实验的必要条件。后续按 [V24双对象选择设计](V24_COMMON_SHAPE_AND_PAIRED_CHOICE_PLAN_20260915.md) 检查真实选择信息和资源竞争，完整四模块、未见布局与实车要求仍保留。
