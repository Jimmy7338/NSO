# 单项地面关联修正与固定路径反事实协议建议

状态：只读诊断后的未来版本建议，尚未实现或试跑。v1的58项执行源码、场景和12条开发槽位保持不变。依据为 `ARTICLE_AISLE_DEVELOPMENT_DIAGNOSIS_20260928.md` 与 `analysis_v1/aisle_gbs_association_audit_v4/`；不以新版本必须取得正收益作为资格条件。

## 唯一建议的算法修改

在**对象关联候选构造**中，排除由公开相机安装高度和当前付费深度共同确认的地面带。该掩码应用在深度连通分量构造前，因而地面像素不会进入新对象支持缓存，也不会成为随后0.4 m支持增长的桥梁。其余关联歧义拒绝、类别两次支持、几何新颖性、反馈上限、共享推断及候选预算规则全部保留。

完整原始RGB-D仍用于TSDF、占据地图和最终评价，不删除重建中的地面，也不裁剪任何评价区域。G/B/S/NBV采用同一几何前端。过滤不得读取类别值、设备尺寸、结构类型、私有包围盒、网格归属或评价真值；不得按类别选择不同地面高度或阈值。

## 当前接口允许什么假设

公开 `public_planner_spec.json` 已给出相机安装高度0.9 m、精确位姿、1%轴向深度标准差、0.25 m平移和30°平面转向。传感实现 `DevelopmentSensorV41.camera_transform_xyyaw` 使用固定相机高度与世界竖直方向。因此本受控平面移动平台允许明确声明：已标定安装高度、已知重力竖直方向、工作地面水平、单次建图期间静态。`world_from_camera[2,3] - camera_height_m` 给出这一模型下的地面高度假设，不需要读取场景私有几何。

公开工作区没有任意地形真值接口，所以上述假设不能推广到斜坡、楼梯、多层地板或安装高度未知的平台。存在这些情况时应保留旧行为，或另设已验证的观测地面估计协议，不能继续硬编码z=0。

## 建议预先固定的保守实现

1. 从当前合法深度、K、T重建世界点与投影光线，计算标定给出的地面高度假设。所有运算只依赖当前已付费数组和公开规格。
2. 按轴向噪声传播计算每点竖直标准差：`sigma_z = 0.01 * depth_z * abs((R @ inverse(K) @ pixel_h)[2])`。只有接近预期地面、且构成足够大二维支撑区域的点才支持地面模型。可在新协议中一次声明64个深度像素、两个水平方向跨度各不小于0.5 m，以及1 cm额外标定容差；这些是工程设计常数，不能在查看方法成绩后反复调整。
3. 使用被约束为水平的鲁棒位置估计（例如候选z的加权中位数）核验地面高度；偏离标定假设超过3 cm、支撑不足或残差不符合声明噪声界时，**整帧回退旧候选构造**。不根据语义判断哪一片是地面。
4. 仅将通过核验的地面带内点从对象关联输入中排除，带宽为`3 * sigma_z + 0.01 m`并设置6 cm保守上限；超出该上限的噪声条件不强行扩带。接近地面的真实设备接触边缘可能也落在该带中，必须报告这一前端限制。它们仍保留在完整重建和评价中。
5. 从第一帧开始构建新版本的独立支持缓存；不从旧缓存直接删除部分点后沿用旧证据SHA，也不把旧支持上的残差套到新掩码。每次保存地面假设、支撑数、残差、阈值、原始观测SHA和掩码SHA。

该修正的作用对象是造成实例支持扩张的近地连通区域。它不负责解决全部同实例碎片化、真正的双实例争夺或错误类别。若这几类歧义仍存在，原拒绝规则继续生效。

## 固定路径反事实实验

输入为已完成且独立复核通过的开发记录，使用封存的实际动作、RGB-D和雷达。先在三方法完全相同的AISLE实测路径上隔离该单项机制；随后可覆盖其余已声明开发路径，不重新渲染传感器，不创建World，不执行新运动，不重融合TSDF，不重测原路径质量。

先做旧前端控制回放，要求实例登记、关联拒绝原因、支持哈希、类别支持数和有效反馈与原保存记录一致。通过后，再用只增加地面关联掩码的新前端从初始帧重建**条件于这条固定路径**的证据历史。

对每个原已保存的重规划时刻，使用同一公共图、实际位置、剩余预算及原候选集合计算反事实评分。冻结候选集合可隔离关联修正的影响；这不是完整新规划器的在线运行。若某时刻新方案会选不同动作，标记该时刻，从其后继续使用原路径取得的证据必须标为离策略、条件性诊断，不能写成新方案已执行的因果轨迹。

实例ID可能因连通分量变化而不同。仅允许用已观测marker位置和不可歧义的几何对应比较轨迹身份；不得用私有设备ID强行配对。对应不明确的实例单独报告，不补齐为成功。

必须输出以下全部结果，无论正负：

- 地面模型通过/回退次数、排除像素比例，以及原始传感数组未改动的哈希证据。
- 近地支持进入缓存的数量、局部支持重叠、单实例碎片化、多实例争夺和类别冲突，分别计数。
- 初次观测、类别首次达到门槛、关联资格丢失/恢复、首个有效几何反馈、首次可靠平面的完整时间线。
- S/B的合格同类peer首次同时存在时间、ρ及结构后验差、非零预测、预算可行动候选、首次候选排序/动作意向差。
- 未能对应的身份、被隔离的测量、仍然存在的零预测或无预算情形。不能只报告减少的歧义数量。

固定路径审查可以回答“前端背景连通是否阻断了本应保留的有效跨实例信息，以及修正能否让该信息在尚可行动时进入评分”。它不能回答新策略的最终J_nav或重建质量是否更好。后者必须另起正式冻结版本、使用声明的布局单位和预算进行真实闭环对照。若旧控制回放不能一致，或新版本需要放松歧义/证据门才能出现差异，应先报告这一失败边界，停止向质量优势推断。

本建议不同时加入类别永久记忆、降低平面门槛、增加候选上限或重设语义权重，避免无法分辨究竟是哪项变化产生作用。
