## 2. 缺少的是XY区域支撑，不是正面和侧面整体没测准

![原阶段网格与参考的三投影](/root/NSO/audit_results/facility_shape_v23_diagnosis_20260915/coarse_extra_projections.png)

图中蓝色为固定评价参考，橙色为真实保存 TSDF 在**原冻结评价窗**内的投影；该窗口仅用于解释原分数，不是在线实例裁剪或补全。没有额外删点、三维填充或清理后重评分。

简单粗扫的 XZ、YZ IoU 已为0.949210、0.926530，而 XY IoU 只有0.013340。前壁和左壁在俯视中只是两条相接的窄带；真实立面接近竖直时，其XY投影接近线，深度噪声给它有限厚度，仍不是完整占地面积。XY预测面积0.069364m²，参考1.280000m²，且有19个分离组件。冻结实现只填闭合投影的有界内孔，不把开放L形自动补成矩形。[投影并集与内孔处理](/root/NSO/utils/facility_outline_v23.py:43)

补看后四周立面形成近闭合投影边界，XY IoU升至0.925369；不应把这解释成相机已从上方测得柜顶。固定相机高度0.8m低于1.6m柜顶，台架没有俯视俯仰或升高传感器。简单ΔQ的三个代数贡献为XY **+0.268462**、XZ −0.001485、YZ −0.042541，主要增益来自XY区域闭合，其他投影甚至局部变差。这不是三个独立因果效应。

## 3. 近地面碎片确实污染了极值与边界；仍有其他真实残差

补看73时简单柜的原外表面 F1=**0.995897**，平均表面误差=**7.432mm**；但外形Q=0.808679、Y尺寸误差=0.548863m、XY/YZ Hausdorff上界约0.484408m。它们不是在度量同一件事：表面F1按面积采样，尺寸和Hausdorff受极端点影响，边界F1又会保留小分量的周长。

从冻结评价窗中的极值，追溯到**原始保存网格三角形**，得到直接证据：

| 阶段／异常 | 实际位置与高度 | 原网格证据 |
|---|---|---|
| 简单粗扫 X最大 | x=5.20m，z=0.010—0.020101m | 对应点来自贴地三角片，而不是柜顶或侧后附件 |
| 简单粗扫 Y最大 | y=4.72m，z=0.010—0.021970m | 已到评价窗后边界；柜体真实后边为4.0m |
| 简单补看 Y最大及XY/YZ最坏边界 | `(3.66, 4.479408, 0.01)`m | 原三角形z范围−0.000452—0.013853m，面积0.000864m²，法向竖直分量绝对值0.925568；这是近水平地面残留 |
| 简单补看 X最大 | `(4.884255, 3.74, 0.01)`m | 原三角形z范围−0.003825—0.013921m，法向竖直分量绝对值0.951023 |
| 两类持续存在的 X最小 | `(3.143554, 3.30, 0.86)`m | 原三角形近竖直，法向竖直分量绝对值0.032730；相对x=3.2的柜侧偏出5.645cm，不能归入地面 |

这里z=0.01的一些点是冻结评价窗口与原三角形的交点，并非假称原文件中恰有同坐标顶点；诊断JSON保存对应原三角形编号、顶点、面积、法向和最近点。

简单补看的YZ投影除主体外有三个分离小组件，面积约0.000694、0.000381、0.000163m²，均在z≤0.023192m。5厘米以下三角片总面积只占窗内表面的1.3077%（其中也包含真实物体底缘，不全是错误），却足以控制尺寸极值。固定窗为复杂右后凸起预留空间，接纳了这些地面残留；仅排除0—1厘米接触带无法保证原始 TSDF 地面不会上浮进入窗口。

这些证据支持地面残留与实例归属是重要根因，**不证明删除低点便能通过所有条件**：柜侧还有5.645厘米偏差，补看YZ IoU=0.893536也低于0.90，预测边界包含局部噪声与多个组件。本审计没有输出真值筛点、最大组件保留或抬高裁剪面的改进分数。

## 4. 下一步选择与必须跨过的门

优先验证一个**各方法共享、不读类别的几何后端**，保留原始 TSDF 作为并列基线。它先从实测点及射线识别地面、外点和实例支持，再在足够证据下拟合外形；不能把 GT 评价窗口直接交给后端。地面分离需要实测平面、法向/多帧支持和误差尺度，不能按本次真值规定“z<某数全部删掉”，否则会误删真实低位管件或底座。

粗扫已有两正交立面和边界时，可以审查其能否约束规则柜体的主要尺寸，并用公共几何先验形成带置信度的闭合外形。它必须区分“测得的表面”与“由几何模型推断的面”，不能声称已经观察隐藏背面。两类粗扫输入相同，公共后端在此阶段应输出相同几何；复杂隐藏凸起须在新观测后修正，不能从类别或真值尺寸预置。仅两个立面不普遍唯一确定物体，应在非柜形、开放凹口、局部遮挡及不完整边缘时拒绝过度补全。

若这套公共建模仍无法在误差内约束边缘/尺寸，才增加有具体目的的共同观察阶段，并支付真实移动和转向；单纯延长绕行会让简单、复杂都付出密集采集成本，可能直接消耗掉希望验证的信息窗口。提升相机高度/俯仰属于新硬件观察能力，不能给当前小车免费增加俯视帧。

进入六工位之前应依次满足：

1. **后端隔离与反例门：**不读 GT 窗口、参考、隐藏尺寸或类别；相同非语义历史输出相同几何；不能误删真实近地附件或把离散碎块拼成虚假的完整柜体；与实测自由射线矛盾时拒绝填充。原始、清理后实测、几何推断三种来源分别保存。
2. **阶段机制门：**冻结后端和原外形验收标准后，简单23步达到预声明完成要求；复杂隐藏凸起仍被合理扣分，补看带来更大改善，实际几何揭示窗口继续成立。若不通过，保留失败并定位，不能在三种输出或多个指标中择优报告。
3. **实际路线与泛化门：**若改变观察阶段则重新冻结并付费执行/独立回放；共同后端需通过非典型设施与噪声边界，再验证六工位公共基本建档、返航和补看预算竞争。当前两个固定形状、一条脚本路线、一个噪声种子不能证明语义选择或整体架构有效。

本诊断产物是原始分数的可复算解释，非新算法成绩。源码、输入和图的SHA见 [产物清单](/root/NSO/audit_results/facility_shape_v23_diagnosis_20260915/artifact_hashes.json)。
