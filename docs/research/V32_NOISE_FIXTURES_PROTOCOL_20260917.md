# V32 解析误差、缺口与观测歧义夹具

2026-09-17，先冻结本协议，再实现和运行几何单元测试。本轮只构造 NumPy 顶点/三角形，复用冻结 V30 的准确 Box 并集和 V31 网格工具。不调用 Q 评价器、World、传感、mapper、TSDF 或旧实测网格，不新增主任务。没有 Q 通过门，不能根据之后评分改夹具。

## 公共几何与 API

基础柜为 `[0,2]×[0,3]×[0,1.6]`，竖面用准确外表面中非 z 法向面构造。`NoiseFixtureV32` 含 `name`、`references` 与 `predictions` 两个只读网格元组、`labels`、`facts`；`noise_fixtures_v32()` 返回固定 33 案，`noise_fixture_names_v32()` 返回固定顺序名称。所有标签仅解释解析测试，不是语义输入，不含 Q 目标。

单实例默认参考为闭合实心柜、预测为四竖面。两实例分别保留两个参考和两个预测，不允许把参考数量随输出缺失或合并而改变。`facts.reference_seed_xyz` 是显式解析归属元数据，不是假造的已付费传感种子；seed 位于公共外侧前面，不用于修复预测。后续若使用归属窗口，应取各参考准确外界或小于间隙一半的外扩量，不能以固定 0.1 m 扩窗给 10 mm 近邻引入人为重叠。

## 固定 33 案

### 1. 八个单角竖面缺口

`corner_gap_000mm/001mm/005mm/010mm/020mm/050mm/100mm/300mm`：仅把 `x=0` 左面从原 `y∈[0,3]` 截至 `y∈[g,3]`，其余三竖面不变。g 分别为 0、1、5、10、20、50、100、300 mm；少掉的面积恰为 `1.6g`。g>0 时 XY 精确线环有开口，两端欧氏距离为 g，不能把 gap 参数传入任何候选算法。参考一律原闭合柜，标签为可能的漏观测形态，不将它宣称为物理空洞。

### 2. 七个整体定位偏移与三个小旋转

`translate_x_001mm/005mm/010mm/020mm/049mm/050mm/051mm`：四竖面沿 x 平移指定距离，参考不动，不按参考配准。其中 49/50/51 mm 三案专门揭示 5 cm 阈值附近可能的跳变，不要求指标连续或自动容错。尺寸保持 2×3×1.6，中心误差就是平移量。

`rotate_z_0p5deg/1deg/2deg`：四竖面绕固定柜中心 `(1,1.5,0.8)` 的竖直轴旋转 0.5°、1°、2°，参考保持原姿态。刚体面积和两点距离保持；世界坐标包围盒通常改变，不能混称尺寸拟合失败。变换参数只作 fixture truth/fact，不供候选进行逆变换。

### 3. 一整侧缺失、六个双实例近邻案例与一个 L

`one_vertical_side_missing`：删除整块 `x=2` 面，面积少 4.8。

`neighbors_gap_010mm/050mm/200mm`：两个独立闭合柜体，第二柜沿 x 平移 `2+g`；准确最短距离为 10、50、200 mm。两参考和两预测逐实例一致。对应 `neighbors_gap_010mm/050mm/200mm_wrong_bridge` 在第一预测并入一块实心错误条：`x∈[2,2+g], y∈[1.35,1.65], z∈[0.65,0.95]`；第二预测与两参考均不变。新增实心体积为 `0.09g`，其端点真的接触两柜。不能把近邻正确实例间的空隙自动补成这种桥，也不能把桥误归入第二参考来消除错误。

`concave_l_vertical`：沿用 V31 两个盒并集的真实 L，XY 面积 4，体积 6.4，竖面面积 16，凹口保留。预测只含真实竖面，参考为完整 L。

### 4. 三个独立面片小扰动

`independent_face_jitter_001mm/005mm/010mm`：采用 NumPy `default_rng(320917)`，按 V30 竖面固定顺序一次产生四个三维向量，逐分量均匀分布 `[-1,1]`；分别乘 1、5、10 mm，刚性平移各自完整矩形面。三档共享同一随机实现，不能算三个独立噪声种子或统计重复。每个面始终是同样面积的有效平面矩形；不独立抖动四角，不产生零面积、扭曲四边形或额外三角化差异。每个坐标扰动不超过幅度，欧氏位移不超过 `sqrt(3)` 倍幅度；不把幅度误称标准差。不同面边缘可能出现缝或重叠，这正是夹具要保留的性质，不做吸附修补。

### 5. 两个完全相同输入的真实闭合歧义案例

`ambiguity_closed_solid_missing_corner` 与 `ambiguity_true_open_shell_same_observation` 的预测数组完全相同，均为 `corner_gap_010mm` 的四外侧竖面观测。A 真值为闭合实心柜；B 真值是同外尺寸的真实 2 mm 薄壁结构：前壁 `[0,2]×[0,.002]`、后壁 `[0,2]×[2.998,3]`、右壁 `[1.998,2]×[0,3]`、左壁 `[0,.002]×[.010,3]`，均高 1.6。B 在左前角存在从 y=.002 到 .010 的 **8 mm 真实通口**；共有预测未包含内侧面、材料厚度端面、顶底面。相同预测的每个三角面都与两种真值兼容。

两种真值都由准确盒并集生成闭合、可定向的材料表面。**材料网格 watertight 不等于外壳封住内部空间。** A 的外侧围合闭合；B 的内部空间真实连通外部。候选只看同一输入就必须产生同一预测表示；这对例子证明 mesh-only 表示不能认证真实封闭性，不要求它同时对两种真值高分或自动分辨窄缝。两案可供后续独立 Q 评价，但本模块不评分。该不可辨结论只针对所给网格：没有声称完整深度/自由射线历史或额外视点也相同；这些额外证据可能消除歧义。

### 6. 两个真实薄壁材料形态

`thin_walls_continuous_002mm` 沿用 V31 以原四竖面为中心的 2 mm 薄壁并集，外尺寸 2.002×3.002×1.6、材料体积 .032。`thin_walls_001mm_opening` 仅把左壁 y 下界由 -.001 改为 .002，前壁 y 上界仍为 .001，形成 **1 mm 真实通口**；其余盒不动。两案参考仍为原柜，预测保留完整薄壁材料外表面，不把薄壁当实心真值。均是合法闭合材料网格，外壳围合状态不同。

## 单元验证与资源

独立几何测试须核固定目录、已知缺口与去面面积、刚体变换、扰动四面非零且面积/平面性保持、真实 L 凹口、正确近邻间隙及桥体积、歧义 pair 输入字节相同与真值不同、B 通口可穿过而前壁厚度段不可穿过、两种薄壁材料的准确闭合边界。测试可用解析线段/三角形交点与网格拓扑计算，不查询项目世界或投影评分。

全部文件和小型证据限制 2 MiB，保留 64 MiB 磁盘，CPU 单线程并 `-B`。首次构造或断言失败保留后仅修可证代码/夹具错误；禁止运行评分后改噪声、缝宽、间距、种子、旋转角或参考定义来争取通过。
