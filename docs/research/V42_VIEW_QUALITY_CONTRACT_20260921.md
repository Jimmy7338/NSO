# V42：从已观测信息预测候选视角的新表面积

日期：2026-09-21。代码：`nso/view_quality_v42.py`；测试：`tests/test_view_quality_v42.py`。

本模块补齐 STGHP 的候选视角收益接口，保持 ANS 层次和四模块名称。输出是**预测的、尚未观测的名义外表面积（m²）**，不是实际 TSDF 精度、覆盖率、实验优势或完整规划结果。

## 调用和观测证据

```python
predictor = ViewQualityPredictorV42()
association = ledger.observe(paid_rgbd)
predictor.observe(paid_rgbd, association['accepted'])
# IGCR 可以在此时更新 ledger 的结构后验。
result = predictor.forecast(ledger.snapshot()['instances'][0], public_candidates)
```

候选项严格使用 `CandidateViewV40` 的相机内参、世界位姿、图像尺寸与轴向深度区间 `[0.1, 4.0] m`。构造候选位姿不需要生成候选图像。导航可达性和返回预算由 V41 路由器检查，预测器不作可达承诺。

`observe` 对当帧支付步、帧 ID、观测 SHA、支持点 SHA、像素索引、实测反投影坐标和标记像素包含关系逐项验证；关联记录与实例快照采用字段白名单。点集来自当帧深度，禁止传入真值位置、设备实际尺寸、网格、未来深度或类别重要性权重。重复传输同一帧拒绝；付费的新静止帧允许接收，但完全相同的 RGBD/K/T 不重复扩大支持。重复判定含数组 dtype 和 shape，与 V41 一致。

预测器独立调用 V41 的实测标记平面拟合，并保留首个可靠平面。它不读取 IGCR 的私有缓存。新拟合与缓存的位移大于 0.15 m，或法向偏差超过 20°，永久标记本实例的平面冲突。无可靠平面、平面冲突或关联不确定时，该实例所有候选收益为零，并返回原因；调用方可继续使用独立的覆盖探索收益。

支持缓存使用与 V41 相同的固定首点体素规则。`support_voxel_m=0.05`、`maximum_support_points=4096` 必须与调用方账本一致。预测时要求快照支持点及散列等于该缓存，避免把未支付的预测表面冒充为已测表面。结构后验必须等于 `normalize(active_structure_prior × exp(geometry_log_scores))`。该检查验证代数一致性；几何反馈是否来自有效 IGCR 调用，仍由账本调用链和集成收据证明。

## 面积预测与语义入口

所有条件使用同一个 V41 名义库：`planar / recessed / louvered / open_frame` 四种结构，各有 0.85、1.0、1.15 三个名义尺寸比例。库的源代码和数值 SHA 进入收据。三个比例等概率；它们没有根据当前真实设备尺寸筛选或调整。

每个名义实体通过已观测标记平面的锚点和法向定位，沿用公开的竖直标记安装假设。由实体盒子的并集生成外表面，去掉内部重叠面，再作确定性的三角形面积积分采样。对每个候选相机：

1. 检查轴向深度、图像边界和朝向相机的外表面法向。
2. 沿候选相机至名义表面点的射线，检查盒子并集的第一个表面交点，排除自身遮挡。
3. 距累计实测支持点不超过 0.08 m 的名义点视作已观察；剩余可见点的面积权重求和得到每个结构/尺寸的新增面积。
4. 对同一结构的三个尺寸求均值，再以账本的结构后验加权，并乘以未重复相机视角的资格掩码：

\[
U_i(v)=\mathbf{1}[v\notin\mathcal V_{\rm paid}]\sum_{s=1}^{4}p_i(s\mid D_{0:t},c_i)\,
\frac{1}{3}\sum_{a\in\{0.85,1,1.15\}}\widehat A_{i,s,a}^{\mathrm{new}}(v).
\]

其中 `D` 是已支付观测；`c` 只通过 OV-SDF 的有效结构先验影响后验。预测器不会直接读取类别作为加分项。G 与 S 的几何支持、名义库、可见性计算和每结构面积完全相同，差别只能来自后验混合权重。类别先验平坦时，S 应与 G 相同；错误或置换先验可能降低实际效果，不设必须改善或必须改变动作的验收条件。

V42 首次接线发现：相同相机视角已实际支付，名义表面与缺失深度的差异仍可能留下正预测面积，导致原地反复拍摄。r1 因此加入保守的资格规则：候选的 K、T 与任一已支付相机相同，且图像尺寸相同，则有效新增面积收益为零。K/T 比较使用绝对误差 `1e-9`、相对误差零，能识别 330° 与 −30° 的同一姿态表示。位置相同但旋转不同、改变位置或内参/图像尺寸仍可获得预测收益。

这是一条针对**静态环境、新视角面积收益**的策略资格规则，不是“这张图中所有预期表面已经测到”的推断。历史包含未关联到目标的已支付帧，包括深度全部缺失的帧；这些帧不增加已知支持点，也不把缺失深度变成自由空间。规则没有建模噪声重试、暂时遮挡变化和分割重试收益，可能保守地拒绝实际有用的重拍；不能据此宣称重复观察无价值。重复观察的真实精度收益需要单独建模与验证。

## 输出与计算边界

`result['candidates']` 的每行包含 `view_id`、`expected_new_surface_area_m2`、四结构顺序的 `structure_new_surface_area_m2`、`structure_visible_area_m2`、12 项 `components` 和候选参数散列。有效收益和 `structure_new_surface_area_m2` 应用资格掩码，保持二者的后验期望等式；`components` 保留掩码前的原始可见/新增/已见面积，`unexcluded_structure_new_surface_area_m2` 和 `unexcluded_expected_new_surface_area_m2` 保留原始预测。`repeated_view_excluded` 与 `matching_paid_views` 记录掩码原因、匹配帧 ID、支付步、观测 SHA 和相机几何 SHA。几何证据包含全部已支付相机历史 SHA，未关联帧改变资格也能追溯。顶层另含关联观测源帧、平面来源、支持 SHA、原型库 SHA、配置与源码 SHA，以及所有能力限制。

默认采样间距 0.08 m，每个原型不超过 20,000 个积分点；每次调用不超过 256 个候选；最多 64 个实例、512 帧。最近实测点查询使用 SciPy `cKDTree` 单线程。缓存只保存几何组件收益，S/G 改变后验不改变缓存结果。

## 当前能力边界和验收

这个模型能预测“若结构假设成立，换到某个视角预计能补到多少未观察的表面”。它仍有明确限制：使用人工标记初始化；名义族可能与真实设备不符；标记安装方式已知；尺寸权重未校准；使用点估计位姿，没有积分姿态不确定性；没有加入未知外部物体遮挡、像素分辨率和深度噪声对收益的影响；不预测同一表面重复观察带来的精度改善；面积积分和已见距离阈值是近似。不得把该代理量写为实测建图准确率或真实条件下的语义性能增益。

18 项解析测试通过：混合期望等式、G/平坦先验一致性、先验置换只影响混合、实测支持折扣及单调性、外表面并集面积、自遮挡、视野与距离零收益、无平面/关联不确定回退、私有字段拒绝、支持及后验校验、当帧像素证据校验、平面来源、重传/静止帧处理、同字节不同图像尺寸、候选与配置边界，以及历史相同视角零收益、旋转/位移/内参改变与容差边界、未关联缺失深度帧的保守资格规则和 330°/−30° 姿态等价。没有创建开发场景 World，没有执行完整策略轨迹，也没有把这些测试当作语义方法优越性的证据。
