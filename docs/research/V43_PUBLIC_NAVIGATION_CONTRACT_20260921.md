# V43 共用导航先验与候选集

本轮补齐六个既有 DEV 场景的**已提供导航先验**，不将它描述为未知环境导航能力。先验为所有比较方法共用；在线只得到粗粒度可达节点与通道。节点缺失和通道连通关系会透露粗粒度障碍约束，这也是实验条件的一部分。

离线编译器从冻结开发资产读取保守二维碰撞包络，采用固定 1 m 格点、固定起点 `(0.75, 0.75, 0.9)` 与 0° 初始朝向。障碍包络各向扩张 0.2 m，再对每条连续线段作封闭矩形相交检查。该方形膨胀包含半径 0.2 m 的圆形机器人，因此可能排除部分真实可行窄通道；不会把只检查端点误写为整条边安全。输出仅保留起点连通分量。V41 图适配器随后将边细分为 0.25 m 平移，转向仍为 30°。

输出图不包含障碍坐标、真实设备实例 ID、类别空间位置、真实结构、内部几何或评估表面。离线源文件摘要保留在编译审计记录中；在线加载器不打开 `evaluation_private` 或 `renderer_private`。

## 在线接口

```python
from nso.public_navigation_v43 import (
    load_public_navigation_bundle_v43,
    select_candidate_states_v43,
)

bundle = load_public_navigation_bundle_v43(scene_bundle_dir, frozen_scene_dir)
states, receipt = select_candidate_states_v43(
    bundle["graph"], current_state, paid_camera_states=history, limit=32
)
```

加载结果包含 `graph`、`graph_spec`、`public_spec`、`workspace`、`certificate`、`sidecar`、`home_state` 和包摘要。每个场景目录仅含 `graph.json`、`sidecar.json`、`certificate.json`、`manifest.json` 四个公开文件。

冻结 V40 公共参数原文件保持不变。新 sidecar 绑定原始公共参数、工作空间及固定协议的文件 SHA；加载器另外锁定协议字节摘要，并严格检查工作空间字段白名单。解析后的参数副本**只改变**导航 `status` 和 `graph_asset`，其他参数必须完整等于冻结协议默认值。旧工作空间内的 `navigation_graph_status=pending` 作为原始记录保留；运行时实际状态以解析后的 `public_spec` 为准。

候选集用公开图上的单位动作 BFS 计算路径代价，尊重后续删除的边。候选位置为原始粗节点以及机器人当前所在的中间节点；已付费的相同节点／朝向被排除。先给最近的最多八个有效位置各保留一个候选，再按代价补足，总数最多 32，每个位置最多四个朝向。该选择不读取语义后验、表面预测或私有几何。控制器可从此共用集合进一步选取最多八个几何上相关的检查视角；目标保持及返航预算由控制器另行处理。

这个池是有界候选近似，不保证一次覆盖所有视角；由于 360° 平面激光在同一 XY 的转动不能自动产生新二维发现，探索奖励应另行排除已经付费观测的位置。不能把候选图上的节点总数直接当成实际传感二维覆盖面积。

## 验证与产物版本

最终包为 `audit_results/v43_public_navigation_r1_20260921`，总计 58,291 字节。初始包在发布前发现公开工作空间返回值缺少字段白名单，因此保留初始产物及修改前源码快照，增加严格边界后重新生成 r1。两包的 24 个场景公开文件字节完全相同；改进的是加载验证，并未改变场景图或实验难度。

14 项测试通过，包括薄墙穿越、碰撞接触、固定起点、参数漂移、重绑定后的私有字段拒绝、证书篡改、运行时私有文件访问拒绝、候选路径代价、位置多样性和删边后的可达性。另用现有 V41 连续扫掠圆碰撞判定交叉检查全部 **516 个粗节点、826 条连续边**，无碰撞；未创建 World 或传感帧。交叉检查收据：`audit_results/v43_public_navigation_review_20260921/result.json`。

这一步建立可复查的导航接口与静态碰撞证据，不是完成规划轨迹、语义效果对比或覆盖率实验。
