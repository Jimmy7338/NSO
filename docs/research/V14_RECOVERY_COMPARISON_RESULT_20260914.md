# V14：受阻重规划的配对执行结果

2026-09-14。**公共执行修正已通过：同一 D12-00 开发场景、同一 192 步预算上限下，二维覆盖由 19.80% 提高到 36.36%，三维 F1@5cm 由 29.65% 提高到 43.78%。两条轨迹均无碰撞并返回起点，新执行的全部 192 步已通过独立进程精确重放。此结果归因于受阻后的公共重规划，不是语义创新的性能证据。**

## 实现与安全契约

新增独立版本 `nso/recovery_runtime_v14.py`，保留原 ANS 全局目标—局部动作层次与四模块。旧运行器源码和历史证据没有改写。

去程动作被原安全守卫拒绝后，先确认当前地图上的返航仍可行且还有额外预算，再重新选择一次全局目标。新的首个动作仍通过相同占地与后继状态返航检查。若替代目标仍被拒绝、没有安全替代或预算只够返航，就转为返航；每个观测状态最多一次恢复尝试，不允许无动作循环重试。返航阶段不会重新开始探索。只有实际传感观测被接收后才扣预算、融合地图并更新反馈。

候选由同一已测几何生成器生成，名额仍随观测实例数变化，评分仍是原几何 G。此次没有修改语义评分、类别权重、地图安全边界、传感器、TSDF 或评价区域。新执行器对之后所有语义与几何对照都应一致启用。

五项针对执行风险的测试通过，覆盖恢复动作复查、未回传观测时禁止二次取动作、第二次拒绝后返航、返航阶段不重启探索、无安全返航时不授权动作以及仅剩返航预算时不重规划。其中多个相关断言在同一个测试中验证。

## 配对证据

[比较协议](../../configs/virtual3d/semantic_v14_recovery_comparison.json)在新轨迹执行前封存。复用已通过重放的原 D12-00 轨迹作为开发对照；它此前已被查看，不能称为独立确认。两版配置、初始传感输入和前 53 个动作及传感哈希一致。

第 53 步，原计划的下一步前进再次被判定为 `next_footprint_not_known_safe`，剩余预算为 139。新执行器成功选择了经过安全检查的替代路线，首个动作保留 38 步返航成本。之后共执行到第 192 步，返回原始位置与朝向。只有一次受阻恢复，没有发生反复恢复循环。

| 项目 | 原执行器 | 受阻重规划 |
|---|---:|---:|
| 预算上限 | 192 | 192 |
| 实际付费动作 | 92 | 192 |
| 全局规划次数 | 2 | 10 |
| 无碰撞、安全返回起始位姿 | 是 | 是 |
| 最终二维覆盖 | 19.79735% | 36.36009% |
| 三维 precision@5cm | 99.82500% | 99.78333% |
| 三维 recall@5cm | 17.40924% | 28.03905% |
| 三维 F1@5cm | 29.64795% | 43.77684% |
| 全局覆盖 × F1 | 0.05869508 | 0.15917301 |
| 平均表面误差 | 3.445 毫米 | 3.222 毫米 |
| 表面误差第 95 百分位 | 13.410 毫米 | 12.539 毫米 |
| 参考采样估计新增可见表面积 | 127.287 平方米 | 211.134 平方米 |
| 行驶路程 | 16.0 米 | 35.2 米 |

覆盖提高 16.56274 个百分点，F1 提高 14.12889 个百分点，联合分数增加 0.10047792。三维改善主要来自完整性；precision 略降约 0.04167 个百分点，不能写成所有精度指标全面提高。表面误差来自当前无噪声人工仿真，不是 ZED 实测计量精度。

这是相同截止预算下利用原先闲置预算的收益，实际动作数和路程并不相同，不能解释成相同行驶路程下的提升。仿真动作时长按配置分别为 92 与 192 秒，是动作时间模型，不是 CPU 总运行时间或实车完成时间。

新历史摘要记录了 9 个外层自然决策，恢复时的第 53 步规划发生在运行器内部，因此完整模块记录中为 10 次全局规划。不能漏计内部恢复决策；下一阶段的候选分支采集必须同时捕获这两类决策。

曲线每 16 个动作及实际终止点评价，提前停止后的地图保持到第 192 步。全局主指标使用共同的可观测参考集合，16,000 次真值表面采样、种子 2026，预测网格采用原评价器固定采样种子 812。新增可见表面积是该采样上的几何可见估计，不等于全部正确重建面积；没有仅对有利类别加权。曲线积分仅为补充描述，不作语义训练准入门槛。

## 对原语义负结果的影响

额外核查了原 V13.2 全部 102 条分支的封存模块日志，**触发安全拒绝的分支为 0**。所以本次受阻恢复解释了 D12-00 的预算闲置，却不能解释旧 Q0–Q3 的低语义信息价值。此前 0.384%–0.410%、未达到 0.5% 门槛的结论保持不变；没有因此启动训练或将新公共执行收益写成语义贡献。

新轨迹中，观测几何实例数最多为 8，但其中包含没有类别证据的几何簇，不能等同于识别了场景中的 8 个真实设施。更晚状态的剩余预算较少，许多设施观察角色不可达，必须与类别识别和候选可行性一起分析。

## 后续顺序

先从封存的新历史恢复所有 10 次全局规划，包括内部恢复决策，补齐完整状态、反馈、共享候选及描述快照；再冻结多设施的匹配条件与两次决策信息诊断。几何匹配和语义观测是否仍有信息价值必须先核验，不能直接复用不同物理观测的状态作因果配对。

新协议要分别控制候选、执行恢复和语义评分，并覆盖类别相关、独立、反向及低置信条件。只有足够的候选信息价值成立后，才进入等容量模型训练、分组验证、闭环与新的独立确认。Q0–Q3、D12-00 均是开发材料；F00–F11 保持冻结。自然语义、实例条件反馈校准、强外部基线与 ROS1 实车有效性仍待完成。
