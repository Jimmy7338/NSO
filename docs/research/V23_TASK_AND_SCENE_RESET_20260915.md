## 1. 本轮已得到的判断

“增加有效观测可以改善建图”已有证据，不能再作为每一版都需重跑的未知假设。现有 Open3D TSDF 在通用双目台架中，4米单帧到同视角24帧独立测量的平均表面误差为40.876→12.683毫米；复制同一帧无改善，固定偏差也不能保证被平均消除。这里没有改变视角、支付旅行成本或标定真实 ZED。细节见 [传感与评分审核](V22_SENSOR_METRIC_REVIEW_20260915.md)。

当前三项问题需要分别处理：

1. **任务口径不完全一致。** 原主分数检查完整可观察外表面的 precision/recall，轮廓只作诊断。P00 的一个 B 设施已有轮廓 IoU=0.931576，但外表面 recall=0.592282、F1=0.725264。若实际用途是位置、占用尺寸、外露凸起和净空复核，应按这些交付要求验收；不能把完整表面采集和外形建档当作同一个任务。
2. **简单/复杂没有形成足够清晰的观察需求差异。** 当前两类都使用2.2米宽前板和其后的0.8×0.8米箱体。简单类也遮住大块需评分的背侧；复杂类只另加附件。类别名本身没有保证“简单少量观测足够、复杂补看更有价值”。
3. **路线把基本建档和额外补看绑在一起。** P00 两类首选各漏两处设施，且 A/B 末端不是相同的侧后观察阶段。A 本身 F1 可提高7.795个百分点，但 B 损失16.078个百分点，已经盖过 A 的收益。仅调整背景对称性也不够。

V22 的10条完整任务和10次新进程回放现已完成，10/10覆盖合格、返航、零碰撞，主执行1744动作。正式分析核验116份冻结源码、12份参考缓存和1817个产物。两父的类别条件选择相对最佳固定选择上限为 **0% / 0.3596%**，其余两组参考采样均为0；固定复杂优先相对最佳固定选择为 **−2.5935% / −0.6605%**。停止在原场景、原候选及共同 N 后续上扩量或训练。见 [完整结果](V22_EARLY_COVERAGE_RESULT_20260915.md) 和 [正式分析](/root/NSO/audit_results/facility_v22_information_analysis_20260915/result.json)。

勘误：初始静态 A/B 路径的分岔是 P00第8步、P01第7步；实际每5步刷新后，两父的 A/B **付费动作均在第6步分岔**。旧 P00 局部诊断把静态8步写为实际，原审计保持封存，以正式动作记录为准。

## 2. 首选故事：多工位设施外形与占用空间建档

小车在工厂公共通道中取得导航地图和各设施的基本外形，用于设备布置复核、外部尺寸记录、凸起与通道净空检查。基本外壳易于记录；带外露管件、侧后凸起或多层安装结构的工位，需要额外进入观察通道。总时间不足以对每个工位都做密集采集。

语义提供的知识是“这一类设备/工位通常在哪个方向存在尚未看见、但影响外形的结构”，从而提前分配观察时间。距离、遮挡、入射角、已观察完整度和降噪规律仍是所有方法共有的几何知识。语义价值由实际外形改善验证，不按设备类别、停留次数或预测收益直接加分。

首版仍用两套六工位开发布局，先证明单工位机制和完整任务可行，再扩为规模实验。六设施实验不能写成大规模场景有效性。后续规模变化须同时改变工位数、支路代价和信息组织，检查 CPU 计算及任务成功率。

## 3. 场景的具体变化

| 要素 | V23 应满足的条件 | 实施前的验收依据 |
|---|---|---|
| 公共粗建档通道 | 一条所有方法可使用的付费通道，经过所有设施的基本观察区域；不因选 A 就完全漏掉另一组设施 | 真实传感、实际 TSDF、逐设施记录；不能仅以二维覆盖合格代替 |
| 简单设备 | 采用能从基本观察阶段约束主要外形的简单封闭外壳，取消宽前挡板无谓遮住大块必需外形的构造 | 少量实际观测后外形达标；追加同成本观察的边际收益较小 |
| 复杂设备 | 外露凸起影响占用边界，初期被真实遮挡；结构尺度在既定相机和 TSDF 下可恢复 | 补看侧后视角后尺寸/轮廓改善，不能只增加表面点数 |
| 两个选择臂 | 同类公共算法生成，访问相当的侧后观察阶段并朝向对象，匹配去返费用及公共任务负担 | 实际到达、图像内有效支持和重建质量，不能只检查 endpoint 或代理正值 |
| 类别信息窗口 | 在两个选项必须分岔前，类别线索已可见、关键隐藏结构尚未揭示 | 新轨迹自身的传感历史配对；不沿用旧 N 的第20步 |
| 错误与无信息条件 | 保留非典型设施、低置信提示、类别置换以及充足预算 | 测试停止补看和反馈修正，不要求每个条件都正增益 |

公共粗扫可以形成机制实验的共同前缀，但所有平移、转向、采集和返航均计入总预算。它不是完整自主方案的替代：进入效能阶段后，必须由共同观测驱动的规划器完成这些工作，不读取真值路线。

单线雷达与相机可采用各自范围。此前共用5米是模拟契约，并非两传感器的物理必然；新范围应按通道可观测性和传感参数先声明，深度及 TSDF 不随雷达放大。尚未选定新雷达范围，相关接口见 [独立量程设计](V21_INDEPENDENT_LIDAR_RANGE_DESIGN_20260915.md)。

## 4. 先实现外形验收，再运行新策略

用户的“外轮廓正确就该给高分”采纳为新任务原则。首选评价方向是**固定多方向的外轮廓一致度，加位置和外部尺寸验收**，完整外表面 F1 与连续厘米误差继续旁报。不能直接把旧 silhouette 数字替换到旧 J 后声称新胜利。

在任何 V23 策略成绩产生前，先写出可计算契约和单位形状测试，冻结以下项目：

- 评价相机/投影方向、任务高度范围、外形包络定义和厘米容差；这些由任务与场景确定，不随策略看到哪些面而变化。
- 正确的简单闭合外壳获得接近满分；外部包络不变的内部构造不影响主分数。
- 单块正面薄板、错误深度尺寸、错位外壳、漏掉影响外廓的凸起必须受到相应扣分。多视图 IoU 要与位置/尺寸联合检查，不能只使用有没有射线命中。
- 缺失设施记零；未观察、几何推断、实际测量三种状态分别保留。若使用几何补全，对所有策略使用同一个不读类别的补全器，输入不得包含真值评价窗口、隐藏尺寸或参考模型。
- 当前 TSDF 网格不保证闭合，不能直接把网格内部填充当作可靠的实心体 IoU。优先检验固定投影和尺寸契约；如需体积包络，必须另行验证共同闭合/补全算法。
- 主联合效用仍以二维覆盖与全部设施等权外形质量组合为首选；**具体公式、方向、尺度容差与达标门尚未实现/冻结**。冻结时明确一个主终点，并旁报原 `C×外表面F1`、设施完成率及达到同等质量的动作数。不能在结果出来后在多个分数之间选择最有利者。

新的指标不会自动使语义有效。如果基本路线已经满足真实外形需求，就应得到好成绩。优势可来自相同质量下减少时间，或有限时间内完成更多真实有额外观察需求的工位；不能通过扣掉基本方案应得的分数制造空间。

## 5. 下一轮的有界执行顺序

1. **形状—指标验收。** 实现并检查上述正确壳体、内部变化、薄板、错尺寸、漏凸起、空重建六类单位夹具；再冻结外形任务协议。失败先修指标，不启动规划矩阵。
2. **真实观察需求。** 只做简单/复杂两类各一组可支付的公共粗扫与侧后补看，保存真实 RGB-D、TSDF 与独立回放。检验简单类基本外形是否已足够、复杂类是否因新视角而改善，以及精度/完整度/外廓分别贡献多少。已有平面多帧台架不重跑。两类仍无观察需求差异，就修改物理设施与观察通道，不训练。
3. **完整任务可行性。** 新建两个父布局，先检查共同在线覆盖、所有设施基本记录、侧后视点可达性、返航，以及完成全部密集采集的有效路径成本下界。依据这些成本冻结有竞争且可行的主预算；充分预算另作边界。真值见证与在线成功分别记录。
4. **一次配对信息筛查。** 冻结两父×两类别排列×公共选项的完整矩阵、固定类别规则和独立回放。比较条件选择上限与同一共同可行池内最佳固定选择，再比较实际固定规则。报告类交换是否改变最优选择、相对/绝对增益和所有失败；保留两个父均>5%的开发筛查目标，不能用参考采样充当独立布局。
5. **通过后验证完整方案。** 在相同候选、任务信息、算力、预算和后端下比较强几何 NBV、同容量几何/语义收益头、固定语义、完整方案、类别置换、低置信和去反馈；冻结方法后进入未见父布局。自然前端、原神经栈和 ROS1 实车仍分开验收。

每一步未通过时输出具体失效机制和新假设。不得在同一失效构造上反复增加种子或网络规模。场景可按方案机制设计；进入独立确认后必须保持方法、场景生成规则和评分冻结。

## 6. 保留四模块与相关方法的合理连接

OV-SDF 保存实测形状、类别条件的未见外形需求和置信度；STGHP 在覆盖、基本建档和定向补看间分配任务；RPN-UQ 负责安全到达、朝向、实际成本和返航；IGCR 用观测到的外形变化更新实例/方向的预计边际收益。这是内部算法设计，不改变 ANS 层次或四模块接口。

[SG-Nav，NeurIPS 2024](https://arxiv.org/abs/2410.08189) 支持利用对象—组—房间关系在未观察区域前进行选择；其 ObjectNav 成功率不能当作本项目重建增益。[LSG/xFLIE](https://arxiv.org/html/2412.19582v3) 提供目标、视点、部件的层次探索/巡检参考，但论文明确网格仅用于可视化，不能引用为三维精度证明。[MACARONS，CVPR 2023](https://arxiv.org/html/2303.03315) 的新增可见表面预测可参考其距离、视场和遮挡历史处理；它也不证明“类别越复杂，任何补看都必然有效”。以上原文于2026-09-15核查，支持任务与机制动机，不替代本项目实验。
