2026-09-15。毕业 14 天判定窗口中的一个候选家族，仅两个父布局、每父两个类别排列。本协议先供主任务审查；只有源文件及本协议冻结、主任务授权后，才允许一次不超过 600 秒的静态进程。没有运动、采集、SensorPacket、TSDF、Q 或训练，不扩场景或网络。旧草稿的停止状态和所有 V24 结果保留，本文件是重新授权后的新版本。

## 固定几何与输入边界

`env/facility_choice_v25.py` 首版 `two-facility-physical-partitions-v25-r0`，父布局 D25-P00/P01 分别继承 D24-P00/P01。原 V24.1 本体、外露附件、评价窗、可见标记、相机/雷达/噪声参数及提议前缀不变。类别无关隔板左右镜像，每个工位新增五块实体板，高 2.4 米。以柜体中心横坐标 cx、正面纵坐标 f、向内为局部正 x：内长板 x=1.4…1.6、y=−0.8…2.4；内前回折 x=0.8…1.6、y=−0.4…−0.2；外长板 x=−1.4…−1.2、y=1.0…2.4；外回折 x=−1.4…−0.8、y=1.0…1.2；后方内移板 x=−0.2…0、y=1.0…2.4。所有坐标相对 cx/f。

外板起点移到本体 0.8 米后缘之后，后方内移板拟提供比柜体外侧面更远的真实背景，同时遮挡后部斜窥。此设计未经可观测性验证，不假定夹持或遮挡成功。新增板与所有本体/附件连续 AABB 的最小距离必须至少 0.2 米，大于 0.08 米体素 26 邻接对角线约 0.1386 米；该真值间距不保证带噪实例分离，运行时不得使用 GT owner 分割。

所有几何均加入同一个实体 box union，由原传感器射线解释；禁止非物理屏蔽、只渲染某类别、冻结几何方法改选或移除任务地面。旧 V24 服务点即使仍可站立，也可能已失去原观察含义。本版 service_regions 置空，分别报告旧点在新安全图中的保留数量，并将可见性和旧成本证明明确标为不可复用。本版不冻结新的服务成本、完整任务预算或完成质量门。

## 一次静态检查的范围与通过条件

1. 构造四个世界，只允许纯几何查询；静态子类拒绝 step/sense/scan。按原机器人半径及 0.2 米网格检查锚点安全、全部安全地面与锚点连通、完整提议前缀每个状态和动作合法、分离间距至少 0.2 米。构造失败直接留存结构化失败，不绕过安全门。
2. 每父原完整提议前缀的每个姿态，都用原 canonical clean renderer 比较两排列的浮点深度数组，要求严格相同。RGB 中类别标记本来应不同，不能要求 RGB 同像；按真实可见表面及物理贴片边界确认两对象都曾有至少 16 个有效标记像素，对齐已有 MarkerTracks 创建实际 seed 的运行契约，不降低门槛。仅输出计数和摘要，深度/RGB 数组只临时存在内存。这是静态投影配对，不是实际付费传感验证，带噪 seed 和实例组件仍未验收。
3. 固定检查两对象原 front 和 outer-side 前缀停靠姿态。顶部采用真实顶边中央区段（front：x=cx±0.4，y=f，z=1.6；outer-side：外侧面 x=cx∓0.8，y=f+0.2…f+0.6，z=1.6）；外侧本体后缘采用 y=f+0.8、z=0.4…1.2。检查投影边界紧内侧像素命中本体面，紧外侧像素有实际正深度背景且比该本体面远至少 0.2 米。逐段报告成功像素/测试像素；每段至少一对有效夹持才通过这个有限契约，仍报告是否全段通过。若不在画面内、前景不是本体或背景无效，保留失败。此检查不能证明全部外形支持充分或简单柜达到某 Q。
4. 对每个复杂设施的两个新增附件，检索其后部附近预声明范围内的可达离散视点：局部 x 在 [−1.8,1.8]、y 在 [1.8,2.9]，四种朝向均允许。对完整世界与移除该单附件的世界做理想深度比较，至少一个不同像素作为该附件确实贡献可见外表面的见证。找到见证后可停止该附件检索；未找到只说明此有限候选集合未给出证据，不能声称全局不可见。保存见证姿态、可达性和像素数，不将其作为在线候选或质量成功。

上述四项组成“有限静态可用性门”；任一失败均保留。原 P01 实际前缀 C≈0.7696 的负例仍在，静态安全和投影通过不能改写成新 C≥0.8。主任务可在首版出现明确安全/可观测缺陷时决定至多一次修正；必须保留首版源与失败记录，不能根据 Q、语义相对收益或主观好看程度搜索参数。

## 有界首次信息距离

同时加入一个决定性但有限的诊断：在每个真实排列的完整 GT 安全姿态图上，从共同前缀终点锚点 BFS。每个安全格开放全部合法原地左右转向及前进，单位成本均为一动作；不能只使用预定路线的边。图仅给评价侧最乐观的运动能力，绝不能进入运行时。两个排列分别求完整姿态距离，再按两者可达距离的较小者排序检查姿态；这是对几何方法有利的最小成本，不要求它实际已建出该图。

从距离 0 开始逐层检查所有姿态，完整检查首个出现理想深度差异的层后停止，报告距离、同层见证和各自安全性、到达路径及动作数。这个距离是两个真值图中最乐观的理想信息下界，不是一个可执行未知图策略的精确成本。没有显著性阈值：一个不同像素就视为理想信息，故不能把它等同于带噪可识别。可用变动附件包围盒的保守视锥排除证明无差异；其余姿态必须实际比较干净深度。此处所有推断仅适用既有离散位姿和理想像素，不能外推连续姿态或实际识别成功。

若某姿态只在一个排列安全，但两相机原点都在实体之外，仍可作为给几何方法更乐观的静态比较，并显式记录“并非两排列共同安全”。若相机原点落入另一排列实体而不能用当前 renderer 比较，记录删失，不将该姿态当成零信息；只有此前各层全部可比且无差异，才给出精确的首次干净信息距离，否则保留已排除的范围与后续见证，距离标为未完全确定。最多检查距离 72 的完整层；时限到达则保留完成的层，不能称全局没有信息。

本轮不据首次信息距离直接选预算，也不证明改选昂贵或语义有价值。后续若需要改选成本，必须仍在上述完整合法动作图上，报告最优合法改选/返航路径，而不能要求几何方法执行完整长选项。
