# Exposure之后是否启动未见布局主比较：机制门

制定时间：2026-09-28，Exposure V3尚未冻结、未启动任何在线episode。本文明确原预声明中“可行动作用”的证据等级，不改变开发12、两轮消融各12或条件主48矩阵，不采用端点正增益作为启动条件。

首先要求全部36次开发/消融尝试各有终态记录及相应独立审查。失败按原样保留；新V3若不能提供有效的传感、执行、测量与输入权限证据，不能只挑出成功条目宣称技术通过。资源允许启动条件另行记录；600秒为原付费driver上限，离线评价时间单列。

在三个固定开发场景中，寻找至少一条可核验的S/B行为链：

1. 使用同一版本、场景、预算、噪声种子，比较两个已审查运行实际传感数组相同的最长前缀；只忽略run命名导致的frame_id差别，不忽略深度、扫描、位姿、时间或相机参数。
2. 在共同前缀中，已取得且合格的同类几何证据使S的留一共享权重/后验与B不同。实际规划状态使用当帧几何反馈之后的快照，实例配对依据已观测锚点而非GT身份。
3. 差异传播到最终被选中的可执行观察宏动作，并产生首次实际动作分歧；该分歧发生在返航锁定前，且两臂当时均通过实际预算和返航守卫。仅有后验小数变化、未选候选分数变化、词典序显示差异或日志命名差异不够。
4. 同步检查候选权限、共同地面和曝光前端、输入支持与算法配置，确认差异与共享路径相符，而不是传感权限不同、源文件漂移或两条已分歧路线之后的不配对比较。诊断宏动作可以构成有效行为链，不限定必须是直接视角。

该门只要求至少出现一次可执行的信息—动作联系，不要求最终F1/J增加，也不要求在多数布局发生。若通过，仍须对预先指定的全部六个T0/T1布局、120/160预算、92811噪声实现、四方法执行同一个48槽位矩阵；不能只选出现增益的场景族。92812的第二组48本夜暂缓决定已在看到主实验结果前作出。

如果没有满足上述等级的S/B链，保存全部36条尝试，停止本夜扩增在线开发，不启动主矩阵。共同比例修正带来的路径/质量变化、B/G类别作用、历史局部类别作用及S/B共享作用分别陈述。此时主比较的状态应为“机制前提未满足，未执行”，而非失败、零分或已完成。未来改变先验模型或研究对象需要另行明确新计划，不能在本夜剩余槽位之外继续搜索结果。

即使通过，该门仍是已见开发集上的研发判断，不是独立效力证明。主比较只有在源码、配置、评价、完整槽位和启动证据冻结后才开始，启动之后不再使用其结果改控制器或参数。
