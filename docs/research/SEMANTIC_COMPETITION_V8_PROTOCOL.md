# V8 双对象预算竞争：24 分支开发机制协议

2026-09-11。结构门槛与本文件中的停走规则在新的候选收益产生前固定。配套机器合同为 `configs/virtual3d/competition_v8_protocol.json`，场景首合同为 `configs/virtual3d/competition_v8_contexts.json`。当前状态是**待结构检查的开发方案**，不是结构已通过、语义已有效或完整系统已验证的结果。候选生成、评分器和运行器必须另行封存后才能执行未来分支。

## 1. 本轮解决什么问题

[V7 独立分解](/root/NSO/eval_results/response_v7_value_diagnosis_20260911/REPORT.md)显示：8 个父上下文的全场面积率条件 oracle 增量全部为零，全部候选新增面积合计的 91.13% 是背景；对象单独计算也只有一个微小非零差异。类别可读并不意味着类别能改变最优动作。

V8 只检验一个有应用动机的正控制：设备外形与当前几何观测相同，可见资产类别指示不同的遮挡后结构，而本轮预算只能深入检查两件设备之一。真实收益仍由相同传感器与建图过程产生，不能用类别直接指定奖励。

本轮不训练、不标定，不打开 V7 的 C 或新 E，不使用 753／754、301—308、401—412。2 个父上下文 × 2 个交换世界 × 每世界 6 条共同候选，最多 **24 条新物理分支**；评分方法不增加物理分支数。P0/P1 是开发镜像与噪声块，不是 24 个独立样本，也不是充分的独立泛化检验。

## 3. 无未来收益的结构硬门槛

先完成全部四世界的共同前缀和结构审计，再决定是否执行任何未来分支。固定参考由原评价器按唯一并集外表面生成，最初请求 32,000 点，原点权重为全 mesh 总面积／32,000；保留原可观察过滤，不按过滤后点数重新归一化。

1. **配对输入相等。** 同父两世界逐帧的 depth、scan 全字段、位姿、内参、时间戳、非标记 RGB、标记支持掩码以及非标签地图逐元素相同；只有标记颜色／解释类别可以不同。S/O 的接受对象性相同，G/O/N 可用几何和候选相同。候选构造须恰有两个共同实测几何组，且每组均有实际可读标记支持；评价器另核它们确实支撑两个槽位，不用真值补分组。类别必须从实际 RGB 标记读取，不能从 world 名称、GT 类别或资产中心补齐。若出现无标记组，S的边缘回退与O的对象接受可能混淆细类效应，不能当作本机制的合格历史。
2. **全场面积守恒。** 两世界各有一件相同 H 和 L，几何不得相交制造额外表面。唯一并集 mesh 总面积之差 ≤`1e-10 × max(1,两面积绝对值)`。分别保存原参考、类别、权重、唯一化信息及 SHA；不能只靠资产盒面积相加。可观察过滤后参考面积与采样差异全部报告，不要求它们与解析总面积相同。
3. **背景实际饱和。** 四世界各自满足 `Σw·prefix_seen·[class=1] / Σw·[class=1] ≥0.90`，分母是该世界固定可观察参考中的背景。只能使用实际帧、实际有效 depth 与物理位姿计算 prefix_seen。不得给 mapper 预填背景，不删背景，不按类别加权主效用。报告仍未见的背景面积及完整前缀成本；90% 本身不保证背景路线以后不支配。
4. **仍有两个未解决对象。** 两槽位在 prefix 后各有严格正的未见可观察参考面积（数值零容差 `1e-10 m²`）。报告分母和已经观察比例；不按所剩面积的大小选择父上下文。
5. **同池与成本。** 每历史恰有 6 条候选，按共同传感器几何生成，两交换世界的动作、状态、朝向、代价和 ID 精确相同。角色顺序固定为 `coverage_anchor, old_surface_rotation, west_entry, east_entry, west_deep, east_deep`。AABB 为实测点各轴5%／95%分位范围，以**共同history第一帧**相机相对组中心的最近主方向估计前向（并非每对象首次真正被看到的帧）；entry/deep 使用其背向实测边界外 0.4／0.8m 的目标，再选同一安全图上的近邻状态，允许目标欧氏误差≤0.35m，禁止使用真实设备中心。每槽位 deep 的实际背轴距离必须比本槽位已选 entry 至少增加0.2m（浮点容差1e-12m）；无有效entry、无合格deep或目标误差超限即角色失败，不用其他候选填充。`old_surface_rotation`须在起点旋转后的视锥／量程内包含严格正比例的实际已测点，按该支持比例降序、代价和位姿升序选择；这只是已测点的投影条件，不保证实际无遮挡复看或精度提高。所有路径是付费去返路径，含返回原朝向，计划长度在 1—48 内。两个深入代表优先同成本；若不相等，保留实际差值与后述成本不等条件，不通过重采路线追求好收益。
6. **互斥预算证书。** 在共同已知安全朝向图上，起点到西／东探查区并返回的最短代价各≤48，访问两区后返回的最短代价>48。实际实现对每区全部朝向状态取定向最短距离，单区为`min_z[d(s,z)+d(z,s)]`；双区分别枚举西→东和东→西，取`min_z1,z2[d(s,z1)+d(z1,z2)+d(z2,s)]`中的最小值。该算法等价于保留两位已访问区状态的最短路，包含返回原朝向；仅凭两条独立路线代价相加不构成证明。

探查区仅用于评价／结构审计：每槽位真实中心 x±0.3m，y∈[5.9,6.5]m。在线候选只能由实测前／侧片的几何推定设备与观察方位，不能读取这些 GT 区域或资产中心。另报告忽略障碍但保留步长、边界、旋转与起终朝向的乐观图双区成本；只有这个**下界也>48**，才可称预算物理上不允许访问两区，否则只能称当前已知安全图不允许。

任何一世界未通过上述硬门槛，都记录**整版构造失败**，本版不产生未来分支；不删除世界、放宽90%、加扫到过线或按之后的 oracle 换场景。实现错误可另立版本修复，保留首次失败合同与所有原始记录。

## 4. 评分与干预：先封存，再执行

本轮 S 允许一个**明确给定的资产结构先验**，用于条件化候选相关的观察响应；先验、公式、量纲、代价处理、方向计算与 tie 规则须在四历史预测统一封存前固定。H/L 的资产结构说明可作为先验来源，当前 world 的隐藏位置、GT 表面积和未来可见性不能作为评分输入。它不是新数据学到的规律，也不是校准后的真实面积／F1 预测。

首版先验使用实测设备几何分组的宽 w、高 h、深 d，定义 `A_prior=wh+2nwd`，类别2的 n=3、类别3的 n=0，边缘／无标记先验 n=1.5；混合可见票 v（类别2为−1，类别3为+1）采用 `n=1.5(1−v)`，X将v取反。它表达封闭背面与多层资产潜在响应的粗略结构关系；**不是唯一并集真实面积公式**，其支撑范围和可见性可能错误。尺寸只能由共同实测几何计算，退化维度保留实测零值，不得拿场景的1.2m／1.6m或真值补齐。

每分组在假设背平面固定取5×5个点。每点的背向 FOV／距离获取因子 g 在[0,1]内：相机须位于该假设背边界外>0.15m、点在视锥与深度范围内，因子为 `1/(1+(distance/R)^2)`；否则为0。**各点分别**对路线全部付费状态取最大、减去共同 prefix 最大值后截非负，再对25点求均值，形成 `Δg`；不是先把整个面的平均数取max，也不是逐帧求和。扣除项必须通过显式必填的 `prefix_camera_poses` 使用**全部151个实际前缀相机姿态**（初始帧加150动作帧），不得只取 mapper 抽稀保留的 keyframes，否则会把漏掉的旧观察误算为新支持。它是几何预测，不能称遮挡首交点证书。分组、支持与尺寸对全部方法相同；共享几何合并／去重，不能仅让S按类别拥有更准确实例。

固定基础量 `B(route)` 还原既有N特征的雷达未知并集面积、相机未见并集面积，以及旧支持质量增量（质量均值乘实测支持点数与0.15²m²）。三项系数均为1；前两项可能重叠，明确是共同代理和而非去重的真实3D面积。N 为 `B/L`；G/O/S/X 为 `(B+ΣA_prior·Δg)/L`。全部通道的B完全相同，且只除一次L。实现中G用全部几何组；O用有标记组，S/X在无标记组加边缘先验回退，M=G；因此第3节强制合格历史的两个组全部有可读标记，保证本批S/O没有无标记接受差异。若对象分组把一个对象拆多份，其面积并不因此成为真实去重面积，结构审计须保留这种错误。

最终选择按分数降序、计划代价升序、candidate_id升序精确tie。每种分项及先验总面积留档；这些m²量纲代理相加仍不等于全场真实新面积，也没有参数不敏感或绝对校准保证。最终候选／评分源码及全部依赖须在未来分支前封存；未封存不得开跑。

| 通道 | 同池输入与固定规则 | 必须避免的混淆 |
|---|---|---|
| N | 共同路线、覆盖与旧面观测质量控制 | 不能人为清零真实微小质量，也不能只因短旋转 rate 放大而省略结果 |
| G | 可用共同几何、方向、遮挡／视点新颖性；类别边缘先验 | 几何不能只设弱常数；不得剥夺 S 同时使用的非语义信息 |
| O | 与 S 完全相同的对象接受与支持，类别边缘化 | S/O 差异只剩细类别，不允许更好实例分组或额外候选 |
| S | 与 O 相同几何／对象性，加入预先声明的类别条件响应 | 不将潜在结构权重称为已兑现面积或精度 |
| X | 冻结 S，仅在推断输入交换 2／3 | 不重训，不改实际物理帧、动作、真值或噪声 |
| M | 实际执行缺失解释路径，回退同一 G | 逐候选分数和选择均须等于 G |

每个评分器保留全部候选原始分数、分项、选择和可用性，面积率不能重复除动作数。类先验相同的边缘 G/O 应用相同的固定边缘化规则。若另报旧 V7 冻结模型迁移，应标为类别／分布变更下的附加诊断，不能让它成为唯一几何或净响应对照。

四历史的候选、评分器源码、参数、全部预测和选择统一生成全局 release，随后执行器才能开始任何未来分支。评分进程不得读取参考类别／面积、未来 RGB-D、outcome 或 oracle。保存前置执行凭证，不能在已有分支结果后补封存。

## 5. 实际执行、排他性与评价

所有通道复用同一候选的单次真实执行结果。每候选从独立恢复的相同 prefix mapper／world 状态开始，使用同一相对付费步的共同标准噪声流。最新传感器地图必须在每次动作前检查足迹安全及付费返回可行性；该执行守卫不是误差环境下的无碰撞定理。拒绝动作、改返程、未到目标、碰撞、预算不足或未恢复朝向分别记录，不按 GT 补路。

记录计划长度和实际付费长度。原主效用为 `u=新增全场唯一可见外表面积/实际付费动作`；失败短分母结果保留，但不称成功返程。零实际动作单列未定义，不能填0或删样本。全部24条完整后才能给全池 oracle；若完整性／安全问题中止，记录预定与实际数量，禁止将已完成有利部分称全批通过。

固定参考可见性只由实际有效深度像素、内参／量程／视锥及 GT 首交点、评价器物理位姿判定；本版 pose noise=0 方可使用相同帧位姿。去程／端点／返程按先后集合并去重；TSDF 输入永远只有实际观测。同步保存全场、背景与两槽位的新增面积，后两者只诊断。

**路线访问不等于传感器排他。** 在全部分支后检查：每条声明为深入某槽位的候选，从另一槽位获取的新增面积／该另一槽位 prefix 未见可观察面积必须≤0.10；目标槽位须获得>1e-10m²新增。并报告每条候选两个比例，若任一候选同时取得两边各≥90%的剩余证据，则预算竞争机制失败。分母固定为 prefix 剩余量，不随结果重定义。该检查失败不删路线或改GT区，也不把两区图距离当成通过证明。

评价继续报告全场 F1@2／5cm、precision、recall、固定旧支持误差、二维覆盖 C 与覆盖面积、`J=C×F1`、终点增量。分支 J-AUC 固定 48 动作窗口，按前缀／到达／最终检查点线性插值，短路线后保持最终地图；拒绝或失败检查点也入表。它是**稀疏分支近似**，不等于逐帧真值积分，也不代表剩余预算继续覆盖的收益。新可见面积不等于真实重建精度改善。

## 6. 何时信息理论上有用

对同父两个交换世界的固定六候选真值表，以两世界各半计算

$$V_u=\tfrac12[\max_a u_+(a)+\max_a u_-(a)]-\max_a\tfrac12[u_+(a)+u_-(a)].$$

有限表中 `V_u≥0`，且 `V_u=0` 当且仅当两世界最大化动作集合相交：共同动作的两个非负遗憾等权相加只有在各为零时才能达到上界。按 `1e-10` 的固定数值容差报告最大集合与交集，同时保留原始差值。该 oracle 是知道真实类别条件收益的理想决策相对最优共同决策的上界，**不是 S 成绩或可部署算法**；不能据它生成候选或筛掉上下文。

简化等成本情形，若深入 H/L 的真实可兑现面积为 `qH>qL`、成本同为 ℓ，其他候选不支配且背景无位置偏差，则 `V=(qH−qL)/(2ℓ)>0`。正确识别 H 槽位概率为 p 的规则相对最佳无信息共同规则增益为 `(p−1/2)(qH−qL)/ℓ`。因此需要可兑现响应差异和 `p>1/2`，可读标签本身不够。

若西／东成本不同且响应只随资产类型变化，还需同时满足 `qH/ℓwest>qL/ℓeast` 与 `qH/ℓeast>qL/ℓwest`，等价于 `qH/qL>max(ℓwest/ℓeast,ℓeast/ℓwest)`（qL>0）。存在剩余背景时必须把背景新增加入各动作全场效用；对象公式不能替换实际全场 oracle。总GT面积守恒不保证 F1 线性、次模性或相同最优选择。

## 7. 固定停走规则

下列条件只表示值得另立新的 T/C 与完整闭环计划，不等于通过旧独立验证协议，旧门槛不放宽。

1. 结构、预测前置封存、全24条执行账本、原始观测独立重放、参考与分项复算全部通过；物理碰撞或未完成返程使安全门槛失败，安全返回但未到原目标单列。所有深入候选均满足第5节排他性。
2. 两个父块的**全场面积率** oracle 均>1e-10，最大集合不相交；对象 oracle 或 F1 oracle 非零不能替换此项。另报最优共同候选、背景占比与仅共同成功返回候选的敏感性表，后者不替换原表。
3. S 相对 G、O、N 的四历史等权面积率均值各提高≥10%，且两个父块各为正；对照均值<1e-6 时采用绝对增量≥0.01m²/动作。必须同时报告三个对照，S>弱G 或 S=N 不通过。每个父块 S 的世界条件选择应随真实 H 槽位交换，且正确关系的面积率均值严格高于 X；M 逐项等于 G。
4. S 相对 G/O 的平均 F1@5cm 增量差不得低于−0.001；相对 N 的 F1增量／动作均值差>0，两个父块非负；相对 N 的覆盖平均损失≤0.1m²/分支。J、J-AUC 与全部分解同时报告，任何合成指标不能隐去精度／覆盖退步。

本小批不拟合预测模型，因此不套用“测试相关性达标”或“校准通过”等标签。若以面积量输出手工先验，仍报告误差与校准曲线，只称未标定先验诊断。无信息类别、几何已揭露、先验失配、自然类别识别、新实例与主流原作者基线须在后续预注册验证补足；本24条不替代这些控制。

任一门槛失败即如实归因到构造、几何候选、先验兑现、净响应、精度或执行；本版停止扩样。不得按oracle保留“好上下文”、换主指标、调先验到选中最优、增加分支直到达标。两个开发块的正差不能给出总体显著性或主流领先结论。

## 8. 四模块接口、复现与交付

OV-SDF 保存实测可见类别和条件先验，绝不把隐藏假设灌入地图；STGHP 在共同候选与有限预算中选区域；RPN-UQ 使用共同已知安全图和最新地图执行守卫，不能把确定性守卫称为校准概率；IGCR 保存真实新增证据、失败、成本与预测兑现。ANS 全局区域选择／局部付费执行接口保留，本轮仍仅验证局部机制，不自动完成四模块协同与定位精度实验。
