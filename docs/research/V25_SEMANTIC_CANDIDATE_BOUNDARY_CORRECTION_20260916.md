# 语义候选发现与固定候选排序：实验边界修正

2026-09-16。用户指出：语义可能负责判断哪些地方值得补看，无语义对照不应提前获得这些答案。源码核对支持这一质疑对当前端到端解释的限制。本次只修订后续实验定义，不新增采集，不改原冻结代码、协议、指标或负结果。

## 当前四任务究竟预先提供了什么

采集器预先指定了234步公共前缀，然后强制执行A或B补看并返航。它没有在线决定是否补看、何时开始、发现哪个目标或生成何种路线。两个设施还通过实际人工标记的并集定位，类别代码另行记录。

`scripts/audit_facility_choice_v25_service_cost.py`中的`service_masks`读取真实附件几何，通过移除附件前后的射线差检查可见性，并在两排列共同的真值安全图上生成路线。随后所有固定选项比较共享该目录。这是评价侧设计的观察收益台架，不是一个从自身观测发现补看位置的无语义规划器。

原4+4及其0%信息价值仍成立，但只针对已提供的两个固定路线。它不能否定语义的候选发现、补看时机或全程资源分配价值。镜像控制只处理视角和成本不对称，同样不能补齐候选发现验证。

## 合法的无语义能力

几何方法可以依据自身深度、雷达、位姿、已观测地图、遮挡边界、观察方向不足和可观测不确定性主动补看。若它凭这些信息找到同一区域，必须允许执行，不能人为禁止访问设施以制造语义优势。

它不应获得隐藏附件位置、真值服务视点、未观测区域的完整安全路径，或未执行动作的真实未来收益。语义方法同样不能读取这些真值；它只能依据实际识别到的类别与置信度、合法训练/历史得到的条件先验，提出“某处可能值得检查”的假设，再用付费观测检验。实际重建与评价不因类别获得额外奖励。

## 后续分成两层验证

主比较从相同场景、初始状态、传感与预算出发，各方法自主探索和生成补看目标；不固定234步之后才允许语义介入。允许继续覆盖、几何探查、补看、改选和返航。相同的是行动能力、任务知识边界、后端、预算、安全规则及评价；候选池可以因方法而不同，这本身就是待测贡献。

为归因，另设以下机制消融。每个候选必须记录来源及生成时实际可用信息，不能直接使用现有GT路线目录：

| 候选产生 | 候选排序 | 检验目的 |
|---|---|---|
| 几何观测 | 几何预期收益 | 无语义主基准 |
| 几何＋语义条件提议 | 几何预期收益 | 语义提出目标的作用 |
| 几何观测 | 加入类别条件收益 | 给定几何候选后的排序作用 |
| 几何＋语义条件提议 | 类别条件收益＋观测反馈 | 完整方法，仍需去反馈消融 |

共同候选池只用于明确的排序消融，不能强制成为唯一主实验。控制或报告候选数量、规划计算成本及实际动作成本，避免将额外搜索量误归为语义贡献。已有语义模板预测＋实测纠错基线仍需保留，证明候选发现有作用不自动证明新颖性。

在线补看判断应结合预期外形改善、当前观察不足、类别置信度、覆盖需求、动作及返航成本，并与其他动作比较；不使用真值Q、不规定每次发现设施都必须补看，也不将“类别复杂”直接变成固定奖励。OV-SDF提供实际语义/几何状态，STGHP产生并比较目标，RPN-UQ检查执行和返航，IGCR根据实际观测修正先验。当前四任务没有实现或验证这条在线决策链。

## 接续优先级

先核查并实现机器人侧的观测接口与候选来源，再冻结少量从自身观测自主决策的G/S实验协议。原镜像路线已通过静态检查，保留为可选的局部收益诊断；不再自动启动那4条采集，也不以其固定目录的筛查失败直接否定整个语义方向。原>5%筛查门未被改成通过，原结果保持负结论。
