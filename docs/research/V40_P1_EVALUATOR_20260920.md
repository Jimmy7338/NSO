# V40 P1 静态可观察外表面评价合同

实现：`nso/surface_evaluation_v40.py`；解析测试：`tests/test_surface_evaluation_v40_p1.py`。本P1只验证静态几何评价链，不创建World、执行规划、融合TSDF或产生新轨迹。完整GT作为“预测”、删除设施或添加错面只是解析sanity，不是重建效果。

## API与输入边界

`CandidateViewV40(intrinsic, world_from_camera, width, height, near_m=.1, far_m=4., view_id='candidate')` 使用 optical z-forward 相机，near/far 均裁剪相机光轴深度 z，与协议 `depth_min_m/depth_max_m` 一致；不额外按欧氏径向距离裁剪。欧氏射线距离仅用于判断样本之前有无遮挡。深度约定写入 reference fingerprint/manifest 和结果，ID必须唯一。K/T、尺寸及范围校验；候选可达性由上游独立候选生成器认证，本评价器不通过实际路线推断，也不声称自行证明导航可达。

`freeze_reference_v40(vertices, triangles, triangle_instance_id, candidate_views, *, sample_spacing_m=.10, seed=4001, max_samples=200000)` 返回 `ReferenceSurfaceV40`。GT包含全部任务设施及背景遮挡网格，背景ID=-1；三角面需具有正确外法向，上游应提供实体并集外表面。返回只读 `points, point_instance_id, area_weights`，`manifest()`绑定GT数组、候选K/T/FOV/range、样本、采样参数SHA与fingerprint。调用必须在任何轨迹前完成并封存，所有方法复用同一引用。

`evaluate_surface_v40(reference, pred_vertices, pred_triangles, *, C_map, threshold_m=.05, sample_spacing_m=None, seed=4002, max_samples=200000)` 返回JSON。不接受预测owner/类别/语义权重、路线、选中设施列表或tight GT ROI。预测网格完整提交，不能先删除背景或远处错面。C_map由独立覆盖测量提供，评价器只校验[0,1]并与质量分开报告。

空GT、无任务实例、退化三角面、索引越界、重复GT三角面、无候选、完全不可观察实例、过大采样请求等拒绝。空预测是合法的“未重建”结果，所有任务实例仍在宏平均分母内，Q和J为0。背景允许非闭合遮挡面；目标实体外向/拓扑合法性仍需上游几何合同审计。

## 固定参考集

每个目标三角面的采样数为 `ceil(area / spacing²)`，至少1；每个样本权重为 `triangle_area / count`。用确定性三角形重心坐标的面积均匀低差异式序列及显式随机相位seed，估计各实例可观察面积。满足以下条件的样本才进入固定参考：至少一个声明候选处于三角面正面，点在相机视锥和传感范围内，且相机到点的线段没有被任何GT目标/背景三角面截断。

水平与竖直面按同一规则；地底面、封闭内部等不能从有效候选观测的面不会进入参考。某任务设施若没有任何可观察样本，则拒绝这套参考，不能默默将它移出分母来制造高分。候选集合与有限面积采样构成近似；不是精确可见多边形求交，局部窄缝/微小可见面可能需提高采样密度并在测试前重新冻结。

## 精确距离与全部预测面积账目

完整预测表面先按三角面顶点坐标去除完全重合的重复面，不依赖GT、朝向或ROI，并报告提交/去重后的面数及移除面积，避免复制正确面抬高precision。不会把近似重合或仅部分重叠的三角面当作精确重复；上游仍需审计一般自交/重复覆盖。对其余完整预测表面另做稳定面积采样，使用精确点到三角面距离，而不是稀疏点云之间的距离，避免5cm匹配阈值被采样间距直接污染。每个预测样本先求其到完整GT的最近点和实例；阈值内的任务匹配还需检查GT最近投影点是否属于声明候选可观察域。

1. **可观察目标TP**：最近GT为任务实例、距离≤阈值且投影点可观察，计入该实例precision分子和分母。
2. **正确但参考域外**：最近GT为任务实例、距离≤阈值但不可观察，单列 `correct_target_out_of_reference_area_m2`，不提高或降低可观察域F1。
3. **正确背景**：必须到GT背景的几何距离≤阈值，单列 `correct_background_area_m2`，不能靠预测owner声称背景而免罚。
4. **额外FP**：到任何GT任务/背景均无法在阈值内匹配的面积，无论距离多远都计FP。固定分配给最近GT任务实例，没有距离截断；即便最近完整GT是背景也不能豁免，仍寻找最近任务实例承接FP。

四项面积之和必须等于完整预测面积；没有ROI裁剪。最近投影点不可见而另一个稍远可见点在阈值内的边界情形可能被保守分类为参考域外，因此本实现明确报告“最近GT投影可见性近似”，不宣称精确求到连续可观察子面的距离。阈值内的匹配沿用几何评价公差，并非零误差证明。

完整mesh全局precision同时报告：全部正确GT匹配面积（含背景及正确参考域外）/完整预测面积；`extra_false_positive_area_m2`同时独立报告，防止大量额外面积集中分配给某一实例后被宏平均稀释。实例归属仅在离线评价中使用GT最近面，不进入任何规划/观测接口。

## 主指标与解释

对每个任务实例i：precision为可观察目标TP面积/(TP面积+分配FP面积)，completeness/recall为其固定参考样本中到完整预测mesh距离≤阈值的面积比例，F1为二者调和平均；无预测分母时precision=0。Q为所有任务实例F1的等权宏平均，**不是宏precision与宏recall再做调和平均**。分别输出C_map、macro_precision、macro_completeness、macro_f1/Q以及J=C_map×Q，无类别/语义加权。实例完整漏检仍贡献F1=0。

实际噪声传感、地图来源、覆盖分母、返航/碰撞资格仍由未来runner独立记录，此静态模块不据此声称完整ANS或SLAM有效。V39仅外竖面口径不得和此V40可观察外表面Q混算。候选认证、评价合同门、固定采样精度检查及真实重建集成通过前，不开始独立测试矩阵。
