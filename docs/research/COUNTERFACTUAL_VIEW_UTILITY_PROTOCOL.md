# 设施场景的语义视角价值反事实开发协议

本协议在共同历史、共同地图、共同候选和共同动作成本下检验：细类别信息是否提高真实有效观测收益，以及完整隐藏表面模型为何仍可能产生负贡献。它是有限开发实验，不是独立确认；不改变 ANS 双层结构及 OV-SDF、STGHP、RPN-UQ、IGCR 接口。原则与有条件推导见 [理论文档](COVERAGE_SEMANTIC_THEORY.md)。

当前依据：V4 改善了开发集的覆盖代价，但仍弱于去物体假设版本；实测反馈在已完成对照中没有产生决策差异。新设施已实现唯一实体并集外表面和 RGB 标记读取，尚未证明规划价值。标记实验中出现多个背景假设且目标类别只改变部分预测面积，因此“标签读到了／预测分数变了”均不算本协议通过。另据[旧表面参考审计](LEGACY_SURFACE_REFERENCE_AUDIT.md)，8个旧世界经过可见性过滤后仍有约0.285%—1.908%的冗余／内部权重，可见共面重复均来自复杂货架；本协议必须使用新唯一外表面参考，不能直接继承旧参考，也不预断原方法排名是否改变。

## 1. 已有能力与输入边界

使用 `env/virtual3d_inspection_v4.py` 的 `InspectionConfigV4`、`InspectionWorldV4`、`read_inspection_markers_rgb` 和唯一并集外表面。主感知设置为 `appearance='marked', semantic_source='rgb_marker'`；读取器只获得当前 RGB，仅在可见标记像素返回 2／3，其他像素为 0，不会给出整物体实例分割、隐藏类别或目标中心。标记是人工设备识别色，不是自然图像开放词汇能力。

规划器可用已录制 RGB-D、相机内参／输入位姿、单线雷达、其建立的占据与表面地图，以及深度聚类得到的对象范围。`world.objects`、`inspection_truth`、`_solid_primitives`、`reachable`、完整 mesh 和物理类别仅留在实验搭建／评价进程；不得用于当前分支评分、筛选候选、可达性或逐实例参数修正。独立真值派生的诊断只能在所有评分和选择写盘后运行。第7节的离线监督校准只使用751／752事后结果，参数封存后才能评价753／754，不能把这种离线校准称为机器人在线获得真值反馈。

旧 `scripts/check_semantic_signal_v3.py` 只执行端点捕获，不是本协议执行器；不得直接把其输出视为本阶段结果。新执行器需按下列流程实现。尤其不能复用其中默认 0.1m 的 `GridConfig`：必须明确继承设施的 `resolution_m=.2`、实际半径、深度范围、360° 雷达视场和预算。

## 2. 冻结的有限开发矩阵

共用 96×72 RGB-D、3cm TSDF／12cm 截断、单线雷达、零输入位姿误差、零深度丢失；噪声两档 `depth_sigma_m=.01/.03`。不增加模型训练或 GPU 依赖。工作单元使用 `bays_per_side=1`、其他设施尺寸保持默认，`complex_fraction=.5`，每个场景有两个对象。选择这个规模是为了逐个分支检查，不称大尺度实验。

开发种子固定为 **751、752、753、754**。751／752 仅用于拟合兑现比例和确定一次内部修正；753／754用于随后固定版本的开发检查，仍不属于论文独立确认。此前已查看的731—734仅作已有可读性证据。**301—308及401—412禁止用于本协议。**

| 物理场景组 | 参数变化 | 每种子固定历史检查点 | 历史数／噪声档 |
|---|---|---|---:|
| 主机制组 | ambiguous + correlated + shelves | step80、step160 | 8 |
| 几何可辨对照 | open + correlated + shelves | step80 | 4 |
| 无信息类别关系 | ambiguous + independent + shelves | step80 | 4 |
| 反向类别关系 | ambiguous + reversed + shelves | step80 | 4 |
| 隐藏形状失配 | ambiguous + correlated + vertical_baffles | step80 | 4 |

合计24个历史／噪声档，每历史至多12个共同决策候选，主分支上限 **576**；追加后述固定小范围候选充分性审计最多32个分支，总上限608。每分支至多48个前进／转向动作，所有评分变体共用同一次真实分支结果。两档噪声、检查点及物理控制均为种子内重复条件，不能当独立样本。

RGB 标记的 `independent/reversed` 关系组会改变真实标记颜色，不能声称其 RGB 不变；须核对几何、深度、雷达与位姿不变。只有同一物理场景上的标签 `shuffled/absent` 干预要求 RGB-D、雷达和位姿逐字节一致。

## 3. 共同历史生成与封存

1. 每个物理场景／噪声档用同一个 `QualityCoveragePolicy(..., 'coverage')` 从真实起点执行。逐步保存原始 RGB-D、雷达、输入位姿、动作和时间；prefix 控制器不读取类别进行决策。
2. 保存step80与预定的step160快照。若控制器提前停止，记录实际停止步并把后续预定检查点标记不可用，不为制造成功样本改起点、延长探索或换种子。
3. 同一快照重放到 `SemanticHistoryMapperV3`，生成所有评分器的共同占据图、实测几何、质量证据和安全朝向图。除语义字段及对应形状概率外，应断言几何状态、TSDF顶点／三角形、起点朝向及已见证据键一致。
4. 记录可见标记像素数、带标记支持的几何簇数、可达候选数；这些用于解释信息是否存在，不作为看完结果后删除样本的标准。主机制组若过半快照没有标记支持，先判为采集条件不足；保留零信息快照并单独报告，不可只呈现有标记子集。

源码、配置、完整prefix、候选表和初始地图分别计算哈希。生成评分表后再开放未来分支与真值评价。若根据结果修改算法，保留旧版本，全部数据归开发记录；不得把753／754继续描述为未查看检查集。

## 4. 公平的候选与评分控制

候选池只生成一次：基于共同实测几何取4个前沿／覆盖位姿、4个几何对象环绕位姿、4个已知自由空间均匀位姿。每组先按确定性“动作代价、坐标、朝向”排序，再按距离分位取样；缺额由其余组按相同顺序补齐、去重。朝向由观测几何确定或按四离散朝向确定性轮取，禁止按语义分数或未来收益筛入。覆盖anchor的首目标必须包含在前沿组中。

从共同当前位置和朝向建立已知自由空间的 `orientation_graph`，以同一前进／转向单位代价生成每个候选的去程和回到共同起点朝向的最短路。所有方法共享机器人轮廓、安全图、候选序列及接驳代价。只保留去程加回程不超过48动作且去程至少1动作的候选；理由逐项保存。零候选是可行性失败，不能用真值位置补足。

| 评分器 | 允许的差异 | 用途 |
|---|---|---|
| G：几何形状模型 | `semantic=False`，共同形状库、共同实测几何似然 | 强去语义对照；不能永久固定混合概率 |
| O：仅物体性 | 与S相同可见非零标记支持；`fine_categories=False`，近看类别奖励为0 | 检验细类别是否超过物体／背景信息 |
| S：细类别形状模型 | 正确RGB标记；类别只改形状概率；其余同G／O | 本阶段主要语义命题 |
| X：错误标签 | 对同一frame的2／3交换，RGB不变 | 类别语义的干预验证 |
| M：缺失标签 | 语义字段全0，其他不变 | 缺失输入回到共同几何模型 |
| N：无隐藏形状收益 | 同候选、同已有表面／相机覆盖分支，仅将隐藏表面通道置0 | 排除候选减少造成的“去模型更好”假象 |

主要S／G／O比较统一关闭旧的类别近看额外项，使增量来自细类别条件形状；当前完整V4评分另设S+为次要读数，明确它同时含近看奖励。不得把两种语义来源合成一个无法归因的对照。各评分器应输出原始隐藏面积、实测面质量项、相机／雷达覆盖项和最终带代价分数，不能只留最终排名。

G／O／S／X／M共享形状点坐标和几何候选；只允许概率／有效面积权重变化。当前完整V4开关会同时改变对象候选，因此N必须通过固定候选评分得到，不能直接把不同候选池的闭环 `no_hypotheses_v4` 当成本机制消融。M应与G在同一历史上的预测和选择一致；若不一致，先定位额外语义路径。

## 5. 实际动作和共同噪声的反事实执行

每候选从相同物理状态、相同prefix和同一初始TSDF开始，执行已存的去程、到达帧、回程。使用真实 `world.step('forward'/'left'/'right')` 与 `world.scan()`；所有沿途帧均按相同规则融合。到达时自然获得的一帧即为本阶段端点观测，不免费添加四帧、不瞬移到端点、不提供当前策略没有的无成本停留动作。

返回成本包括恢复共同起点朝向；若前进碰撞、路线不可执行或超出48动作，保留为该候选失败结果，不用真值修路。返程是用于公平比较相同结束状态的实验设计，不声称现有完整控制器已经实现覆盖保留路线。另记录不含返程的单向代价供实际离开区域的场景解释，但不得用它替换主要成本。

现有深度噪声由 `SeedSequence([scene_seed, step_count, 739])` 决定。同一分支绝对步号对所有评分器完全相同；不同候选从同一步开始，因此按相同相对动作序号共享标准噪声序列。两档标准差使用同一标准噪声场。每个候选只模拟一次，六种评分器读取相同结果；未来分支不重新根据某个评分器的标签生成物理观测。

同时记录：(a) 去程新增观测；(b) 到达帧相对所有此前去程帧的剩余新增观测；(c) 回程新增观测；(d) 全分支的唯一并集。预测也必须在整段已存路径上逐面元取最大值／并集去重，不能拿仅端点预测去拟合整条行驶路线的实际收益。

## 6. 独立外表面与TSDF评价

使用设施的唯一实体并集外表面，先独立按物理面积固定采样32000个点，再以固定可达视角格点筛定可观察参考；每个保留点权重为原并集面积／32000。全体方法共用同一参考、真值遮挡场景及可见性判据，不按类别加权，不把不同零件重叠面重复计面积。有限参考和视角格点近似须写入结果元数据。

对参考点q，评价器用物理相机姿态／内参、真值首交点和该帧有效深度像素确定是否在这次观察中可见，记为V(frame)。唯一新增可见外表面积为 `A_new = Σ_q w_q · 1[q∈(∪V_future)\(∪V_prefix)]`。该量表示本分支提供了多少新可见物理表面；它不证明这些表面已被准确重建。应保存每个q的prefix／去程／端点／回程可见位图，以便复核去重。

真实重建收益另算：共同前缀网格与融合新深度后的网格，分别在同一参考上计算F1@2cm／5cm、精确率、完整率和表面误差；保留负增量。主要TSDF结果为 `ΔF1@5cm` 与 `ΔF1@5cm / 全部动作数`。同步报告二维实际覆盖增量和分支48动作窗口内的联合AUC；分支结束后只保持最后地图，不凭空添加观测。检查点包含prefix、到达、返程结束；若AUC仅在这些点插值，明确是稀疏近似。

对象区域结果仅作已预定诊断：评价器按全部对象的真值空间和物理类别分解面积与误差，G／O／S使用完全相同参考。主决策价值仍报告全场景，不允许只在S选中的对象或“复杂”类别上重新定义主分母。

## 7. 校准、排名与完整隐藏模型归因

按历史分别报告Spearman相关、成对排序正确率、top1实际收益、top1后悔值及选择一致率；所有收益为真实 `A_new`、`A_new/动作`、`ΔF1`、`ΔF1/动作`，不能只与另一个代理相关。常数预测或常数结果时相关标为未定义，保留这些历史及选择结果。计算类别前后概率差、信息读取准确率只能说明输入可用。

用751／752拟合一个预先限制在[0,1]的共享兑现系数；在753／754上报告原始与校正面积MAE、面积总量偏差、零真实增益但正预测比例、每种子的排名和选择收益。S／G／O使用相同校准形式和相同拟合样本量；不得让S按类别拟合而G只拟合一个常数而不单列容量影响。当前没有校准的假设概率不能标为真实成功概率。

| 失败原因 | 评分封存后的可计算诊断 | 对应的独立效用检查 |
|---|---|---|
| 背景伪对象 | 每个几何簇的实测点到唯一真值面的物理类别比例、目标实例支撑比例；假设权重在背景／真实对象上的分配 | 将背景假设权重置0的**真值诊断上界**与原预测之差；绝不将此上界当可部署方案 |
| 形状／概率失配 | 各形状到真实外表面的距离、预测点落在实体内部／自由空间的比例；类别先验与实测似然各自贡献 | 比较同候选G／S／X及baffles组的校准误差，不因标签正确就认定形状正确 |
| 可见性误判 | 对每条候选预测射线，比较已知图＋假设自遮挡与真值首交点 | 统计实际被其他物体挡住、被自身挡住、出视场及深度无效的面积 |
| 重复计益 | 预测新面中实际已被prefix／去程看过的面积；相同实测证据键的重复支付 | 分离去程、端点剩余和回程增量，检查全路径并集恒等式 |
| 质量代理失配 | 证据账本增量和真实ΔF1、固定支持面误差之间的对应 | 账本增加而F1下降的比例；不截掉负例 |
| 候选覆盖不足 | 对预定seed751、753的主组两个检查点，在0.01m噪声下额外评价每对象front／rear审计位姿，最多4个／历史 | 这些仅由实验器的`inspection_truth`取得；若不在共同已知安全图可达则只记不可获取，不瞬移；上界不得纳入方法排名或重新选择 |

最后一项最多4历史×4候选＝16分支；为候选哈希失败等实现复核保留16个重放分支，总追加不超过32。若额外审计位姿明显更好而正常池未覆盖，先改几何候选生成；若正常池已有高收益位姿而S未选中，先改概率／可见性／收益，不混为“场景不合适”。

## 8. 预先通过门槛与失败后的动作

这些是开发进入下一阶段的门槛，不是统计显著性或论文独立优势结论；一旦修改门槛，旧结果保留并标记版本。

1. **完整性硬门槛：** prefix／候选／物理输入匹配、真值隔离、唯一面积、动作会计及source冻结全部通过；失败则本次效用结果不可用于正向结论。只修复执行／评价错误并完整重跑。
2. **预测门槛：** 在753／754的主机制组，S对实际`A_new/动作`的平均成对排序正确率至少0.65，且比G和O各高至少0.05；可定义的Spearman平均至少0.30。所有零信息历史计入选择收益汇总，另报缺失比例。
3. **实际语义价值：** 相对G和O，S在主组的top1真实`A_new/动作`均值各提高至少10%，且两个检查种子块方向均为正；当对照均值低于1e-6m²/动作时不报百分比，要求绝对增量至少0.01m²/动作。同步要求平均`ΔF1@5cm`不低于对照超过0.001、top1后悔值不增加。
4. **校准门槛：** S校正后面积MAE相对自身原始预测下降至少10%，检查集总预测面积／总实际面积在[0.5,2]；全零分母时标为未通过。该较宽范围仅排除严重失配，不称校准完成。
5. **新增模型净收益：** S相对同池N的top1平均`ΔF1/动作`须为正，两个种子块均不为负；全场景二维增量每分支平均代价不超过0.1m²。否则不得因S>G就宣称隐藏模型本身有净贡献。
6. **负控制与失配：** M应恢复G；X及reversed组相对正确关系S的主收益至少出现下降方向。independent组若仍持续大幅胜出，先检查标签／几何泄漏或对象性混淆。baffles组若比G平均`ΔF1`低超过0.002或误差率明显恶化，判定模型鲁棒性未过，不能扩大领域结论。

门槛2失败：在OV-SDF内部修正背景实例筛选、形状似然和可见性，不改变共享候选。门槛3失败但排名通过：检查成本、饱和和任务效用映射；不要加大语义密度权重。门槛4失败：在IGCR内部用真实证据拟合兑现量并保持持久身份。门槛5失败：用N差异定位重复通道／错误对象，必要时以语义条件有效观测需求替换具体箱体库，但保留语义核心与四模块接口。候选不足则只改STGHP内部提议；不可达失败则修RPN-UQ的几何／预算接口。

## 9. 执行顺序与交付物

先实现一个独立的小执行器，调用现有设施、mapper、朝向图和评价API；不覆写旧确认协议或已冻结结果。先跑751／752主组的4个历史×两档噪声（最多96分支），核查逐帧重放与四项分解，再按原配置完成剩余矩阵。首批若发现代码错误，保留失败目录并完整重跑；若只是效果差，保留结果进入归因，不提前换种子。

目录至少包含：`protocol.json`、`sources.zip`及哈希；每物理fixture配置和外表面审计；共同prefix与地图；评分前的固定`candidates.json`／`predictions.json`；每候选动作、实际帧与扫描、代价／失败原因、到达和最终网格；独立参考及可见位图；`outcomes.json`、种子块汇总、失败归因表、校准参数和只读重放验证。文件中的状态明确区分“输入可读”“预测有效”“真实单步价值”“闭环总体优势”。

只有本协议的机制门槛通过，才固定模块修改并恢复设施闭环比较；本协议本身不证明ANS完整四模块系统、主流baseline优势、真实开放词汇识别或SLAM定位精度。独立种子在开发、同池消融、完整隐藏模块净收益及覆盖代价同时过关后另行冻结启用。
