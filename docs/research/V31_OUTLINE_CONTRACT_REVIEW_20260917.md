# V31 投影外形契约：独立执行前审查

2026-09-17。此文是候选规则的只读设计审查，未运行候选实现、解析评分或既有网格重评分；新增 world、sensor、mapper、TSDF 和主任务均为 0。未修改 V23/V30 的代码或分数。结论是**可以进入有界解析门，但尚未验收指标，也没有语义有效性结论**。

## 1. 修正的对象与不能扩大的主张

V23 在 `utils/facility_outline_v23.py:43` 把投影面积二倍值不大于 `1e-14` 的三角形直接丢弃；随后仅对剩余三角面求 union，再填每个有界孔。其边界采样和距离函数也只遍历 polygon exterior（同文件第 63、88、99 行）。因此完整竖面的 XY 线支持不是“不准确”，而是没有进入此种面积表示。V30 完整实例 companion 复用了这一规则，解决的是预测裁剪问题，没有改变这个表示缺口。

候选修正把真实已提交表面的退化投影保留为线，并仅由它们实际闭合的平面环生成外形区域。它适用于“三个投影的外轮廓及尺寸”，不能称为已观察顶底面、闭合 3D 重建、体积精度或全部外表面完整率。投影环的各段可能来自不同高度的表面；平面闭合不等于 3D 中存在一个实测闭合面。

不能把“准确竖面、薄片、实体等价”写成无条件保证。准确且连续的完整外侧竖面可形成同一 XY 闭环；有明确厚度的连续薄片只应在其已知几何偏差范围内接近参考。带缺口的薄片没有同样的闭合证据，在禁止补线的合同下必须保留这个差别。三投影本身还存在不可辨识性：不同 3D 表面、内部结构或缺面可能具有相同三投影外形，任何此类指标都不能靠改公式辨认它们。

## 2. 冻结前应写死的几何规则

建议把每个投影表示成面积、线、点三个互不混淆的证据层。

1. 非退化三角投影先作 polygon union，得到 `A0`。不得把所有三角形的内部边都加入待罚线集合，否则同一表面的换对角线或细分会改变成绩。
2. 每个退化三角投影只保留其自身的投影线凸包，即实际共线点的最远端点线段；全重合则为点。这里允许的是**一个退化三角形的线支持**，绝不是整设施或多片段的凸包。
3. 对 `boundary(A0) ∪ degenerate_lines` 作无吸附、无缓冲的 noding、去重及 polygonize。线段交叉产生交点；不能连接原来不接触的端点，不能以 2/5/10 cm 的评分阈值作几何吸附半径。
4. 将 polygonize 得到的有界面与 `A0` 合并，再沿用外轮廓任务的有界孔填充。保留非凸边界与不相连组件。环面来源、填孔面积、组件数均单列，不能把评价区域填充称作新增实测表面。
5. 供边界评价的支持应为 `boundary(A) ∪ (degenerate_lines \ A)`，再按几何集合去重；保留位于面积之外的开放线、桥线和孤立线。原面积内部的线不参与外轮廓罚分，但其长度可单列诊断。这样合法重复边、重三角化和共同边只算一次。
6. 主实现已选择在输入侧拒绝 3D 零面积三角形，防止用虚构 wireframe triangle 冒充实测表面。数值判定阈值必须冻结；正面积 3D 三角形的正交投影不可能精确退化为单个点。若数值处理仍产生零长点，应作为非法/数值诊断保留并拒绝该输入，不能扩成面积、提高 recall，或按顶点数赋予任意“长度”。不得静默清理旧 TSDF 的退化面后冒充原提交网格。

“精确 noding”应准确表述为输入坐标上不主动 snapping 的浮点几何运算，不是证明了任意精度的数学精确运算。冻结 Shapely/GEOS 版本、`grid_size=0` 或同等参数、退化判定及无效几何处理。不得使用自动 `buffer`、端点合并、`make_valid` 后静默删除几何等方式修成功。遇无效结果应保留输入 hash 和失败收据。

## 3. 边界、面积和多余几何的计分

继续固定 `Q_projection = min(F1_length, IoU_area)`；三投影、全部任务设施的分母不变，阈值仍为 .02/.05/.10 m，边界积分间距 .01 m。

线长 precision 从整个预测边界支持到参考外边界积分；recall 从参考外边界到整个预测边界支持积分。长度使用 union 后的真实线长而非线段数量。Hausdorff 需要计开放线端点；孤立点按上文非法/数值诊断处理。面积为空时该投影质量仍为 0；可以保留线支持的 P/R 作为诊断，但不能让接近正确轮廓的开放 U 形得到完整投影质量。若实现选择将这时 P/R 一并记 0，也须预先固定，避免混用两种口径。

额外的外部悬线不能因没有面积而被丢掉。给一个正确边界追加长度 `L`、且全段距参考大于阈值的独立线，若正确边界周长为 `P`，本规则应有 precision=`P/(P+L)`、recall=1、F1=`2P/(2P+L)`，IoU 仍为 1。这个解析关系可直接作为断言，验证额外几何确实进入分母。

不得宣称“所有错误桥接都必然被此分数发现”。跨越非凸外形真实开口、并闭合成错误面积的桥接应受 IoU 惩罚；两分离组件间的外部线桥应受线长 precision 惩罚。**完全处于正确填充区域内部、未改变任何三投影外边界的错误 chord/面、重复重合表面和被合同主动忽略的有界内孔，属于本外轮廓任务的盲区。** 若毕业任务要求惩罚这些错误，还需要独立的实测表面/占用一致性诊断，不能把外形 Q 改名为完整 3D 精度。

实例层另有一个已有边界：`nso/facility_outline_v30.py:137–160` 对未归属额外 slot 保留诊断，但它不进入固定真值设施 macro；一个额外独立假设施可能不降低已归属设施 Q。主实现已选择新增 `output_precision = uniquely_matched_nonempty_slots / all_nonempty_slots`，用它乘固定任务 macro Q，并另保留 base macro；任何非空未关联输出使新增输出资格门失败。这能处罚未关联假设施，但它是按输出实例计数的假阳性项，不是面积加权几何精度，且受 slot 拆分粒度影响，必须如实披露。唯一性应基于**非空 slot**计数，否则一个有重复 seed 的空 extra 仍会经旧 Counter 破坏正确归属，与“空 extra 不罚”矛盾。重复非空归属仍使该参考为 0。建议全空分母时 precision 固定为 1（无假阳性），base macro 仍为 0、全部设施 missing，绝非成功；不可把分母 0 变成 NaN 或少算任务。漏检、重复非空 seed、模糊归属仍须保留全部任务分母且不手工纠正。`minimum separation` 仅表示非空且不是完全重复组件，不是验证了自然语义实例分割。

## 4. 第一道门必须包含的解析反例

所有尺寸、坐标、厚度、旋转、阈值及预期关系应在运行前写入 fixture 清单与 hash。以下是验收关系建议，不是运行结果。

| 固定 fixture | 必须检查的关系 |
| --- | --- |
| 同一盒形的闭合实体、四面连续准确竖面 | 三投影面积与参考一致，Q 各为 1（仅预声明浮点容差）；不得声称顶面变成已实测。 |
| 同一非凸 L/U 外形的闭合实体与完整外侧竖面 | 保留凹口，禁止整体凸包；理想对应表示应等价。 |
| 非世界轴 yaw、平移、换对角线、细分、输入重排及重复面 | 对同一几何集合的表示成绩不应变化；以坐标变换后的参考比较，不在线对齐预测。 |
| 固定小厚度的连续完整薄片 | 不要求逐位等于零厚度表面；偏差上界按 fixture 厚度及已知解析面积/边界制定，不能看 Q 再定容差。 |
| 明确投影为开放环：缺一边、正长度微小缺口、断开的薄片角接点 | 不得自动补线；只有线而无面积时该投影 Q=0。微小缺口也应保留，说明算法在拓扑闭合处存在不连续。 |
| 非凸开口上的错误连接、两分离组件间的线桥和面桥 | 前者增加错误面积；线桥受长度 precision 惩罚；面桥受面积/边界惩罚。各例都要把错误放在参考外部可辨识处。 |
| 正确形状外追加远离参考的退化投影线、非法零面积 3D 三角、额外盒形 | 合法竖面产生的外部线满足上一节解析分母关系；不能用零面积 3D 伪三角构造线 fixture，非法输入必须明确拒绝；额外盒形不能被过滤。 |
| 额外盒形为同一 slot 与独立未关联 slot 两种输出 | 前者 base Q 应降；后者即使 base macro 不变，output precision 应降、完整输出门必须失败。正确两实例加一个未关联非空实例时，系数应为 2/3；加空 extra 应不变。 |
| 缺失、全部缺失、重复非空 seed、模糊关联、空 extra 的重复 seed | 固定任务分母，缺失实例 Q=0；全空系数处理确定；空 extra 不改变原正确值；不能借 union+GT 窗口自动修复身份。 |
| 投影内部 chord、投影不可区分的 3D 缺面、嵌套有界孔 | 明确列为合同不辨识/主动忽略的对照，不写成已验证 3D 完整性。 |

必须特别区分“缺失某个可见方向造成投影支持缺口”与“任意少一个面”。后者有时被其他表面在投影中完全遮盖，不可能同时要求纯外轮廓等价和保证所有缺面降分。正例、反例及不可辨识对照全部保留，不因无效或低分删 fixture。

门的通过应是：正例符合预先算出的等价/误差关系，可辨识反例按上述机制降分或触发明确完整输出门，不可辨识反例被如实标注，输入与版本均可复核。仅换新公式后 V30 四案 Q 上升不是此门通过。若精确闭环要求使真实薄片长期无法成环，也只能报告适用范围不足，不能在本轮追加调参、吸附或补线。

## 5. 建议最小 API 与证据字段

建议新文件独立实现，旧模块保持不动。核心先只接数组，避免解析门构造 world 或 mapper：

```text
projection_support_v31(vertices, triangles, axes, frozen_parameters)
  -> ProjectionSupportV31(
       area_geometry, boundary_support, exterior_open_lines, isolated_points,
       diagnostics, input_geometry_sha256, contract_signature)

compare_projection_support_v31(predicted_support, reference_support,
                               spacing=.01, thresholds=(.02,.05,.10))
  -> saved P/R/F1, IoU, Q, missing_area,
     Hausdorff/invalid-point diagnostics and explicit support gates
```

`diagnostics` 至少保留：面积三角数、线退化三角数、点退化数、去重前后线长、noding 后长度、polygonize 产生的闭合面数、未成环线长、被面积覆盖的内部线长、填孔面积、最终面积/组件数、额外孤立点数、是否发生吸附/修补（必须 false）。若仅“长度守恒”没有证实几何集合相等，不应写成 noding 完整性证明。可保存紧凑 WKB/hash；不用生成大型图或重复网格。

新实例 evaluator 可继续使用冻结实际 first seed 的唯一评价侧归属，但不能读取类别或观察次数，不向 backend/planner 传 GT 尺寸、外壳、bounds 或 reference。预测整体输入 hash 必须前后一致；bounds 只用于参考与归属，不能裁预测。新增输出的语义应为 `measured_projected_support` 与 `evaluation_enclosed_2d_region`，不能叫作补出的实测 3D 面。

V31 原始 Q/J 与新 Q/J 必须版本化并列。base 外形 Q、output precision 与两者乘积分别输出；保存每个乘数的原始计数。C80、返航、安全和总预算资格不随外形公式改变；新增完整输出门与原物理资格分别报告，最终可取两者 conjunction，不回写旧资格或旧分数。第一道门通过以后，再对 V30 保存网格做解释性开发诊断，仍是见过的数据，不是独立语义确认。
