# V33下一阶段：先验证方向信息价值，停止当前路线扩量

2026-09-17。本文件是V32后的开发设计，尚无新场景成绩，不把计划写成已验证方案。保留ANS全局/局部结构和OV-SDF、STGHP、RPN-UQ、IGCR。主任务已16/36，剩余最多20；2026-09-29必须作有效性去留判断。

## 为什么转向

V32在不改原观测的情况下缓解了毫米断环问题，但5cm主联合指标下，当前固定A/B目录的两选项全知oracle也只等于最佳固定B。更好网络不能超过同一目录的全知上限。复杂设施自身补看增量较大仍不足以说明“优先复杂类”是最优决策，因为覆盖、方向、位置与可兑现程度共同决定净收益。

下一候选问题定义为：**在遮挡工位/设备通道中，类别能否提前预测哪一个观察方向能取得可测的外形信息，节省先探看再改选的代价？** 类别不能直接给分，只有真实执行后获得的外表面/外轮廓改善计收益。场景故事是有限时间内完成设施外形建档，而非强迫无语义方法放弃补看。

## 单一场景家族与公平控制

采用有实体遮挡的设备工位/通道家族，让同样前部几何和一般可见性下，不同设施类型的关键外露结构分布在不同服务侧。类别提示只描述类型，不能编码绝对坐标或最佳动作。类别与可观测结构的关系必须由明确几何生成规则产生，不用“看到复杂类就增加Q”的公式。

构造两个父布局与成对类别/结构排列，并预留类别失配或无信息控制。通道长度、遮挡、设施尺度和传感视场在成绩前固定，不为使语义赢而逐次延长错误路线。普通几何对照具有相同对象位置线索、规则、动作、候选生成能力、共同地图后端和历史训练分布；它可以补看、获取真实几何信息后改选并返回。主S/G允许各自提案，只有排序消融共用候选。语义算法只额外获得合法类别条件信息。

## 先做零物理筛查

下一执行批仅包含一个有限、可穷举或有明确最优界的几何模型，不新增world/传感/TSDF主任务。复用已有V29有限信息价值工具，必须明确其离散代表点、可见性和识别假设，不能把理想界当真实收益。

1. 固定动作、预算、遮挡与真实返航，先验证公共覆盖与双侧关键表面可观测。若新预算与V30不同，作为新任务协议明确冻结，原48步失败照旧，不写成原任务成功。
2. 对无类别信息G允许全部合法探看和识别后改选，求其期望最优值/可核界；对有类别信息的条件最优策略使用同一动作和预算。不能仅比较两个固定臂后称强G。
3. 两个父布局均要求信息相对价值超过沿用的5%开发筛查门，且不是由失去C80或返航资格换来。输出无类别最佳策略、类别条件选择、识别时机、改选成本和失败路径。
4. 同时检查主阈值及预声明邻近阈值的排序稳定性、类别置换/无关类别控制。2cm才正而5cm无空间的情况不能晋级。物理实验前再冻结测得3D表面P/R、外轮廓支持与覆盖的评价分工；不把支持Q单独当完整3D精度。

只允许一个首版模型加一次有明确几何/信息合同缺陷依据的修正，不能因收益小而无限扫尺度、视点或预算。两版都不满足门，即停止此场景家族，汇总反例与可行范围供导师决策；不以训练模型来绕开信息上限失败。该阶段不宣称新颖性或主流方法优势。
