# V43 观测占据图与公共导航安全约束

2026-09-21。实现位于 `nso/observed_safety_v43.py`，保持 V40–V42 冻结源文件不变。安全与二维发现代理由 S／G 两组共用，不读取实例类别、结构原型、仿真器或真值障碍。

## 调用顺序

```python
safety = ObservedSafetyV43(
    public_graph, robot_radius_m=0.2,
    unknown_space_policy="provided_navigation_prior")
receipt = safety.update(
    mapper.snapshot(), mapper.occupancy_arrays(), router.state)
utilities = safety.discovery_utilities(candidate_states, radius_m=2.)
decision = router.choose(utilities)  # 对更新后的图重新计算返航预算
guarded = safety.guard_action(decision["action"])
```

`update()` 先检查 V42 地图版本、形状、int8 占据值、数量与 SHA、行列坐标约定、最近已付费观测 SHA，以及最近相机位姿与当前公共图状态一致性。保存输入副本，不保留外部可修改占据数组。相同版本的完全相同输入可重放同一回执；同版本更换地图、当前观测掩码或状态以及版本倒退均拒绝。所有验证和局部碰撞查询完成后才删边。

V43 控制器还将地图全部历史观测 SHA 与已接收帧历史逐项比对，确认来自同一条测量历史。哈希证明输入绑定与复查一致性，本身不证明量测为真实物理传感器产物。

## 连续扫掠几何与返航

每条已声明的 0.25 m 图边以起终点线段为中心，机器人圆形足迹半径默认 0.2 m。障碍是地图中被实际标为占据的闭合方格，采用线段到 AABB 的精确二维距离与半径比较；距离相等的切触也判碰撞。计算包含线段内部最近点、端点和格角，不能只检查边两端，也不能把整个轴对齐外包框当作扫掠面积。

局部查询仅枚举边及半径外包范围附近的格子，每次最多 65,536 格；公共图最多 4,096 条原始可用的扩展基本边。超限在图修改前报错。该策略避免逐条边与整张地图所有占据格做笛卡尔积。

发现冲突后只通过已有 `block_observed_edge()` 删除公共图声明的边，不添加可通行边、不清除原点障碍。回执记录每条新删边的地图版本、占据 SHA、最近观测 SHA、占据或未知格见证，以及历次由本安全模块删掉的边。其他模块因已经发生的实际碰撞删边仍保持删除，本模块不冒充这些外部事件的证据来源。

当前圆形足迹已碰到占据格时，平移、旋转及新付费观察均停止；圆形模型转向不会改变足迹，不能用原地转圈绕过冲突。`stop`／`blocked` 只返回终止决策，不产生新观测或额外免费动作。

删边之后，路由器必须在同一更新后的图上重新计算去程和回到起点 XY／航向的费用。若新的测量使机器人无法返航，结果应为 `no_budget_feasible_return`／`blocked`，保留已执行动作；不能恢复被删边或额外赠送动作。此约束只对已有公共图与已测障碍成立，不保证未观测障碍永远不会阻断返航。

## 未知空间声明

构造器必须显式指定 `unknown_space_policy`，没有隐含默认授权：

- `provided_navigation_prior`：允许依照各方法共享的既有导航先验穿过未知格；回执明确未知不等于已测空闲，地图外也属于未知。
- `reject_unknown`：未知格及地图外的足迹接触也删边并停止当前不合格足迹。该 guard 的删除保持单调，不自动重新开放早前因未知而删掉的边。

因此，使用前一种策略的实验必须在论文中披露导航先验，不能写成完全无地图且已证明安全的探索。

## 共享二维发现代理

`discovery_utilities(states, radius_m=2.)` 返回候选状态到局部未知格面积的映射：对候选 XY 半径内格中心作圆盘筛选，再统计未知格面积。相同 XY 的不同航向得分相同，对应全周单线雷达的二维代理。`discovery_receipt()` 记录输入 SHA、半径与所有候选得分。

这一代理没有预测遮挡后的真实可见面积，也没有读未来扫描；不计地图外面积。它不能直接报告为实际覆盖增益或三维精度。V43 控制器另外将已经付费到达过的 XY 的发现得分清零，降低通过同地转圈重复获取二维代理奖励的风险；三维新视角收益仍由单独的结构后验预测器计算。
