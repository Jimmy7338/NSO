# V41 R0/R1：观测关联、当前残差与原语导航接线结果

日期：2026-09-20。承接 `07e7d3094` 的六类开发资产与静态评价器，本轮新增运行接口并完成 **73 项解析测试**。本轮没有启动实际 DEV World、传感轨迹、策略 rollout 或 TSDF 融合；不能增加新的语义优势或整体性能结论。

|问题|本轮实现|当前验证边界|

|原地转向的新视域被当作重复|按新增实测支持判断几何更新资格，不再只按相机平移距离|原地转向的新支持可更新；重复支持不累积证据|
|合法静止新帧可能与旧包完全相同|新 ID + 连续付费步骤允许相同数组，标记重复测量并禁止新证据强化|原 ID 重传与非连续步骤仍拒绝；合法性由 sensor/router 的动作账目约束|

|返航遗漏转向或只验证 XY|导航守卫计算原位原朝向的完整返回成本，检查完整相机外参|独立审查修复高度跳变/光轴roll可被误接受的问题；新增碰撞仍可能导致 blocked|

新文件独立于旧 P0/P1 源码和封存。ANS 全局—局部层次及四模块设计保留；目前实现的是它们所需的接口部件，尚未构成完整四模块自主运行。

## 实际像素残差如何计算

共有原型库从通用 `structure_boxes()` 构造，使用预声明名义尺寸 `(1.2, 0.8, 1.6) m` 及有限尺度，覆盖 planar、recessed、louvered、open_frame。调用方没有读取本次场景真实设施尺寸、姿态、AABB、owner 或全节点深度表。

从当前实际标记像素拟合竖直平面，检查平面性、完整尺寸、倾角和不确定性。这个锚点是观测标签面，不是已知物体中心。后续无标记帧只有先前观测锚点仍有效、当前几何关联唯一时才计算残差；否则明确拒绝。

对每种结构，在有限尺度、偏航和面内偏移候选中，用射线与实体并集预测当前相机的轴向深度，与当前关联像素的有效实测深度比较。误差截断，缺测不当作“没有表面”的证据。输出每结构 loss、样本数和未校准 pseudo-log-likelihood。独立审查还修复了重叠盒体在近裁剪内错误露出内部面的射线问题，现按区间并集取实体外表面。

这是一条可审计的当前帧几何反馈链；名义原型、姿态拟合、关联误差和似然尺度都仍需开发场景验证，不能把它称为已校准概率或已完成自然实例识别。

## 本轮实际验证

|测试集|通过数|
|---|---:|
|观测实例账本|17|
|实际像素残差|19|
|运动/传感适配|24|
|原语导航及返航|13|
|合计|73|

主线额外封存了一个独立指定平面的解析观测，统一相机高 0.9 m，分别输入 G/S 账本，再调用当前残差与反馈入口：

- 同一解析包 → 2 次账本接收 → 2 次实际像素残差 → 2 次反馈应用；G/S 的几何状态及残差完全相同。
- 四结构残差分别约 **0.000592、0.166481、0.120814、0.158653 m**，最小值对应这项解析夹具的平面结构。
- 该单帧没有达到两视角语义激活条件；不能利用 G/S 相同或不同的结果宣称语义效果。
- 同一当前帧接入原语路由器后可在动作 0 选择下一步，没有强制前缀；所用候选 utility 明确是合成输入，真实语义视角预测器尚未实现。
- 公开 1 m 边的观察/返回任务需 21 个原语，20 步预算被拒；这由构造观测测试验证，不是实际机器人执行轨迹。

额外接线使用的解析像素包及全部中间结果保存在 `audit_results/v41_runtime_interfaces_20260920/`。单元测试的其他解析夹具另列于测试源码与日志，不计作研究场景或独立性能样本。

## 实际运行门与尚未完成部分

真实 `DevelopmentSensorV41` / factory 在读取资产之前检查持久资源；没有关闭检查或使用 RAM 冒充持久盘的参数。本次实际探测为 ext4，空闲 **569,147,392 字节**，所需最低 **10,737,418,240 字节**，状态为 `blocked_before_world_creation`。用不存在的资产路径触发工厂也首先得到该资源拒绝，证明未进入资产读取。前后计数中的 World、RGB-D 研究帧、scan 和付费实际动作均为 0。

初始传感采用统一 grant：step 0 有一帧、动作成本 0；后续前进、转向、主动观察及碰撞尝试均计一次动作并产生同一步传感包。相机 near/far 使用 optical-z，雷达范围使用径向距离。实际噪声和无色标关联的成功率还没有开发轨迹证据。

下一阶段剩余三项核心接线：

1. **观测驱动的语义视角收益预测。** 从当前实例支持、结构先验及原型预测候选可见新表面/信息，接入 STGHP，不能用手工重要性分数或真实收益替代。
2. **完整观测地图和 TSDF。** 将 V41 传感包接入实际建图，修正旧 mapper 近裁剪与坐标假设；每帧只融合一次，不向预测几何注入真值。
3. **公共导航与实际任务运行器。** 建立并审核共同粗导航先验、统一动作及终止记录。满足持久资源门后执行预声明的小型开发诊断，再运行 S/G 动作 0 闭环及独立重放。

本轮完成 R0/R1 接口验证，R2–R4 实际运行仍未完成。现有论文的性能证据继续以之前封存实验为准。
