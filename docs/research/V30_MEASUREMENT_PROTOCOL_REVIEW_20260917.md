# V30 固定路线像素实验：测量与计费协议独立建议

2026-09-17。本次只读源码审查，不修改旧后端、指标或新运行器，不运行世界、融合或采集。

结论：**V24 实测清理、共同 TSDF、三投影计算核心可以复用；完整 V26 evaluate 不能原样称为“无预测裁剪的全局外形评价”。** 三投影对本场景的纯竖直实测面还有明确适用性风险，应在首条成绩前写入协议，并用解析网格测试确认行为。不能为追求通过而在成绩后改窗、删点、补面或换指标。

## 可复用的最小链路

固定两条 A/B 完整路线，跨两排列逐动作复用同一串；路线与传感参数在首条 Q 前冻结。每次采集从 action 0 开始，18 个公共动作加 30 个后续动作，总计 48。每次转向和前进后各有一包，初始包不算付费动作，合计每主任务 49 包、四主任务 196 包。返航必须恢复同一位置及朝向，不能把终点前的最好阶段冒充返回结果。

可直接复用 `QualityMapperV2`，显式配置 TSDF 体素 0.04 m、截断 0.12 m。它包含 `frames/mesh/surface/quality`，满足 `FacilityMeasurementV26.snapshot` 的接口；只有裸 Open3D volume 则不满足这些元数据接口。每包只融合一次，不以同帧复制增加独立观测数。

`FacilityMeasurementV26.observe` 及 `snapshot` 可沿用：两个固定 `MeasuredOnlyBackend` 从 frame 0 接收全部实际深度；第一次真实 RGB 二值 marker 有效像素提供 seed，后续几何处理不接类别或参考信息。保持原 16 像素、0.75 m 关联及至少两种付费位姿的支持诊断；不能按 GT 指定两个 seed，不能从若干候选挑 Q 最高的实例。`MeasuredOnlyBackend._enclosure` 已禁用推断，completed 必须与 observed 字节一致，inferred 为空。

快照先于独立 reference/evaluator 构造。保存 raw 全局 TSDF、两个完整 observed mesh、各自 seed 收据、实测/地面/清理/未分配点的数量与 hash、metadata hash；评分不得回写这些对象。未检测、地面未拟合或观测组件为空按结果保留，不抛弃该主任务。

注意 `FacilityMeasurementV26.snapshot` 本身是终态操作，调用后不能继续 observe。若要保留 prefix 18 的快照，不能对同一 measurement 调用 snapshot 后继续喂终点；最小版本可只保存 prefix 原始包和配对检查，主评价仅最终 48 帧后进行。

## 评价裁剪与主指标

原 `OutlineEvaluatorV23.evaluate:211` 对提交的预测 mesh 调用 `clip_mesh_to_bounds`，并非只裁剪参考。`FacilityMeasurementV26.evaluate:197` 用它评价 observed union 与 raw。该行为适合明确声明的“固定空间归属窗分数”，却会忽略窗外预测错误；如果把窗设为紧贴真值外形的 AABB，就可能隐形修复尺寸/地面残片污染。

建议 V30 在新评价侧适配器中保持原 Q5 公式，使用**固定 seed 唯一关联后的完整、未裁剪实例 mesh**计算主值：

\[
q_i=\tfrac13\sum_{p\in\{XY,XZ,YZ\}}\min(F1_{5cm}(p),IoU(p)),\quad
Q_5=\tfrac12(q_A+q_B),\quad J=C_{2D}Q_5.
\]

直接复用 `projected_envelope`、`compare_projection`、1 cm 边界采样、2/5/10 cm 阈值，以及原尺寸/中心误差与完成条件。该改动是**预测归属与裁剪方式的预声明版本变化**，不能声称与旧 `evaluate` 完全同一实现或直接跨版本比较历史 Q。旧宽归属窗分数可保留为明确命名的次要对照，不能在两者之间择优汇报。

归属窗只在评价侧用于 seed—reference 匹配和参考完整包含检查，不进入重建或规划。两排列应完全复用同一宽窗，预先声明例如原坐标 A：x=[-5.25,-0.75]、B：x=[0.75,5.25]；均 y=[1,7]、z=[0,2]。这是独立于类别的工位区，不是依据终点预测或成绩选择的裁剪盒；统一世界平移时同步变换。最终具体值须由运行器协议在首次 Q 前固定。

固定缺失规则：每个真实任务设施始终占宏平均分母的 1/2。只有一个实际 seed 唯一落入该窗且无重复归属时，才用对应完整实例 mesh；没有唯一映射或该 mesh 为空，该设施主 q 记 0 并给具体原因。重复/歧义不得经 GT union 窗重新分配后当作实例成功；漏建不从平均分母删除。未归属及额外观测几何继续保存，不能删除来提高分数。

完整实例 mesh 中的地面残片、墙片和跨窗部分必须继续影响该实例的未裁剪投影、尺寸及 Hausdorff，不能在评分前按真值修正。另列 raw 全局网格尺寸/面积/数量、未分配几何及各实例跨窗诊断。将包含真实地面/墙的 raw 全局地图直接与“两台设施”作无裁剪对象分数也不合适：那混合了不同任务范围。raw 窗分数只能作为参考归属的次要诊断。

## 三投影在本场景的适用性风险

`projected_envelope:43–57` 将三角面投影求并，并填充二维轮廓内部孔；真正退化成线的投影不膨胀成面。新场景所有相机 z=0.9，低于柜顶 1.6 和附件顶 1.2，底面又朝下或接地；不增加俯仰/高度时不能默认有可见水平设施面。

因此，即使四个竖面本身重建准确，理想竖直三角形的 XY 投影也可能全部退化；噪声、TSDF 角部及不连续薄片能否形成闭合二维环并不等于真实顶面观测。旧 V23 的粗扫 XY 极低已有这一机制。保留逐投影面积、F1、IoU、退化标记、Hausdorff 和尺寸误差，不能只给一个平均数。

首条前应有两个无采集解析反例：完整封闭参考自比满足 Q=1；移除水平面后的精确竖面模型检查 XY 退化及得分。若第二项低分，必须明确 V30 主分数衡量的是“当前实测表示在原三投影任务下的表现”，**不能把低 Q 或选臂不翻转单独当作语义机制被否证**。本审查不建议加免费俯视、GT 补面、凸包或类别外壳来抬分。若论文要求“已看清全部可见外侧即应完成外形”，需要另立共同观测外形表示验证，不能在这四条成绩后临时修补。

## 传感与动作合同必须显式对齐

1. **坐标和步长。** 旧 `GridTransform.validate_cpu_mapper:54` 固定原点 (0,0)、0.2 m 网格；V29 原坐标有负 x，且一次 forward 为 1 m。可整体平移世界/相机/reference 到合法 0.2 m 格中心，保留相对几何；不应把原始负坐标直接塞入旧 mapper。新 driver 必须按真实 1 m 段检查扫掠碰撞，不只检查端点；旧自主 runtime 的“一步一格”验证不能直接用于这串路线。48 是本次预声明动作单位，不等价于旧 0.2 m 步长的 48 动作或实车时间。
2. **视角。** 96×72、fx=fy=48 和水平 90° 对应垂直约 73.74°；V29 有限模型使用水平/垂直均 90°。旧 SensorPacket 校验要求 fx=fy，不能一面声称完全沿用旧合同、一面暗设 fy=36。应明确像素化后的垂直视锥变化，真实信息窗口需重新核实际包。
3. **距离。** V29 4 m 是欧氏射程，旧 RGBD/TSDF 的 max_depth 通常是光轴深度。若要求同一物理半径，应在渲染时按真实首交欧氏距离拒绝超程，再保存轴向 depth；否则须明确传感范围变化。不可将未命中、超程 0 深度直接写为实体表面或确定自由空间。
4. **轴向深度与噪声。** 光线方向归一化后的 t_hit 是欧氏距离，需要转换为 camera-z 后才可送既有重建器。固定通用视差噪声的参数与 seed；同一路线同时间索引的随机场不依赖排列/类别。人工 marker 只从真实首交表面绘制，绝不能穿透遮挡或直接用隐藏标签生成 seed。原 frame.semantic 可以记录可见标签，但主测量不能信任它定位。
5. **地面支持。** V24 后端至少需要 40 个实际水平法向候选才能拟合地面（108–118 行）；无地面则组件和实测实例网格为空。该失效必须保留并按缺失报告，不能在新任务中读取 GT floor 或临时调低条件。两设备与墙的观测组件若误连接，同样只报失败，不用参考盒拆开。

## 冻结前最小验收与终态报告

只需小型解析/手写接口测试：前进扫掠而非端点；camera-z 与欧氏射程；已知平面深度及遮挡首交；任意黑 RGB 即使 semantic=3 也无 seed；类别换色不改变深度/TSDF几何；空实例和重复归属保持二设施分母；预测远处多余面能降低未裁剪分数；metadata/mesh hash 在评价前后不变。加上上述三投影退化反例。不要为了这些门另跑完整任务矩阵。

四条实际采集各自保留主进程及不同 PID 的独立回放，回放核全部 49 包、动作、姿态、费用、安全事件、原/实测网格数组 SHA 与终点评价。所有主尝试都计入总上限：正常四条后主额度从 12/36 到 16/36；回放成本另报，不能当独立环境样本。失败、低 C、低 Q 完整保留，不按结果更换路线或预算。

C 必须来自实际已测二维建图与预冻结可达任务地面的评价交集，不能直接用固定路线经过格数量或理想解析可见面积。仍报 C≥0.8、48 动作内、精确返回、0 碰撞/执行失败的任务资格；对象 seed/实例归属合格另列。没有完整 C 定义就暂不能声称已验证 J 或任务合格，但可以保留真实 Q 和执行结果。

四条是固定脚本采集的机制实验。最佳固定臂、正确类规则、反向规则及事后 oracle 可从同一四格目录反事实汇总，不能称它们都新执行了独立政策，更不能称当前 ANS 主对照或持久 option 自主闭环。所有解释均以这次固定场景、实际传感和既定实测表示为限。
