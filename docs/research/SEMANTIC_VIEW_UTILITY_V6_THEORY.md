# V6：语义条件视角响应与可兑现观测效用

状态：2026-09-11 的方法推导与最小开发探针设计，**不是效果证明、概率校准结果或新独立实验**。保持 ANS 双层及 OV-SDF / STGHP / RPN-UQ / IGCR 接口。本文件不修改 V3/V5、原评估协议或已执行结果，不查看 753/754，也不使用 301–308、401–412。

## 1. 核心判断

下一步应预测“在当前历史和具体路线下，真实传感器将增加什么有效证据”，而不是继续给类别对应的隐藏面积加权。**需要显式的视角条件响应，但最小版本不需要补全完整物体、生成完整深度图或求完整贝叶斯信息增益。**

首先检验直接响应的条件均值能否预测候选内实际收益，并改变选择；只有这个检验通过，才值得增加未来观测分布和两步信息价值。把“更确定类别”“模型熵下降”“预测面更多”直接当作建图回报，会再次绕过当前最缺失的因果链。

本轮依据见 [评分诊断](COUNTERFACTUAL_SCORE_DIAGNOSIS.md)、[V5 同数据消融](../../eval_results/counterfactual_view_v5_rescore_first_20260910/results.md) 和 [独立审阅](../../eval_results/counterfactual_view_v5_rescore_first_20260910/independent_review.json)：

- 72 条共同分支、6 个可用历史中，V3/V5 的细类别均没有改变 G/O 的选择。AUC 改变的收益属于评分目标变化；AUC 下 N 还在一个历史中优于完整隐藏模型。
- 旧评分语义扰动小于几何排序间隔；0/432 个候选—评分对达到 recall 上限，不能归咎于 clipping。
- 两动作重复旋转并非完全无效：固定已见支撑上的平均距离改善约 0.011–0.049 mm。问题是这类微小局部改善与覆盖、全图重建效用的预算权衡失配。
- 背景权重、拟合错误、射线可见性、重复计益及任务效用是不同问题。降低背景的模型权重，不自动校正剩余几何；模型几何分数改善也不等于行动收益。

## 2. 一手论文支持什么，不支持什么

**BayesianNBV（SIGGRAPH 2026）** 从随机曲面后验模拟未来扫描，再计算任务效用的期望改善。它支持“预测将观察到什么，再计算对任务的价值”，而非把不确定性或类别当通用奖励。正文也给出分类自信但错误时，熵型目标可能失效的例子。本文只借用决策分层，不声称 CPU 复现其随机 Poisson 管线。[原文 §3.1、§4.1](https://arxiv.org/html/2605.05095v1)

**NBV-SC** 用已观测果实表面拟合超椭球、估计缺失面，并用已知占据/自由空间排除不成立的预测；它还加入视角差异和移动代价。该工作说明“形状补全后补看”本身已有先例，结构先验必须接受观测约束。其物体模型与果园任务不能替本项目货架假设背书。[原文 §III-B、§III-C](https://arxiv.org/html/2209.15376v2)

**Informative Object-centric NBV（ICRA 2026）** 同时涉及对象表示和选视角，几何评价有对象区域口径。因此本项目必须共享重建后端，并把全场景收益与对象区域诊断分开；不能仅凭对象优先就推出完整场景优势。[原论文](https://arxiv.org/html/2602.08266v1)

特别注意：BayesianNBV 的 expected positive improvement 中有正部截断；NSO 的真实 TSDF `ΔF1` 允许为负，不能复制该截断后宣称优化了无偏的期望 F1 增量。

## 3. 从完整形状改为可观察响应

记共同历史为 $D_h$、仅由该历史构造的几何为 $g_h$、可见语义为 $z_h$，共同候选路线为 $a=(v_1,\ldots,v_L)$。所有到达、旋转、返程动作均付费。

真正要估计的是

$$p(Y_a\mid D_h,z_h,a),\qquad
Y_a=(\Delta A_{new},\Delta F_1,\Delta C,\Delta E_{old},\text{failure}).$$

其中 `A_new` 是独立评价的唯一新增可见外表面，`ΔE_old` 是固定原支撑上的误差变化；两者和 F1 均不能互相替代。实际部署时当前真值不可用，此式只是任务层的理想预测对象。

最小探针直接估计条件均值 $\mu_a=\mathbb E[Y_a\mid D_h,z_h,a]$。它不要求先恢复完整箱体中心、背面位置和内部层板，再把推测面面积当真值。语义应该改变**视角响应曲线**，例如某类局部片的侧向位移比同位置旋转更可能揭露新结构；不能只给整个物体乘一个重要性系数。

### 3.1 当前代码能提供的输入

可以读取冻结 raw RGB-D / scan 重放后的 `SemanticHistoryMapperV3`：已测表面点、法向、固定证据键、视向 bits、信息/残差、已观测地图、RGB 标识像素和相机历史。可以在共同候选每个付费状态上对**原历史 TSDF**做投影/遮挡判断。所有这些输入在选分支前存在。

不能读取当前 fixture 的真实对象中心/包围盒、隐藏结构、真值可达区、完整 mesh、未来分支的深度、visibility 位图或 outcome 来构造特征。训练标签可来自训练折的已完成分支；测试折的这些内容只能在预测封存后评价。

当前语义源是人工 RGB 标识读取；未标注像素是“未知”，不等于已确认背景。局部片锚点是**已测支撑点的质心/法向**，不能改称真实对象中心。可继续共用几何簇作索引，但簇本身不是已证实的物体实例。

### 3.2 少量、可解释、共享的描述量

对每个几何簇/局部片 $j$，构造 $\phi_j(D_h,a)$：

| 描述量 | 可以反映的响应 | 不得推断的内容 |
|---|---|---|
| 相对已测法向的前/侧/反向暴露，历史视向新颖度 | 当前路线是否提供不同观测方向 | 真实物体背面必在某处 |
| 相对已测片的平移视差、最近距离、有效 FOV 支撑 | 旋转和移动揭露能力不同 | 近距离一定提高真实精度 |
| 已测片投影附近的深度边界、未知空间射线机会 | 可能有遮挡解除，而非只是再次看到旧片 | 未知射线一定命中新的物理面 |
| 已见方向数、旧证据信息/残差、重复状态比例 | 剩余补看需求与饱和 | 残差小就没有偏差或位姿误差 |
| 原几何预测覆盖、路径长度、前进/旋转数 | 覆盖机会和真实代价 | 使用真值修正可达性 |

不以 V5 完整包围盒确定这些方向和距离。法向符号不确定时保留双向/绝对投影描述，不能偷用物体朝向。全路线视向覆盖采用并集/最大暴露，避免回程重复累加；顺序影响另用首次出现动作数描述。

语义权重只作用在这些共同描述量上。标签不允许创建额外候选、改变局部片索引、运动成本或“有效面积”的类别权重。

## 4. 共享响应、条件先验与残差

令 $H_j$ 表示局部片的**可观测响应类型**，而非完整物体几何。例如“主要重复旧面”“侧向移动可揭露新支撑”两类；可保留不新增/遮挡失败响应。响应由同一组低维函数 $r_k(\phi_j)$ 描述，语义仅改变混合系数 $\pi_{jk}$：

$$\widehat\mu(D_h,z_h,a)=b(x_{geom})+
\sum_j\sum_k\pi_{jk}(g_h,z_h)\,r_k(\phi_j(D_h,a)).$$

更安全的解释是：$r_k$ 拟合共同几何预测的**有符号残差**，允许语义降低收益预测；不是额外增加一份恒正隐藏面积。否则通用 camera-coverage 预测已经支付过的新增面又会在语义通道支付一次。

若用完整响应均值 $m_k$ 而非残差，则应以 $\sum_k\pi_km_k$ **替换**共同预测一次，不再加到同一份通用新面预测上。正收益/零收益发生率、兑现数量和已有面改善应分别记录。

目前手工类别比例、形状打分或混合系数没有校准证据时，只能称条件混合系数。不能把 `posterior` 的变量名当作已建立 $p(g\mid H)p(H\mid z)$ 的证据；更不能直接继承被 V5 拟合诊断否定的箱体似然。

### 4.1 最小 CPU 探针：条件混合特征 + 固定 ridge

允许先用线性条件响应：

$$x_S(a)=[x_{geom}(a),\sum_j o_j\pi_{j1}\phi_j(a),\sum_j o_j\pi_{j2}\phi_j(a)],$$

其中 $o_j$ 为 O/S 共同的物体性通道；无标识簇不能直接设为真背景。G/O/S 对全部簇、方位基函数、训练折和候选使用相同来源的数据。模型是可解释的预测探针，不是几何精度模型。

当前拟议训练标签为 $y_A=\Delta A_{new}/L$，并单独拟合 $y_F=\Delta F_1$。这样目标直接对应原协议指标，绕开固定全场景面积归一化与未经校准的 F1-shaped recall。**面积率预测已经含成本，排名不能再除一次 $L$。** F1 标签保留负值。

固定 $\alpha=1$，训练折内标准化，按历史中心化后拟合：

$$\widehat\beta=\arg\min_\beta\sum_{h\in train}\frac{1}{|\mathcal A_h|}
\sum_{a\in\mathcal A_h}(\widetilde y_{ha}-\widetilde x_{ha}^{T}\beta)^2
+\alpha\|\beta\|_2^2.$$

实际 V6 实现约定是“各历史候选平均平方误差之和 + alpha 正则”：设计矩阵和标签各乘 $1/\sqrt{|\mathcal A_h|}$，固定 $\alpha=1$。当前每历史同为12候选，将整个目标乘12才等价于通常的“逐行平方误差求和 + 12 倍正则”；不能将其写成通常行求和下的 $\alpha=1$。这里修正文档原先误写的 $12/|\mathcal A_h|$，不改已冻结数值或追结果调整正则。标准化使用训练折中心化特征的逐行均方根；当前候选数相同，和各历史等权一致。未来候选数不同时，这一标准化规则仍须显式记录。标准化/零方差列处理都只能拟合于训练折，不能看留出标签选择特征或调 $\alpha$。

实际 V6 开发探针使用 `[共同路线特征, Σoφ, Σo(2π−1)φ]` 的12列等价线性混合参数化；但 ridge 对坐标变换并非一般不变，具体这12列及其标准化属于冻结模型定义。方向描述量来自实测簇，不使用补全箱体中心或尺寸；混合系数 $\pi$ 仍取归档 V3 的 `shelf_probability`，其中包含旧形状打分。因此它尚未实现独立校准的类别响应先验，也不能称为完全摆脱旧形状模型的响应模型。

历史中心化有明确限制：测试历史可用全部已知候选特征求特征均值，但不能用测试真实收益均值恢复预测截距。中心化模型首先是**候选内相对响应/排名模型**，不自动给出绝对面积、发生概率或校准截距。相对预测允许为负，不能因原始面积非负就截为0制造假平局；同样不能用中心化 F1 的正负判定绝对风险。事后中心化测试标签算误差，应单独标为相对误差，不能称绝对 calibration。

当前仅做 751→752 与 752→751 两个方向的留一几何种子诊断；同一 seed 的噪声、历史、全部候选必须在同一折。两折仍然是已查看开发数据，不能因样本拆分就改称独立确认。

### 4.2 强对照及干预语义

| 通道 | 最小含义 | 必须保持的公平性 |
|---|---|---|
| N | 去掉对象/语义响应的共同几何路线基线 | 单独拟合其允许特征，保留全部通用覆盖/旧面信息，不人为削弱 |
| G | 同局部片、方向描述和响应结构，边缘化细类别 | 单独重训强 G，不能只把 S 的输入清空却沿用 S 权重 |
| O | 加入与 S 完全相同的物体性，但不区分细类 | 单独重训强 O；不能让 S 独占更好的背景筛选 |
| S | 与 O 同对象性，细类只改变共享方向响应混合 | 不增加类别奖励标签，不使用未来真值特征 |
| X | 训练完 S 后，**仅在测试输入**交换细类别 | 同时交换训练/测试并重训只是标签重命名，不是错标负控制 |
| M | 缺失类别时明确回退该折独立拟合的 G | 显式验证逐候选相等，不能默认“输入0”等于G |

新 N 的具体特征集合必须记录；原 V3/V5 的 N 与 rate/AUC 结果继续保留，防止通过换弱基线制造净收益。单独 G/O 的参数可不同，但每种使用同训练量、固定正则和自己的训练折标准化。$α$ 相同不代表有效容量相同：报告列数、训练设计秩及 ridge 有效自由度。

还应区分两类表：固定 S 响应权重、只换先验的**机制干预表**，以及 G/O 各自重训的**强对照表**。后一类共享描述来源和模型族，却不共享最终拟合权重，不能称“所有数值除先验之外完全相同”。两类都保留，分别回答通道作用与方法是否超过强基线。

## 5. 可辨识性与可证的边界

### 命题 A：语义必须与候选相关量交互

如果一个历史内的语义修正为 $s(a,z)=g(a)+c(z)$，其中 $c(z)$ 不依赖路线，则所有候选排序不变；按历史中心化后该语义项严格为零。证明是两路线相减时常数抵消。

因此类别总数、类别平均置信度、场景“复杂程度”本身不是足够的创新机制。需要 $z\times\phi(a)$，且不同类别对应不同**方向/视差/剩余证据响应**。即便响应不同，如果所有可达候选提供相同暴露，仍可能没有决策价值。

线性诊断还应检查语义交互列是否完全落在共同几何特征张成空间中。若是，训练数据无法将其作用与几何回归区分。矩阵秩/残差特征检查只诊断当前样本的可辨识性，不证明总体关系成立。

### 命题 B：更好的条件预测不自动等于更好的选择

对平方可积真实响应 $Y$，若使用真实条件均值，则

$$\mathbb E[(Y-\mathbb E[Y\mid X])^2]-\mathbb E[(Y-\mathbb E[Y\mid X,Z])^2]
=\mathbb E[(\mathbb E[Y\mid X,Z]-\mathbb E[Y\mid X])^2]\ge0.$$

这是条件期望的正交分解。它说明类别在真实响应条件分布中有信息时可以降低最优预测误差；不保证有限样本 ridge、失配先验或测试域也改善，更不保证 argmax 改变。候选排序和实际选择收益必须分别检验。

### 命题 C：误差控制足够强时，预测选择改善才有证书

若同历史所有候选满足 $|\widehat\mu_S(a)-\mu(a)|\le\epsilon$，且新选择 $a_S$ 相对比较动作 $a_G$ 有 $\widehat\mu_S(a_S)-\widehat\mu_S(a_G)>2\epsilon$，则 $\mu(a_S)>\mu(a_G)$。

证明：真实差至少为预测差减 $2\epsilon$。这个条件需**同时覆盖候选集**；普通训练残差标准差、两个交叉验证折或 ridge 系数置信区间不提供该证书。当前仅报告误差/排名/实际收益，不能把经验残差写成风险保证。

## 6. 何时再做显式未来观测与信息价值

直接响应探针只估计 $\mathbb E[Y\mid D,z,a]$，**没有**定义新观测 $y$ 的似然，也没有更新后验的能力。不能据此计算 $I(H;y)$、expected entropy reduction 或声称 BayesianNBV 已实现。

若直接响应在更多训练支撑和固定开发检查中通过，可在原接口内增加小型响应分布：零新增/有新增发生模型 + 正收益大小分布；对旧面误差另设允许负效用的响应。分布要对每个实际付费步骤的已预测暴露状态条件化，并保持固定空间证据键去重，不能把12条反事实路线的收益当12次独立可累加观测。

随后才考虑两步选择的信息价值。设免费诊断观测为 $d$，后续可行动作集合固定，则

$$EVSI(d)=\mathbb E_y\left[\max_a\mathbb E[U(a,H)\mid D,y]\right]
-\max_a\mathbb E[U(a,H)\mid D]\ge0.$$

证明同 [既有信息价值推导](COVERAGE_SEMANTIC_THEORY.md)：观察后可以继续采用原最优动作。**真实小车的诊断动作不免费**，它消耗剩余预算并改变状态；可行集合缩小后，净收益可以为负，需要把诊断直接收益、付费轨迹和后续可执行收益一起比较。

反例：$H$ 为等概率二值量，$d$ 完全揭示它，但两后续动作在两种 $H$ 下效用始终为1和0。此时互信息为1 bit、决策信息价值为0。减少“形状/类别不确定性”不构成本任务的有效回报。

最小 CPU 后续实现可以使用很少的响应模式和有限结果分箱，对相同候选做深度为2的枚举；不必先上高成本 GP/完整随机曲面。若改用采样未来深度/点云，样本必须来自训练后验、共享原地图遮挡与传感器模型，不能使用当前测试场景真值。缺乏联合视角模型时，不应假定跨视点响应独立。

## 7. 覆盖、质量与预算：两层问题不要混淆

当前探针仍以原面积率为主标签，是为了回答“语义是否有可辨识的候选排序价值”；**它没有解决完整闭环的 rate 目标偏差**。F1 独立预测不能在看到留出结果后用于挑最有利的主评分组合。

下一层可沿已实现的共同预算 AUC 做消融：若固定代理累计增量 $u_t$ 单调，路线完成后保持，

$$A_B=\sum_{t=1}^{L}\frac{B-t+1/2}{B}\Delta u_t.$$

这是预算一致的积分，不再把总收益直接除很短的路线长度，但仍依赖效用标定。终点直接回归的总收益不能冒充逐步 $u_t$；真实 TSDF F1 也不保证单调。单条分支 hold 不包含短路线结束后的继续规划价值。

质量可在后续分成“新有效支撑”和“原有支撑改善”。例如在明确误差模型下，把面元贡献写成 $a_j P(|e_j|\le\varepsilon)$；测量误差含共享偏差时可用 $\sigma_b^2+\sigma_r^2/n_{eff}$，不能对重复帧简单按独立样本缩方差。这个概率在噪声/偏差模型校准前仍是代理；它的好处是让微小改进是否跨越实际精度要求成为显式问题，而非强制清零重复观察。

二维覆盖另作可行性/进度约束，沿用同起点覆盖锚点、动作预算与实际失败记账。未知环境中的终点覆盖非劣、全局最优、适应性次模或真实 F1 改善均没有因此获得无条件保证。

## 9. 可证伪条件与开发纪律

1. **信息不够：** 类别—方向交互没有候选内变化，或语义特征被几何完全解释，记录为不可辨识；不能靠扩大类别权重强迫选点变化。
2. **预测失败：** 两个留一几何种子方向都报告相对误差、排序、top1 实际收益、负例、G/O/N差异。只改善训练拟合或只在一个 seed 获益，不算机制通过。
3. **选择无收益：** S 改变选择但真实面积率不增，或者 F1 明显恶化，保留失败；不把“语义被使用”当创新已验证。
4. **容量混淆：** 同时报告单独重训的 G/O 与 S 固定权重干预结果；它们回答不同问题，不能择优展示一类。
5. **错标失效：** X 是冻结模型的输入干预；M 确认等于 G。训练/测试共同交换标签得到相近结果是编码不变性，不是鲁棒性或阴性对照通过。
6. **小样本与外推：** 72 条路线是相同历史下的反事实潜在结果，不能当72个独立环境。两 geometry-seed 折无法证明泛化、概率校准或统计显著性；应报告每折、每历史、特征秩及外推程度。
7. **数据隔离：** 折定义、特征、固定正则、目标与选择规则在计算留出预测前落盘；训练文件白名单和预测封存哈希可复核。模型只能从训练折读取 outcome，特征构造代码不接受 outcome/真值对象接口。
8. **旧门槛保留：** 本探针不修改原协议的面积率、F1、G/O/N、错误标签及失配控制门槛。753/754本轮保持未查看；后续是否进入固定开发检查由整个机制的证据决定，不由某个最好数字决定。

如果直接响应探针仍不能超过强 G/O，优先结论是“当前可获得的类别和视角特征不足以建立可验证的额外响应价值”。下一步应增加预先设计的、几何歧义但视角响应可比较的训练证据或改进观测描述，不能把失败包装成几何精度理论、持续换权重或提前查看保留种子。

本文件支持一个可兑现、可证伪的语义研究问题；它没有给出本项目优于主流方法或完整方案已有效的结论。
