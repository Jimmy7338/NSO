# V10：保留四模块的 CPU 实测闭环

本阶段落实 [V10接口合同](FOUR_MODULE_CPU_CLOSED_LOOP_V10_CONTRACT.md)。ANS全局目标—局部执行两层及OV-SDF、STGHP、RPN-UQ、IGCR接口保留；CPU后端通过原 `NSO_Components` 与 `NSORuntimeIntegration` 调用，尚未运行训练后的ANS神经策略。真实输入干预和原始轨迹回放已完成，但冷启动轨迹完全原地旋转，**接口接通不等于完整导航或效果通过**。

## 本轮结果

- [语义实包干预](../../audit_results/cpu_semantic_packet_v10_development_20260911/REPORT.md)：同一Q0真实151帧前缀分别输入原类别、交换类别、缺失类别，34项核对全部通过。交换类别把S选择从左侧深观察点改为右侧；物理地图、TSDF、非标签质量字段和完整六候选池完全一致，G/N分数不变。交换后S等于原X，缺失后S等于原G，最大误差均为0。每组账本使用151个实际位姿，而不是69个关键帧。没有执行新路线或读取GT评价，此证据证明语义沿真实接口影响选择。
- [接口集成检查](../../audit_results/cpu_closed_loop_v10_integration_tests_20260911/verification.json)：新增9项真实生命周期测试与旧11项兼容测试通过；另外候选9项、传感契约7项、反馈9项、当前格障碍4项通过，共38项V10检查及11项旧检查。预算、朝向、去重、终止及场景隔离属于这些检查的范围。
- [三维原始轨迹回放](../../eval_results/cpu_four_module_v10_replay_20260911/REPORT.md)：32付费动作、33组RGB-D/雷达、47条候选、25次全局选择和32次反馈均独立核对；最终完整质量状态与TSDF网格一致。**32动作全为旋转（左右各16次），前进0次，只有1个位置和3个姿态。** 终点与锚点相同，不能表述为离开起点后的导航返航成功。备用返程接口在该轨迹中调用0次。

冻结软件协议的局部生命周期检查通过，独立回放状态为`passed_full_cpu_integration_replay`。该状态的含义是记录、预算和数值复现一致，不包含平移探索成功。原始运行和检查规则保持不变，另加[运动范围审计](../../eval_results/cpu_four_module_v10_replay_20260911/motion_scope_review.json)明确披露此局限。

## 从传感包到下一次动作

唯一输入为对齐的RGB-D、二维雷达、带来源声明的离散位姿、时间戳、动作与回合编号。当前CPU适配器明确要求0.2m栅格、世界原点(0,0)、固定中心相机/雷达外参、N/E/S/W朝向和同步时间戳。通用坐标变换已检查非零原点及行列方向，但现有mapper不支持的配置会被拒绝；这不是已经完成ROS1 ZED适配的声明。

运行时对完整传感包先校验、计算哈希和去重，再融合一次地图。初始帧只建立历史；每个真实付费动作后，OV-SDF以实际深度回投的类别支持更新语义状态，IGCR记录新增观测与质量代理，STGHP接收最新地图和反馈版本。全局决策保存位置、朝向、去程、返程预留及唯一选项编号，本地动作逐次通过RPN接口的地图守卫。到达目标后重新决策，使用当前位姿和剩余预算，返程锚点始终固定。

| 模块接口 | 当前实际输入与输出 | 已知能力边界 |
|---|---|---|
| OV-SDF | RGB-D实测支持、几何分组、可见类别；输出密度场与类别条件结构先验 | 人工资产标记，无开放词汇识别或校准类别概率 |
| STGHP | 已观测连通区域、全朝向候选、语义状态、历史与预算；输出带完整位姿的选项 | 连通区域图，不能声称已识别复杂房间/门户或有独立拓扑性能增益 |
| RPN-UQ | 当前占据图、足迹、动作及动作后返程预算；输出允许/拒绝和原因 | 确定性守卫，无训练概率或校准不确定性，概率字段为空 |
| IGCR | 真实帧、固定旧支持、地图版本、真实动作和终止状态；输出有符号反馈与真实历史 | 观测代理，不是真值F1或互信息；未作为PPO训练奖励 |

同一回合的所有实际相机位姿均保留，不能以抽样关键帧代替。候选路线的预定返程从不写入实测历史。无反馈消融只冻结规划使用的相机历史；实际地图、动作成本、终止及原始帧仍正常更新。

## 预算及收益定义

设当前剩余动作预算为 $b_t$，固定返程锚点包含位置和朝向 $h=(r_h,c_h,\theta_h)$，$d_{M_t}$ 为当前已观测完整足迹安全图上的有向最短动作数。候选选项 $o$ 由去程 $\pi_o$ 和预留返程 $\rho_o$ 组成：

$$0<|\pi_o|,\qquad |\pi_o|+|\rho_o|\le b_t.$$

执行的每一步都再次要求当前和后继足迹已知安全，且

$$1+d_{M_t}(x_t^+,h)\le b_t.$$

若地图保持不变，执行后 $b_{t+1}=b_t-1$，因此后继仍有预算内返程。这是当前观测图上的条件不变量。新观测、定位误差或地图冲突可能使旧返程失效；此时重新计算返程或明确停止，不能将上式写成真实未知环境中的无条件成功保证。旋转也付费，返回同一格但朝向不同不算回到锚点。

全局选择评价实际承诺执行的去程总收益：

$$\widehat U_t(o)=\widehat A^{2D}_t(\pi_o)+\widehat A^{cam}_t(\pi_o)+\widehat Q^{old}_t(\pi_o)+\widehat V^{sem}_t(\pi_o).$$

各项沿用既有固定物理尺度；返程仅约束可行性、参与同分成本比较，不计入当前承诺收益。原V9.1评价完整固定往返路线，V10到达目标后可取消原返程并重规划，故必须区分这两种承诺范围。当前预测和式不是实测联合指标 $C\times F1$；候选得分、实际观测反馈和离线GT评价分别记录。

语义先验沿用现有人工资产域定义 $wh+2nwd$：类别2为三层货架、类别3为闭合柜、缺失为边际化层数1.5；没有根据V9.1未来结果重估系数。S/G/O/N及类别置换/缺失诊断可在同一几何候选上比较。当前几何分组会随测量刷新，仍不能声称已经解决稳定对象身份与噪声引起的需求再生。

## 实测反馈与停止

IGCR使用稳定的0.15m质量体素键，不用每次改变的抽样点集作旧表面分母。初始已观测支持集合为 $K_0$，沿用既有可靠性代理

$$q_t(k)=\frac{I_t(k)}{I_t(k)+0.25+100e_t(k)},\qquad
\Delta\bar q_t=\frac{1}{|K_0|}\sum_{k\in K_0}[q_t(k)-q_{t-1}(k)].$$

保留负变化；$e$ 为传感器残差平方的统计量，不是GT误差。新增二维格须已被观测且不在累计已奖励集合中；新增测量支持也必须投影到已观测二维格。类别更新、重复帧或模型自行生成表面都不能领取新增测量奖励。

真实终止帧先融合和反馈，再关闭回合与重置。机器人自主停止时只追加零动作、零观测、零奖励的逻辑终止事件，引用最后真实帧。重复包不能再次融合、计费或发放奖励；冲突包与跨回合数据拒绝。发生融合或后续模块异常的回合保留失败状态，禁止将重发当作新一次有效观测。

代码审查还发现旧mapper会在插入障碍后把机器人原点格强制设为自由。通过合法传感包的0.05m雷达命中可触发这一问题；新V10 mapper保留原点处已有或本帧测得的占据冲突，使当前足迹守卫拒绝动作。旧冻结mapper不改写；正常无冲突序列与旧mapper的地图、质量及TSDF数组一致。

## 检验范围与尚未解决的问题

[开发集成协议](../../configs/virtual3d/cpu_four_module_v10_integration_protocol.json)规定从Q0人工资产世界初始帧出发、32动作总预算、无脚本前缀、固定起点朝向返程。执行前归档源码，保留每帧RGB-D/雷达、选项与调用来源链、最终地图和TSDF，随后独立原始回放。它检验真实闭环与状态不变量，不是语义性能试验，也不占用保留的独立种子。

早期软件集成夹具已出现有预算内重复往返但没有新增观测的情况。新的32动作冻结轨迹进一步确认没有平移；27个动作没有新增二维格，第11步后二维新增一直为零，全部25次选择的语义孔口增量为零。尽管传感器噪声会产生新的测量体素或小幅代理变化，不能把这些变化解释为探索推进或GT三维精度提升。

[独立停滞诊断](../../audit_results/cpu_v10_rotation_stall_review_20260911/REVIEW.md)用归档33帧和独立足迹/BFS证明：22/25次规划存在预算内安全平移并完整返程的状态，首帧向北走一格并恢复初始朝向的总成本为6动作，低于32预算。问题不是没有安全空间。覆盖候选仍先按“可见性代理/完整返程成本”仅留下一个目标，之后才交给总收益评分器。首帧有863个可行有向状态，却只输出原地旋转；整个47项候选记录没有任何平移目标。22次有平移空间时，平移目标的最大端点总代理均超过提交的覆盖候选，前级面积率筛选仍将其丢弃。

另外，25个选中选项累计预测2028格次相机新增观察，执行中只有277格次对应预测格被实际新增观测，17次去程没有兑现任何预测格。这些是可重复计数的“格次”，不是唯一面积。连续二维视野预测与实际稀疏深度回投不一致，历史尝试没有消耗未兑现的通用视野代理。下一阶段须同时修正候选保留和已经尝试方向的重复可见性收益，不能只再增加语义权重。

修改仍限制在既有四模块内部：STGHP保留真正可推进的覆盖选项并与总收益目标对齐；IGCR将实际观察历史用于整个收益估计的需求消耗；OV-SDF保留类别条件结构先验及标签对照；RPN继续采用相同足迹和返程规则。在开发域修正并冻结后，再做完整S/G/O/N、去反馈、单次规划及候选/去重的单项对照。所有方法使用相同传感器、运动成本、返程约束和GT评价，才能检验可归因的语义增量。

V9.1原0.5个百分点F1幅度门仍失败，四模块整体优于主流方法仍未证明。后续还需要可运行的官方/公平适配基线、类别错误与先验失配、非真值位姿、ROS1实际记录回放。当前位置和朝向使用精确模拟输入，本阶段不能报告SLAM漂移改善。
