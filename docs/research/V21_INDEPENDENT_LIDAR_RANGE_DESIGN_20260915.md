# V21 备选：独立雷达量程契约

日期：2026-09-15。**状态：只读备选设计，未实施、未选定新量程、未运行实验。** 当前 V20 公共覆盖实验继续使用其冻结配置；本文不预设它会失败，也不修改其源码、预算或评价结果。

动机是让二维通道建图与近距离三维建档使用各自的传感范围。学校小车已经能提供 ROS1 的 ZED 深度/位姿及单线雷达数据，但当前并无该雷达有效量程标定；不能将某个假定范围写成实车参数。若采用本方案，所有方法共同使用同一新传感配置，范围变化本身不算语义贡献。

## 最小接口改动

`utils/rgbd_contract.py` 的 `PlanarScan` **已经具有独立的 `range_max_m` 字段**。目前的强耦合位于它的生产者、CPU 校验及规划预测，而非扫描数据结构本身。

| 当前文件／函数 | 新版本需要做的事 |
|---|---|
| `env/facility_documentation_v19.py` 配置；其继承的 `env/canonical_box_scan_v14.py::scan()` | 增加有限正数 `laser_range_m`；雷达求交截断和扫描包上限使用该字段。相机 `max_depth_m=5` 保持原值。 |
| `nso/cpu_sensor_contract_v10.py::SensorPacket.validate()` | 当前硬性要求 `scan.range_max_m == config.max_depth_m`；新版分别校验深度≤相机上限、扫描≤雷达上限，并保留同步、外参、射线数量、单位和位姿检查。不能简单删除量程校验。 |
| 新批次 packet 构造入口；`nso/decision_replay_v13.py::load_packet()` 的新版包装 | 构造新版 Packet。旧 loader 固定返回 V10 类型：仅比较哈希时可以继续读取，若把保存包重新送入运行时，则须包装成新契约类型，避免再次触发旧的同量程校验。 |
| `nso/facility_candidates_v20.py::ObservedRouteSpaceV20.visibility()` | 覆盖预测使用独立雷达范围，仍只计算未知二维格；`route_mask()` 保持整条出程的并集去重。 |
| `nso/facility_runtime_v20.py::FacilityBackendV20.assess_action()` | 逐动作的雷达覆盖预测同步使用独立范围，与候选预测及实际扫描一致。 |
| `nso/observed_gain_calibration_v10_1.py::route_masks()` | 分开 radar/camera 半径。`attempted_camera_mask()` 和相机 FOV 仍使用相机范围，不能一并放大。 |

这些是下一版的改动定位，**不得原地修改已冻结的 V19/V20 文件**；应使用版本化配置、世界和契约适配入口。

`SensorMapper.update()`、`ObservedRuntimeMapperV10.update()`、`coverage_budget_v20.scan_hit_mask()` 已按扫描包的 `range_max_m` 处理激光返回；`facility_budget_v19.scan_known_mask()` 已沿真实扫描射线更新已知格，无需为了独立量程改写其算法。ROS1 录制流程也已分别保存相机深度上限与雷达范围。

## 保持三维观测边界

RGB-D 渲染、视差误差公式、TSDF 深度截断、已观测表面精度预测、相机 FOV、外表面参考和近观见证继续使用 **5 米相机上限**。更远的雷达只能改善二维观测和已知导航图，不能直接增加三维表面、设施 recall、F1 或精度。双传感器预测同一个未知格时最多记一次二维新增；已知格的 `camera_seen` 补看仍不算新增二维覆盖。

长量程不会自动解除遮挡。当前实际雷达为 180 束，而 `visible_mask()` 使用较稠密的离散射线；量程增大后，两者的空间采样差异可能扩大。当前雷达仍是理想求交，不能将 RGB-D 的视差噪声当成雷达噪声，也不能把稠密射线的预测格数当作实际扫描覆盖。

## 实施前后的最小验证

1. **契约隔离：**同一固定姿态下，更改雷达范围不改变 RGB-D 字节；分别验证深度越界、扫描越界和配置不一致会被拒绝。重新核对两排列的初始非语义匹配。
2. **融合隔离：**向两个新 mapper 输入完全相同的 RGB-D、不同量程的真实扫描，TSDF 网格和深度质量统计应相同；二维地图可以不同。仅雷达新增不得提高外部三维评分。
3. **预测与实际：**在固定少量姿态核对 180 束实际扫描、稠密覆盖代理及单步 IGCR 新增；检查遮挡、窄障碍、边界、无返回和恰好到达最大范围的处理。使用保留的深度噪声条件检查二维融合偏差；若另加雷达噪声，须先独立声明模型，不能混用深度噪声。
4. **预算与在线能力：**重新取得该传感配置的覆盖/返航可行见证并检查近访成本竞争；同时用观测驱动的在线公共基线与独立回放验收。几何见证不能替代在线成功。若保留原 160/184 步作固定预算比较，应明确这一比较条件；若重新应用预算公式，应冻结新预算并分开报告，不能混称同预算改善。

新配置必须重新冻结源码、传感元数据、参考缓存和物理记录。现有评价缓存签名包含完整配置，不能静默复用旧缓存。只有在线证据支持这个传感分工和资源竞争之后，才讨论是否进入新的语义收益筛查；本文没有启动该阶段。
