# V23 外形指标与付费形状观察台架协议

日期：2026-09-15。执行前声明。只验证评价实现与观察需求，**不是六工位自主任务、语义策略或完整架构比较**。原 V19—V22 数据与分数不改写。

## 固定评价

网格三角形分别投影到世界坐标 XY、XZ、YZ 平面，求二维并集并去除有界内孔，保留外部凹口和分离的外部组件。相反观察方向具有相同正交投影，不重复计权。不做尺度归一化、配准、三维内部填充或类别条件补全。三投影符合不唯一确定完整三维几何，原外表面 F1 和连续误差必须并列。

沿每个投影外边界按最长1厘米的线段中点采样，权重为各采样对应的真实边界长度。距离计算到另一个投影的整条线段边界，不计算到离散参考点；2/5/10厘米内的预测和参考长度比例分别为 precision 和 recall，取 F1。主阈值5厘米。长度积分是固定数值近似，不称精确连续积分。

每个投影同时计算包络区域 IoU，定义 `q_v=min(F1_boundary@5cm, IoU_projection)`，设施质量是三个 q_v 等权平均，全任务质量 Q 是设施等权平均，J=C2D×Q。边界 F1 单列为诊断，不能将 Q 称为纯 F1 或完整三维精度。采用较小值是共同满足外边界和投影区域的保守约束，没有类别权重。

这一步修复了代码审查中的实际反例：沿立方体棱排布互不相连的微小几何块，边界距离可以很小，区域却几乎没有覆盖。只有边界 F1 会错误高分；新增区域条件在任何物理策略成绩产生前确定。

另外报告对称平均边界误差、Hausdorff下/上界、位置与三轴尺寸误差。中点采样及端点距离最大值给出下界；加最大线段采样间距的一半给出保守上界，因为点到集合的距离为1-Lipschitz。边界完全相同则精确报告0。设施完成要求每个投影的 Hausdorff上界≤5厘米、IoU≥0.90，三轴尺寸绝对误差及中心最大轴误差均≤5厘米；完成率不是主奖励，不在看到结果后切换终点。

评价窗口在世界建立时固定、设施间互不重叠。原参考必须被窗口包含，唯一允许的参考裁剪是地面接触带[0,0.01m]；不能静默截去侧后凸起。缺失设施/退化预测投影记0，不从宏平均删除；外部窗口之外的假几何另由全局指标检查。预算记录缺失时不判定任务合格。真值窗口和参考不能进入预测器、补全或规划输入。

基础版本继续直接评价原始 TSDF，没有几何补全。推断/实测来源不能由评分器猜测；本次每个预测都标注为原始传感积分网格。认可非闭合但三个外廓充分的模型，仅是本任务的外廓达标，不是已测得所有背面。

实现使用固定 Shapely2.1.2 的[平面并集](https://shapely.readthedocs.io/en/stable/reference/shapely.union_all.html)与[几何距离](https://shapely.readthedocs.io/en/stable/reference/shapely.distance.html)，依赖在 `requirements-3d-v23.txt`。独立单位夹具覆盖正确外壳、内部变化、开口凹处、内孔、薄板、位移/尺寸、漏凸起、分离假几何、微片反例、空/漏设施、非闭合充分外廓及预算门。

## 两条实际观察序列

两类世界共用8×8米房间和闭合本体 x[3.2,4.8]、y[3.2,4.0]、z[0,1.6]。复杂类增加真实连接的右后外露附件，包络延伸到x5.08、y4.60；附件在0.25米雷达高度以上。初始遮挡由普通射线求交产生，没有类别控制的噪声、深度隐藏或可见性覆盖。

两类都执行同一96动作路线，84次0.2米平移、12次90度转向。阶段为初始0、前视3、粗扫23、后视48、额外侧视73、返航96；每次动作产生一帧新深度，阶段评价不额外采集。第96步返回相同位置和朝向，由声明路线自然结束；不补免费 stop 或额外帧。真值侧静态可达性属于台架设计，不冒充未知环境自主规划。

两条均使用原通用 iid_025px、noise_seed1901、5米相机/雷达、96×72图像、精确位姿、4厘米体素和12厘米截断 Open3D TSDF。位姿漂移、相关材质噪声和真实ZED标定没有实现。本小批次不自动扩展到理想/固定偏差条件，后续策略实验仍需这些边界。只有一个开发几何和一个噪声种子，不能给泛化或统计显著性结论。

每阶段报告固定外廓指标、原 V19 可观察外表面 F1@2/5/10厘米、precision/recall、连续误差、全局指标和真实二维覆盖。原表面参考每设施3000点、预测4000点、全局12000点、stride4、seed2026，在动作0准备时单独冻结。两个世界各有自己的参考，不能复用旧 V19 缓存。

## 本轮判断与停止规则

先验证初始深度、扫描、内参与位姿匹配；颜色/类别线索单独记录。全程记录同一动作下两世界的首个非语义差异，尤其检查粗扫结束前是否已经揭示结构。初始匹配不保证完整粗扫配对；揭示早于之后的语义决策时，要据此调整信息入口或场景。

本轮观察需求条件为：简单类在粗扫23步已满足上述设施完成标准；复杂类从粗扫23步到补看73步的 Q 增量为正且大于简单类同段增量。同时报告各阶段的原值、绝对差、尺寸/边界/完整度变化，两个条件失败也保留全数据。不因这两条固定路线选择或放宽分数门，也不直接把类间响应差称作语义策略收益。

若简单类粗扫未达标，先查原始网格外廓支持、传感/分辨率、朝向及是否缺少共同几何建模；若复杂类没有更高需求，先查真实可见性与观察通道。任一条件失败时不启动六工位完整矩阵或网络训练。本轮只提供下一步设计证据。

## 保存与复核

准备时冻结代码、配置、本协议、依赖版本、世界几何和参考；准备不执行付费动作。每种形状保存97份原始传感包、逐动作位置/朝向/覆盖、6个阶段网格和评分、运行PID及耗时。每条独立新进程从同一世界执行相同实际动作，逐包与保存传感核对，并以保存包重新融合、匹配阶段网格与指标。原始采集和重放PID必须不同，全部回放通过后才汇总。

总量固定为2条×96付费动作及2次独立回放；不把阶段、类别、同轨迹敏感性或回放当作独立布局。失败保留错误和已产生证据。主 Goal 中同容量网络、强几何对照、四模块闭环、独立规模场景和实车迁移均不由本台架代替。
