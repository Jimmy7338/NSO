# V22 执行前协议：早期覆盖路线的类别信息机会

日期：2026-09-15。状态：执行前声明；运行前必须完成本文列出的源码、配置、矩阵与输入冻结。本文没有新增实验结果，不授权自动扩大矩阵或训练。

保留 ANS 全局—局部层次和 OV-SDF、STGHP、RPN-UQ、IGCR 接口。本轮是 CPU 机制筛查：初始类别能否指导有价值的覆盖路线选择。它不验证自然开放词汇识别、训练收益头、完整语义架构或相对强 G 的优势。依据为 [V22 设计入口](V22_COVERAGE_LINKED_SEMANTIC_PLAN_20260915.md) 与 [四个初始观测审计](/root/NSO/audit_results/v22_initial_coverage_opportunity_20260915/review.md)。

## 1. 本轮能回答与不能回答的问题

固定同一初始观测侧候选集合，对不同首选运行完整预算与相同后续 N，检验：

1. A/B 首选能否在有效观测窗口内改变实际付费动作，而不是在共同前缀结束前已取消、合并或丢失目标。
2. 不同首选是否改变覆盖合格条件下的六设施外表面质量和联合指标。
3. 同父的类别—结构排列交换后，路线回报是否出现与初始类别相关的差异；预先固定的类别规则是否优于纯覆盖 N 及反向类别规则。

仅发现“有一条 A/B 路线比 N 好”，不能证明语义价值；这可能只是几何接近更合适。仅发现普通 G 比 N 的外形好，也不属于本轮语义证据。事后按回报选择最优路线只能作为信息上限，不能冒充实际可执行的无未来信息策略。

本轮可以否定“这两个父、这些覆盖选项、共同 N 后续足以提供所需类别收益”的具体机制假设。阴性结果不能推广为所有主动 SLAM 中语义无用，但也不能在没有新机制理由时继续训练或扩大同一实验。

## 2. 不变的物理与评价条件

- 每条完整任务预算：P00 160、P01 184 个原子动作。平移、转向、返航全部付费；无脚本免费前缀、无提前终止后补采集。
- 初始输入：只有动作 0 的真实保存协议所规定初始观测。原 RGB-D/单线雷达 5 m、iid_025px、noise_seed=1901、精确离散位姿、TSDF 0.04/0.12 m 不变。它们仍是通用立体视觉替代模型，不是真机标定。
- 评价：原真实可达地面覆盖 C2D；六设施等权外表面 5 cm F1 为 Q；J=C2D×Q。漏建设施记 0；原全局及 2/10 cm 指标只作既有敏感性输出。不得改变评价窗口或按路线选设施。
- 主参考 seed=2026，2027/2028 是同一轨迹的参考采样敏感性，不是独立重复或置信区间。只读冻结 V19 缓存，不重生成、不复制整套参考。
- 任务成功需 C2D≥0.80、返回原位置和原朝向、零碰撞、termination.failed=false，且原子动作数不超预算。首度达到 80% 不替代终点资格。原 J 对所有轨迹照实报告，不以高 J 抵消不合格。
- V21 的固定公开 ROI 已知格覆盖账本仅是规划启发式。不得把其 0.8 目标当成真实可达地面的覆盖证书。

## 3. 共同候选与首选规则

A/B 是动作 0 中两个带标记的观测实例，按观测 AABB 中心的 x、y 顺序从左到右命名；不读取模拟器资产编号、隐藏结构或 assignment 选择目标。配对观测需验证深度、扫描、位姿、观测几何和候选相同，初始类别票交换。

首选只在原公共候选中满足 `group.startswith('coverage_')` 且原 N 分数>0的路线比较。保留原八条覆盖候选，不增添朝向变体或独立近访。每条都须具有去重的预测未知格并集，并通过当前观测安全图的完整去返路径与费用检查。正预测增益不保证实际增益。

固定规则：

- N：原 N 分数最大；并列按去程动作、去返总动作、candidate_id 从小到大。
- A/B：对应观测实例的既有 `ObservedPrecisionResponseV19.per_asset_expected_precision_change` 最大；并列同上。只用原参数：最多128个观测点、观测网格遮挡容差0.12 m、原5 cm精度代理。必须有正代理值；无正机会则准备失败，不强塞其他选项。

A/B 关联公式不读类别票，不增加拟合权重。它选择真正已有的覆盖路线；不能把纯质量绕访改名为 coverage。所有首选使用相同 N 覆盖候选准入和逐步安全返航守卫，不允许只给 A/B 放宽预算或运动检查。原可选质量路线的覆盖余量准入门不构成本轮新增特权：本轮根本不从该质量候选族取首选。

预期映射只能用来检查实现，不能硬编码替代上述公式：

|父|排列数|N|A|B|每排列独特选项|
|---|---:|---:|---:|---:|---:|
|P00|2|0|2|0，与N别名|2|
|P01|2|0|2|1|3|

若重新计算不符合这个映射、源 hash 或初始配对条件，停止准备并诊断；不能在观察新回报后改关联公式。

## 4. 目标保持、共同后续与去重

初始干预只执行一次。选中后，保留原 endpoint 的位置、朝向及 option 身份；每5个动作使用新观测图重算到该目标的路径。保留目标不代表强迫到达：剩余覆盖预测消失、观测路径不可用或去返预算不足时，沿用共同取消/回退规则并记录原因。每一步仍由原 RPN-UQ 已观测足迹与后继返航守卫独立授权。

不安装私有设施近访、额外观察承诺、免费转向或不同停止条件。原候选的 `asset_index` 仍为 None；`v22_observed_target_index` 只作审计说明，不改变执行。到达、取消或其他共同重选后，一律由同一 V21 N 逻辑继续直至真实任务终点。早到不能为某组额外补质量观察，早停不能补满或重开任务。

P00 N/B 去重必须同时满足完整候选路线、目标状态、刷新/取消规则和后续 N 一致，不能只看 candidate_id。允许不同审计别名，禁止别名改变执行。现有 `FacilityRuntimeV22` 的观察目标索引只用于日志，未增加执行分支；冻结前仍须验证这一点。

矩阵为 P00 两排列×2独特首选 + P01 两排列×3独特首选 = **10条新完整轨迹，加10次各自独立进程回放**。P00 每排列的一条 N/B 轨迹可以映射到两个逻辑控制名称，但不得作为两个样本计数。P01 N/A/B 三条各自独立执行。相同几何的不同排列仍是不同物理任务，不能跨排列去重；三组参考采样也不增加轨迹数。

V22 新初始化和首选日志改变后，本轮 N 要重新运行，不能直接拿 V21/V20 N 的行为等价声明替代这些新对照。任何中途失败都保留已执行动作与证据；不得删除失败后按新设置重跑为同一版本。

## 5. 冻结的类别规则、反向对照与主信息价值

以下规则用于从完整干预矩阵取出反事实选臂回报，不增加物理轨迹。它们在回报前固定，只读取初始观测票，不读取 assignment 或隐藏类别：

- `S_negative`：选择初始 canonical class_vote<0 的观测设施关联路线。在当前人工标记定义中，该票对应复杂设施的提示。
- `S_positive`：选择 class_vote>0 的观测设施关联路线，作为反向类别对照。
- 必须恰有一个负票和一个正票；零票、缺失或歧义视为本轮前提不满足，不用未来回报补标签。A/B 关联公式及共同后续均不因票值改变。

这是预声明固定类别先验的反事实策略评价，不是已经训练或部署的语义网络。若以后作为在线策略执行，必须另行证明该规则只改变初选、没有额外隐藏状态或后续逻辑；本轮不得宣称已完成该部署。

主表逐任务报告 N、A、B 的完整资格、C、Q、J、动作和失败/取消。P00 N/B 别名必须先归并为同一个 canonical 选项。主信息价值使用如下**同父两排列均成功合格的共同选项池**，不得只为有利的一次选择保留失败选项：

`K_p = {o：canonical选项o在父p的两种排列均满足任务成功及预算条件}`。

其中 J 仍是原始 C2D×Q，不作失败记零替换。对每个父 p，定义：

- 最佳固定非语义选择：`V_fixed,p = max_(o∈K_p) [J_p,排列0,o + J_p,排列1,o] / 2`。两排列必须共用同一个 canonical 选项。
- 类别可区分的条件选择上限：`V_cond,p = [max_(o∈K_p) J_p,排列0,o + max_(o∈K_p) J_p,排列1,o] / 2`。两个最大值仍在同一个 K_p 内取，但可按可区分的类别排列选择不同选项。
- 主绝对信息价值：`VOI_p = V_cond,p - V_fixed,p`。
- 主相对信息价值：`relative_VOI_p = VOI_p / V_fixed,p`。

如果 K_p 为空或 V_fixed,p 为0，主 VOI 比较不可用，不能填0或改用其他分母；报告具体排除项与原因。**开发信息门为两个父的主 relative_VOI 均超过5%**，分母是最佳固定非语义选择，而非 N，也不是失败记零后的值。一个父失败或不可用就没有通过该共同信息门；不得只平均剩余父布局。

两种最优值需要终点回报，都是有限矩阵的事后 oracle 分析；其中 V_fixed 是固定选臂 oracle，并非新训练的几何策略。它们只能由分析器计算，不能进入候选生成、运行时或预声明类别规则。条件 oracle 与固定 oracle 的差只提供这些开发父和动作集合上的类别信息潜力，不证明泛化、学习或完整架构效果。

固定 `S_negative` 的实际选臂值，分别与 N、最佳固定非语义选择及 `S_positive` 比较，报告两排列原值、资格、父内均值、绝对差和可用时的相对差。`S_negative > N` 单独不足以归因语义；若固定规则在同一共同可行池内优于最佳固定选择，才支持该规则实际兑现了信息。上限超过5%但固定规则未优于最佳固定选择，只能说明存在上限空间，不能宣布固定先验成功。原 N 的每个失败继续保留，不得用不合格 N 的高 J 或低分制造优势。

固定规则可能在每种排列选中不同选项，且这两个实际所选任务均合格，但其中某选项在另一种未被该规则选中的排列失败，因而不属于 K_p。此时该固定规则的实际两排列政策值仍单独报告，明确标为 `outside_common_feasible_pool`；它不是上述受限条件 oracle 上界内的比较，不能把其超出上界写成矛盾或把不同选项池的差混入主 VOI。反向规则或 N 存在同类范围差异时同样标注。任何政策的实际所选任务有失败，都不得仅取合格行计算合格政策均值。

为显示失败与可行性带来的影响，可另报明确命名的边界分析 U：任务成功时 U=J，否则 U=0；在全部 canonical 选项上计算失败记零的固定/条件 oracle，以及 A/B 的配对交互：

`D_U = (U_A,排列0 - U_B,排列0) - (U_A,排列1 - U_B,排列1)`。

给出四项原值和方向。U、D_U 及其 oracle 只作补充边界分析，不修改原 J，不替代共同可行池主 VOI，也不继承其5%门。未知可见性、取消和失败不能通过归零后重新命名而消失。这里仅有两个开发父布局的有限证据，不将参考种子、独立回放或 P00 别名当独立样本，不作未经支持的统计显著性声称。

## 6. 实际执行是否兑现了早期机会

初始静态路线提示 P00 A2/B0 在第8个动作分岔，P01 A2/B1 在第7个动作分岔；这是准备检查，不能当作真实执行已发生。分析须记录初选目标、每次保留/取消、实际首次动作分岔、到达或回退时间，以及相同选臂在两排列中深度/扫描/位姿首次差异。

旧 N 的动作0—19几何共同窗口只属于旧 N 历史。新路线在5步刷新后可能改道；必须用新轨迹自身记录判断类别是否在结构揭示前提供机会。不得用未来几何差异动态调整首选或删除不合适的任务。

完整分析按最初分配的首选保留所有结果。若干预在分岔前取消或多个臂汇合，报告“此执行机制没有兑现区分”，不能删掉这些行后声称强增益。若分岔实际存在而合格回报不随类别排列改变，说明当前早期信息入口没有达到所需价值。假设后侧平面支持为0不是实际不可见；非零也不是实际质量改善。本轮不新增晚至第29步的末端转向变体。
