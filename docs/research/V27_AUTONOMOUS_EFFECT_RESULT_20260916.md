# V27 反馈修复自主效果结果（2026-09-16）

## 结论

V27-A 的反馈接线修复已经转化为**一次可重复的行为和终点收益变化**，但预先冻结的整体验收门没有通过，当前完整方案优势仍不能成立。

- A复杂／B简单：启用反馈完成13次更新，但路线与关闭反馈完全相同，`ΔJ=0`；
- A简单／B复杂：启用反馈完成11次更新，首次下一动作在165步分叉、实际动作在166步分叉，`C/Q/J`均提高，`J`相对提高4.7516%；
- 两排列平均相对关闭反馈的 `J` 提高2.4040%，但预设规则要求两排列都严格为正，第一排列为0，因此反馈自主收益门失败；
- 修复后完整S相对历史G的两排列 `J` 分别为−3.5744%和+3.1297%，平均相对差−0.2174%，没有通过两排列均为正且均值严格超过5%的完整方案门。

因此可主张“IGCR稳定反馈在一个排列中改变了候选选择并改善终点联合指标”，不可主张“完整语义系统稳定优于几何规划”。按冻结协议停止在当前P00/seed上扩量。

## 冻结条件与可比性

四条新任务保持V25r1 `D25-P00`、400动作、`iid_025px`、seed1901、相同建图、设施归属和 `C/Q/J`。`S_no_feedback`保留相同语义提案和排序，只禁用方向反馈表写回。每条主任务均由新进程、新世界和新运行时完成一次独立自主回放。

复用V26历史G前，两条G保存历史共794包分别通过V26与V27运行时，794个规划状态、全部全局规划和下一动作完全一致，两个反馈表为空。该等价审计进行1588次离线地图更新，没有新世界、动作、网格或Q评价。

## 反馈如何改变行为

第一排列中，13次更新有8次代理饱和；方向系数最终包括0.875和0.703125。反馈从动作311起改变5次规划中的候选分数，公共候选最大分数差约0.000690，但始终没有改变选中位姿，因此路线和终点完全相同。

第二排列中，在首次分叉前，复杂设施线索 `cue-0001` 的sector 0已于130、140、146、160步更新，系数依次达到1、1、0.984375、0.8125。动作151起候选分数发生变化；动作165时两方法仍有相同12个候选，但关闭反馈选择sector 0方向位姿`[25,15,1]`，启用反馈抑制该重复方向并选择sector 1位姿`[29,19,0]`。这提供了“观测反馈→方向分数变化→动作分叉→终点差异”的一条完整链，但只在一个排列中成立。

当前反馈仍是最后一步相邻观测的 `improved_common_patches/16` 代理，第一排列13次中8次饱和。它没有直接估计整条选项带来的外形Q变化；第二排列复杂设施Q反而略降，也说明该代理尚未校准为设施外形收益。

## 下一步

停止继续扩展P00或增加同类seed。下一项应先用现有保存包离线检验“相邻面片改善代理”与真实局部外形Q改善是否相关，并审查反馈发生时机、饱和和候选分数边际：

1. 用评价真值只作离线标签，按到达选项计算设施局部外形增量，不把Q输入在线规划；
2. 比较当前 `/16` 代理、完整选项累计实测改善和离线外形增量的排序一致性；
3. 若代理相关性不足，将IGCR改为选项级、实例／方向条件的外形收益残差，并由RPN-UQ输出校准的不确定性；
4. 先在保存历史和有限反事实候选上过行为门，再决定是否消耗新的主任务额度。

该方向保留ANS层次与OV-SDF、STGHP、RPN-UQ、IGCR四模块，并把可验证语义创新收敛为“类别／实例／方向条件的外形收益预测及在线残差校正”。自然语义前端、含定位误差SLAM、外部主流基线和ROS1实车仍待验证。
