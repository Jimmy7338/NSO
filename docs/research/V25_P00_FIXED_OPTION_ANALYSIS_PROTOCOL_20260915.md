## 任务与共同条件

- 每父每臂只使用一份预先冻结的动作串，两排列相同。它是离线设计的固定采集选项；评价侧GT安全图可用于准备这些对照选项，但不表示在线规划器知道地图。禁止按隐藏排列改路径。

- 共同主表示为V24的实测表面清理输出，不启用V25推断；保留实测、未知，原始TSDF另行评价。不可在成绩出现后改指标、阈值、实例对象或选表现较好的表示作为主结果。
- 原seed基于真实可见二值标记几何建立，两实例不按GT owner分离。评价侧再按固定窗口核对唯一关联，原seed不重新匹配到较高分对象。

每条的动作串、传感配置、噪声种子、共同后端和评价器均由执行协议与清单冻结。本文件不替代运行器的容量检查及来源清单。无预算内完整选项时，该选项不可通过截断轨迹伪造返航成功。

## 终点输出

逐条报告实际付费动作、剩余预算、碰撞、是否回到规定位置及朝向、任务资格、真实可达二维覆盖C、全部设施等权外形Q和J=CQ。主Q沿用冻结V23三投影的min(边界F1@5cm,IoU)均值；漏建记零。另报原始TSDF成绩、每设施分数、前缀与终点变化及来源。

全部4条结果均入表。主任务资格要求预算内、零碰撞、规定返航和C≥0.8。不能只挑合格子集或最佳中途快照比较。若资格或独立回放不完整，下面信息价值只能标为未成立/未完成，不能充当合格任务的语义优势。

## 运行前确定的比较

令两个排列为x=1,2，J_A(x)、J_B(x)是两臂在同一排列下的终点联合值。

1. 固定选项参照：`J_fixed=max(mean_x J_A(x), mean_x J_B(x))`。这是看过开发结果后的最佳固定臂，只有两个固定选项；不称强几何或可主动探查的G。
2. 理想选项上限：`J_oracle=mean_x max(J_A(x),J_B(x))`。报告绝对差以及分母为正时`(J_oracle-J_fixed)/J_fixed`。这是两个已测选项内的事后上限，不是所有路径上限或已学策略。
3. 预定正确类别规则：选择复杂设施（预期x=1选A，x=2选B）。先核对公共前缀中两个真实可见标记的类别及其与观察实例的关联，不能仅用隐藏assignment字段冒充实际语义识别；未获得所需线索时只能报告人工类别上限。该规则在未知未来Q前已确定；单列其均值及相对最佳固定臂差异，不能把事后oracle改名为该规则。
4. 类别置换规则：与上述相反选臂，使用完全相同的已测任务结果作预定反事实汇总。它说明固定动作目录下标签方向的作用，不称独立执行了新的语义策略。
5. 分别列C、Q、两实例改善与动作成本，检查联合增益是否仅由空间位置、覆盖差异或某条更长路径解释。不得仅依据复杂设施被访问次数判定收益。

本批只有一个父布局、一种预定噪声种子及两个排列；不报告泛化成功或用这两个排列构造貌似充分的统计置信区间。P00通过至多支持执行另一父布局或后续自适应G/S验证。开发目标仍为两个父布局类别信息相对联合收益严格超过5%，并最终验证可执行语义规则、强几何对照和完整系统；不能仅凭本批oracle大于0宣布完成。
