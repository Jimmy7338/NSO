## 1. 必须保留的结构与可修改边界

| 不变量 | 应保留的输入／输出职责 | 允许修改的内部实现 | 不能混淆的证据 |
|---|---|---|---|

## 2. 主程序真实实现与断层

### ANS 主链确实存在，权重和原平台运行仍缺失

`main.py:460` 创建 Neural SLAM，`:466` 创建全局策略，`:477` 创建局部策略；`:759` 更新地图与位姿，`:1281` 采样长期目标，`:1338` 请求短期目标，`:666` 调用局部策略。FMM 在 `env/habitat/exploration_env.py:1403` 和 `:1446`。这是可识别的双层执行链。

### STGHP 确定性复核

直接实例化 `SemanticTopologicalGraph(min_room_area_cells=20)`，构造 30×50 已知地图、中央隔墙和 4 格宽门、起点在左室，强制更新。实际返回 **1 个节点、0 条边**。两室门道连通后被 `label(free_space)` 合并，随后从窄通道邻域寻找不同房间编号无法建立这条门边。此结果验证了接口内的结构问题，不代表 CPU V3 当前使用该错误拓扑——V3 根本未调用它。

### 理论表述需同步纠正

`utils/reward.py:65` 对新增格点求一次占据熵，未计算观测前后条件熵差。若传入观测后的确定占据概率，新观测越确定，熵反而越小。它只能称为熵加权代理；不能直接宣称实现了 `I(M;z|history)`。无概率时返回平方米，有概率时返回 bit（`:63` 与 `:69`），数值量纲也不同。

论文的全局 `O(HW)→O(|V|)` 复杂度结论忽略构图、候选生成、全局栅格距离场和局部规划；现实现不能支持。MC-Dropout 的均值／方差惩罚也只是一种启发式效用，若要宣称概率风险上界，必须补校准假设和单独风险界。

回环实际存在描述子与历史匹配路径，但 `loop/pose_correction.py:7` 仅把当前位姿向历史位姿插值，未构建、求解位姿图，也未重融合历史地图。`loop/semantic_vlad.py:97` 是固定类别直方图；不等同 CLIP 语义指纹。论文当前的 PGO、漂移改善及开放词汇回环说法均缺少对应实验证据。

## 4. 当前对照不是主流方法原实现

`coverage` 来自自有 `QualityCoveragePolicy` 的二维覆盖目标，`legacy_geometry` 是同一文件的角度补看，`geometry_v2` 是本项目同结构去语义；它们都是**内部对照／可解释基线**。现工作树没有已执行 TARE、FALCON、PONI、SemExp 或 2025–2026 语义覆盖方法的原作者代码实验。原 Habitat 目录中有基线基础设施，不等于这些论文方法已复现。

最新所有方法共享传感器、动作预算和选定 TSDF，这避免后端收益冒充语义收益，但工厂对 `coverage/legacy_*` 忽略新 planner 参数且使用旧两视点选择器；它们与完整方法并非“只去掉一个模块”。`geometry_v2` 才是比较语义增量的主要结构匹配对照。`no_hypotheses_v3` 同时移除了形状假设和物体候选，适合检验新增物体机制整体净收益，不能单独归因于先验。

保留两层证据：

1. **机制层**：共享同一 mapper、运动学、候选数量和规划预算的去语义／仅前景／去形状／去路线对照，回答我们的新增信息是否有效。
2. **外部方法层**：选择任务相容的近期覆盖或密集建图方法，固定作者版本，列出移植项、传感器和目标差异。若只能 CPU 重写核心选择器，应称“按原文实现的适配基线”，提供方程与原代码对照、独立单元行为检验，不能称完整作者系统复现。保留作者默认参数和等量开发调参两种结果。

论文现有 ANS/PONI 等 92.4% 主表仍为未经验证数字。当前三维结果不能用于恢复或背书这些数值。

### 已由代码定位的机制缺口

1. **预测收益尚未由实际收益校准。** `camera_joint_planner_v2.py:118` 写预测分项，`:126` `_active` 只记录目标及二维预测格数。没有对一次物体补看的预测隐藏面积与实际新增表面作在线匹配、降权、停止或重试预算更新。历史深度排除能消除部分重复假设，但不能保证整个目标的效益被正确估计。
2. **区域是 4m 方格，不是真实门户拓扑。** `camera_joint_planner_v2.py:72`、`:98` 以空间分桶和“每桶一次”限制路线。同一房间可跨桶，不同隔墙两侧也可能同桶；当前算法缺少多房间覆盖预算的显式维护。这是解释布局差异的机制假设，需修正后消融才能确证因果。
3. **候选预算被替换，可能丢失普通观测点。** `semantic_completion_v3.py:212` 将 20 个统一采样视点缩为 10 个，加 10 个物体环绕视点；物体视点在 `:171` 只按路径距离排序后等间距抽取，没有按有效可见面积筛选。`no_hypotheses` 的优势可能同时来自候选集与收益模型，需公平候选集实验分开诊断。
4. **形状模型存在硬编码误差。** `semantic_completion_v3.py:43` 使用固定 .2m 投影；`:56` 设定 .9/.65m 最小尺寸与高度范围，`:86` 固定 3 层板，`:93` 背板朝向仍根据粗方位汇总；`:107` 只用已测点到模型表面距离，尚未把自由空间矛盾纳入假设级似然。双方都共享该模型，但语义可能更强地放大一个拟合有偏模型。
5. **联合目标是代理，存在归一化误差。** `camera_joint_planner_v2.py:39` 用未知加自由格点估计面积；`:45` 用质量经验公式，`:55` 以相机二维足迹乘条件质量代替三维 recall，再假设 precision=1 构造 F1。`semantic_completion_v3.py:225` 用 `2×平面地图面积` 归一化表面积。货架层数增加会改变真正表面分母，这个在线估计不具备恒等关系或误差界。
6. **语义效应混有两个机制。** 类别先验之外，`joint_planner_v2.py:59` 还有架体近看奖励。仅前景对照已去掉这两项，能说明细类别整体信息有作用；仍需“仅类别后验、无近看加分”消融才能主张是隐藏形状推断带来全部收益。

## 6. 最小实际挂接方案

### 先做 CPU 同接口适配器

建议新建一个明确命名的 `NSOCPUComponents`，复用四模块方法职责与返回约定，附一个 `backend_manifest` 明确是几何／语义机制验证而非神经网络权重恢复。其每步调用链必须可从日志确认：

```text
mapper.update(RGBDFrame, PlanarScan)
→ components.update_semantic(当前可见证据；内部更新类别条件需求)
→ components.update_topo(当前地图、位姿、需求)
→ components.predict_reachability_uq(候选执行特征)
→ components.select_topo_target(预算、风险和覆盖／重建边际收益)
→ 原局部执行接口(act / observe_outcome)
→ components.compute_reward(前后实际地图证据)
→ 记录预测与实测差异，更新内部收益可靠性
```

已有签名没有深度、内参、实例后验和预算字段，不能靠伪造这些输入装配。保留旧位置参数和返回值，增加可选关键字 `sensor_frame`、`surface_state`、`candidate_states`、`remaining_budget` 等；旧调用默认保持兼容。语义场仍是 `H×W`，额外实例后验作为显式 sidecar。收益反馈只有过去和当前真实观测，没有 evaluator 对象、真实参考网格或未来深度。

RPN 适配器若尚无可靠训练数据，可以显式输出“几何约束＋经验置信区间”及状态标记；不能把 `mu=1,var=0` 写成已验证神经 UQ。先完成地图可达和执行预算约束，然后用实际目标尝试结果训练／校准，未校准模块不能在主论文承担风险保证贡献。

### `main.py` 热循环的具体挂点

| 插入位置 | 可用输入 | 必须完成的输出／处理 |
|---|---|---|
| 初始 `:573` 和每步 `:759` 地图更新之后、`:773` 附近 | `obs[e,:3]`、`planner_pose_inputs[e,:3]`、局部占据／探索图；需要环境另行输出传感器深度、K、米制相机位姿 | 调用同一 `update_semantic`；以真实深度反投影，禁止沿固定半视距投点。初始帧与每次重置也要处理 |
| 全局窗口同步 `:1213` 后 | 全局占据／探索／历史访问 `full_map[e]`、米制 `full_pose[e]`、OV-SDF 全局场 | `update_topo` 建图、更新区域需求与边成本；全局起点用 row=y/res、col=x/res |
| 初次目标 `:606` 后及周期目标 `:1289` 后 | 原 ANS 策略提案，候选局部地图，预算，地图坐标 | 候选 UQ→拓扑选择→安全目标；全局目标投影为安全门户，再减 `lmb` 原点传局部 FMM；不可把远房质心简单 clip 到局部窗口 |
| `:1256` 奖励汇总处 | 上一周期地图快照与当前传感器地图；不可用 GT 参考精度作在线奖励 | `compute_reward` 产生一次 IGCR 分解并写 rollout；不能再叠加同一环境奖励导致双计 |
| 目标结束／失败 `:1345` 附近 | 选择时保存的输入特征、目标、预算；实际到达与消耗结果 | `add_rpn_experience`，仅训练模式更新；失败标签必须对应当时的地图与目标，不能用完成后的新地图替代 |
| reset / done | 场景索引与终止前记录 | 先保存指标与反馈，再 `reset_scene`，同步清空旧语义、拓扑、回报快照与目标尝试 |

当前 Habitat 接口中，深度在环境内部 `exploration_env.py:339`、`:441` 处理，主策略 `obs` 为 RGB；因此新增同接口适配必须把**传感器深度与标定**显式带出来，不能从 `infos.fp_proj`、真值位姿或评价可探索地图偷取替代输入。

**全局策略兼容的关键点：** 原 Actor 输出连续二维高斯动作，随后 Sigmoid 成目标，并没有 `H×W` 网格 categorical logits。`apply_uq_mask_to_logits` 不能直接 reshape 连续动作冒充栅格分布。可保留原 Actor 作为长期候选提案器，对一组实际候选计算其原策略 log-density，再加语义／信息增益和 UQ 项；训练时若执行分布改变，rollout 需保存同一实际分布的 log-prob，避免仍用原高斯 log-prob 做 PPO。CPU 验证阶段可以不训练，但必须明确这一差异。

以上是最初审计时的挂接设计，**当时尚未实施；之后已完成的实际接线与剩余限制见第 8 节**。接线完成的最小检验应包括：四模块均有非零调用计数；给定同一观测与候选的语义干预会改变预期分项；关闭语义恢复共同几何先验；风险输入影响目标而不改变评估真值；奖励恰好计一次；跨窗口／reset 坐标一致；实际输出仍由局部执行器完成。

## 7. ROS 1 / ZED 回校前后的边界

现有 `RGBDFrame` (`utils/rgbd_contract.py:25`) 使用米、光学坐标和采集时刻的 `world_from_camera`；`PlanarScan` 独立记录雷达位姿。`record_ros1_rgbd.py:45` 同步 RGB-D／雷达并按各自时间戳查 TF，支持外部标签话题，**不发布运动指令**。录制与 CPU 回放前置工作可复用，但 ROS 进程、ZED 驱动、语义识别及 `move_base` 接入尚无实车验证。

需补齐：

1. 核对相机／雷达 TF 外参、深度单位、注册分辨率、相机 K/P、时间偏差、位姿跳变与现有 SLAM 配置。中控型号口述不明确，不能自动推断 Jetson 或 CUDA。
2. 用实车 ZED 已发布深度和位姿作为输入；保留 IMU/GPS 原始数据，不把当前 CPU 算法称为实现新的 IMU/GPS 融合。
3. 准备真实可见语义证据提供器：关键帧检测／开放词汇描述→对齐深度→实例／类别后验；缺失、误标与置信不足时按共同几何先验回退。盒／架手工映射的范围要公开。
4. 对接 `move_base` 的目标位姿、成功／超时／取消与局部避障，用反馈训练执行可达性。禁止把当前 90°／0.2m 离散动作直接作为底盘速度。
5. 固定时间而非仅离散动作数比较；以独立参考测量三维误差，分别报告地图完整率与几何精度。固定 bag 只能验证给定轨迹的重建，不能证明机器人能主动访问未录到的视点。

## 8. 审计后的实际接口挂接与验证

新增 `nso/runtime_integration.py` 的 `NSORuntimeIntegration`，并在 `main.py` 初始帧和每步感知后调用 `observe`、初次和周期长期目标后调用 `choose_goal`、场景终止后调用 `reset_scene`。原全局 Actor、FMM 短期规划和 Local Policy 保留。所有四模块开关关闭时适配器是无状态 no-op。

`observe` 从传感器局部地图与窗口原点合成每场景自己的全局快照；实际调用 OV-SDF 更新／读出、拓扑更新和 IGCR 计算。`choose_goal` 在 eval 或固定全局策略时调用真实拓扑目标选择，用已知安全空间路径选择局部窗口内的目标，不把远目标穿墙截断。UQ 必须严格加载匹配当前网络的 checkpoint 才可推理并门控拓扑目标；无权重、LFS 指针或旧点估计权重都显式标记不可用，随机初始化不参与动作选择。启用 UQ 时不再同时加载和使用旧点估计 RPN。

语义缺少 CLIP 时不会创建检测器或接受 0.5 常量作为证据；缺检测器／权重或推理失败时显式标为 unavailable。真实可用网络进入评估冻结摘要。每场景独立奖励计算器替代共享实例；状态快照在 reset 清空。

尚未越过的边界：

- OV-SDF 本次仍使用旧近似投影接口，真实深度反投影未修。CPU V3 隐藏形状机制尚未挂到该管理器，不能称新语义机制已经进入原神经系统。
- IGCR 在 `main.py` 先作为实际地图变化诊断输出；原 PPO 奖励保留。原因是自动 reset 后主程序收不到终止前的传感器地图，直接替换会漏末步或混入下一回合。记录明确标为 diagnostic，未声称训练奖励已替换。
- PPO 训练原连续动作分布时禁用目标后处理，保证行为动作与原 log-prob 对应。若要训练受新目标分布影响的全局策略，必须实现分布一致的候选 Actor，而非简单改目标后继续用旧 log-prob。
- STGHP 内部的两房一门分割问题本次未改；UQ 仅证明权重／接口接线，未完成风险校准或训练经验回路；本次不宣称任何性能提升。

验证：新增 11 项轻量接口测试全部通过，使用真实 NSO 管理器、奖励计算器、拓扑目标接口及加载固定测试张量的 UQ。覆盖关闭兼容、场景奖励与地图状态隔离、全局／局部坐标和绕墙路径、不可达目标回退、机器人完整 footprint 不伸入未知邻域、随机 UQ 不调用、已加载 UQ 对真实拓扑门控的影响、LFS 拒绝、CLIP 缺失和训练动作一致性；其中 main 调用位置仅作 AST 结构检查。原有 16 项冻结评估／终止记录／指标回归也通过。共 27 项检查通过，不等同完整 Habitat 或实车执行。
