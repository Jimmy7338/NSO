# V13 后续训练的隔离与语义对照约束

2026-09-14。本文约束后续模型实验，不表示信息价值门槛已通过，也不是训练已执行的报告。当前 V13.2 正在执行冻结的全部配对候选。

## 已暴露开发数据不能重新命名为未见验证

Q0–Q3 的物理候选回报、匹配历史、固定评分负例和信息价值已用于机制诊断。即使训练时每折不读取被留出父场景的标签，开发者此前也已经依据这些场景改动执行定义。因此，这些父场景上的留一分组结果只能称为开发交叉验证，不能宣称符合“验证场景未参与算法／特征／门控设计”的强隔离要求。

若 V13.2 通过信息价值筛查，Q0–Q3 继续作为训练／内部开发组。先冻结特征、归一化办法、损失、模型容量、超参数选择程序、门控和验收门槛，再构建并封存全新的验证父场景。未来最终确认集与该验证集另行隔离。F00–F11 不参与上述任何选择。若在验证结果揭示后修改方法，该批验证数据降为已观察开发证据，不能重复宣传为新的独立通过。

父场景分组同时包含其两种类别排列、全部决策点、所有候选路线和传感帧。镜像、传感噪声重复、参考表面重采样或多次物理重放均不能制造新的独立父场景。

## 输入与监督分开

训练输入必须从执行前已落盘的观测描述符、实际地图和候选路线构造。可使用剩余预算、已知往返代价、已分配地图的未知比例、预计相机／雷达新观测、实例测量支持、方向观察缺口和观测到的类别置信度。

禁止把结果行里的 `before.coverage_2d`、全局 F1、真实可达面积、参考表面、隐藏对象类别、未来回报，或场景／排列／候选 ID 当作预测输入。特别是 `before` 指标虽然处于时间前缀，但由离线评价真值计算，不能因此视为机器人已知量。父场景 ID 仅用于分组，候选 ID 仅用于动作对应及预定平局规则。

几何模型与语义模型需要相同容量、训练预算和选择程序；标准化及任何残差限制只在训练父场景拟合。零置信度回退必须通过实际选择检查，不能仅靠输入变量名称保证。新版本的去程后重规划标签不能混入旧完整往返标签后仍声称同一回报定义。

## 全局改类别名称不等于删除语义信息

设类别为 s，π 是固定的一一重命名。由于 π 可逆，知道 π(s) 等价于知道 s，因此允许重新训练的模型仍然可以恢复同样的类别条件动作规则。对整个训练集和测试集统一交换两个类别，并重新训练，不构成“语义信息被打乱”的零信息对照。

需要分别记录两种不同实验：

1. **冻结正确语义模型，仅在推理时交换类别。** 检查已训练策略是否依赖正确的语义对应关系；这属于输入干预／错类敏感性检查，不等于单独训练的随机语义模型。
2. **独立随机语义安慰剂模型。** 在观察未来回报前固定随机化程序和种子，类别赋值不依赖隐藏结构与收益。同一历史中的所有候选必须共享同一实例标签表，不能给每条候选随机一套不一致的当前观测。训练组和未见组独立随机化，并报告全部预声明随机化重复，不能选择最差一次作为对照。

还应保留不输入语义的同容量几何模型、固定类别先验、零置信度与受限语义残差模型。语义信息价值的理想最优选择也不属于可部署基线。所有方法使用相同候选池、总预算、返航约束及重建后端；候选生成或执行方式带来的共同改善分别计入对应模块，不能计为语义净贡献。

## 晋级顺序

当前先完成 V13.2 物理执行与三组固定参考采样筛查。若未通过，继续修改候选、观测表示、执行机制或预先定义的场景分布，保留负例，不启动模型晋级。若通过，只授权开展上述隔离条件下的训练与新验证设计；不自动证明可学习性、闭环收益或真实语义有效性。

完整主张仍需要冻结模型的独立场景、闭环执行、强几何与质量感知对照、自然语义输入和实车证据。当前合成类别标记与理想位姿条件下的结果不能替代这些环节。
