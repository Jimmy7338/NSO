# V40 P0 多设施实例观测与信念合同

状态：新接口与解析合同验证，未运行 World、真实残差反馈闭环或48条开发试点；冻结 V35/V39 文件不改。实现 `nso/instance_belief_v40.py`，测试 `tests/test_instance_belief_v40.py`。仅依赖 NumPy 和标准库。

## 输入与公开 API

`PaidRGBDObservationV40.from_mapping` 必须且仅接受 `frame_id, paid_step, rgb, depth_m, intrinsic, world_from_camera` 六键。RGB 为 H×W×3 uint8，深度为同尺寸、有限非负轴向深度；K 为有效针孔内参，T 为合法刚体 world-from-camera。构造时复制并只读封装数组；不接受 owner、semantic、hypothesis、未来帧、GT、World 等附加字段。`frame_id` 只作不透明去重索引。paid_step 必须从0连续递增，重复帧或跳步拒绝。

`InstanceBeliefV40(*, palette, structure_names, class_structure_prior, mode='S', geometry_prior=None, ...)`：palette 显式映射类名到RGB，class_structure_prior 独立映射同一类名到K维正权重；K≥2，允许多对多，不使用类别ID的算术来确定结构。默认几何先验均匀，不允许某结构权重为0；权重归一化后小于1e-9也拒绝。它们是声明的条件先验，不是经实验校准的识别准确率。

- `observe(observation)` 返回 JSON 可序列化的接受/拒绝组件、关联、视位与逐实例信念收据。
- `snapshot()` 返回独立 JSON 副本，含 `instances`；每项有 `instance_id, anchor_world_m, structure_names, structure_probabilities, geometry_prior, geometry_log_scores` 及语义/冲突信息。
- `geometry_snapshot()` 是显式语义无关合同，包含锚点、几何先验/分值、视位代表、反馈去重、接受数、关联歧义和逐帧关联；相同输入下 S/G 可逐项精确比较，不能靠任意删字段宣称几何一致。
- `apply_geometry_feedback(instance_id, *, frame_id, log_likelihoods)` 仅接受此前已经唯一关联该实例的付费帧，绑定其已记录视位，不允许反馈未见/歧义/其他实例的观测。

## 组件、几何关联与证据独立性

从可见 RGB 中按已配置颜色取四连通组件，默认至少16像素、至少8个有实测深度的有效像素。未知颜色、很小组件不注册；没有深度的已知组件明确拒绝。用 K 反投影实测深度，按实际欧氏距离≤4m筛选，然后以T转入世界系、取逐坐标中位数作为**标记锚点**。该锚点不是完整设施中心，未知颜色或无标记设施不在此P0模块的发现能力内。

关联仅按3D锚点距离，默认半径0.75m，不比较类别、结构概率或 GT owner。旧实例候选超过一个、多个组件争抢同一实例、同帧多个新组件彼此过近时拒绝关联，不猜 owner。与歧义有关的旧实例临时暂停语义条件先验；下一次明确关联可恢复此前无冲突的类证据。锚点固定为首次有效观察的中位数，不用重复近视位把锚点向局部遮挡方向累计漂移。

新实例按组件首像素的几何顺序编号，类别字典重排、类名重命名或颜色—类名映射置换不影响实例编号/关联几何。两个不同类别的远隔设施分别维护自己的类集合，不像V35那样形成全局冲突。

视位采用每实例的实测相机原点代表集合：距任一代表小于0.25m即复用该视位；新代表必须与已有全部代表相隔至少0.25m，默认最多16个。这避免坐标落在栅格边界两侧的微小位移获得双份证据；同原点旋转不新增独立视位。该规则是保守相关性近似，不证明真实统计独立。到达视位上限后继续关联并记录观察，但不把新位置伪装成旧位置，也不增加其几何反馈。

## 各实例的语义与几何组合

每个实例分别存类别支持视位。默认单一类别得到至少两个不同视位支持才启用其条件结构先验；不会把重复帧或每次重看都当新语义似然累乘。在S模式，唯一受支持类别无关联歧义时使用该类条件先验；G模式始终使用同一几何先验，保留相同组件/关联与几何反馈。两者均有

\[
p_i(z=k)\propto\pi_i(k)\exp g_i(k),
\]

其中 (g_i) 仅累积本实例、已接受帧的几何反馈。每视位仅应用一次反馈，向量减去最大分量后截断到[-6,0]，累计重新定中心并截断到[-24,0]；这是数值稳健评分而非已校准概率。反馈可纠正错误类别先验，但不能更改类别—结构表。

若同一实例先后见到两个受登记类别，S保守退回几何先验，其他实例不受影响。**本P0的已见类冲突集合不会自动遗忘**：这不是完整的语义冲突撤销算法；后续正确几何反馈仍可改变结构权重。歧义关联导致的临时暂停则可由下一明确观察解除，两种状态分别报告。

## 信任边界与本轮可声称内容

白名单和帧/实例绑定可阻止直接传入隐藏owner、未来帧或未关联实例，无法从任意实数判断 `log_likelihoods` 是否确实来自已付深度。**上游已付几何残差评分器尚未实现和集成**，必须后续审查它只读当前/历史实测数据及合法公开模型，不能把此接口测试描述成真实3D残差反馈闭环跑通。

本轮只验证解析输入、连通组件、K/T变换、几何关联、局部信念、重复证据与越界拒绝。人工标记不是自然实例识别；几何近邻关联不是解决跨遮挡重识别。保存单设施帧兼容测试不能拼成多设施性能证据。真实多设施、类别结构偏移、未知目标发现和标记消失后的几何关联仍需独立开发与冻结试点验证。
