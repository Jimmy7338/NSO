# V35 下一阶段：把实测路线优势转成在线语义策略

2026-09-18。V34固定P00路线通过实际覆盖、TSDF质量和3次独立回放门；主J等权均值相对+6.5644%，2/10cm方向一致。主任务19/36，余17；本文件是实施与准入计划，尚未实现V35控制器，也未开始新自主任务。总体毕业Goal保持未完成。

## 要回答的问题

在同一场景、传感、42动作预算和公共建图后端下，系统能否仅从已付观测获得类别／几何证据，主动选择观察方向，并保留实际J优势？错误类别能否被新几何证据纠正？G必须能够主动取信息、补看与改选，不能故意取消它的一般几何能力。

固定路线结果中的oracle并非实测Q的全局上界。V35双方不能访问实际hypothesis、评分GT、未来实际包或预先存好的本实例最佳动作串；禁止从episode_id读取构型。允许双方同样持有两个构型模板、公共任务域及其关系先验，但须明确属于有任务先验的设施主动建档，不是完全未知环境探索。保留本轮强制18步前缀作为第一阶段限制，不能称42步全程自由优化。

## 四模块的可执行职责

| 模块 | 本轮拟实现职责 | 共同输入与隔离要求 |
|---|---|---|
| OV-SDF | 维护实测地图、类别置信度与两种服务方向的后验 | 主TSDF仅融合观测；预测模板单独存放，不当已测表面 |
| STGHP | 以当前后验、已观察表面和剩余预算选取全局观察方向／局部目标 | G和S共用动作能力、模板集合、规划求解器与覆盖返航约束；不直接播放V34路线 |
| RPN-UQ | 执行当前局部动作并报告可达／地图冲突／返航余量 | 真实安全域只由环境做执行判定；策略所用地图或先验清单明确封存；确定性检查不称校准概率风险 |
| IGCR | 用新深度／雷达与模板预测的残差更新几何后验及未观测收益 | G同样获得几何更新；不得把离线Q、参考面或真实构型作为反馈 |

先保留可解释的轻量类别条件模型与几何似然，不训练大网络。类别先验必须来自RGB读取结果及置信度，不能在控制器创建时注入真实类别。人工颜色接口只验证信息机制，自然图像类别识别仍须独立验收；保留可替换前端供后续CPU图像验证和ROS1小车接入。

## 先完成零新增主任务的接线准入

1. 读取V34保存包，独立定义在线可读字段和禁止字段，隔离评估器与控制器。共同模板预测可以使用公开两假设；任何实际世界GT只留在执行／评价侧。
2. 冻结几何似然、类别可靠度、停止条件和规划目标。优先复用现有有限求解和预算账本；若原可见性代理与实测响应不一致，使用当前开发数据做诊断并明示，不在确认集调目标。
3. 用保存数据做干预：去类别后前缀G状态相同；相同几何、不同类别可改变S选择；新几何能纠正误导类别；同一包输入四接口的实际调用与状态变化完整留痕。G允许获得同一新几何信息，未知／低置信类别应回退到共同先验。
4. 检查动作逐步由当前状态产生、付费传感后才更新，收益不因单纯重复帧虚增。同时验证覆盖预算和返航可行性，禁止通过强制冻结G或偷用实际hyp使S获利。
5. 上述检查通过后才写独立运行协议并冻结源码、参数、矩阵和对照。接线未通过时继续修实施问题，不启动主任务消耗配额。
