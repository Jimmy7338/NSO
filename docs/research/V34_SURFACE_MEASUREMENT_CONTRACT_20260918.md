# V34 单设施实测表面合同（夹具执行前冻结）

版本 `v34-area-surface-1`。依据已冻结 V34 测量计划，本版本定义 Open3D TSDF 输出的单设施提取与标准面积均匀表面 P/R/F1。开发只使用解析网格，不构造 World、传感器或 TSDF。它不重写 V33 的理想可见面积结果，也不评价网络或自然语义能力。

## 预测提取

输入为原始 TSDF 网格、预先声明的公共设施 AABB（2×3 min/max，世界坐标）。公共 AABB 必须在采集前由同父两种构型的所有设备实体边界取并集确定，对两个构型和政策相同；不得使用当前真实构型、GT owner、可见性或评价分数缩小它。API 不接收 GT 参考、类别或观测次数。

1. AABB 每轴两侧固定外扩 **0.20 m**。对每个相交预测三角形作六半空间精确多边形裁剪和扇形再三角化，不按中心点筛选，不加封口、不填洞、不贴合真值。
2. 地面是实验公开已知平面 `z=0`。仅去掉**全部顶点满足 `|z|≤0.02 m` 且单位法向满足 `|n_z|≥cos(10°)`**的三角形。法向方向无关；斜三角形或近地竖直附件不按高度整体剔除。不自动拟合地面、不改变保留顶点位置。
3. 剩余所有三角形参与 precision，包括公共 ROI 内错误附件、错误尺度与分离杂片。报告输入/裁后/地面删除/最终面积、三角数及 ROI 界。ROI 外预测不计入本单设施 precision，这一限制明确披露；不得把它称为全场景错误几何惩罚。
4. 输入中零面积（面积≤1e−12 m²）面和完全相同的重复三角形规范化去重；顶点/面顺序不改变几何。有限面积的近似重复、不连通或多余表面不按 GT 清理。无顶点吸附、配准、凸包或类别补全。

近地算法明确限制：真实厚度低于 2 cm 的水平附件与共面地面仅凭几何不可可靠区分，本规则可能移除它们；当前 r1 非底座附件起点为 0.4 m。竖面 recall 仍包含全部参考高度，不因提取过滤而裁掉低处目标。

## 评价

构造 `SurfaceMeasurementV34(full_reference, vertical_reference)`，两参考为同一冻结实体并集：前者全部准确外表面、后者全部外露竖面。参考只存在评价侧，不能输入 TSDF 或预测提取。当前每场固定一个设施；禁止漏检后移除该设施分母。

- 从全部预测面按三角面积概率、三角形内部平方根重参数化抽取 **32768** 个均匀表面样本，PCG64 seed **340918**。计算每点至完整 GT 三角网格的最近欧氏距离，得到 precision 距离。
- 从固定全部外竖面以同样方法抽取 **32768** 个样本，PCG64 seed **340919**。这批参考样本在构造时固定，与政策、阶段和观测集合无关。计算至全部预测三角网格的最近欧氏距离，得到 recall 距离。
- 距离使用 Open3D CPU `RaycastingScene.compute_distance`，单线程、float32 查询/三角形；不是最近采样点距离。阈值为 **0.02、0.05、0.10 m**，条件 `distance≤threshold`，无通过率补偿。每阈值报告 P、R、`2PR/(P+R)` 和 `C_map×F1`；主指标固定 5 cm。
- 两个方向各报面积采样距离 mean、RMSE、P95。precision 表示预测表面的准确程度；recall 表示全部参考外竖面的重建完整程度，不能把 recall 称为坐标精度。
- 空预测 P=R=F1=joint=0，误差统计为 null（没有有限可测距离），不报伪零误差。参考为空或非法输入直接拒绝，不能悄悄改变任务。
- 水平面只进入预测 precision 的采样和完整 GT 距离，不进入 recall 分母；因此正确竖面预测本身可以 P/R/F1=1，不要求臆造屋顶/底板。额外错误水平面仍会降低 precision。

采样是固定随机面积估计，有限样本误差存在。等价重三角化不承诺逐 bit 相同得分，但正确自匹配必须近零距离/满分；复杂负例的两个三角划分评分差允许至多 0.015（低于 32768 样本比例估计的保守数值检查量，不用于策略优劣门）。网格整体与参考共同刚体旋转时结果保持数值等价；不是对单独预测做对齐。

资格独立报告：`C_map≥0.8`、实际 returned、collisions=0、failed=false，且明确给出非负 paid_actions/budget 并合规。未提供预算不能 eligible。分数不因不合格而删除；未知预算不阻止形状评价。C_map 由外部冻结评价合同计算，提取器/评价器不生成或修改覆盖率。V34 主要比较和止损仍服从上位协议，不由这些夹具阈值决定。

## 首次解析夹具

夹具在读取任何 V34 实测质量之前固定：正确全部竖面；缺整侧；原正确面加远离真值的额外面；单独平移错误；同物体不同三角划分（包括负例）；空预测；参考/预测共同刚体旋转；预测提取的跨 ROI 大三角精确裁剪、近地竖直附件保留、地面与近地平行面剔除、ROI 内额外几何保留，以及输入不变/预算未知资格。

测试只调用解析 BoxV30 并集、Open3D 网格距离和提取，不调用 World、传感、mapper、TSDF、旧保存网格或新主任务。首次及修复后的 stdout、exit code、源码 SHA 均保留至独立 `audit_results/surface_measurement_v34_unit_20260918`，总量≤2 MiB、磁盘保留≥64 MiB，CPU 单线程。失败保留，不通过改变场景、主指标或阈值掩盖。
