# V43：观测驱动的四模块 CPU 控制器

日期：2026-09-21。实现 `nso/controller_v43.py`，测试 `tests/test_controller_v43.py`。

V43 将已有的观测关联、结构后验、实测残差、候选视角面积预测、共享探索收益、占据安全检查和逐动作返航预算接入同一个控制器。它保留 ANS 层次及 OV-SDF／STGHP／RPN-UQ／IGCR 接口，采用有明确计算上界的贪心 CPU 实现；不是原论文各网络已经训练或完整方法已取得性能优势的声明。

## 调用与四模块接口

```python
controller = ANSControllerV43(public_graph, home=home, budget=160,
    palette=palette, structure_names=names, class_structure_prior=priors, mode='S')
mapper.update(paid_rgbd, paid_scan)
accepted = controller.accept(paid_rgbd, mapper, execution_outcome='success')
decision = controller.choose()
```

每个支付帧只允许一次 `accept`，之后最多一次 `choose`。调用方执行返回的 `forward / left / right / observe`，并在新支付帧中报告实际成功或碰撞；`stop / blocked` 为终止状态，不消耗额外动作。没有强制的前置探索动作或额外免费观测。

- **OV-SDF**：V41 已观测实例关联与类别条件结构后验；人工标记和保守的几何支持关联仍是当前前端能力边界。
- **IGCR**：V41 当前支付深度像素残差，验证来源并在有效新支持下修正后验。G 与 S 接收同样的几何残差。
- **STGHP**：V42 共享名义结构表面的候选视角新增面积预测，并跨已观察实例求和。
- **RPN-UQ**：结构后验产生的名义面积离散度、已观测占据安全检查以及逐动作返航储备。它是确定性的 CPU 替代接口，不是已训练的轨迹网络或已校准的真实精度不确定性估计。

## 初始探索、候选与资源上界

没有观察到设施时，控制器仍可使用同一公共导航先验和已测占据网格探索。二维收益为候选位置周围默认 2 m 圆盘内的未知网格面积，来自 `ObservedSafetyV43`。该代理没有预测遮挡后实际能看到多少未知面积，不能写成实际覆盖增益。全周单线雷达已在某位置采样后，该位置所有朝向的二维探索收益归零，避免原地转动重复索取相同的二维未知面积收益；三维检查可继续选择未支付的新朝向。

候选池由 `select_candidate_states_v43` 根据公共图、当前位置和已支付相机状态生成：最多 32 个视点，按公共图的逐动作距离选择位置，并用每位置最多四个朝向的配额保留位置多样性。候选生成不读取类别、结构后验或私有场景信息。

每个已观测实例仅在同一候选池中选择至多八个视角。筛选按**已测锚点与视轴的夹角、距离、节点名和朝向**排序，不读取语义概率。因此在相同观测历史下，G/S 的候选池及实例候选分配相同。该上界可能遗漏有价值的远处或侧后方视角，属于当前贪心近似的限制。

控制器最多保留八个实例；预算至多 511 个付费动作，与预测器至多 512 帧（含初始传感帧）一致。构造器复制公共图、类别先验和配置，不保留调用方可变配置的引用。

## 收益、离散度与返航

令二维未知面积代理为 \(D(v)\)，实例 \(i\) 的期望新增名义表面积为 \(\mu_i(v)\)，结构条件面积离散度为 \(\sigma_i^2(v)\)。默认使用：

\[
U(v)=w_D D(v)+w_I\max\left(0,\sum_i\mu_i(v)-\lambda\sqrt{\sum_i\sigma_i^2(v)}\right),
\qquad w_D=w_I=1,\quad\lambda=0.
\]

二维和三维项分别在收据中保留，权重是**预先声明的设计常数**，未通过性能结果校准。默认离散度仅供诊断，不声称 RPN-UQ 的不确定性项已经带来规划收益；可配置的非零 `uncertainty_penalty` 也必须在实验前声明。跨实例的方差求和假设潜在结构独立；名义原型相互重叠可能导致面积重复预测，没有真值几何去重，不得当作实际总表面积。

V41 路由器按 `U / (到达的逐动作代价 + 1 次观测)` 排序，并检查从当前状态到候选、一次观测、回到起点**位置和朝向**的完整预算。0.25 m 平移和 30° 旋转均计费，碰撞尝试也计费。安全模块只依据实测占据移除已声明边，不增加穿越未知障碍的真值边。穿过未知网格的许可明确来自所有方法共有的公共导航先验，不代表未知即自由。

每次接受实测帧后重新检查占据和返航。当前机器人圆形足迹与已观测占据冲突时立即终止为 `blocked`；无法找到预算内返航路径时也可终止为 `blocked`，不能把这类失败写成返回成功。

连续 12 个付费动作没有新增已知占据单元、也没有新关联支持体素时，默认看门狗锁定返航；此后不会重新开启探索。该限制防止无观测进展的循环，也可能提前停止长距离经过已知区域的有效任务，需在后续实验中作为固定设计约束报告。

## 事务和可追溯性

调用方先完成一次实测建图，控制器随后验证：建图帧数等于当前支付步加一、当前帧 ID／SHA 一致、所有历史帧 SHA 等于之前已经接受的支付序列、占据数组 SHA 一致、相机标定不变、轴向裁剪保持 `[0.1,4.0] m`。建图结果不得携带真值覆盖分母。

接受顺序是动作／位姿校验、观测实例关联、IGCR 残差与反馈、视角预测缓存、占据安全更新。任何在这一变更阶段发生的错误会将控制器标记为不可重试；必须保留失败证据并丢弃该控制器及部分执行的回合。建图由外部调用方先执行，因此控制器不会声称能回滚 Open3D。

选择决策返回候选池收据、每实例分配、逐实例预测、二维原始／重复位置屏蔽后收益、三维期望和离散度、实际混合权重、路由预算、安全约束、当前支付观测 SHA 及配置 SHA。在线控制器不接收 World、场景目录、实际设备尺寸、GT 实例边界或未来传感帧。

## 本阶段验证范围

控制器解析测试覆盖无语义的 action-0 探索、G/S 相同几何与候选分配、两实例收益求和、候选上界、相同 XY 不重复领取全周雷达探索收益、看门狗返回精确起始朝向、预算不足直接停止、帧与决策次数、建图历史一致性、失败后禁止部分重试、外部可变对象隔离，以及混合权重和离散度的明确记账。测试中的平面深度来自独立的有限几何解析交点；不创建开发场景 World，也不构成场景覆盖、实际三维质量或语义性能优势的证据。
