## 四、失效机制诊断

### 4.1 输入门控不是唯一原因

90步前缀的18个初始候选中，12个因共同几何特征超出训练范围而触发语义回退。这12个候选同时具有全零语义特征。

因此，“门控挡住了语义”只解释部分执行机制，不能解释全部失效。没有可用语义特征或没有有价值的动作机会时，简单放宽门控、增加权重或扩大神经网络不能保证有效。

### 4.2 候选机会受到限制

原候选池主要提供单个覆盖点与原地旋转。保持48步预算，改为4个不同位置的覆盖候选、候选总上限12后：

- 初始候选总数：18 → 40。
- 非零语义特征候选：6 → 32。
- 有语义机会的初始状态：6/8 → 8/8。

这说明候选生成会限制语义能够影响什么，但“特征非零”仍不等于“知道类别就能选到更好的动作”。

### 4.3 单路线目标没有提供语义选择价值

逐一执行40条封存路线后，在“单路线联合收益 / 实际动作成本”目标下，Q0–Q3的配对语义信息价值均为0。因此该组数据没有触发单路线目标的重训流程。

这里的信息价值比较：知道语义排列时分别选择最优候选，能否超过不知道排列时采用共同候选的最优平均收益。该判断只适用于当前封存候选和指定回报定义，并不是对整个任务中所有语义价值的否定。

### 4.4 存在弱延迟价值

将目标改为“强制首选候选，然后由相同几何策略延续至完整48步预算”，得到：

| 父场景 | 配对语义信息价值 |
|---|---:|
| Q0 | 0.003115 |
| Q1 | 0.013852 |
| Q2 | 0.000000 |
| Q3 | 0.004491 |

平均增加约0.005364，相对无语义理想选择约 **0.53%**。这是当前候选池、初始状态及固定几何延续策略下的有限候选理想选择差距，不是整个任务的通用收益上限。

## 五、主要闭环结果

以下均为90步前缀后的48步自适应预算，每行8个开发分支。主指标为 `covered area × F1@5cm` 的增量。

| 候选池 / 评分方法 | 平均联合收益 |
|---|---:|
| 原候选池 / 几何 | 0.449480 |
| 原候选池 / 原V11语义 | 0.727874 |
| 多覆盖候选 / 几何 | 0.870661 |
| 多覆盖候选 / 原V11语义 | 0.917990 |
| 多覆盖候选 / 原V11打乱语义 | 0.878424 |
| 多覆盖候选 / 取消门控 | 0.827588 |
| 多覆盖候选 / 有界语义修正 | 0.852327 |

解读：

- 多覆盖候选 + 原V11语义，比原候选池 + 原V11语义高 **26.12%**。这包含候选生成的贡献，不能全部归因于语义。
- 相对于同一多覆盖候选池的几何模型，原V11语义平均高 **5.44%**，分支比较为2胜4平2负，不是逐场景稳定改善。
- 正确标签比打乱标签平均高0.039566，为2胜4平2负，4/8的动作序列发生变化。
- 有界语义修正在原候选池通过局部均值门槛，但在多覆盖候选池中劣于几何和打乱标签，因此不作为通用修复。
- 取消门控在多覆盖候选池中退化，不能据此删除门控。
- 零置信度对照在三个完整比较分层中均与几何动作完全一致，共24/24。

原实验部分 `summary.json` 的 `promoted=true` 仅代表该脚本的局部门槛通过。结合后续负结果，本轮总体结论仍是 **不进行正式模型提升**。

## 六、分组重训结果

使用40个候选的48步完整回报，按父场景留一法完成4折训练。一个父场景的两个排列始终位于同一折，验证父场景不参与该折拟合。

配置：

- 几何和语义网络容量相同：12-4-1。
- 每种模型3个随机种子，800轮训练。
- 原始几何/语义特征仍为12维；本轮尚未实现后续规划中的增强特征。
- 对照包括正确语义、打乱语义和几何模型。

结果：

- 正确语义与几何模型：8/8选择相同。
- 正确语义与打乱语义：8/8选择相同。
- 三者平均所选48步回报均为0.990131。
- 没有新的语义增益，因此没有对这些重训模型开展正式提升或独立确认。

四个 `held_Q*_candidate_bundle.json` 仅是可加载的开发候选。内部兼容旧加载器的状态字符串不能被解释为效能验证通过；外层 `candidate_only` 和本交接中的结论应作为接续依据。

## 七、V13下一步执行方案：已设计，尚未实现

目标是验证语义价值是否在不同探索阶段被现有状态表达和短时目标掩盖，而不是强制每个状态都产生语义动作差异。

1. **采集真实轨迹中的多个决策点。** 从几何基线的完整开发轨迹中覆盖探索早期、设施接近和细节观察阶段；执行前冻结采样规则。所有候选必须来自当前观测地图与安全返回约束。
2. **保留完整历史和反馈状态。** 回到某个决策点时重现其之前的动作、传感器包、预算及在线反馈，而不是仅用相似地图重新初始化。记录决策前历史哈希和候选池哈希。
3. **为每个候选取得相同剩余预算的延续回报。** 候选之间使用共同延续策略，主标签为决策点至预算结束的原始联合收益；不能用未来真值构造输入特征。
4. **实现增强观测特征。** 纳入剩余预算与往返成本、未知地图比例、预计新增相机覆盖、设施方向性观察缺口、类别置信度及实例几何不确定性。具体维度和实现需在新协议中写明，当前没有完成。
5. **按父场景隔离所有相关数据。** 同一父场景的全部决策点、排列及延续放入同一分组；特征标准化、门控范围和超参数选择均不得使用验证父场景。
6. **比较同容量模型并保留消融。** 几何、正确语义、打乱语义、零置信度，以及几何基础分 + 学习式语义修正。只有真实配对回报存在语义差异时才引入相应排序约束，零信息状态允许语义不改变动作。
7. **先筛选再闭环。** 分组验证需优于几何与打乱标签，并检查阶段性退化；通过后再执行完整预算闭环、安全返回和低置信度回退检查，随后才讨论新独立确认集。

此前“多覆盖候选 + 原V11门控评分”保留为开发基线。原主指标保持不变，可见3D面积和设施局部重建质量作为解释指标记录。所有失败状态、无效候选和负结果必须保留，不得用F00–F11调参。
