# 毕设项目对话上下文交接

更新时间：2026-09-11。本文用于在更换设备或新建对话后直接恢复研究任务。它总结用户已确认的目标、不可变约束、方案演进、现有证据和下一执行顺序；具体数值仍以冻结结果 JSON 为准。

## 1. 用户目标与已确认约束

项目目标是完成一个面向特定大规模、具有语义结构环境的主动 SLAM 覆盖规划方案及毕业论文。用户要求方案既在有限时间内增加二维建图覆盖，又提高三维建图质量，并提出以二维覆盖面积与三维建图精度的乘积作为联合指标。该思路保留，但必须同时报告两个因子及运动代价，不能只用乘积掩盖其中一个维度的退化。

用户明确要求：

1. 必须保留可验证的语义创新，不能把语义降为可选装饰模块。
2. 保留论文的 ANS 全局/局部双层架构，以及 OV-SDF、STGHP、RPN-UQ、IGCR 四模块接口；允许优化模块内部算法。
3. 在无独立显卡的当前环境先跑通 CPU 虚拟三维闭环和论文证据链，再回学校做实车验证。
4. 实验室小车使用 ROS 1；ZED 双目相机已经能发布深度和位姿；另有镭神单线雷达、IMU 和 GPS。车载计算平台具体型号与 CUDA 能力尚未核实。
5. 方案有效性必须先于扩大实验规模或继续论文包装；失败实验需保留，不能挑选成功结果。

## 2. 研究问题的收敛

早期目标“尽快提高二维覆盖”不能充分解释为什么机器人应更多观察高语义区域。项目因此转向覆盖约束下的三维质量分配：基础探索负责获得可通行空间，语义条件观察收益模型判断哪些类别、实例和观察方向值得追加视角。主指标固定为共享前缀之后的

\[
\Delta\bigl(A_{2D}\,F_{1,5\mathrm{cm}}\bigr),
\]

并保留二维覆盖、三维 precision/recall/F1、表面误差、新可见表面、距离、时间、碰撞与返航等分项。

语义创新的可证伪假设是：在几何历史无法区分具有不同内部结构或遮挡需求的对象时，正确类别信息应改变候选视角排序，并在同容量几何网络、固定语义先验和类别置换对照之上产生实际闭环收益。低置信度语义必须回退到几何模型。IGCR 在线反馈只有在改变后续动作并改善结果时才可声明为独立贡献。

## 3. 已完成的方案演进

### 3.1 资产审计、冻结评估和指标修正

历史结果审计发现三类关键问题：部分实验只验证接口调用，没有验证有效平移探索；旧复合盒参考表面包含内部或重复面积；V10.3 的收益反馈版本条件遗漏，导致反馈没有按预期进入闭环。仓库保留原失败结果，重算了唯一外表面指标，并在 V10.3.1 修复反馈闭环。修复后预测与实际观测能够结算，但反馈开关仍为 8/8 同轨迹，因此 H3 未成立。

网络资产审计又确认：V10.x CPU 路径没有训练或加载原 ANS、自然语义、RPN-UQ 或 SSC 网络；历史小 MLP 和线性回归不足以证明语义价值。由于当前没有 GPU，阶段 1 选择可在 CPU 上严格消融的 57 参数语义条件观察收益 MLP，并建立同容量几何 MLP 控制。

### 3.2 V11 训练与开发闭环

V7 数据中 8/8 配对上下文的主任务最优动作相同，类别信息价值为零，因此不再用于证明语义选择收益。V9.1 的 Q0--Q3 左右语义交换上下文具有非零信息价值，用于 V11 整组留一开发训练。正式训练和独立数值重训复核通过，但 Q0--Q3 已参与开发，不能作为独立确认。

第一版 V11 闭环按冻结规则失败。根因不是简单参数不足，而是三个契约错位：训练使用单个完整往返候选，闭环生成了分布外候选；运行时只执行去程而训练标签对应完整往返；闭环主门与训练指标不一致。失败的 56 条分支完整保留。

V11.1 不改变四模块层次和冻结模型，统一使用 `rate_single` 候选契约、完整安全往返层次选项、逐候选分布外回退和统一主指标。开发域 56 条分支全部通过，学习语义相对同容量几何、固定语义和类别置换的主指标均值分别提高 19.56%、27.77% 和 63.94%；56/56 独立物理与指标重放通过。低置信度 8/8 精确回退到几何网络。反馈与关闭反馈仍为 8/8 同轨迹。

### 3.3 独立人工场景确认

首轮 E00--E11 在未来动作和结果均未查看时因压力层覆盖分离不足停止。这是结构设计失败，不进入 efficacy 统计，记录仍保留。

第二轮 F00--F11 在世界构造前以种子 413--424 冻结。24 个配对前缀全部安全，efficacy 与覆盖压力层结构分离通过。随后只解封 F00--F07 efficacy 层：96 条分支全部完成并通过预设主门。学习语义相对同容量几何、固定语义、固定几何和类别置换的主指标均值分别高 29.13%、22.40%、35.55% 和 65.75%；配对为 8/8/0、13/3/0、16/0/0 和 16/0/0。八个独立上下文的单侧符号检验均为 0.00390625，整组上下文 bootstrap 区间均高于零。所有分支安全返航并调用四接口，低置信度逐轨迹等于几何网络。

F08--F11 覆盖压力层随后完成40条分支并全部安全。在平均93.60%的起始覆盖下，各方法最终覆盖均达到99.67%--99.74%；学习语义主指标比同容量几何低0.002514（约$-0.05\%$，0胜7平1负），并与类别置换8/8相同。该负结果说明当前语义贡献发生在基础覆盖接近完成后的三维补看阶段，覆盖动作主导时没有额外类别价值。

当前可以说“冻结人工双设施机制上的独立程序化 efficacy 及96/96后置重放通过，覆盖压力层40/40安全并经重放确认但无语义增量”。不能说已经证明从未知环境开始的语义覆盖优势、自然开放词汇、大规模场景、主流方法领先或实车有效。

## 6. 论文陈述边界

当前最强证据是：小型学习型语义收益头在冻结人工双设施机制的独立 efficacy 上，相对同容量几何网络和固定语义对照产生正的闭环联合指标增量，并在类别置换时稳定退化。覆盖压力层则与类别置换同轨迹且略低于几何网络。证据支持类别条件信息用于基础覆盖后的三维补看预算分配，不支持它改善覆盖主导阶段。

论文仍需补齐自然语义前端、从未知环境开始的全程覆盖、外部主流基线、计算代价、真实位姿误差和实车重复实验。二维面积乘三维 F1 的相对增量不能写成二维覆盖率和三维精度分别提高同一百分比。开发域反馈消融没有动作增量，因此不得将 IGCR 在线校正写成已经验证的性能贡献。
