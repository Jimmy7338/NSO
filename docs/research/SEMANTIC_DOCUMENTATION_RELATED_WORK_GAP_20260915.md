# 设施语义建档：三篇最接近工作的机制审查

核查日期：2026-09-15。结论是：**“语义引导探索、补看提高质量、几何与语义联合评分、观测后重规划”均不能单独作为本项目的新创新。** 当前可以检验的更窄主张是：在相同已观测几何和真实路径预算下，类别信息能否提前预测尚未揭示外形的定向补看收益，并通过实际观测反馈纠正错误预测。这仍是研究假设，没有被现有结果证明，也没有完成穷尽性新颖性检索。

本轮只审查指定的三篇主论文，实际阅读方法、算法、评价和限制；ActiveSGM 另读实现补充。版本分别为 [SWAP v1，2023-03-13](https://arxiv.org/html/2303.07236v1)、[ActiveSGM v2，2025-11-13](https://arxiv.org/html/2506.00225v2)、[VISTA v1，2025-07-01](https://arxiv.org/html/2507.01125v1)。另核作者代码的具体文件，未安装依赖、下载数据集或运行论文系统。以下“未见”只表示在这些被审材料中未找到相应建模与实验，不能推出整个领域不存在。

**三篇论文实际解决的问题**

|工作|语义如何进入决策|质量与反馈|路径、预算及本轮判别|
|---|---|---|---|
|SWAP|语义用于选定巡检实例；探索后补网格孔洞，再检查表面。缺口边是待观察目标，先处理近实例。|在线更新实例网格；检查相机分辨率和入射角，评价合格可见表面比例。|图上连通、最短路和巡检巡游成本；有阶段时限、继承探索返航机制。未按类别预测未见外形的边际收益。|
|ActiveSGM|渲染候选视点，联合轮廓缺失和类别分布熵，并用欧氏距离惩罚；不偏好指定类别。|在线更新语义高斯图；评价语义分割、几何准确/完整度及图像渲染质量。|有避障路径规划、步数上限；假设位姿与执行准确。没有本文所需的覆盖门与返航联合验收。|
|VISTA|语言查询相关性进入候选采样和轨迹评分，与历史视向差异结合。|新图像更新地图和视向历史；静态选帧评价渲染，实机评价搜索成功、到达时间和路径效率。|Dijkstra 路径、受限朝向、滚动重规划和电池时间上限；任务是搜索，并非全部设施外形建档。|

表中机制对应 [SWAP §III–V、算法1–2](https://arxiv.org/html/2303.07236v1#S4)、[ActiveSGM §3–5、补充S.1](https://arxiv.org/html/2506.00225v2#S3)、[VISTA §III–VI、算法1](https://arxiv.org/html/2507.01125v1#S4)。这些质量口径不能直接与本项目的外形 Q 或 J=C×Q 对比；例如语义分割 F1 不等于外表面 F1，合格观察分辨率也不等于已测得三维尺寸误差。

SWAP 与我们的任务叙述最接近。它假定分割点云可用，仿真用模拟分割、实机用实例 AprilTag；其分辨率/视角约束不等于类别条件的外形误差预测。因此“稀疏设施比背景值得精细观察”及“探索—补洞—巡检”需要作为已有关联工作引用，不能只更换四模块名称。其给定实例输入也提醒我们：人工类别或 marker 的机制验证，不能自动算自然语义网络成功。[SWAP §IV-A、V-B](https://arxiv.org/html/2303.07236v1#S5.SS2)

ActiveSGM 的语义损失不反传几何参数；它的语义规划项是当前类别分布的不确定性。VISTA 的语义项表达与搜索查询的相关程度。二者均不能直接解释为“该类别再看这个方向，外形 Q 将提高多少”。这是本轮对公式含义的区分，不是对它们整体效果的否定。[ActiveSGM §3.1–3.2，式5–8](https://arxiv.org/html/2506.00225v2#S3)、[VISTA §IV-C，式2–4](https://arxiv.org/html/2507.01125v1#S4.SS3)

**作者代码核查与 CPU 边界**

ActiveSGM 核查提交 `1a3c62962b4e7660222eddc5da6df88391bd710c`。`office0/ActiveSem.py` 选择 `active_gsv2`；规划器实现距离、缺失像素和语义熵乘积，但使用 top-16 平均熵及特殊值处理。更关键的是，候选循环调用 `sim.simulate(candidate_pose)`，仅用所得深度有效性屏蔽模拟数据缺失区域。这是作者注明的数据集处理细节；它仍额外查询了未执行候选的模拟观测，不能直接进入我们的无免费未来输入协议。CPU 改编需删除这一输入、只用已观测地图，并明确不再是逐字相同实现。[作者配置](https://github.com/lly00412/ActiveSGM/blob/1a3c62962b4e7660222eddc5da6df88391bd710c/configs/Replica/office0/ActiveSem.py#L103)、[作者候选评分代码，约1174–1213行](https://github.com/lly00412/ActiveSGM/blob/1a3c62962b4e7660222eddc5da6df88391bd710c/src/planner/active_gs_planner_v2.py#L1174)

其官方实现使用 CUDA 光栅化与 OneFormer，说明的是双 A6000 配置。当前毕业任务不应把完整 ActiveSGM 移植成 CPU 软件作为前置条件；可以用现有地图计算“未知覆盖＋预测类别熵”的评分适配器，但要单列表示、前端和输入差异。给所有像素确定的人工类别再声称复现了抗噪语义熵机制也不成立。[ActiveSGM 作者安装与运行说明](https://github.com/lly00412/ActiveSGM/tree/1a3c62962b4e7660222eddc5da6df88391bd710c#readme)

VISTA 作者仓库已经公开，不能沿用论文 v1 中尚待发布的代码状态。核查主仓库提交 `d75639384ab7e2a01b226d54ea3cbe8f2351544d`，其固定子模块 VISTA-Plan 为 `3a87472cb56288941a83b06c67c9d28380f4e768`，VISTA-Map 为 `38c6c448cefe3ced96cd939f4fb781964510514e`。发布版 `generate_info_gain` 的语义聚合是“最大值与正值均值的平均”，与论文文字的整图均值不同；不能不标版本地混合两种实现。[作者聚合代码](https://github.com/StanfordMSL/VISTA-Plan/blob/3a87472cb56288941a83b06c67c9d28380f4e768/src/vista_plan/scripts/planner.py#L448)、[作者视向覆盖代码](https://github.com/StanfordMSL/VISTA-Map/blob/38c6c448cefe3ced96cd939f4fb781964510514e/vista_map/coverage/utils.py#L35)

官方完整流程要求 CUDA GPU、ROS 2 Humble 和外部位姿来源；它不是当前 ROS1 小车的直接替换件。视向覆盖、可见性、路径评分可以在共同 CPU 表示上实现机制适配，但不能把适配器称为完整 VISTA 复现。尤其把它的语义偏置采样换成共同候选池后，只是在控制候选差异下比较评分规则。[VISTA 作者依赖及子模块说明](https://github.com/StanfordMSL/VISTA/tree/d75639384ab7e2a01b226d54ea3cbe8f2351544d#readme)

SWAP 的论文给出了 CPU 上运行的规划实例；本轮确认其探索基础 [GBPlanner 作者仓库](https://github.com/ntnu-arl/gbplanner_ros)，没有确认到与 2023 论文完整对应的 SWAP 发布快照。该仓库当前默认内容已演进为 OmniPlanner，不能将现在的默认分支等同于 SWAP。对毕业任务，更合适的是明确标注“依 SWAP 机制实现”的近实例、已观测孔洞/低质量表面补看规则，不承诺复刻无人机全部软件栈。[SWAP §V及表I](https://arxiv.org/html/2303.07236v1#S5)、[GBPlanner 当前说明](https://github.com/ntnu-arl/gbplanner_ros#readme)

**候选创新需要在哪里产生可证伪差别**

把待学目标写清楚比继续增加模块名称更有用。令 h 为已付费的非类别观测历史，c 为从当前观测得到的类别及置信度，a 为可执行的完整观察动作段，b 为剩余预算。候选预测器估计：

\[
\widehat{g}(h,c,a,b)\approx\mathbb E[Q(h\oplus O_a)-Q(h)\mid h,c,a,b].
\]

这个表达式是本项目拟检验的目标，不是上述论文已经证明或我们已经学会的函数。Q 的真值差只用于离线标签和独立评价；在线输入只能来自实际已观测地图、视角、距离、遮挡支持、残差和已付费历史。闭环反馈本身不是创新，还必须证明反馈代理与真实外形改善有关，且比不反馈或只用几何反馈更可靠。

|候选主张|最容易混淆的已有内容|能够否证本项目差别的结果|
|---|---|---|
|类别预测尚未揭示的定向外形需求|把任务相关性、语义熵或固定类别优先级换名|同几何历史下，类别置换/移除不改变收益；或固定类别权重同样好|
|语义让预算花在更有效的设施建档上|只让“重要设施”在评分里权重更高|设施等权 Q、覆盖、安全和返航联合验收后优势消失|
|反馈纠正错误先验|仅重算地图、减少重复视角或取消不可达目标|移除反馈无影响；反馈只追随代理数值，实际外形误差不改善|
|提前信息具有不可替代价值|让几何基线保持开环、不能探看/改选|G 用同等合法的短探看和改选动作即追回收益，语义净优势消失|

“未见外形”也要逐输入证明：首次结构相关深度/scan 差异前才存在强配对窗口；路线转向、廉价斜窥及到达后的重新选择都应允许真实发生。不能把理想首选 oracle、强装目标或“复杂类别补看均值更高”直接当可执行语义策略优势。场景可以按机制设计，但设施重要程度不能在看到分数后改变，合法探看不能只对 G 禁用。

**最小强基线建议：先保证能回答问题，再谈完整复现**

建议把前三项设为最小公共对照，不要求这两天安装三个新系统，也不扩大既定实验条数。所有方法使用同一地图/外形后端、类别无关设施实例接口、候选全集、可达性/返航守卫和真实付费执行；参数仅在开发场景选定。

1. **N：共同覆盖。** 提供任务资格参照，不能作为唯一竞争者。任务成功的验收继续同时检查覆盖、安全和返航。
2. **G：会补看、会探看、会改选的几何规划。** 使用已观测边界缺口、视角/距离/遮挡支持及外形反馈，按真实路径成本比较观察段。加入近设施补洞机制和视向多样性，避免语义只战胜一个从不精细观察的基线。不可给 G 真值外形或免费未来图像。
3. **S-static 与同容量 G/S 收益头。** 固定类别优先级检测“只是类别加权”的解释；训练阶段 G/S 拥有相同特征容量和标签构造，仅类别通道不同。再做类别置换和去反馈消融，定位改进来自哪里。不能用一个弱 G 头与完整大 S 网络比较。

若以上比较确有净优势，再把三篇论文的决策机制接成共同候选池上的附加评分适配器：SWAP 式近目标补洞/检查、ActiveSGM 式覆盖与类别熵、VISTA 式相关性与视向多样性。明示这是**机制基线**，不能宣称运行了三套作者完整系统或达到了其论文数字。几何深度、自然语义概率和任务查询不具备时，对应适配器的缺失输入应明示，不能用真值接口补齐。

本轮直接支持的决定是：保留当前 CPU 后端，先验证类别对预算内边际外形收益的增量解释和可执行价值。三篇论文没有替我们证明这一点；它们反而要求我们把比较基线做强。成功门仍按[毕业恢复计划](/root/NSO/docs/research/GRADUATION_RECOVERY_PLAN_20260915.md)执行，不能把换成另一种质量口径或更换表示后的共同收益计为语义创新。

最后保留一个明确检索缺口：作者官网已经列出 2025 年的 *Semantics-Aware Predictive Inspection Path Planning* 及语义驱动巡检学习工作。本轮按三篇上限未扩读，不能据标题判断它们已经覆盖或没有覆盖上述窄主张；在论文中使用“首次”“全新类别条件预测”前，至少还需排除这些直接邻近工作。[作者出版物目录](https://www.autonomousrobotslab.com/publications.html)
