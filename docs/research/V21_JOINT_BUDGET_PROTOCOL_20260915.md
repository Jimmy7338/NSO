## 固定算法与比较条件

令 Ω 为所有方法共享、执行前固定的任务矩形栅格区域，其形状与哈希在初始化后保持不变；它只提供任务范围，不包含障碍位置或真实可达掩码。令 K_t={x∈Ω：belief_t(x)≠unknown}，定义：

`C_ROI(t) = |K_t| / |Ω|`

`D_t = max(0, ceil(0.8 × |Ω|) − |K_t|)`。

0.8沿用公开任务门槛作为规划启发式，未声称两个分母等价。运行日志必须以 `C_ROI` 或明确标注单位的等价字段区别于评估 C2D；原 S/P 可作为导航模型诊断，不能再参与预算缺口、候选收益、速率或质量放行。

每个已付费动作的新增为 `|K_t \ K_(t−1)|`，损失为 `|K_(t−1) \ K_t|`。unknown→occupied 同样属于建图已知；free↔occupied 不产生二维新增；已知格上的相机补看属于三维观察，不能重复挣得二维覆盖。历史速率采用最近最多6个覆盖意图前缀，计入这些前缀中的全部付费移动、转向及零增益动作：

`r_t = 0.5 × max(0, Σ新增格 − Σ损失格) / Σ付费动作`。

损失跨选定前缀合计后才能截零，不得逐前缀删除负数。没有样本则速率不可用，净增为零则速率为零；不得编造正速率。质量意图轨迹不冒充覆盖速率样本，其花费仍从总动作预算扣除，其实际新增仍更新 K_t。

候选沿途预测 mask 继续复用 V20 的出程观测并集 U_a，只计 `U_a ∩ Ω ∩ unknown_t`。折减预测为该集合格数乘以已有 `union_yield` 与0.5；不得再把未知格临时设为free后，使用 S 的连通扩展作为已知格收益。缺口、预测、实测增量和速率至此使用同一已知格单位。

质量候选的模型条件保持：

`outbound_cost + return_cost + 5 + ceil(max(0,D_t−predicted_gain)/r_t) ≤ remaining_budget`。

剩余缺口为零时覆盖预留为零；仍有缺口但速率不可用或为零时不放行。返航路径、转向费用、原5动作额外余量及速率/收益两个0.5折扣均不调参。模型放行只允许候选参与质量竞争；运动许可继续由原观测地图逐步守卫决定。达到 C_ROI≥0.8 不触发评估达标声明，也不允许提前改写终止资格。

共同 N 选择、候选池生成、原 G 的几何方向与深度精度评分、路线每5动作刷新、地图融合和执行守卫均保持 V20 行为。本轮只改变覆盖预算账本；G 仍是公平的无语义几何质量基线。类别不改变预算或质量评分，也不改变外表面评价权重。保留 ANS 层次及 OV-SDF、STGHP、RPN-UQ、IGCR 接口，不安装 V19 的预定设施首选，不开展训练。

最少预检分为三项，必须留下结果与源码哈希，不能只在文档中宣称通过。

1. **账本单位与信息边界。** 固定 Ω 不随障碍确认或S/P变化而改变；同格多传感预测取并集，重复包不再次融合或收费；新增、损失及零增益动作正确记账，候选预测不修改真实 belief；非零缺口且缺少速率时不虚构完成时间，零缺口仍保留返航及5动作余量。预算组件不接收世界可达掩码、评估器、真值设施边界、类别或未来轨迹。交换类别而保持观测几何、候选和标记存在性不变，应保持 G 的几何评分与预算决定不变。
2. **四条完整 N 行为对齐。** 以 V20 已封存原始包重建四条完整 N 历史：在交付每个历史动作结果之前，让新运行时自行提出下一动作并逐步对比；同时核对每次候选的几何、路径、动作成本、N分值和选中目标，以及路线保留/取消、逐步守卫与终止行为，最后比较地图/网格摘要。允许改变的范围仅为新预算诊断及必要的版本标识；字段归一化规则必须明确，不得排除实际决策字段。不能先强塞旧动作、只检查初始候选或只比较终点，就宣布 N 没有变化。全部一致才可复用 V20 的四条 N 作为本轮配对基线，并记录逐案匹配计数和旧证据哈希；这是旧观测上的行为等价检查，不算新物理实验。任一步不一致、历史不足或无法严格比对，就在新版本执行新的 N四条及独立回放，不借用旧N成绩。
3. **G 实际闭环与复现。** 四条都执行新世界的真实传感、实际动作、TSDF融合及外表面评价，保存原始包、动作、逐步覆盖代理、仅评估侧C2D、质量检查点、候选预算原因、模块日志、最终网格与所有哈希；独立进程回放逐项一致。原参考缓存只读，源代码、协议及参数在付费任务开始前冻结。失败分支完整保留，不换场景、阈值或种子补齐通过数。

候选通过预算、按真实 G 分数被选中、执行付费质量观察、终点 Q/J 相对 N 改善是四层不同证据，需逐案分别报告。此前一条 N 历史的反事实曾预算放行6个质量角色，既没有执行它们，也没有证明实际 G 分值与收益，不能计入本轮成绩。每条还应报告取消的质量目标、实际观察动作、首次C2D达标、当时返航成本与终点实际余量；首次覆盖达标后剩余动作数不能直接当作可自由补视预算。

证据完整与G共同可行性分别验收：四条完整记录及回放通过说明结果可复核；四条均满足原最终资格才可宣称本矩阵G共同可行。联合质量收益另按匹配N的逐案ΔQ/ΔJ报告，不在看到G结果后追加或移动百分比门槛。若G继续退化为纯覆盖、没有实际质量观察，或Q没有改善，即便安全完成，也不能宣称联合质量机制得到验证；若覆盖失败，则保留失败并审查代理或实际预算竞争，不能用训练绕过。

## 解释边界与后续

公共 ROI 已知格包含障碍，未知分母可能含无法看到的封闭设备内部；噪声误分类也会改变已知状态。它是任务区域建图进度启发式，既不是“真实可达自由空间覆盖”，也不是后者的上界、下界或置信界。导航守卫和最终原C2D评价各自独立保持；不能因为代理先达到80%就降低真实覆盖门槛。本次不扩大量程，也不把不同代理之间的单历史高低用作模型优越性证据。

本矩阵仍只有两个开发父场景和配对排列；三个表面采样参考、四次独立回放以及一条历史中的多个时刻都不增加独立环境样本数。G 的靠近降噪、换视角补遮挡属于公共几何能力，不能顶替语义创新。通过共同可行性与实际质量分配检查后，新的12条语义信息筛查仍需独立声明并执行：语义应在相同候选、预算守卫及观测前提下，帮助选择尚未揭示的外部结构观察对象与方向；类别置换和几何对照必须能区分该信息价值。未得到这种可验证增益前，不把扩大训练量当作下一阶段默认动作。[优势场景与语义判断原则](/root/NSO/docs/research/ADVANTAGE_SCENARIO_DESIGN_PRINCIPLES_20260914.md) 继续有效。
