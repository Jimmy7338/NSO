# V21 后续语义选择入口诊断（2026-09-15）

结论：已有 V20 N 轨迹存在一个严格配对的早期传感历史窗口，但默认第一次付费后全局重选发生得太晚；补充检查还发现，单纯增加公共5步预热并不足以开放A/B质量观察入口。两父场景均在动作20首次出现非语义深度差异，而全局目标直到动作28才重新选择。因此，不能在动作28只看当前帧相同，就宣称整个几何观测历史严格相同。5步时历史仍匹配，但本轮只读重评分中两父的A/B候选全部被当前公共预算门拒绝。下一版需要区分“预热后质量选择”和“早期覆盖路线的语义选择”两个不同方向，均未证明信息收益。

包匹配阶段只读取 [V20 完整 N 证据](/root/NSO/eval_results/facility_v20_coverage_probe_20260915/manifest.json)，没有调用世界、传感模拟、地图融合或评价器。审计比较两父、两排列的692个已保存包，共346对帧，逐项核对705个原输入文件哈希。新产物为 [汇总](/root/NSO/audit_results/v21_semantic_entry_20260915/result.json)、[逐帧字段与差异](/root/NSO/audit_results/v21_semantic_entry_20260915/frames.json)、[来源记录](/root/NSO/audit_results/v21_semantic_entry_20260915/provenance.json) 和 [复现脚本](/root/NSO/audit_results/v21_semantic_entry_20260915/analyze_saved_packets.py)；4项审计产物哈希已复核一致。后述5步候选检查另在独立实例中重建指定旧观测，仍没有新物理动作或传感帧。

匹配采用原始数组dtype、shape和字节的严格哈希，不引入浮点容差。非语义字段包括depth、scan、相机内参、相机/雷达位姿、时间戳及雷达角度/量程参数；RGB颜色与semantic数组包含有意改变的类别提示，因此排除在本项几何配对测试之外。本文“完整非语义历史”指这些指定字段，并不声称全部RGB几何线索或模块候选也已逐项配对。每个包先与对应结果中的实际动作、姿态核对，再比较两排列。两父各自两排列的整条动作与姿态均相同，scan、内参及两种位姿也全程相同；首次非语义差异确实来自depth，不是两条机器人轨迹分叉。

动作0也是一次全局选择；上表的动作28是其后第一次全局重选。默认每5动作执行的路线刷新保留原覆盖目标，不能自动等同于在动作5开放一次新的语义全局决策。

动作20两父均有23个深度像素数值不同：11个属于双方共同有效像素，另12个为有效掩码差异；有效定义为有限且深度大于零。P00最大共同有效深度差为2.585592米，P01为2.488442米；有效像素数分别是5032/5044、5059/5071，差异不是浮点尾数。动作20–23的深度差异已进入历史，即便动作28当前帧重新相同，过去的观测与后续地图也不能假定相同。本检查没有定位这些像素对应哪个结构，也没有证明现有几何特征一定能利用它们；它确定的是严格非语义信息配对从动作20开始失效。

下一阶段必须先把“获得覆盖经验速率”和“选择尚未揭示结构的观察目标”在时间上接起来。[V21 联合预算协议](/root/NSO/docs/research/V21_JOINT_BUDGET_PROTOCOL_20260915.md) 的初始时刻没有付费覆盖速率，A/B质量路线不能通过公共覆盖预留检查；直接沿用旧frame0强制安装A/B，会绕过正在验证的公共规则。

入口A是“公共5步预热后，全局重选质量观察对象”。所有方法使用相同预热、入口、候选容量和预算；5动作计入总预算，选择后保留目标意图，不能把不同分支都截成相同短前缀后丢弃目标。为避免直接扩成12条才发现门未开放，本轮已在两父各取A复杂/B简单的一条旧历史，利用新N等价脚本的公共配置及初始化接口，重建帧0至动作5。运行时先自行提出动作，再读取该动作的保存包核对；10个旧付费动作全部一致。随后只在完整观测边界切到G并调用一次候选评分，不安装目标、不执行新动作、不读取第6帧或未来评价。参考缓存只提供公共传感配置，没有读取参考几何数组。

两父共12个A/B候选均有正几何质量项与正G分数，但全部因 `insufficient_predicted_coverage_reserve` 被拒，两次诊断都退回N候选0。因此失败原因已不是缺少付费速率，而是当前缺口与预测覆盖预留仍过大。A/B关联仅使用已观测左右标记簇，不读取真值设施包围盒。全部21/20个候选的group、pose、动作成本、N/G分值、观察簇关联及完整预算原因，见 [5步检查结果](/root/NSO/audit_results/v21_semantic_entry_20260915/warmup5/result.json) 与 [完整候选记录](/root/NSO/audit_results/v21_semantic_entry_20260915/warmup5/full_selections.json)；独立子目录5项产物哈希通过，原包匹配审计的封存文件未改。这是当前固定V21预算下对入口A的否证，不是新策略完整任务的结果，也不证明所有早期观察都不可能。

入口B是“在结构尚未揭示时，用类别信息选择覆盖路线或支路”。语义不必只能用于覆盖达标后的额外补视；它也可能帮助同一批具有二维覆盖增量的公共候选，提前选择更值得经过的设施方向。该方向必须另立版本，让几何与语义对照共享覆盖候选、动作成本、返航守卫及公共预算规则，类别只影响候选价值排序，不能获得独有安全豁免。它要验证的是覆盖推进与预期外部建档需求能否同时受益，最终仍按原C/Q/J与返航资格验收。当前并未实现或执行B，也没有证明早期覆盖候选确实提供了可被类别区分的选择；尤其不能把“在同一条路线多看几帧”自动称为语义创新。

入口时间与信息窗口确有冲突：另行只读核对 [当前V21首条G的原模块日志](/root/NSO/eval_results/facility_v21_joint_probe_20260915/case_00/module_calls.json.gz)，其首次候选预算放行在动作37；这只是单条开发轨迹的事后时刻，不参与上述5步候选计算，也不代表四条G整体已可行。原N的严格深度历史在20步已分化，因此不能直接等待到28或37再套用“所有几何历史相同、只多语义信息”的论证。

已失败的5步A/B入口不得强制安装或追加免费观测。可另行预先声明更长且不超过已确认严格配对窗口的公共前缀，或重新设计能延后结构暴露、同时更早获得覆盖经验的工位布局；也可独立检验入口B。各方向都需要新版本物理与信息配对检查，不能扫描多个入口后只报告最有利回报。若合理设计始终无法同时满足“观测信息可控制、存在可支付的不同选择、保留待揭示结构”，应据此修订场景机制，而非扩大语义训练。

只有入口合规后，后续12条语义信息筛查才有可解释前提。它还必须验证类别是否提高对未见结构的目标/方向选择质量，并以完整任务的实际C/Q/J和安全返航评估收益。普通靠近降噪、换角补遮挡仍属于几何基线能力；本审计既未证明这种收益，也未证明额外语义收益。当前正在执行的V21 G四条及其冻结代码、预算、策略保持不变。
