# V16 三维观测反馈通道：实现与传感器重建核查

2026-09-14。已实现 `nso/surface_feedback_v16.py`，7 项测试通过；使用已有四条 V15 传感器记录重建地图，768 步新增测量支持与原 IGCR 记录逐步一致，44 个真实决策点的地图数组及 TSDF 网格哈希全部一致。**该通道尚未接入规划评分，没有新的语义效能结论。**

本实现针对 [V15 反馈诊断](V15_FEEDBACK_OBSERVABILITY_DIAGNOSIS_20260914.md) 中发现的二维相机兑现率与三维观测变化不一致问题。它是后续 IGCR 的辅助观测输入，不替换 ANS 层次或其他模块。

## 实际实现

`SurfaceFeedbackV16` 从当前地图的完整稳定质量支持键读取三维证据，不从抽样点云重新生成编号，不读取类别、场景真值、参考表面或评价结果，也不修改地图或融合传感器。

每次付费观测后的输出包括：

- 首次进入已观测区域的三维支持格数；消失后重新出现单独记录，不再次计入首次发现。
- 以前见过的支持格新增的观察方向数；保留累计方向证据，防止丢失后重新出现产生重复计数。新支持格的初始方向另列。
- 以本次动作开始时的支持集合为固定分母，计算可靠性代理的带符号变化；缺失的旧支持仍留在分母中，质量记零。新支持不能仅靠加入比较集合抬高本次统计值。
- 改善、退化、缺失和重新出现的支持数量，以及动作号、地图版本和坐标版本。

可靠性代理继续采用原实现的 `I / (I + 0.25 + 100 residual)`，以便检查接口一致性；它没有被标定为表面误差、precision 或 F1。与旧的“只比较初始 193 个点”统计不同，本次动作前已经建立的全部支持都能参与下一次质量比较。不同动作的分母不同，**这些均值变化不能直接相加后解释为全任务质量提升**。

每个输出要求连续的付费动作号、恰好一次地图更新以及相同网格和显式坐标版本。不满足条件时，拒绝更新且保留原观察器状态。位姿图优化或坐标系变更后，必须完成重映射并显式建立新的观察器；调用者提供的版本号并不能代替真实标定校验。

本模块不具备实例关联能力，输出明确标记 `instance_attribution_available=false`。不能把全局观测变化全部归给所选设施，也不能把支持格计数乘以固定面积后称为真实新增表面积。

## 核查结果

输入仍为一个 D12-00 开发父布局的四个结构版本，没有新增独立父场景或策略执行。

| 核查项目 | 结果 |
|---|---|
| 新增模块测试 | 7/7 通过 |
| 已有记录的动作后更新 | 768/768 完成 |
| 每步首次支持数与原 IGCR 账本 | 768/768 一致 |
| 原全局决策点的地图数组及 TSDF 网格 | 44/44 完全一致 |
| 每条轨迹相机预计二维新增为零的动作 | 73 |
| 这 73 步中新通道记录到三维代理变化 | 每条均为 73 |
| 这 73 步新增支持格／旧支持新增方向 | 每条 377／3,009 |
| 这 73 步的质量总变化为正／负 | 每条 71／2 |

新的 73 与旧诊断的 41 不矛盾：旧诊断只检查新增支持和**初始固定点集**质量，本实现还检查全部先前支持的方向和质量变化。71 次正代理变化也不是 71 次精度提高；既有地图统计中的最大信息量、残差平滑和重复观测都会影响代理，需要另行检验它与真实候选回报的关系。

四条回放总耗时约 103.5 秒，包含传感器读取、地图重建、TSDF 核对和新通道运算；不等于观察器单独耗时，更不能作为车载实时性成绩。未运行真实 ROS 或实车。

测试覆盖二维相机已饱和时新增高度层支持、后续新建支持参与下一动作固定比较集、缺失／重现去重、方向累计去重、带符号退化、无效动作／地图版本／坐标版本的原子拒绝，以及不读取标签或别名修改地图。

## 尚待完成

运行中的 V15 原 46 候选实验未导入此模块，结果仍须按原冻结规则评价。三维观察器的测试通过不构成语义信息门槛通过，也不允许开始模型训练。

后续应在通过数据资格检查的开发集上，建立只基于动作前观测的设施关联和方向归因，将三维辅助观测与候选的真实长期增量标签区分开，检验其能否校正预测误差。保留同容量几何对照、语义打乱、零置信度、固定语义及关闭反馈对照。只有三维反馈实际改变选择并改善独立分组的物理指标，才能主张 IGCR 的语义条件反馈具有净收益。
