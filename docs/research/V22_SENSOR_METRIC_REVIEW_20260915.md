# V22 传感与外形指标独立审核

日期：2026-09-15。范围：只读 V19–V22 共用实现、既有 V19 台架及 V22 P00 已封存结果；没有新轨迹、重建重跑或冻结源码修改。本审核不替代整批 V22 分析。

**结论：当前模型已能体现近距和独立多帧的收益，不能再把所有负结果归因于“模拟器不奖励多看”。但它仍是乐观、简化的观测模型；主指标衡量完整可观察外表面，不等于“轮廓看起来正确”。任务意图若是粗外形建档，下一版需要先声明粗外形验收标准，而非把未观察背面悄悄记作已建好。**

## 1. 当前实际用的传感与融合

V19 覆盖了旧 V15 的 `sense()`，因此配置里的 `depth_sigma_m=0` **不代表 V19–V22 深度无噪声**。主条件对解析轴向深度施加视差噪声：`d=480×0.12/z+ε`、`z'=480×0.12/d`，ε 的标准差为0.25参考像素；同父/动作步/seed 可重复，不同动作步重新采样。固定偏差+0.25像素是另一个敏感性条件，不在主条件中。种子不读类别或资产编号。[配置和噪声函数](/root/NSO/env/facility_documentation_v19.py:21)、[实际 sense](/root/NSO/env/facility_documentation_v19.py:163)

一阶近似 `σ_z≈z²σ_d/(fb)` 给出1米约4.34毫米、4米约69.44毫米；这是输入像素深度的解析近似，不能与融合后网格误差混用。输出图像96×72、焦距48像素，480是噪声参考像素单位，不是输出焦距，更不是实车 ZED 标定。[图像配置](/root/NSO/env/virtual3d.py:19)、[传感元数据](/root/NSO/env/facility_documentation_v19.py:155)

每个观测包的深度直接进入 Open3D TSDF，使用精确外参、4厘米体素、12厘米截断。融合没有按语义加分或直接按“看了几次”修改评价。附带质量账本记录视角、距离和入射角，但这些代理数值不是 TSDF 的噪声或融合权重。[融合入口](/root/NSO/nso/mapping3d.py:23)、[实际 TSDF 重设及质量账本](/root/NSO/nso/mapping3d_v2.py:7)

视角在物理观测中通过真实射线、遮挡、投影分辨率及融合作用；当前深度误差函数不显式依赖入射角、纹理或材质。不能据质量账本的角度项，声称模拟相机已实现这些成像困难。[轴向求交](/root/NSO/env/canonical_rgbd_v15.py:14)

## 3. 外轮廓正确与完整外表面是两个验收层次

主质量 `Q=六设施外表面 F1@5cm 的均值`，precision 检查预测表面是否靠近真实表面，recall 检查固定可观察真实表面是否被重建。轮廓 IoU、边界像素误差和尺寸误差只作诊断，没有进入主分数。[距离与 F1](/root/NSO/utils/facility_metrics_v19.py:250)、[六设施宏平均](/root/NSO/utils/facility_metrics_v19.py:288)、[轮廓诊断](/root/NSO/utils/facility_metrics_v19.py:218)

因此，“三维外表面完整且位置正确”会得高分；“一张或几张剪影看起来正确”不能保证高 F1。IoU 只看射线有没有命中，不检查命中深度，薄前板也可能遮满轮廓；未建背面则仍缺少三维表面。代码已有独立六实体夹具的正确网格 F1>0.999、轮廓 IoU>0.99、空网格 Q=0 等断言；本审核只读这些断言，没有把它们当作此次重新执行的测试。[现有测试](/root/NSO/tests/virtual3d/test_facility_metrics_v19.py:50)

真实保存结果正体现此差别：P00 case00 的 B 轮廓 IoU=0.931576、precision=0.93525，但 recall=0.592282、F1=0.725264；A 的 IoU=0.858234、precision=0.91425，但 recall=0.388868、F1=0.545649。当前主要不足是完整度，不是所有已建表面都很不准。四条 P00 每条都漏两处设施，固定六设施平均的理论上限因此已降到2/3，即使其余四处全部完美。[case00 原结果](/root/NSO/eval_results/facility_v22_early_coverage_20260915/case_00/result.json)、[四条分解](/root/NSO/audit_results/v22_p00_tradeoff_diagnosis_20260915/result.json)

参考包含从任一固定可达格及四个可执行朝向能看到的表面，并非只评价本条路线看过的部分。当前路线没绕到背面，不会使这个背面退出任务；真正从所有参考观察位都不可见的表面会被筛除。这是完整外表面任务的定义，不能把“本次没看”与“任务上不可观察”混为一谈。[可观察性筛选](/root/NSO/utils/facility_metrics_v18.py:13)

## 4. 是否仍在用内部结构或细碎采样压低分

当前设施只有封闭本体和外露实心附件，没有旧式内部架层。几何由实心盒并集生成，只输出有空邻域的边界面，移除内部及重叠面；关键设施通过背侧外露附件产生结构差异，相关尺寸至少12厘米。外露凹折面属于当前声明的外表面，不是任务无关内部。[设施几何](/root/NSO/env/facility_documentation_v19.py:116)、[并集边界算法](/root/NSO/env/virtual3d_inspection_v4.py:90)

参考先按三角形面积分配采样，不按三角形数量计权；细分成很多三角形不会凭空增加其面积权重。每设施固定3000个参考候选点、4000个预测点，过滤可观察参考后再计算距离；参考、窗口和种子在策略执行前冻结，类别不进入评价。[面积采样](/root/NSO/utils/reconstruction_metrics.py:6)、[参考与缓存](/root/NSO/utils/facility_metrics_v19.py:132)

采样近似仍存在，但当前证据不支持其主导 P00 差距：四条任务各自跨2026/2027/2028的 Q 最大范围分别为0.005386、0.003702、0.005329、0.003104；远小于两个选臂的主参考 Q 差0.024905、0.035462，且排序没有翻转。这只是固定参考敏感性，不能当置信区间。未做“去附件只评分粗本体”的实验，不能量化附件占低分的全部比例，也不能据此宣布附件难度完全合适。

## 5. 下一版必须明确的限制

- **任务层次：**若最终需求是粗外形建档，应事先定义粗外形/多方向轮廓及尺寸验收，把外露细节完整度单列；所有方法共用冻结标准，并保留缺失设施和未验证面的状态。不能事后只保留得分高的轮廓指标，也不能把薄前板或推断的背面当作已观测完整外形。
- **传感真实性：**当前精确位姿、无纹理失败/材质/随机失深、主误差逐帧独立、固定偏差只作敏感性。它对长期重复观察的平均收益偏乐观；后续需要实车静态/移动深度记录约束误差与相关性，而非人为放大噪声制造优势。
- **角度与分辨率：**输出仅96×72，4厘米体素与12厘米截断固定。以12厘米特征为例，正视时4米仅约1.44像素、1米约5.76像素；几何存在不等于当前距离能可靠恢复。参考使用连续射线判断可见，也不是离散像素和 TSDF 可恢复性的证明。下一场景需要声明真实可支付的侧后观察阶段、朝向和特征尺度；现有平面台架没有替代这一检查。
