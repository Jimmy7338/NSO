# V31 解析外形夹具：执行前几何契约

2026-09-17。本文件先于夹具实现及测试冻结。只构造解析顶点、三角形与实例归属元数据；不调用项目 World、传感、mapper、TSDF、旧保存网格或任何 Q 评价。新增主任务数为 0。保留 V23/V30 源码与结果。

## 目的与边界

供新版投影表示验证：同一物体的闭合实测竖面可能没有顶底三角形；精确闭合线环和未闭合、虚假外形必须可区分。夹具不预设新 Q 数值或成功阈值，不将推断闭合、观测次数或类别变为奖励。测试仅核坐标、面积、体积、连通边界、三角化不变的几何性质与元数据。后续审核器可独立评分，但不在本模块内执行。

所有几何的单位为米。基础矩形柜为 `[0,2]×[0,3]×[0,1.6]`；矩形 footprint 面积 6、周长 10、竖面面积 16、全外表面积 28、体积 9.6。闭合面来自 `BoxV30` 与准确的 `union_exterior_faces_v30`。竖面夹具仅去掉法向为 z 的面，保留全部四面和真实边缘，不添加顶底面。它的 XY 三角形投影面积为零，但其线段并集构成闭合矩形边界；XZ、YZ 面积分别为 3.2、4.8。

## 固定夹具目录

1. `box_closed`、`box_vertical`：上述同一参考几何的完整边界与全部竖面。`box_retriangulated`、`box_vertical_retriangulated` 用预先固定的公共坐标切分并换对角线；几何支持范围不变。`box_duplicate`、`box_vertical_duplicate` 逐个重复相同三角形，几何集合不变，但原始三角面积求和会翻倍，不能据此增加支持或收益。
2. `box_four_thin_walls`：四块厚度恰为 0.002 的正交薄壁，厚度以原四竖面为中心，z 范围仍为 `[0,1.6]`；准确去除相互接触/重叠内部面。外尺寸为 `2.002×3.002×1.6`，中央空腔为 `1.998×2.998×1.6`，材料体积为 0.032；XY 材料投影面积仅 0.02，外边界包围面积为 6.010004。这只表示测量薄片可能具有的几何形态，不宣称它是真实实心柜，更不把空腔自动实心化。新版表示如何处理内环与外包络须另外明确，不能混称相同三维形状。
3. `l_closed`、`l_vertical`：两个同 owner 的实心长方体 `[0,2]×[0,1]×[0,1.6]` 与 `[0,1]×[1,3]×[0,1.6]` 的准确并集。XY 凹 L 面积 4、周长 10、体积 6.4、竖面面积 16、全外表面积 24。接触面完全剔除。外尺寸仍与基础柜相同，XZ/YZ 与矩形参考相同；XY 凹口是必须保留的区别。
4. `box_vertical_missing_side`：从四竖面中删除整块 `x=2` 面，少 4.8 平方米；XY 只剩三边，不能称闭合线环。不得为获得闭合而补上缺边。
5. `box_expanded_030`：六方向各向外扩 0.3，外尺寸为 `2.6×3.6×2.2`；`box_shifted_030` 仅整体沿 x 平移 +0.3，尺寸不变、中心偏移 0.3。二者参考均为原柜，不能通过预测对齐消除差异。
6. `l_notch_filled`：用完整矩形柜填掉 L 的整个凹口，XY 面积从 4 增至 6；`l_convex_shortcut`：固定五边形 `(0,0),(2,0),(2,1),(1,3),(0,3)` 挤出至 1.6，XY 面积为 5、体积 8。这两个错误预测是显式解析构造，不在任何预测处理函数中调用凸包，也不能因为尺寸相同而视作正确 L。
7. `box_extra_detached_box`：原柜加一独立 `[3,3.4]×[1,1.4]×[0.4,0.8]` 实心块。`box_extra_open_strip`：原柜加一块 `y=1, x∈[2.4,3.2], z∈[0.4,1.2]` 零厚度矩形实测薄片；其 XY 投影是原柜外一条长 0.8 的分离线段，XZ 投影面积为 0.64。额外离散几何与悬空线段不能静默丢弃。
8. `empty`：没有顶点或三角形，参考仍为原柜。

## 双实例元数据夹具

两个相同柜体分别位于原位和 x+5，固定参考窗口互不重叠，每个窗只用于评价归属。`both_present` 含两完整预测及各自一个解析 seed；`one_instance_missing` 保留两参考、第二预测为空且 seed 为 None；`all_instances_missing` 两预测都空；`duplicate_seed` 提交两个完整柜网格，但两 seed 都落在第一参考窗。所有 seed 是明确标记的解析测试元数据，不是伪造传感观测。后续评价不得因为丢实例或重复归属缩小分母，也不能用完整预测的坐标修正重复 seed。

## API、验证与资源

模块仅依赖 numpy、标准库及冻结的 `nso.box_union_geometry_v30`。`MeshFixtureV31` 提供只读 `vertices[N,3]`、`triangles[M,3]`；`reference_meshes_v31()` 返回 `box/l_shape`，`geometry_fixtures_v31()` 返回具名预测及参考名称、预声明事实，`association_fixtures_v31()` 返回两实例输入和预声明归属事实。调用方可自行转换到网格库，模块不导入评分器。

必要测试独立核对解析面积/体积、闭合与竖面开口、重三角化和重复面支持范围、2 mm 薄壁材料体积、L 凹口及错误填充、额外分离/悬空几何、固定两实例元数据。只运行新小型测试，`-B`、CPU 单线程，保留 64 MiB 磁盘。失败保留后修正构造或报告协议矛盾；禁止用评分结果选择夹具尺寸、修剪困难表面或追调阈值。
