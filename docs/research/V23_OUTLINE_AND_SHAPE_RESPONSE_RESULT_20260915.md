# V23 外廓指标与实际形状观察响应结果

日期：2026-09-15。**补看已有实测收益，复杂设施的收益更大；本批预声明工程门仍失败，完整语义策略尚未验证。** 同一条付费路线中，粗扫23步到额外侧视73步的外形质量增量为复杂 **+0.338613**、简单 **+0.224436**，差为 **+0.114177**。两类粗扫非语义历史一致，首次深度差异出现在动作37。这支持继续检验类别能否预测额外观察需求，但不等于证明类别引导选择、学习网络或四模块整体架构有效。

“简单设施在23步已完成”的条件没有满足，故冻结的 `observation_demand_gate_passed=false` 原样保留。**这是一项本批工程门，不是语义选择效用的数学必要条件。** 不应为了让简单模型无噪声地通过所有5厘米条件而无限延迟选择实验；下一版本应针对已查明的问题加入公共观测处理，并尽快检验两对象同预算下的实际选择价值。

## 任务、指标与证据范围

任务价值是形成可用的设施位置、尺寸、外廓与占用空间档案，供场地盘点、空间布局及机器人通行规划参考。外轮廓正确应获得高分，同时需要避免离散碎片或薄板伪造完整空间支撑。这里仍未达到可直接用于真实安全通行的模型保证。

[冻结协议](/root/NSO/docs/research/V23_OUTLINE_AND_SHAPE_PROBE_PROTOCOL_20260915.md) 对每个设施 i 的世界坐标 XY/XZ/YZ 三投影求三角形并集，去有界内孔、保留外部凹口和分离组件。每个投影的 `q(i,v)=min(边界长度F1@5cm, 投影包络IoU)`；设施质量为三个 q 的等权均值，任务 Q 再对全部设施等权平均，`J=C2D×Q`。本台架每个形状仅一个设施，缺失仍计0；**类别、语义票、访问次数均不进入评分**。Q 不是纯 F1，也不是完整三维几何精度。

另外固定报告边界 F1、位置/尺寸误差、边界均值及 Hausdorff 上下界，并保留原 V19 可观察外表面 F1、precision/recall、连续误差和全局指标。设施完成要求三投影各自 Hausdorff 上界≤5厘米、IoU≥0.90，三轴尺寸及中心最大轴误差≤5厘米。采样长度积分是数值近似；三个投影不唯一确定闭合三维模型，也不证明隐藏表面被观察。原始 TSDF、几何推断与语义预测不能混称。

[14项行为检查](/root/NSO/audit_results/facility_outline_v23_preflight_20260915/result.json) 已通过，覆盖正确外壳、内部变化、凹口/内孔、缺失、位移/尺寸、离散微片等反例及预算资格；它们证明实现边界，不能替代实际任务验证。检查前已修正预算缺失仍合格、边界微片虚高、评价窗静默裁掉参考外附件三项问题，未据物理结果调分。

[原始批次](/root/NSO/audit_results/facility_shape_v23_probe_20260915/result.json) 为2条物理序列、2次独立PID回放，**物理192动作、回放192动作**。每条96动作含84次0.2米平移和12次90度转向，保存97份原包及6阶段网格；阶段评分不免费采集。两条均返航、零碰撞，终点 C=100%，覆盖/返航/预算资格合格，但外形完成判定均为否。回放逐包核验新模拟传感，并用保存包在新 TSDF 中重新融合，匹配阶段网格和指标。

[正式分析 final](/root/NSO/audit_results/facility_shape_v23_analysis_20260915_final/result.json) 核验219项原产物、139个冻结源及两个独立回放。本报告复核正式分析11项、诊断4项和行为检查2项产物哈希。世界只有一个8×8米开发布局、两种形状、一个噪声种子和共同脚本路线；使用原通用 iid_025px、5米传感、精确位姿、96×72图像及0.04/0.12米TSDF，没有真实ZED标定、位姿漂移或自主规划。

## 两条已定位的问题

[最终网格诊断](/root/NSO/docs/research/V23_SHAPE_RESPONSE_DIAGNOSIS_20260915.md) 从原阶段网格复算12个投影并追溯原三角形，没有重新融合、筛点重评分或生成改进成绩。

第一，**局部实测表面不等于设施外形模型**。简单粗扫的 XZ/YZ IoU 已为0.949210/0.926530，XY却只有0.013340。前、左立面在俯视下形成开放L形窄带，原始 TSDF 不会据此推断完整矩形占地。补看后XY IoU升到0.925369，说明四周观测形成了近闭合投影；相机固定0.8米，不能据此声称已从上方测得1.6米柜顶。简单ΔQ的XY贡献为+0.268462，XZ/YZ分别−0.001485/−0.042541，增量并非三个方向都改善。

第二，**近地面残片进入固定评价窗，污染了实例尺寸和最大边界距离**。简单73步的外表面 F1 已为0.995897，平均表面误差约7.432毫米，但Y尺寸误差仍达0.548863米。最坏后缘点 `(3.66,4.479408,0.01)` 来自原网格高度−0.000452—0.013853米、近水平的三角片，直接控制XY/YZ约0.484408米的 Hausdorff上界。面积采样F1与极值指标衡量的内容不同，少量地面残留足以制造这种分歧。

![粗扫和补看的原网格三投影](/root/NSO/audit_results/facility_shape_v23_diagnosis_20260915/coarse_extra_projections.png)

不能由此声称“去地面就全部完成”：仍有高度0.86米的柜侧点偏出5.645厘米，简单补看的YZ IoU=0.893536也低于0.90。部分z=0.01点是窗口裁剪交点，并非原文件恰有同坐标顶点；诊断已追溯对应原三角形。真值窗口只能解释评分，不能成为在线删除错误点的依据。

## 后续验证方向

优先实现各方法共享、由观测约束的地面/实例分离及外形建模：使用实测平面、法向、多帧支持与自由射线约束，避免按当前真值高度删点；保存原始TSDF、清理后的实测支持和推断形状三种来源。相同非语义历史应产生相同几何，隐藏附件只有获得新观测后才能修正，不能按类别或GT尺寸预置；对非柜形、开放凹口、低位真实附件和边缘不完整情况需要反例与拒绝机制。**这些是拟议公共后端，当前尚未实现或取得任何新评分。**

随后冻结新后端并重验配对及阶段响应，同时推进两对象、相同总预算的选择试验：让两条候选路线都承担可比较的真实成本，保留所有覆盖/返航结果，比较固定非语义选择、几何质量选择和预声明类别选择。语义价值来自类别是否在几何揭示前帮助分配稀缺观察动作，不能由两条无竞争脚本的ΔQ差直接推出。

V23的工程失败不改写；新版本是否值得进入六工位，应由真实选择信息与资源竞争的证据决定，而非等待简单类在原始噪声网格上达到理想化完美。根据共同处理后的剩余不确定性再决定是否需要有目的地追加付费视点，不能无限延长绕行消耗信息窗口。有效后再接回 ANS 层次及 OV-SDF、STGHP、RPN-UQ、IGCR 四模块的选择/训练链，并验证独立规模场景和实车；本台架没有代替这些工作。
