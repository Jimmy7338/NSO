# V27 稳定观测反馈设计与实现（2026-09-16）

本文件先固定有限修复设计，随后已在独立新源文件中实现 V27-A，并通过 8 项小型测试及独立代码审查。**V27-A 保留规划使用的 256 个样本和原有最后一步反馈时序，只把反馈的共同 key 支持改为独立、稳定的实测几何账本。** 不同时改成完整选项收益，不改变场景、动作预算、评价指标、语义权重或支持门槛。本轮 V26 四主任务及回放继续使用冻结实现。保存包影子验收尚未执行，新的自主效果尚未验证；下文第 6 节仍是下一步验收设计。

## 1. 已有证据及目标

第一对 case_01 的 13 次实际方向反馈检查均被共同支持不足拒绝：12 次为 0 个，1 次为 1 个，有效更新为 0。随后已完成的同历史离线诊断严格复现了原 256 样本状态 SHA 和原日志计数；使用相同几何白名单的全量面片时，13 次局部共同支持为：

`627, 731, 770, 842, 874, 884, 887, 888, 894, 898, 904, 904, 904`。

对应共同 key 的方向／距离改善并集数为：

`191, 175, 39, 183, 50, 19, 10, 12, 2, 2, 8, 81, 26`。

因此，对这 13 个原实际到达事件，可以将“支持门未通过”定位为输入抽样丢失共同支持，而不是全量实测支持原本不足。该证据没有运行修复后的策略，也没有计算新的 Q，不能证明修复会提升完整任务成绩。

本设计依据 `audit_results/observed_v26_feedback_support_20260916/result.json`（SHA `e57558ad2caddd124e2908148e5713e829c2447cb042a7861ddd793ab5c21724`）；其 3 份库存产物逐 SHA 核验通过。该诊断实际处理 401 个已有包并进行 401 次离线 TSDF 融合，新增物理动作、传感、规划、网格提取和 Q 评价均为 0。它不是零计算的日志汇总，也不是新独立实验样本。

## 2. 两种改法不能混为一次修复

| 设计 | 支持集合 | 收益时间窗口 | 能单独检验什么 | 主要新风险 |
|---|---|---|---|---|
| V27-A，首选 | 规划仍为原 256 样本；反馈从稳定 key 的实测几何索引取局部共同支持 | 原到达转换 t−1→t | 更换反馈支持读取方式是否消除已证实的采样阻断 | 全量计数使原收益代理更易饱和；未解决路途中收益归因 |
| V27-B，暂缓 | 同类独立几何账本 | 选项开始至到达／取消的多付费帧 | 是否需要完整选项观测才能估计方向收益 | 开始／取消／重复访问归因、重规划切段、同一面片重复计数均发生变化 |

不能在 A 中同时冻结选项起点的 cue 中心、锁住该时刻的局部 key 集合，或把路途中累计改善加入终点回报：这些也会改变原门的空间／时间定义。尤其“选项起点固定 key 队列”会排除路途中已经建立、在最后一步应当可比较的 key，不能宣称等价于本次全量对照。

## 3. V27-A 的最小契约

### 3.1 两条数据通道

规划通道完全保持 `geometry_state_v26(..., max_patches=256)`：提案、几何分数、语义模板的几何支持、FOV／观测障碍判定以及 G 的信息白名单均不增加字段。不能把全量反馈面片偷偷交给 G/S 的候选生成器；在相同观测和相同反馈表下，两者原规划输入与分数应保持一致。

具体接线必须给反馈计数增加一个**独立支持参数**，不能把全量 patch state 整体传给 V26 `observe_transition`：其内部 `_semantic_gain(after, ..., cues)` 也会读取 `after.patches`，从而连原语义支持／适用门一起改变。新接口中的 before/after 规划状态和 `_semantic_gain` 始终保留原 256 样本，仅共同 key 与改善计数读取独立账本。禁止替换 dataclass 的 patches 后仍沿用旧 `geometry_sha256`；反馈支持应有自己的数据摘要与来源动作号。

反馈通道拟用新文件中的 `MeasuredFeedbackLedgerV27`。它只从权威 mapper 已消费的当前实测 `quality` 几何字段建立不可变的 key 索引，使用与 V26 adapter 相同的有限值、法向、公共地图范围等白名单要求。保存 key、point、bits、best_range 及帧因果标识；不保存或读取 label、RGB 类别、owner、GT、参考设施窗口、隐藏尺寸或评价 Q。需要校验的其余几何字段只用于与原白名单一致性检查。

为精确实现“当前点位于局部范围、其 key 在上一帧也存在”，允许账本保留上一帧的**全量精简几何索引**，随后按原旧 cue 的 1.5 m 水平半径取局部支持。不能先只留上一帧局部圆内的点，否则点的位置更新或 cue 中心变化可能造成另一个未声明的丢样机制。该索引不输入规划，不保存成新原始数据副本；实现可按 key 连续数组索引，时间／内存与已观测面片数 M 成正比，运行时只需前后两代支持。无需复制 TSDF、RGB-D 历史或提取网格。

这是一份以稳定 key 查询的反馈局部账本，不是“世界表面全量真值”。面片只能来自截至当前已付费观测，key 的存在也不能作为准确表面已建好的证明。

### 3.2 更新的数学口径保持不变

令 `F(t)` 为当前实测白名单的 key→几何记录，`c(t−1)` 为观测前已知的 cue 中心。原规划采样集合不再用于以下计数：

\[
K_t=\{k\in F(t-1)\cap F(t):\|p_{t,xy}(k)-c_{t-1,xy}\|\le1.5\mathrm{m}\},
\]

\[
I_t=\{k\in K_t:\;bits_t(k)\mathbin{\&}\neg bits_{t-1}(k)\ne0\quad\lor\quad
range_t(k)<range_{t-1}(k)-0.01\mathrm{m}\}.
\]

原到达、正预测、已知 cue、可见模板、距离 0.5–2.5 m、相同扇区等门全部不变。`|K_t|<4` 仍返回 `unavailable_insufficient_common_measured_support`，不增加反馈计数，不把缺失替换成零收益。通过支持门后继续使用原 `y_t=min(1, |I_t|/16)`，原反馈因子仍是 `(1+sum_y)/(1+count)`。

只在当前帧新出现、上一帧没有的 key 不在 `K_t` 中，无论数目多少都不能算改善；如果它在后续真实观测中持续存在，则可从那时起按相邻两帧口径比较。`n` 增加本身也不计方向／距离改善。一次转换中同一 key 同时满足方向和距离改善仍只计一次。

必须保留量纲限制：全量诊断中 13 次有 **8 次** `|I_t|≥16`，原代理会饱和。这是新增支持读取后可以预见的尺度问题，A 仍不据结果调整 16、权重或门槛；报告应明确它不是已校准的 Q 预测器。若未来必须改归一化，应另立版本，不能把效果混称为纯采样修复。

### 3.3 每笔付费动作、到达与取消的先后顺序

以下为拟议接口语义，具体函数名可在实施前对齐，不要求修改冻结 V26：

1. **action 0**：原包验证、mapper 单次 update 后，建立规划状态及反馈基线；不产生收益更新。
2. **发出一个动作**：保留当时选中选项的单调编号、端点、预测 cue／扇区，以及上一观测中的 cues；把授权动作号绑定到这一选项。候选编号不能跨重规划当作稳定选项身份。
3. **收到下一包**：沿用现有 episode／frame 唯一性、动作、位姿、时序和预算校验。每个已付费包只融合一次，获取新的反馈几何索引和原 256 规划状态。反馈使用此前选项和 old cues；不能先用这次新发现的类别回填上一动作的预测。
4. **结算该动作**：若碰撞，只记录 paid collision，禁止校准。无碰撞且达到旧选项端点，按上述相邻两帧门结算一次；否则记录 `not_at_selected_endpoint`，不累计一个“隐式完整选项收益”。付费转弯和零改善观测照常形成时序记录；通过支持门的零改善是有效 y=0，不等同 unavailable。
5. **随后重规划**：必须先完成旧动作反馈，再创建新选项。到达立即关闭旧选项；周期重规划替换、原路线不可行、预算／传感终止、选择为空等都明确记录取消／终止原因。V27-A 不因取消而给旧选项加零奖励，也不把已取消选项的路途改善补发给新选项。即使新选择端点相同，也记录新的选择编号，防止将多个规划段混成一次完成。

“每付费观测归因”在 A 中指每个 transition 都能查到授权选项和适用／不适用原因，不表示每步都要更新方向收益。没有后续传感包的动作提议、静态候选评价、重复包重试均不得成为新的收益样本。动作／身份标识只用于 runtime 内部因果核验，不向 G 暴露可能编码类别的场景文本。

每条反馈日志至少保留：before/after action_id、授权选项编号、到达／取消／碰撞状态、cue 来源动作、局部共同数、方向／距离／并集改善数、新 key 数、适用门失败原因、是否写入及写入前后的反馈计数。实际改善与预测都保持独立，禁止由终点 Q 反推该步收益。

## 4. V27-B 的边界（本轮不实施）

若后续需要完整选项归因，必须另外定义：开始时已知支持的基线、后续新 key 何时可进入可比较集合、同一 key／方向位跨多帧去重、返回／转弯动作归属、部分执行后取消如何处理，以及周期重规划同端点是否延续选项。不能把多个相邻 y 相加后当作完成质量，也不能默认取消就是零收益。

这些都是行为定义变化，可能独立改变学习信号；应在 A 已能稳定提供可比较观测后再决定是否需要。已有全量诊断表明原最后一步也有可用支持，所以现在无需把 B 作为修复零更新的前置条件。

## 5. 实施前后必需的五项测试

1. **无关增长不抹去共同 key**：解析已知局部点有至少 4 个共同 key；加入大量远处新 key，规划采样允许改变，但反馈局部支持与改善必须不变。G/S 使用相同几何提取规则；类别交换不能改变账本几何数值。
2. **新 key 与不足支持不能伪造收益**：大量只在后帧出现的点不进入改善；只有 3 个共同 key 仍 unavailable 且计数不增长；至少 4 个但完全无改善时记有效零收益，不与缺失混淆。
3. **空间范围与精确比较**：使用 old cue、after point 的局部范围，与全量参考计算一致，覆盖点跨 1.5 m 边界及 cue 新观测偏移；同一 key 的方向和距离双改善只计一次，距离阈值保持严格大于 1 cm。
4. **授权与生命周期**：action0 无收益；正常接续包只计一次；重复、错 episode、跳号／错动作拒绝；碰撞不校准。到达先结算再重选，取消不加零奖励、不把旧段收益迁给新选项，零增益转弯仍保留付费时序。
5. **规划隔离和消融开关**：在相同记录和固定反馈表下，256 规划状态／候选／分数与 V26 一致；G 收不到语义输入，禁反馈分支不改反馈表。只有启用反馈且有有效到达结算后，允许 S 的原反馈因子改变。测试不能通过构造 GT 或使用评价 Q 驱动此变化。

这些是解析／小型接口测试，不等价于闭环有效性或实车验证。

## 6. 至多一次未来修复验收：原历史上的匹配诊断

推荐先做一项 `matched-fixed` 验收，不新开 G/S 主任务矩阵：使用现有 case_01 的全部 401 个保存包、原授权动作／选项和原 gates，在一次离线 mapper 顺序处理上比较旧采样反馈、新账本反馈及关闭反馈三条**影子计数状态**。原动作和选择固定，影子更新不反过来修改路线，也不再调用规划器或生成反事实传感。

这不是把固定路线当在线策略。它只回答新实现是否恢复了原本丢失的支持、是否按时序实际写入反馈，并防止“模块被调用但表仍为零”的问题重现。必须逐一复现原 13 个事件的 sampled 数和当前全量审计数、记录更新后的计数／因子；禁反馈表应保持不变，旧分支仍为原 13 次 unavailable。其他原 gates 不适用的步骤不能为了增加样本数而放行。

这次未来验收如需重新处理原包，应如实计入离线 TSDF 次数；0 新物理动作、0 新 Q 评价、0 新网格提取。保存紧凑计数与 SHA，不复制原始包。实现、输入、流程和输出容量先冻结，单次执行失败即保留，不据结果修改门槛后重跑。

验收可支持的结论是“采样阻断修复且反馈写入链有效”，不包括 S 比 G 好、原子反馈等于重建收益、或 ANS 整体创新成立。自然语义识别、已训练网络／收益头、IGCR 对最终 C/Q/J 的因果增益，仍须后续独立验证；本文件不提前安排第二组实验。
