# V28 语义重建债务与选项级残差设计（开发方案）

## 1. 设计目标

V28 不再把“局部面片变多”直接解释为“外形质量提高”。系统在二维覆盖资格和安全返航约束下，选择能降低设施外形重建债务的完整观察选项；语义只决定不同类别需要优先验证哪些方向，不改变评价权重，也不向在线规划暴露参考网格或 Q。

保留 ANS 全局—局部层次和 OV-SDF、STGHP、RPN-UQ、IGCR 四个接口。V28 是开发版，必须先通过保存历史行为门和共同建图稳定性门，才允许消耗新的主任务额度。

## 2. 观测状态：实例—方向重建债务

对已观测实例 `i` 和八方向扇区 `k`，OV-SDF 输出：

- `direction_support`：来自不同实际相机位姿的方向覆盖；
- `distinct_pose_count` 与有效基线；
- `range_consistency`：重复观测的稳健距离残差；
- `surface_stability`：共同体素的占用/法向一致性；
- `boundary_fragmentation`：观测组件和投影边界碎片的观测侧统计；
- `class_id/confidence`：独立语义通道，置信不足时回退几何模式。

类别模板只定义需要验证的方向集合与初始权重 `w(class,k)`。在线债务为

`D(i,k) = w(class_i,k) * uncertainty(i,k) * (1 - support(i,k))`。

`support` 必须来自真实观测，不能由模板可见性直接填充；类别 3 不自动得到更高最终分数，只在其关键方向未验证时产生债务。类别交换应改变债务分布，几何输入保持不变。

## 3. STGHP：覆盖保护与类别覆盖

STGHP 继续生成覆盖候选和观测候选，先由 RPN-UQ 与返航预算筛掉不安全选项，再分两队排序：

1. 覆盖队：保持达到 `C>=0.8` 的预计余量；
2. 重建队：按预计债务降低下置信界除以完整选项成本排序。

当覆盖余量不足时只选覆盖队；余量足够时，重建队至少为每个仍有显著债务且存在安全路线的实例保留一个候选，再进行统一容量排序。该规则解决 V27 中类别 3 有候选却几乎从不进入最终选择的问题，但不强制机器人访问不可达或低价值目标。

候选容量保持 12。开发行为门固定为：两个 cue 均出现后的保存快照中，只要类别 3 仍有可行正债务候选，最终短名单不得连续 10 次完全没有该实例候选；类别 3 的候选份额在两个排列分别至少达到 20%。这是机制覆盖门，不是性能结论。

## 4. RPN-UQ：可校准的保守收益

输入为候选前的观测描述、目标实例/方向、完整去程与返程成本、预计可见性和类别置信度。输出 `mu_delta_Q` 与 `sigma_delta_Q`，排序使用下置信界

`LCB = mu_delta_Q - beta * sigma_delta_Q`。

评价 Q 只用于离线标签。训练按场景/实例整组划分；类别 3 在获得足够样本前不得训练或宣称校准，原24条偏斜 V28 诊断只作开发诊断。首版解析回退用观测稳定性改善的保守下界，不称学习模型。

## 5. IGCR：完整选项生命周期

选项打开时冻结目标实例、方向、观测描述和预测分布。局部层每步重验安全路径，但只在以下条件关闭：到达目标、碰撞/停机、预算或返航不可行、目标债务已被沿途观测消除。固定 5 步重规划不再自动取消选项。

到达后用整段实际观测描述变化形成 outcome feature，再由残差模型更新 `(instance,class,sector)` 条件状态。禁止把 evaluator Q 直接写入在线反馈。取消选项单独记录，不补造零奖励。

## 6. 共同建图稳定性

24条选项中13条新增观测后 Q 下降，说明共同表示也需开发修正。该修正对所有方法共用，并与语义算法分开验收：

- 融合使用跨视角支持和稳健残差抑制单视角噪声边界；
- 组件清理不得按类别或规划目标改变；
- 禁止外壳补全和参考几何修复；
- 在现有24条开发选项上报告 Q/F1 正负和最坏下降，不能只报告均值；
- 修正参数冻结后，在未用于调整的新布局上验证，不用开发集非退化替代独立结果。

## 7. 新场景故事与对照

场景为大型设施走廊/实验室设备区。通道二维覆盖可由所有方法完成；预算只允许对部分设施绕行补看。简单和复杂设施正面外轮廓近似，复杂类具有侧向外露附件或不规则包络，主通道视角会漏建。早期可见的语义标志提示类别，真正附件仍必须由深度观测获得。

对照至少包括：

- 强几何质量 NBV；
- 固定类别优先；
- 语义重建债务；
- 类别置换；
- 低置信回退；
- 关闭 IGCR；
- 外部 TARE 地面适配（完成传感桥后）。

同时保留普通场景、类别与结构失配场景和错误语义，报告覆盖损失、Q、J、路径、运行时间和失败。优势场景可以由方法机制反向设计，但必须对应“有限预算下对高风险设施进行定向建档”的真实需求，并在运行成绩前冻结。

## 8. 下一执行顺序

1. 实现只读的 V28 描述符和候选覆盖审计，不产生动作；
2. 用 V27 保存状态验证类别 3 短名单覆盖、类别交换敏感性和无真值输入；
3. 用保存包开发共同建图稳定性修正，单列其对 G/S 的共同影响；
4. 冻结新大型场景的几何、预算、指标、错误语义对照和停止规则；
5. 先做解析上限与成本筛查，确认语义信息价值非零；
6. 只有前五项通过，才执行一组有界的 G/V28 配对自主任务及独立回放。

若保存历史中类别覆盖行为门仍失败，停止新主任务；若共同建图在未见布局仍系统性随补看退化，先收窄论文为“覆盖约束下的观测分配”，不宣称三维精度提升。
