# 语义形状模型 V5：修正依据、实现边界与验证安排

更新：2026-09-10。性质：基于751／752开发数据提出并已检验的内部修正。**共同几何修正目标失败；对象性降权达到局部背景权重抑制目标，但未证明细类别规划收益。V5几何不采纳为默认，源码保留为可复算的失败方案记录。** 本文不修改原有冻结模型、候选或实验结果。

实现见 [semantic_completion_v5.py](/root/NSO/nso/semantic_completion_v5.py)，SHA256为 `7c87a7e28cca8779f73e40b485a32f92feeb3666ebbc907ba2f8080380059cef`。API保留 `ObjectCompletionModel(mapper, semantic, fine_categories=True)`，增加可选 `config=CompletionConfigV5()`。V3继续保留，便于复算和比较。

## 1. 为什么修改

[首批事后诊断](/root/NSO/eval_results/counterfactual_object_diagnosis_first_20260910/summary.json)已对6个可用历史重放，确认地图、形状点及权重与原封存评分一致。在重复历史形成的17个簇实例中，5个簇由唯一真值外表面的近距离支撑确认属于背景。S分配给这些背景假设的潜在加权面积约占49.71%。此外，真实简单对象的假设约59.01%权重离真实外表面超过5cm，复杂对象约17.94%。

这些是模型假设的事后诊断，既不是实际新增表面积，也不是重建F1。它们提示两个可分离问题：部分背景几何被套入对象形状库；稀疏观测和包围拟合可能使预测面收缩或偏入实体。修正只能使用传感器历史中的证据，不能把诊断时得到的真值类别、位置或尺寸送回规划器。

V5仍置于ANS层次及OV-SDF、STGHP、RPN-UQ、IGCR原有模块分工中。本次修改主要发生在OV-SDF内部的对象条件观测需求模型；不声称已完成整个ANS神经系统或其他模块的有效性验证。

## 2. 修改一：实测支撑范围与可见面约束

旧构造器用点坐标的5%—95%分位范围估计尺寸；在稀疏边缘、部分侧面可见或存在最小尺寸先验时，该范围可能比实际可支持范围窄，随后中心平移还可能影响已观测正面。V5替换包围几何拟合部分，同时**保留原几何聚类及接受条件**；接受条件中的分位范围仍保留，不能将本次修改描述为取消了所有分位计算。

共同几何过程如下：

1. 从质量账本恢复与 `quality_evidence(max_points=10000)` 严格对应的体素key。该账本使用0.15m体素，与0.03m TSDF体素不同；点顺序不对应时直接报错。
2. 以实测点的支撑范围估计边界，向外补偿最多半个质量体素，即0.075m，并由账本体素范围约束。补偿用于处理稀疏采样，不代表测量误差置信区间。
3. 使用内向观测法线寻找轴向可见面：默认轴向对齐阈值0.9、至少4个切向不同的质量体素支撑。在满足支撑条件的外侧平面分组内以坐标中位数估计平面位置。
4. 若同一轴的两侧平面均被观测，以它们的间距约束该轴尺寸；若只观测一侧，优先保持该可见面的拟合位置，向未观测一侧应用尺寸先验，避免将可见面随中心整体移动。

未观测充分的水平轴仍沿用原最小尺寸先验0.9m／0.65m。高度仍采用已知地面坐标系下底部为0的显式约定，以及原0.9—1.5m高度先验；这些都不是由当前真值对象尺寸拟合出的参数，也不保证适用于任意物体。

**单面厚度仍不可辨识。** 当历史只显示一个近似平面，且没有侧面、背面或其他约束时，不能从该平面唯一恢复实体厚度。V5只避免无依据地移动已有平面，并记录厚度依赖先验的状态；它不声称解决了不可观测问题。可见面拟合也可能因法线噪声、背景混入或错误分组而失效，因此必须保留负结果。

G／O／S／X／M使用同一支撑拟合、普通box／shelf库、实际几何似然、历史剔除及自身遮挡方法。各自的形状点坐标、假设编号和几何拟合误差必须一致；预测点仅用于规划，不写入TSDF。

## 3. 修改二：标记域中的共同对象性先验

对象性门控只在以下条件同时成立时生效：启用语义；`mapper.config.appearance='marked'`；`semantic_source='rgb_marker'`；历史质量账本中确实存在类别2或3的标记证据。

在该条件下，已接受几何簇有2／3标记支撑时对象性权重为1，没有标记支撑时默认权重为 **0.25**。未支持簇仍保留，几何接受条件、对象列表与候选规则不因无标记而删除。

0.25是一个可配置、非零、**尚未校准的开发先验**。其应用理由仅限于当前有人工设备标识的设施域：已经看到部分有效标识时，未获标识支撑的局部形状具有较低对象假设可信度。遮挡、视角和漏读仍可能使真实对象没有标记，因此不能把无标识直接称为背景，也不能宣称0.25是真实对象概率。自然图像开放词汇检测不在该规则的已验证范围内。

O与S使用完全相同的对象性规则。O设置 `fine_categories=False`，类别2与3的区别不影响其形状先验；S只额外用细类别改变box／shelf概率。X交换同一历史的2／3标签，但不改变对象性支撑。生成面积经过既有历史剔除及确定性抽稀，最终每点权重以输出为准，不把抽稀后的所有权重简单解释为独立校准概率。

## 4. 缺失语义与接口不变量

M必须通过全零语义历史实际构造模型。全缺失时，历史没有2／3标记，对象性门控关闭，细类别先验回到共同几何初值，再使用相同实测几何似然更新。因此M应与G产生一致形状点、权重、评分及选择；不能通过强制复制G结果伪造这一性质。

G一直使用几何通路。普通非标记域也不会自动启用上述对象性门控。模型额外输出 `geometry_audit`、`marker_supported`、`marker_objectness_active`，保留原 `center`、`dims`、概率及拟合误差字段。

[必要测试](/root/NSO/tests/virtual3d/test_semantic_completion_v5.py)的8项检查已通过，覆盖实际G／M一致、G／O／S／X／M共同形状及候选、O／S对象性一致、非标记域回退、实测可见面约束、对向平面间距、质量key对齐，以及真实传感器地图／TSDF不变。这些是实现不变量测试，不能代替真实效用实验。

## 5. 同历史、同候选的开发验证

已使用[首批冻结实验](/root/NSO/eval_results/counterfactual_view_development_first_20260910)已有72条真实执行分支的outcomes完成[V3／V5与两种评分目标的同数据重评分](/root/NSO/eval_results/counterfactual_view_v5_rescore_first_20260910)，不新增导航、不重选候选、不重算或替换真实分支结果。候选池固定为原来封存的同一批去返路径；即使V5保留了同名候选方法，本次比较也不重新调用它来改变池。

比较至少保留G／O／S／X／M／N，统一关闭旧细类别近看额外奖励。主要问题分别是：共同几何修正是否改善预测；对象性规则是否减少背景假设影响；S是否在相同对象性机制的O之上提供细类别增量；S相对同池N是否产生隐藏模型净收益。V3与V5的比较不能代替这些内部消融。

当前数据只来自已用于定位与设计的751／752，因此所有改进均属于开发结果。后续可解释版本需要在参数固定后进行753／754检查，仍按既定协议称为开发检查，不升级为论文独立确认；本V5失败几何不作为默认推进。两条因高噪声前缀提前停止而不可用的预定历史必须保留在采集状态账本中。

根执行器已追加共同48动作窗口下的预测joint-AUC评分消融，以检查短路径 `gain/cost` 与共同预算任务价值不一致的问题。**评分目标变化与语义模型变化必须分开记录。** 所有评分器使用同一时间预算与成本规则；不得把更换评分目标产生的收益归因于细类别创新。

同一评分目标下V3／V5选项没有改变。rate目标下G／O／S／X／M／N在6个历史均同选；AUC目标下G／O／S／X／M仍均同选，但N在751／0.03／80历史不同，且N的平均真实面积收益率与F1增益高于S。因此，细类别增益仍未建立；AUC中隐藏模型的该批净贡献为负，不能写成所有比较均为零。

## 6. 已检验结果及失败规则

[V5事后诊断](/root/NSO/eval_results/counterfactual_object_diagnosis_v5_first_20260910/comparison_v3_v5.json)恢复了同6段前缀、同17个几何簇实例及V5归档模型，逐项核对原地图、实测真值支撑、rate／AUC预测中的形状与权重hash。总S假设距真实外表面≤5cm的权重比例从36.16%升为42.99%，但这不能解释为几何改善：背景权重占比由49.71%降为20.71%，而共同几何G的贴合比例由28.69%降为26.36%；S在真实简单／复杂簇中的贴合比例分别由40.99%／82.06%降为28.50%／75.46%。

简单对象平均中心误差由4.93cm升为6.01cm，平均轴尺寸绝对误差由5.47cm升为6.06cm；复杂对象分别由4.88cm升为5.91cm、5.34cm升为5.88cm。这些都是重复开发历史的事后拟合诊断，不是独立场景统计或主实验指标。

具体规则证据见[传感器侧归因报告](/root/NSO/eval_results/counterfactual_object_diagnosis_v5_first_20260910/SENSOR_RULE_ATTRIBUTION.md)。0.15m质量账本key用于汇总观测，不意味着物体真实边界延伸到体素边界；对实测极值继续补半体素，把原收缩转成了外扩。12个真实对象簇均没有x轴双面约束、均没有上表面约束，导致该补偿长期生效。可见面锚点总体接近真实边界，没有证据表明法向符号反转是本批主要根因。单面厚度仍被原0.65m先验限制，部分原有误差完整保留。此次只记录诊断，不按真值尺寸调整补偿或先验。
