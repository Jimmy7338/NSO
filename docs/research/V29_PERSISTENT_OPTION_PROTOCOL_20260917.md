# V29 持久观察选项合同（实现前冻结）

2026-09-17。仅新增模块和非融合手写传感合同测试；旧V26/V27/V28源与证据不改。当前不产生新主任务、世界、实际传感、TSDF、网格或Q。本阶段不证明闭环性能。保留ANS全局—局部层次及OV-SDF、STGHP、RPN-UQ、IGCR接口；V28r1评分不调权。

全局层只在无打开选项时选择目标。一个选项固定打开时刻、目标位姿（包括朝向）、可选有序观察位姿、cue身份/位置/类别/置信度、原预测代理及起始全量观测支持；不得因5步到期、新cue或类别变化而覆盖这些字段。所有位姿必须能在当前已观测安全图中抵达，并预留完整剩余选项和恢复锚点朝向的返航动作。初始已抵达且无需动作的空选项拒绝。

局部层每个付费动作前重新求解到剩余观察位姿和锚点的路径，不执行存档路线。只能有一个未消费指令；返回一个动作后必须等其同episode、连续action_id、唯一frame_id、递增时间和一致位姿的观测，才可再次规划。每个实际付费转移归属当时的选项，先消费到达帧再关闭，不把末帧挪给新选项。

选项生命周期：

- `completed`：所有有序观察位姿含朝向已实际到达；保留整段实际动作数与各次安全预留，返航预留不是已执行成本。
- `cancelled`：碰撞、未完成观察时传感/预算结束、完整剩余路线/返航不可行或动作安全门拒绝。已付动作保留，取消不补零奖励。路线不可行后锁定返航，禁止同帧重选绕过失败门。
- 周期刷新只记路径重验，不更改option_id/目标/起始支持。安全可行不因旧路改变而取消；需要取消的是新观测图中完整剩余任务不可行。

初版不启用“债务已消除”提前关闭：当前欠观测代理尚不足以判定任务已完成，避免将低代理误写为真实质量完成。该项明确保留为未完成接口。

实现审查补充（封存前）：终止帧先付费归账；碰撞始终优先取消。无碰撞时先确认本帧实际到达的位姿/朝向，全部观察完成则结算completed；仅未完成的观察因sensor/budget结束而取消。两种情况都终止运行；观察完成不等于已返航或任务合格，二者由运行时另行报告。

IGCR结算输出整段观测描述变化：冻结中心邻域的起止共同面片数、新方向/更近量测的共同key数、新key数、实际动作数、不同底盘位姿数（含朝向）及相对起点最大平移基线。新key不自动当质量提升。预测仍是原代理，mu_Q/sigma_Q、残差校准、标量学习奖励均null，不向规划写入Q或伪造已训练IGCR。

测试必须覆盖：跨5步保持身份；顺序多位姿；同格朝向未满足；整段支持包括早于末步的变化；准确计入转向/返航预算；pending重复请求及伪造观测拒绝；类别/对象变化不改原预测；新障碍可绕行仍保持身份、不可行则取消并返航；碰撞/传感停止/预算结束；到达或取消只关闭一次；零动作不获奖励。使用手写观测和不融合mapper，不通过模拟世界产生测试数据。
