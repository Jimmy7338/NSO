# V28 描述符、候选保留与类别先验预检结果

2026-09-17。本阶段完成了新描述符/候选模块、一次有缺陷首版留档、明确缺陷修复、同批历史再验证及独立审查。**实例候选保留和信息边界检查通过；两排列候选份额门仍未全部通过，语义净收益与整体方案优势仍未证明。** 主任务仍12/36，不启动更多P00主任务。

## 实现及确实修复的问题

新增有效版本 `nso/observed_debt_v28_r1.py`，不覆盖V26/V27运行时。按已观测cue邻域提取全量白名单面片描述，生成同一几何/位置候选池，再对仍有正方向缺口的每个cue对称保留至少一个候选，候选上限12、覆盖候选至多4。路径在已观测可行域内并支付返航成本。该原型只对应观测描述与STGHP候选机制，没有完成长选项IGCR或可校准RPN。

首版把“面片到相机”的历史方向位图，与“cue中心到候选相机”的扇区混用。独立解析反例中，6个面片均已从完全相同的候选相机看过，旧版仍给出1/3方向缺口及0.016667语义代理收益。此为代码层面的明确缺陷，不是由Q下降反推的猜测。首版代码、协议和全部结果保存在 `audit_results/v28_descriptor_preflight_20260917`，不作为有效机制成绩。

r1逐面片使用该面片到候选相机的向量查询位图，并只统计当前预计可见的面片；cue中心方向仅用于索引类别先验。最终额外项与“可见且新方向面片数/邻域总面片数”成正比。两个新增回归反例验证同相机重复观测以及不可见面片均不能产生虚假的方向收益。7项测试通过，独立审查再次验证两个关键反例，无新阻断问题。

这并不是已经校准的未来Q。邻域可能包含背景，语义来自人工RGB标志；不同位姿数、有效基线、实例方向支持、边界碎片及质量不确定性当前缺失，输出null。归一类别先验总质量相同，但其方向权重仍是待验证假设。

G是原几何规划，零cue输入。O/S/X共用相同检测输出和几何候选池：O均匀方向先验，S正确类别先验，X交换类别。**O是固定语义检测位置与置信度的类别先验消融，不是独立的纯objectness系统。** L把实际cue置信度改至0.59后重新建池，结果与G完全一致；另用关闭实例保留的S检查保留机制本身。

## 固定口径结果

下表候选份额只纳入“两类cue均出现，且原始池存在复杂类正代理收益候选”的快照，以其全部短名单行数为分母；并非最终选择占比。

|---|---:|---:|
| 固定快照数 | 9 | 9 |
| 满足份额门条件的快照数 | 5 | 4 |
| 复杂类短名单行数/全部短名单行数 | 12/60 | 5/48 |
| 复杂类份额 | 20.00% | 10.42% |
| 预设至少20% | 通过 | 未通过 |

| 实例保留改变S短名单 | 2/9 | 4/9 |

若分母只用正语义候选行，复杂份额为54.55%/33.33%；**这不是本次冻结门的分母，不能用于宣布两排列通过。** 连续10次规划缺席门没有由每轨迹9个稀疏时刻验证。

case03的100/150/200/250步，原始池各有3条复杂类正候选，短名单仅留下1/1/2/1条。这说明本次低份额并非全部由于没有可行候选；保留一条的对称机制能防止完全淘汰，却不保证20%份额或最终选择。独立集合检查确认各快照同时容纳全部复杂候选、4条覆盖及每cue一条候选仍不超12槽；其数量上限12/48=25%可由该池容纳，实际少的7行来自排序/裁剪。这只是容量见证，不是新路线执行或性能成绩。

更关键的是，在上述9个满足复杂类机会条件的快照中，S最终均未选择带复杂类正证据的候选。case03第50步S选中复杂候选，但O也选中同一候选，此时不能归因于类别先验。S/O的两处差异都发生在case01：第150步S选覆盖而O选复杂候选，第350步选了不同的简单设施视点。**本批变化尚不支持“类别信息促进复杂设施有效补看”的目标机制。** 这些仅是固定历史的影子决策，没有执行对应后续路线，更无新的Q/J成绩。

## 下一步的范围和停止规则

继续堆P00轨迹或把复杂类奖励放大都不能回答有效性问题。本次不把“候选进入名单”升级为“值得执行”。下一阶段先冻结一个有界的**完整观察选项与收益可辨识性协议**：

- 定义从决定前往目标到完成观察的持久选项，5步重规划只修正安全路径；取消、到达、返航分别记账，不再用最后1–5步代替整个补看。
- 对新设施场景先作可达性、可见结构差异、候选完整成本和信息获得时刻的解析筛查。正确/交换语义共享几何观测前缀；强几何对照允许发现欠观测并补看。需要说明类别额外告诉了哪一种方向或结构风险，而不是给无语义对照禁用补看。
- 在新观测/成绩前冻结一个场景版本、所有设施等权外形Q与覆盖C、均匀先验/类别交换对照和失败规则。与旧20%开发门分开登记，不能修改旧失败结论；先证明新设计存在可执行的不同观察选项及非零潜在收益，再决定是否值得采集有上限的物理对照。
- 共同建图链的下降先做层级归因，再决定修哪一层；不将每个短片段Q都必须单调提高作为正确性要求。未完成前不宣称三维精度提升。

保留ANS与四模块接口，2026-09-29有效性判定日期不变。自然语义、真实SLAM位姿误差、主流外部基线和ROS1实车优势均仍待验证。
