# 网络训练现状审计与优化路线

更新：2026-09-11。范围：当前工作区及已经归档的实验，不把脚本存在、README 记录或 Git LFS 指针当作已验证模型。

## 结论

V10.x CPU 三维闭环没有训练或加载端到端神经网络。它验证的是四模块调用链、传感器观测约束、层次规划、安全返航、人工语义条件和在线收益反馈。该证据不能代表原 ANS 神经策略、自然语义前端或学习型 RPN-UQ 的性能上限，也不能支持“完整端到端方案已经优化”的表述。

代码里虽然有多个神经模块，但当前实现是分模块训练与规则接线，并非从图像、深度一直对最终覆盖—重建目标联合反向传播的单一端到端系统。Neural SLAM、局部策略、全局 PPO 和点估计 RPN 各有独立优化路径；语义检测器没有任务训练路径，四模块中的拓扑与收益组合还包含不可微规则。

此前确有两类轻量拟合：二维 CPU 候选 RPN 训练了一个 5 输入、16 隐层、113 参数的 MLP；V6/V7 对候选观察收益拟合过线性/岭回归模型。前者的验证准确率为 0.9932，但同一验证集上的动作预算规则为 1.0，说明其结果主要由简单成本条件解释；后者没有建立稳定的语义选择净增量。它们均未接入 V10.x 三维闭环作为神经网络组件。

## 纳入当前研究主线的优化路线

### A. 先训练可归因的语义观察收益模型（当前 CPU 阶段）

保持 ANS 双层结构和四模块接口，将 STGHP 的候选路线评分内部替换为小型可训练收益头。每个候选只使用决策时可获得的信息：二维未知空间、预测可见体素、实测表面覆盖、视角新颖性、类别、结构先验、识别置信度、实例历史、路线成本及 RPN 可达性。监督标签来自候选执行后的真实新增二维观测、新增可见表面、局部完整性改善和代价，不读未来真值作在线输入。

训练与比较采用逐级模型：

1. 几何收益模型 `f(G,a)`；
2. 固定类别权重，检验“只偏爱某类”是否足够；
3. 语义条件收益模型 `f(G,Z,c,a)`；
4. 带置信门和实例残差的完整模型；
5. 完整模型去反馈、错误语义和低置信语义消融。

第一版使用 CPU 可训练的小型 MLP，并保留线性/树模型作为容量对照。损失同时约束实际收益回归、同一历史内候选排序和置信校准；训练/验证按场景族与设施实例分组，禁止同一布局变体跨集合。验收同时看预测 MAE、排序后悔、校准误差、动作是否改变，以及最终 `C_2D×F1`、新增区域局部完整性、路程和时间。训练损失下降而规划结果不变不算机制成立。

### B. 再做原神经栈的逐模块恢复与优化

恢复真实 checkpoint 后先冻结全部网络做输入、输出、速度和基线复现，再一次只开放一个训练模块：RPN-UQ 校准、全局策略适配、自然语义前端域适配，最后才评估联合微调。每一步都与上一冻结版本共享场景、预算、重建后端和评价协议。这样可以区分语义收益模型带来的增量和通用导航网络变强带来的增量。

SLAM 与局部策略优先复用可靠预训练权重；只有 ZED/实车回放表明位姿、深度或局部控制域偏移明显时才微调。全局 PPO 必须基于实际执行目标的概率分布重新训练，不能在采样后修改目标却沿用旧动作对数概率。RPN-UQ 必须报告可靠性曲线、ECE/Brier 与失败分组；语义前端必须在自然图像上报告类别/置信度错误，并把置信度传入收益头。

### C. 算力安排

当前无独立显卡时完成 A、数据契约、轻量训练、回放和消融。历史 ANS 权重若能从 Git LFS 恢复，可做有限 CPU 冻结推理审计；大规模 PPO、SLAM、检测器或视觉编码器微调留到有 GPU 的实验室环境。实机前先冻结一套可在 CPU/核显上运行的轻量方案，并记录语义推理与规划耗时。

## 论文边界

当前可写“构建了保留四模块接口的 CPU 可解释闭环，并开始验证语义条件观察收益”；不可写“所有端到端网络已经联合训练”“开放词汇视觉已验证”或“神经网络优化证明了完整系统优势”。只有学习型语义收益头超过几何与固定类别对照，随后神经栈冻结/微调对照和自然语义测试也通过，才逐步提升完整方案主张。
