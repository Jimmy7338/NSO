# 新布局主比较的分析口径

状态：**分析计划，尚未启动主矩阵**。开发记录与主矩阵始终分开。只有开发任务证明传感—规划—返航—重建—评价可用，并能解释 S/B 的实际方法差别和行为机会，才冻结具体主协议。无需开发得分为正；但若 S/B 全部只在返航后改变信念，扩大任务数量不能代替解决作用时机问题。

## 固定条件与研究问题

静态资产已保存三个任务族各两个测试布局：AISLE、CELL、LOOP 的 T0/T1。这些布局共用公开结构族，检验布局变化而非未见类别泛化。候选预算为 120/160 个原子动作，候选噪声种子为 92811/92812，均为 1% 轴向深度噪声的独立实现，不能写成两种噪声强度。

四方法为共同 CPU 机制下的 NBV、G、B、S。主对比是 S/G（增加类别条件处理的作用）和 S/B（共享处理的额外作用）；S/NBV 用于解释完整有限前瞻方案相对直接选向的表现。所有方法的传感、候选权限、几何初始化、对象关联、导航先验、重建与原子成本保持一致。G具有补看、诊断和重规划能力。该比较不代表原 SWAP、VISTA 或 TARE 全系统的性能排名。

最大数量为 6 布局 × 2 预算 × 2 噪声实现 × 4 方法 = 96 条，最终实际执行的固定集合由独立协议声明。若剩余工作窗口只支持较小集合，应在读取任何测试布局结果前确定完整配对的子矩阵。不能根据测试得分选择第二个种子、增加有利布局或替换不利条件。

## 评价与统计单位

主要质量终点为 \(J_{nav}=C_{nav}Q\)，其中 \(Q\) 是全部四个设施的表面 F1 宏平均。分别给出自由空间覆盖、逐实例及宏 P/R/F1、距离与转向/观察成本、资格率、规划耗时。未观察到的设施保留在分母中。二元局部实验的 J5 与这里的 J_nav 不合并计算总提升。

同一布局的两个预算、两个种子和四方法互为相关条件。六个不同测试布局才是主要比较单位；96 条轨迹不是 96 个独立场景。同一条轨迹多个重建时刻也不增加独立样本数。三个开发场景不得并入测试布局总数。

对每个预算分别进行以下汇总：

1. 按布局、噪声实现严格匹配对照，列出所有预声明槽位的未开始、运行中、失败、完成和复核状态。
2. 对双方合格的配对，报告 \(\Delta J=J_S-J_{control}\)，以及分量和成本差。相对差只在对照非零时计算，并标明是“各配对相对差的平均”还是“均值之比”；不混用。
3. 同一布局先对完整种子配对取平均，再对布局等权平均；同时给出全部布局点、范围及胜/平/负计数。数值相等判据固定为绝对差 \(10^{-12}\)，但计算阈值不代表物理测量精度。
4. 合格配对质量是有条件结果，必须同时列出双方资格率。另可报告任务效用 \(U=\mathbf1_{qualified}J_{nav}\)：已执行但不合格任务在该**成功约束效用**中记零，不能把它的测量 F1 改写为零。未开始的任务不填零，也不进入效用比较。
5. 仅在双方均已终止时形成任务效用配对；记录复核失败并单独解释，不能在质量表中静默删除。因运行窗口未完成的条件清楚列出，不从已有子集外推完整矩阵。

主图优先展示每个布局的实际配对点和连线，再给布局等权均值。六个特定设计布局不能代表工业环境总体。若补充置信区间或检验，应把布局作为聚类单位，说明重复预算/噪声的相关性、固定布局设计与小样本限制；不能把动作帧或实例作为独立重复来制造很小的误差条。未经这些检查，采用描述性统计更清楚。

## 行为证据与选图规则

每个场景保留同尺度的全路径、动作成本和返航状态。主文可用预声明的 T0 布局和第一个噪声种子展示机制，T1 及全部种子放补充材料；图的选择依据为布局和种子标签，而非提升最大值。共同观测前缀内检查类别到达、资格、后验、候选和第一个动作分歧。分歧后的不同观测属于策略执行结果，不能再称相同状态下的单因素评分比较。

真实网格采用共同相机、尺度和显示规则，展示简化只能影响显示，评价仍使用原封存完整网格。颜色应明确表示高度、表面方向或实际测得误差，不能把视觉明暗说成精度。中间曲线来自预先指定动作时刻的实际重融合，不插值补造观测。

若主结果持平或为负，分析适用条件，并保留全部条件。下一版本的改动需要另行标记；本主矩阵不自动回流用于调参后再次宣称独立测试。
