# CPU 开发诊断与冻结对比协议 v1

日期：2026-09-10。承接 `CPU_MECHANISM_INTEGRATION.md`。本阶段先完成开发诊断和规则对照，再冻结全部配置、实现与模型，运行未使用几何上的完整比较。冻结发生在正式结果产生之前；正式结果不用于改权重、换地图或选择模型。

## 开发诊断

基于上一阶段既有候选日志重建：语义加结构改变选择的 96 次决策中，被选候选的几何增益/成本分数平均为几何最优候选的 83.07%，预计动作数平均多 1.16。结构单项对应 79.72% 和多 1.38 动作。这说明评分确实牺牲了几何启发式收益，但不等于已经证明最终覆盖退化的全部因果链。

选定既有环形回合 `loop_seed31_start101_gain_semantic_structure`，从逐步可见掩码恢复当时的地图和路径。219 次 `path_invalidated_censored` 全部由新观测到的障碍扩大足迹安全边界解释；不是机器人实际撞墙，也不是 219 个预算内失败。当前控制器直接放弃失效路径对应的目标，因此仍保留删失标签。将它们计入神经预测准确率会改变任务定义。

诊断脚本：`scripts/diagnose_cpu_degradation.py`。归档：`audit_results/2026-09-10/cpu_degradation_diagnosis.json`。

## 规则对照与决策

追加两条硬规则开发对照：在同样 32 步目标预算下，预计动作数超过预算的候选直接排除，全部排除后执行既有有限扫描/STOP。它虽然能准确识别离线确定标签中的超时，却可能因不能选中远目标而提前结束探索。

追加一条软规则开发对照：保持语义和结构评分不变，将候选乘以 `sigmoid((32 − 预计动作数) / 4)`。4 动作的过渡尺度在这次开发实验前固定，没有参数扫描；数值计算裁剪指数避免溢出。它不训练网络，也不会仅因预计超时屏蔽全部候选。两类规则均不读取未观测地图。

| 开发方法 | 最终覆盖率 | 覆盖 AUC |
|---|---:|---:|
| 几何预算对照 | 82.12% | 0.5029 |
| 语义加结构 | 76.45% | 0.4585 |
| 语义加结构加候选 RPN | 75.38% | 0.4491 |
| 几何加硬预算规则 | 59.33% | 0.3826 |
| 语义加结构加硬预算规则 | 48.70% | 0.3272 |
| 语义加结构加软预算规则 | 79.47% | 0.4536 |

开发追加共 18 回合，固定为上一阶段六张地图及同一起点。硬规则负结果完整保留在 `eval_results/cpu_budget_rule_dev_20260910/`，软规则保留在 `eval_results/cpu_budget_soft_dev_20260910/`。正式比较采用软规则检验神经网络是否优于同样只利用已知路径的低成本评分；硬规则的提前停止作为开发失败案例呈现。所有旧方法和语义/结构权重保持原定义，不因本次开发结果被替换。

合成显著性与任务价值之间没有真实校准关系。因此本阶段坚持物理覆盖为主指标，不新增“语义加权覆盖”来改变已有负结果的含义，也不声称热点偏好必然有助于面积覆盖。

## 冻结配置和隔离

协议：`configs/cpu/formal_protocol_v1.json`；执行配置：`configs/cpu/formal_v1.json`。生成器及模型等文件的 SHA-256、软件版本、历史排除地图和选图规则均已保存。运行入口开始和结束时检查配置、源码、模型及地图；任意冻结文件改变均使本次正式验证失败。结果目录还保存源码压缩包，便于以后恢复当时实现。

地图选择不读取方法性能：遍历各类种子 1000–1099，按顺序选最多两个未使用的几何。几何去重同时考虑 90° 旋转和镜像，并与既有训练、验证及全部开发归档比较。哈希包含形状和占据数组，避免不同尺寸混淆。最终选出 11 张地图：单房间、多房间、走廊、死胡同、大厅各 2 张，环形 1 张；环形生成器的可用几何类型少，剩余未用几何只有一个。各类权重因此不完全相同，不能称为六类均衡采样。

这只保证几何内容没有重复，不能保证地图来自不同分布或独立真实建筑。走廊等类别仍具有很强的模板相似性。

每图使用起点种子 301、302，所有方法配对同一真实起点与朝向、同一合成语义场；地图 128×128，分辨率 0.1 米，机器人半径 0.1 米，传感距离 1.5 米，视野 90°，每回合固定 500 原子动作。转向计步；提前停止后的覆盖保持到完整预算终点再计算 AUC。

八种方法：最近前沿、几何增益/成本、几何预算对照、语义、结构、语义加结构、语义加结构加 RPN、语义加结构加软预算规则。共 **11 × 2 × 8 = 176 回合**。冻结 RPN 沿用上一阶段唯一模型，没有重训、验证集调参或正式测试时更新。

## 统计和完整性

预先指定主要指标为覆盖 AUC，主要比较为“语义加结构减几何预算对照”。先平均同图的两个起点，再对 11 张地图等权平均；配对差值按地图 bootstrap 10,000 次，随机种子 20260910，报告百分位 95% 区间。区间并不能弥补地图少和模板相似性。

最终覆盖率、重复移动、路径长度、碰撞为次要指标；其他方法差异为探索性比较，未做多重比较校正。分析保留全部方法，既不只报告赢家，也不把回合或时间步当独立地图增加样本量。

分析器验证完整的配置矩阵，独立从可见掩码重建每步覆盖及完整预算 AUC，核验地图隔离、配对资产、语义视野、目标到达与删失标签、RPN 冻结哈希。输出地图均值 CSV、配对区间、曲线、轨迹及可用于论文的结果文字。

复现时使用新输出目录：

```bash
.venv-cpu/bin/python scripts/eval_cpu.py --config configs/cpu/formal_v1.json --output eval_results/my_formal_v1
.venv-cpu/bin/python scripts/analyze_cpu_formal.py eval_results/my_formal_v1
```

若源文件、依赖或模型已改变，不能直接沿用 v1 声称冻结复现；应从归档源码恢复，或为新的实现建立新版本协议。`freeze_cpu_protocol.py` 拒绝覆盖已有协议。协议不覆盖真实 RGB-D、开放词汇感知、SLAM 轨迹误差或三维实机性能。

## 冻结结果与解释

| 方法 | 覆盖 AUC | 最终覆盖率 | 重复移动比例 |
|---|---:|---:|---:|
| 最近前沿 | 0.4780 | 77.77% | 6.43% |
| 几何增益/成本 | 0.5001 | 82.81% | 6.52% |
| 几何预算对照 | 0.5011 | 82.67% | 7.48% |
| 语义增强 | 0.4845 | 79.34% | 5.49% |
| 结构增强 | 0.4418 | 72.44% | 14.18% |
| 语义加结构 | 0.4413 | 74.61% | 10.43% |
| 组合加 RPN | 0.4527 | 74.76% | 9.76% |
| 组合加软预算规则 | 0.4519 | 74.22% | 10.57% |

主要比较的覆盖 AUC 差值为 -0.0598，95% 配对地图区间为 [-0.0743, -0.0424]。在本套件中，语义与结构组合没有改善覆盖效率，平均表现低于几何预算对照。此结论不外推至其他语义定义、真实视觉输入或其他规划器。

RPN 相对软动作预算规则的 AUC 差值仅为 +0.0008，对应区间 [-0.0055, +0.0075] 包含 0。本次比较未提供网络超越这一确定性规则的明确证据。不能以此前离线预测准确率较高，代替对闭环探索收益的检验。

可能影响结果的机制包括：语义热点与面积覆盖目标未对齐、结构加权改变了几何前沿优先级，以及部分观测下的足迹安全边界更新导致频繁重规划。开发日志支持这些现象存在，但本实验没有逐项控制并证明完整因果关系。后续应分别验证价值定义、评分权重和目标保留/路径修复策略，不能看到测试结果后在同一套件上继续调参并仍称其为未见测试。

本实验支持的贡献是可观测模块接入、数据隔离和冻结评估，以及对方法适用边界的实证分析；不支持“语义结构融合必然优于几何规划”或“候选 RPN 已证明优于简单规则”的结论。

## 交付与验收

本阶段完成 18 回合开发规则对照和 176 回合冻结比较，无运行失败；正式回合碰撞总数为 0。30 项二维与协议测试、16 项旧评估完整性测试通过，共 46 项。正式结果进一步重建了全部 176 回合的覆盖率与 AUC，核验 11,953 条目标记录，运行前后冻结校验均通过。
