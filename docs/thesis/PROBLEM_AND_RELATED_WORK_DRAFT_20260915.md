# 问题定义与相关工作（工作初稿）

版本：2026-09-15。本文为论文正文候选稿，依据当前任务契约和已核查文献撰写；方法中的条件收益预测与完整系统效果仍待验证，不能作为已完成研究的定稿提交。

工业工位、设备间等环境中的移动机器人，除建立可通行区域地图外，还需要记录设施的位置、占用尺寸、外轮廓及外露附件，以支持空间核查和后续巡检。远距离观察可以提供基本空间结构，却可能遗漏遮挡后的附件或产生较大的边界误差；进入侧后通道能够获得补充信息，同时消耗行驶、转向和返航预算。因此，本研究关注的并非增加观察次数，而是在有限资源下选择能够改善设施外形档案的观察方向。更多观测的收益受可见性、噪声、融合和实例分离影响，不能预先假定其必然为正。

设机器人从未知环境中的初始状态出发，任务区域与设施集合在实验前确定。机器人依次执行动作并获得深度、雷达及位姿等观测，形成历史 \(h_t\)。待选观察段 \(a\) 包括实际移动、转向和取信息过程，消耗预算 \(k(a)\)；所有方法使用相同动作与传感契约，公共前缀、探看、改选和返航均按协议计费。候选只能依据已观测地图和公共任务信息生成，环境真值、未执行视点的真实传感结果和未来评价分数不进入规划器。二维真值可达区域仅由评价侧用于确定覆盖分母，不能成为在线可达性或剩余覆盖量的先验。

令 \(R\) 为评价侧按固定机器人足迹确定的二维可达栅格集合，\(K_t\) 为已知栅格集合，覆盖率定义为 \(C_t=|K_t\cap R|/|R|\)。设施外形采用共同后端生成，并分别保留实测、推断和未知部分。规则外壳先验可以参与所有方法共有的建模，但应满足观测支持与自由射线约束；不能仅依据类别将未测附件写入模型。语义标签也不能改变几何真值、传感噪声、评价窗口、设施权重或任务对象集合。

设任务设施数为 \(M\)，每个设施在 \(p\in\{XY,XZ,YZ\}\) 三个投影上的边界匹配分数为 \(F_{i,p}\)，填充外形投影交并比为 \(I_{i,p}\)。沿用当前冻结口径，边界匹配容差为 5 cm，主外形分数为

\[
Q_t=\frac{1}{M}\sum_{i=1}^{M}\frac{1}{3}\sum_p
\min\{F_{i,p}(t),I_{i,p}(t)\},\qquad J_t=C_tQ_t.
\]

全部任务设施等权，漏建记零，不能只对成功建模的实例求均值。该指标评价外轮廓及投影占用的一致性；多投影不能唯一确定三维形状，故 \(Q\) 不称为完整三维建图精度，另需报告连续外表面误差、位置与尺寸误差。任务无关内部结构不应因未重建而扣分。实验分别报告 \(C\)、\(Q\) 和联合值 \(J\)，仅在同一终点满足预算、零碰撞、返航及 \(C\ge0.8\) 时比较合格任务的联合收益。中途尚未返航的高分不能代替终点结果，高 \(J\) 也不能抵消资格失败。上述定义依据[最小任务契约](/root/NSO/docs/research/FACILITY_DOCUMENTATION_MINIMAL_CONTRACT_V25_20260915.md)。

所有尝试及资格失败均保留在主结果表中，同时报告任务成功率；不能剔除失败后仅比较成功子集，再据此声称完整方法更优。配对试验中任一方法资格失败，都必须作为该对照的实际结果说明。

已有研究表明，语义探索与精细巡检之间可以建立明确联系。Dharmadhikari 与 Alexis 的 SWAP 将体积探索、实例表面重建和巡检组织为不同阶段，根据已观测网格缺口补充视点，并考虑观察分辨率、视角和路径。其意义在于说明普通空间覆盖与目标表面检查具有不同需求；“发现设施后再精细观察”已是已有方法内容，不能作为本文独有贡献。[Semantics-aware Exploration and Inspection Path Planning](https://arxiv.org/html/2303.07236v1)

ActiveSGM 在语义高斯地图上联合几何缺失和类别不确定性评价候选视点，使用距离惩罚并规划可行路径，同时评价语义、几何和渲染结果。这说明语义与几何状态可以共同驱动主动建图。但其类别熵表示当前分类的不确定性，并不直接等同于某一观察方向对设施外形质量的边际改善。[Understanding while Exploring: Semantics-driven Active Mapping](https://arxiv.org/html/2506.00225v2)

VISTA 将语言查询相关性与历史观察方向覆盖结合，通过候选生成、路径评分和滚动规划完成任务相关探索。它说明语义不仅能够重排目标，也能与视角多样性共同影响运动决策。然而，查询相关性描述对象与搜索任务的关系；全部设施等权的外形建档需要进一步回答补充观测是否改善几何质量，不能以搜索成功或渲染分数直接替代该检验。[VISTA: Open-Vocabulary, Task-Relevant Robot Exploration with Online Semantic Gaussian Splatting](https://arxiv.org/html/2507.01125v1)

与本研究候选主张最接近的是 SPP。该方法从带类别和空间关系的场景图中发现重复模式，预测未知区域的目标结构，将预测区域的可见收益用于探索，或迁移巡检视点；再以实际检测结果调整预测的使用。它已覆盖语义预测、观察规划与反馈纠错这一完整思路。因此，本文不能将“语义预测未见结构”或“闭环修正语义先验”重新表述为原创机制。[Semantics-aware Predictive Inspection Path Planning](https://arxiv.org/html/2506.06560v1)

在这些工作基础上，本文拟检验一个更具体的问题：给定相同非类别观测历史、候选动作和预算，设施类别是否仍能提供对付费定向观察收益的额外信息。令 \(c_t\) 为实际观测得到的类别及置信度，\(b_t\) 为剩余预算，候选收益头的目标为

\[
\widehat g(h_t,c_t,a,b_t)\approx
\mathbb E[Q(h_t\oplus O_a)-Q(h_t)\mid h_t,c_t,a,b_t].
\]

这里预测的是共同表示下的外形质量净变化，目标位置、可见体素数或固定类别优先级只能作为可能的解释因素。未来 \(Q\) 差值可用于离线训练标签和独立评价；在线反馈只使用实际观测残差、表面支持及置信变化，不能从评价器读取真值收益。当前冻结外形任务尚未完成这一收益头的实现和效能验证，历史其他指标下的原型结果不能直接迁移为此处证据；也不能因上述四篇未采用相同表述而自动认定新颖性。

为辨别条件收益预测的实际价值，对照应包括能够补看、主动探查和随时改选的强几何方法，以及“结构模板预测可见收益＋实测纠错”机制基线。模板只能来自合法历史或共同训练集；各方法共享实例接口、候选、后端、导航守卫和真实成本。进一步使用同容量无类别收益头、固定类别规则、类别置换及去反馈消融，检查收益是否确由类别条件信息产生。若模板机制已解释全部改善，或几何方法通过合法短探查即可追回收益，则应收回相应贡献主张，而非限制基线的改选能力。

系统实现保留 ANS 全局—局部层次和 OV-SDF、STGHP、RPN-UQ、IGCR 四模块接口，模块名称与组合本身不作为新颖性证据。当前 CPU 虚拟传感、共同建图及接口原型可用于分层验证，但不等同于原神经系统已闭环运行；人工可见类别只用于机制检查，自然语义识别、含定位误差的 SLAM 以及 ROS 1 实车效果均需另行验收。两设施、两父布局的成对实验也仅用于判定机制，不代表大规模泛化。后续依[四个月计划](/root/NSO/docs/research/GRADUATION_RECOVERY_PLAN_20260915.md)先完成有限机制判断，再开展训练、留出环境和实车验证；所有正负结果均按其实际证据范围写入论文。
