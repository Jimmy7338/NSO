# V40 项目与论文升级计划：多场景语义主动建档及可复核系统展示

日期：2026-09-20。状态：**设计稿，未启动新实验**。本计划响应“先设计 plan、暂不考虑小车现场部署”；保留 ANS 全局—局部层次及 OV-SDF、STGHP、RPN-UQ、IGCR 四接口，保留可验证语义创新。历史 V39 代码、结果、指标、论文 PDF 和封存文件不改写。本文件不是新的实验结果，也不自动启动或恢复应用 Goal。

## 1. 研究定位与交付目标

推荐主线：**覆盖与返航约束下，利用设施类别知识预测互补观察的价值，以实测几何反馈修正先验，在有限预算内提高多设施三维建档质量。**

建议英文题目方向：*Semantic-Conditioned Active Reconstruction under Coverage and Return Constraints*。中文毕业论文可保留主动 SLAM 系统背景，但以精确模拟位姿执行的主实验只支持主动观察与重建规划；不得据此声称定位精度提高或未知环境神经 SLAM 已验证。

按 T-RO/IJRR 类研究的贡献完整性设计工作，以“可审查的主张—实验—图表”组织论文；投稿渠道在核心证据完成后确定。四个月优先确保完整毕业稿、可运行 CPU 系统、可靠多场景结果和演示。顶刊录用不是通过增加实验量、篇幅或美化图像可以保证的结果。

顶刊方向的候选贡献收敛为三项，均须由新证据支撑：

1. **条件观察价值建模**：类别信息在已测几何尚不足时提供动作相关预测，且允许在类别无用或错误时回退。区别于按类别固定加权，不以“引入语义”本身作为新颖性。
2. **多设施闭环预算分配**：在探索、补看、转向和返航之间选择可执行路线，实测新证据可以改变设施优先级和观察方向。区别于逐对象独立扫描及只优化终点视角。
3. **条件与边界的系统实证**：在独立布局、不同设施与观察难度下验证效果，并用置换、几何对照、反馈消融及分布偏移解释收益和失效。

SPP 已涉及语义预测与纠错，SWAP 已涉及语义巡检，VISTA 已涉及任务相关视向覆盖。新颖性必须具体到本文模型、决策规则及实测收益，不能靠四个模块名称或乘积指标建立。详细工作对照见 [文献与基线计划](../research/V40_LITERATURE_AND_BASELINE_PLAN_20260920.md)。

## 3. 先修扩展能力，再扩大实验

### 3.1 四模块保留，内部按多设施任务升级

| 接口 | 计划内部实现 | 验证方式 |
|---|---|---|
| OV-SDF | 按设施维护已测表面、实例关联、类别证据和结构分布；类别重复出现不重复累乘置信；未识别实例保留几何路径 | 实例交叉污染检查、类别置换、未知类别回退、留出形状预测 |
| STGHP | 全局分配探索/设施子目标，局部执行有转向成本的短时域路线；对比单步贪心与固定设施访问顺序 | 相同候选与成本下的完整轨迹对比，候选覆盖与计算预算统计 |
| RPN-UQ | 所有策略保留碰撞检查和返航预算；有不确定性时比较风险建模与共同保守保护 | 贴近障碍、定位扰动和预算边界检查；不靠关闭安全保护制造消融劣势 |
| IGCR | 只由已执行传感的几何残差、观测支持和类别冲突修正信念，抑制重复无效访问 | 正确/错误类别下分别开关反馈；看动作变化及实测质量，而非只看后验数值 |

当前代码的单设施所有权、全局类别账本、P00/P01 与前缀依赖须先解耦。多个设施的构型不能直接枚举成指数规模的联合状态；优先对象因子化信念、有限路线候选和短时域滚动执行，记录近似造成的误差。具体代码位置与实现门见 [实验和实现计划](../research/V40_EXPERIMENT_AND_IMPLEMENTATION_PLAN_20260920.md)。

### 3.2 两条任务轨道，结论分别写

- **机制轨道**：保留可比较的共同前缀，隔离同一观测历史下的语义决策价值。用于回归与因果诊断。
- **系统主轨道**：取消固定观察前缀，从动作 0 自主选目标、探索和补看；第一版允许各方法共享明确披露的粗导航/安全先验，实例只能由实际观测发现。公共安全图不等于在线探索未知地图。

粗导航先验不额外提供未发现设施的真实构型、网格或逐实例评价ROI。若某任务必须公开资产位置目录，作为另一种有资产清单的任务条件，所有方法同等获得并单独报告。主协议的设施清单与评价ROI由离线评价器维护，规划器不读取它们来发现目标。

完全未知地图导航、真实 SLAM 后端和 GPU 神经重建作为独立条件扩展。本轮计划不把它们列为 CPU 主线与毕业交付的阻塞项。若论文要宣称未知场地探索或 SLAM 定位优势，必须完成对应扩展后再增加该主张。

### 3.3 语义输入也要分层验证

先用清楚标注的可见人工类别提示检验规划机制；随后在虚拟 RGB 上采用可在 CPU 执行的类别前端，按实例、网格与纹理划分开发/测试，并报告类别混淆、置信度及拒识。几何 G 可以读取同样几何，语义方法也不能读取隐藏构型 ID。

主扩展须超出“精确二选一真值模板”：用开发集确定的类别结构分布或多个原型预测观察需求，测试包含同类未见尺寸、附件及部分不在原型库中的形状。已测模型始终只由真实执行的深度融合；预测表面只参与规划。不要求为了模块名称强行训练大网络，原开放词汇/神经能力如未实际执行则继续标为未验证。

## 4. 六类场景及其科学作用

场景可以围绕目标问题设计。先规定遮挡、结构规律和预算条件，再生成并冻结完整场景集合；开发中看过的场景不再成为测试场景。不能依据本方案是否获胜筛除测试布局。

| 场景族 | 实际问题与机制变量 | 主要比较与预期检验 |
|---|---|---|
| A 机柜/机房通道 | 服务侧、通风结构及开口需要互补方向观察；通道覆盖易先完成 | 类别条件选向是否减少走错侧面的代价 |
| B 仓储货架与遮挡工位 | 多层结构、侧向遮挡、同类实例规律；几何缺口与类别知识都可能有用 | 强几何 NBV、SPP 类结构预测与本方案如何分配观察 |
| C 混合实验室/设备区 | 简单与复杂设施混合，多个设施竞争有限预算 | 系统能否按剩余可获得质量而非固定类别权重分配预算 |
| D 几何充分的开放区 | 可见结构易判断、设施简单或类别与隐藏结构无额外关联 | 语义应接近零收益并避免明显额外损失，是主矩阵中的中性组 |
| E 大范围与覆盖压力 | 面积、通道长度及预算稀缺；少量设施值得观察但探索成本高 | 覆盖—质量取舍、达标成本、过度补看是否损害任务成功 |
| F 先验失配与识别扰动 | 错误类别、未知类别、同类结构例外及漏检 | 反馈和回退是否限制损失；不得期待所有情况下仍优于几何 |

候选规模：小型约 12×12 m、4–6 设施；中型约 20×20 m、8–12 设施；较大型约 30×30 m、16–24 设施。数值是资源预检前的设计值，不代表当前渲染与规划已经能高效运行，也不直接称城市级或超大规模。

A–D 各留出 6 个父场景，共 24 个；每族兼顾小中大与遮挡变化。E/F 各留出 6 个父场景，共 12 个边界场景。父场景的对象组合、布局拓扑和网格实例须有实际差异；镜像、旋转、噪声重复和同一设施的左右构型仍归属于同一父组。每族 6 个父场景只能提供有限的分族精度，不保证足够检验所有交互作用。

场景来源采用两层：可控程序化/CAD 场景负责隔离机制；小规模外部网格/公开室内资产负责减少对自建几何的依赖。外部资产按实际体积、标注、许可及可渲染性选择，先检查一个场景。Replica 官方提供几何、纹理与语义实例信息及渲染示例，但“headless”不等于已经验证无 GPU 可运行；其资产不必然包含本任务所需的结构规律。[Replica 官方说明](https://github.com/facebookresearch/Replica-Dataset/blob/main/README.md)

如果仅在程序化设施中有效，应明确按受控场景论文写；外部场景中的零增益也是有效边界，不能添加新类别权重把分数补回来。

## 5. 方法比较的层次与公平性

### 5.1 共同 CPU 主矩阵：目标八种方法

| 方法 | 用途 | 必须保留的能力 |
|---|---|---|
| S 本方案 | 整体效果 | 实际四接口、类别条件预测、反馈与预算规划 |
| G 同构几何 | 识别语义净增量 | 与 S 相同几何、结构知识来源、规划容量、反馈和安全约束；只屏蔽类别条件 |
| 几何质量 NBV | 强非语义对照 | 主动发现缺口、绕行补看、朝向与路程成本 |
| 固定语义/结构无关语义 NBV | 验证“值得多看”是否足够 | 可读类别并补看，但不使用类别条件隐藏结构分布 |
| Frontier 探索 | 解释覆盖效率与任务差异 | 正常前沿维护、可达性和返航；不作为唯一几何对照 |
| SWAP-I 或通过合同检查的原规划核心 | 语义巡检质量 | 正常巡检与几何探索；若缺少孔洞模块须披露 |
| VISTA-I | 任务相关视向覆盖 | 真实类别相关性、历史视向与非零可执行决策 |
| SPP 类结构预测强对照 | 最接近预测与纠错的前作 | 由已观测实例形成图、重复结构预测与预测失配处理 |

S/G/几何质量 NBV/固定语义 NBV 为四种必做核。优先完成与 SPP 的接近工作对照；具体是原核心迁移还是机制适配，以开发期输入合同和原版能力检查确定并实名记录。方法名单与实现层级在测试前冻结；只允许依据接口/资源可行性收缩，不能查看测试名次后选择对照。

所有方法使用同一传感模型、已付费观测原则、地图融合及评价代码；路径不同时各自获取自己的实际观测。共享合法先验，分别记录其是否使用。相同初始状态、预算与噪声配对机制；前进、转向、停留拍摄都收费。调参仅使用开发布局，同等调参配额，保留失败配置。外部机制须先在作者任务或解析例上验证关键行为，防止适配器无意削弱基线。

### 5.2 原生规划器/完整系统单列

优先级：**任务匹配的 SPP/SWAP 语义规划核心 → TARE 传感/朝向和执行适配完善 → 条件允许时的其他完整系统**。TARE 不再按当前带大量等待的成绩直接进入公平排名。先完成窄视场、朝向、关键帧触发、地形和路点执行的合同检查，拆分每个实际动作由谁选择。

原版语义网络、重建后端或硬件资源不同的系统比较可以回答整体管线效果；它不能用于单独归因规划或语义模块。VISTA、ActiveSplat、ActiveGS 等原神经/高斯路径的 GPU 需求需按固定版本核查；CPU 机制适配保留其名称后缀，不冒充原版。GPU 对比不是本阶段必做项。

## 6. 实验矩阵、预算与阶段门

以下是**拟定上限和分阶段交付**，不是已获结果或自动批量执行指令。

| 批次 | 拟定组成 | 新主轨迹数 | 作用 |
|---|---|---:|---|
| P 两周开发试点 | 独立开发场景，接口/因果/资源检查；失败计数 | ≤48 | 决定模型、候选、分辨率和对照名单是否可冻结 |
| M 共同 CPU 主比较 | A–D 24 父场景 ×8 方法 ×2 传感种子 | 384 | 系统均值、配对差、场景族边界；四必做核为192条 |
| B 边界与偏移 | E/F 12 父场景 ×S/G/固定语义 3 方法 ×2 种子 | 72 | 覆盖压力和先验失配，不与主比较混为新独立确认 |
| A 机制消融 | 预指定8个主父场景 ×4新增政策 ×2种子 | 64 | G/S复用主矩阵；不重复计样本 |
| N 原生系统比较 | 独立冻结条件、通过适配门的完整规划器 | ≤48 | 单列原核心或系统效果 |

完整共同 CPU 扩展目标为 **520 条主轨迹**；必做核收缩版本为 **328 条**（192+72+64）。加试点和原生比较的拟定上限为 616 条；这些数字不含重放，且所有失败主任务都占用配额。旧 V36 的 35/36 和 V39 的 20 条保持历史原值。

四种新增消融政策：类别置换 X、正确类别无反馈 S-nf、错误类别无反馈 X-nf、相同语义输入下的短视贪心 S-myopic。X/X-nf 用同一置换规则；所有政策保留安全与返航。RPN-UQ 以独立合同与扰动检查验证安全设计，若其不确定性内部没有真正实现，不制造“去 RPN 后撞车”来声称该创新有效。

重放单独计数：开发与关键因果条件完整重放；正式批次至少对预先指定的每场景族/方法代表条件做全策略重放，所有主轨迹做封存和传感/建图完整性检查。确定性软件如资源允许全部策略重放；异步原生 ROS 的固定动作重放只验证传感与建图，明确不等于原策略重复。不能只重放胜例。

预算、噪声和偏移不做无限全排列。主表固定一个典型预算规则；覆盖压力进入 B 批次。要画同一场景的预算/噪声连续响应曲线，必须另行给出预冻结的配对设置与计数，不能把不同场景散点伪装成同场景扫参。中途算法改动后的测试场景转为开发数据，后续只能使用此前隔离的备用组。

### 两周开发门的具体要求

1. 多实例不串扰；设施发现来自实际观测；类别置换只改变类别条件；候选真实 World/GT 查询为零；结构假设不进入实测 TSDF。
2. 从动作 0 自主执行至少两种开发布局；探索、补看、返航均实际发生；几何对照能够主动补看。
3. 新模型在预先定义的目标开发层提供有实际意义的收益。建议门为 S/G 平均 J 提高至少 5%、覆盖及合格率不下降；这是开发工程目标，不能作为确认显著性门或论文保证。
4. 中性组不出现无法解释的持续语义奖励；置换/错误类别能暴露依赖，几何反馈有合理的损失抑制。负控制如果没有预期行为，先审计而非扩大样本。
5. 给出小中大场景的 CPU、峰值内存、磁盘与候选数记录，能够完成一批受限任务并可重放。

第 7 天作接口与资源评审，第 14 天固定是否升级。允许一次针对已定位实现缺陷的更正并保留旧记录；两周后不通过则继续完成已有成果论文、收窄扩展主张并报告失败原因，不删除语义创新或四模块约束，也不无限继续同一设计扫场景直到获胜。

## 7. 指标与统计：结果要能被解释

保留 J=C×Q，但多设施的新 Q 需单独冻结，不能和 V39 单设施数值混合。V40主参考集合拟为在预定义可达候选视点及传感工作范围内可观测的设施外表面，符合条件的水平面、竖直面均纳入；封闭内部、地底面等不可观测面排除。该集合由独立评价器一次性确定，对全部方法相同，不能按每条轨迹实际看到了哪些面重新裁剪。V39仅外竖面的口径保留作历史辅助，新口径须先通过评价合同检查再用于正式测试。

- **主质量**：所有任务设施的实例等权表面 F1@5cm，漏检/漏建的任务设施计零；同时报告表面积加权 F1、precision、recall、距离误差及2/10cm敏感性。实例等权防止大型简单设施淹没小型困难设施。
- **覆盖与代价**：公共可达域覆盖曲线、前进距离、转向、付费观察、预算、规划延迟 p50/p95、峰值内存。模拟运动时间与实际 CPU 耗时分别报告，不称实际机器人实时性。
- **任务资格**：预算内覆盖达标、零碰撞、准确返航。报告全体计划任务分母及失败原因。除原始 J 和完成例条件均值外，冻结资格调整效用 U=1[合格]×J，并将失败计零，防止仅报告幸存任务。
- **多设施效果**：逐实例质量分布、达到质量门的设施比例、最差四分位实例质量、有效新观察与冗余观察比例。比例必须有独立定义，不能用“看过次数”替代重建质量。
- **全场景辅助检查**：另报共同域的占据准确性及全场景几何质量，区分“已知区域更多”和“建图更正确”。墙面/地面的大面积得分不能替代设施宏平均；设施ROI内高分也不能代表全场景模型都准确。
- **联合收益形状**：J 和覆盖/质量分解随已付成本变化；在固定检查点从实际历史重建并离线评价。截止点后未达标记为未达/删失，不把截止时刻伪装成已达标时间。

主统计单位是父场景；2个噪声种子、多个设施、帧和重放不是额外独立样本。先在父场景内部做配对聚合，再按场景族分层给出父组 bootstrap 95% 区间、绝对差、相对差、胜/平/负及失败率。预设主要对比为 S/G 和 S/最接近结构预测语义基线，主表对A–D四族等权汇总；A–C目标组与D中性组的分组分析在测试前声明，不在结果出来后另选有利组。其他探索性对比标明，涉及多重检验时修正。24父的规模是可行性目标而非已证充分统计功效，最终数量可依据开发方差在打开测试结果前调整。

模型、预算规则、实例权重、可观测参考表面、ROI、阈值、采样随机数和失败规则全在测试前固定。所有方法用共同参考分母，不以各自可见表面作为自身分母。参考网格、评价色标和最终真值只在离线审计/展示层使用。

## 8. 理论与方法写作

理论围绕实际决策问题写，不增加无法对应实现的定理。

1. 条件信息价值：同一候选集、正确条件模型、可以忽略语义且不计额外成本时，条件信息不降低期望最优效用；证明成立的条件及严格增益需要改变最优动作的条件。它不是手工先验必然提高 F1 的证明。
2. 实际成本与错先验：语义预测价值需减去推理、运动与错误决策代价；给出无收益、错误先验及预算不足的反例，并对应 D/E/F 场景。
3. 返航可行性：仅在公开静态安全图及执行模型成立时证明逐步保留返航预算的不变量。定位扰动的经验鲁棒性不能替代概率安全证明。
4. 算法近似：写出多对象因子化、候选裁剪和短时域规划的计算量；实测候选数量与延迟，不能把固定支持集的次模性质直接用于非单调 TSDF F1 乘积。

所有被使用的符号、先验来源、训练集、超参数和停机条件与实际配置对应。文献综述按“信息来源—预测对象—规划目标—反馈—任务条件”比较，包含最接近语义方法的真实优势。

## 12. CPU、存储与复现预算

V39四种共同CPU方法各4例的中位总耗时约8.8–14.3秒，只说明旧分辨率/单设施运行记录；宿主存在其他任务，不能作速度排名或按设施数线性外推。新场景先实测小中大各例，再估算 `轨迹数×单条p95耗时×重放系数`；保留数据生成、规划、融合、评价和显示各段计时。资源紧张时减少并发与预先声明的比较范围，不能运行后删除慢方法。

本轮只读检查时持久磁盘约0.7GiB可用，尚不具备扩展批次和公开大数据集的存储条件。执行前要求持久可用空间至少 `max(10GiB, 2×预计本批峰值+2GiB)`，或采用通过同等恢复检查的外部持久存储；该阈值是工程预算，不是本轮已满足的条件。先清理确认无效的可再生缓存或取得持久容量，保留唯一实验、权重和封存源码。RAM缓存重启会消失，不作为唯一证据存储。

每批固定commit、配置、场景清单、划分、种子、依赖版本和SHA；建立实际启动/完成/失败/重放账本。场景审计和最终评估处于规划器权限之外，图表与论文数字由已封存结果构建。文档变动不回写V39发布包；远端推送等待之前具体目标授权问题的答复，本计划不重试被拒绝的推送。
