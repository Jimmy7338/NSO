# 可纳入正文的算法描述：预算约束下的一次诊断信念规划

2026-09-28。以下依据已保存 CPU 实现整理；没有运行新实验，也没有修改控制器。第1节与算法1可直接用于正文，第2节用于编辑核对。

## 1 数学定义与执行过程

算法面向工业设施在当前配置下的预算受限主动建图。布局调整引出再次获取环境几何的需求；在下面定义的一次任务内，设施几何保持静止，算法不承担跨时刻变化检测、历史地图增量更新或动态避障。决策侧选择观察姿态，局部执行侧检查动作与返航条件，四模块将观测登记、规划、守卫和反馈连接为闭环。

输入为共同安全姿态图 \(\mathcal G\)、起始姿态 \(s_0\)、两个公开模板 \(T_0,T_1\)、总预算 \(B=42\) 及18步共同前缀。模板包含各姿态的预测深度、扫描和潜在曝光表，G与S拥有相同权限；真实构型、未来实测和评价真值不传入控制器。输出为逐步执行的动作序列、观测账本及实测地图，终点评价在输出封存后独立进行。

在第 \(t\) 次动作后的观测处，规划状态记为

\[
x_t=(s_t,b_t,M_{0,t},M_{1,t},p_t,\mathcal V_t),\qquad b_t=B-t.
\]

其中 \(M_{h,t}\) 为历史姿态对应的模板曝光并集，\(\mathcal V_t\) 为已访问姿态集。构型权重满足

\[
L_t^g=\operatorname{clip}_{[-24,24]}(L_{t-1}^g+\delta_t),
\qquad p_t=\sigma(L_t^g+L_t^s).
\]

首次姿态的 \(\delta_t\) 是有效深度、扫描模态的截断损失差 \(e_1-e_0\) 的均值，再截断至 \([-6,6]\)；重复姿态或关闭反馈时取零。深度与扫描分别至少需要8个有效像素、3束有效扫描。损失为归一化残差平方的一半，上限12.5。类别在两个不同XY位置各获至少16个精确颜色像素且无另一标记颜色混入后，设置 \(L_t^s=\pm\log9\)；重复帧不累乘，已登记的类别发生冲突则清零。G恒取 \(L_t^s=0\)。这些是固定尺度的伪似然权重，未经概率校准。

只有两个模板预测不同的位置参与残差，实测零深度与零扫描距离作为缺失值忽略。深度残差在参考视差域归一化为 \((57.6/z-57.6/\widehat z_h)/0.25\)，扫描使用 \((r-\widehat r_h)/0.02\)。深度模板无返回时取损失上限；没有有效模态则不增加几何证据。扫描的0.02 m是权重尺度，不代表模拟器施加了该幅度的随机噪声。

令 \(\widetilde J_h(M_h)=\widetilde C_h(M_h)\widetilde F_h(M_h)\)，分别使用模板的理想地面曝光和潜在外竖面面积比例；它不是实测 \(J_5\)。预测停止值为

\[
Z(s,M,p)=
\begin{cases}
p\widetilde J_0(M_0)+(1-p)\widetilde J_1(M_1),
&s=s_0,\ \min_h\widetilde C_h(M_h)\ge0.8,\\
-\infty,&\text{其他情况}.
\end{cases}
\]

动态规划状态另含 \(q\in\{0,1\}\)，表示本次前瞻是否仍允许一次未来诊断。动作 \(a\) 将姿态变为 \(s'\)，曝光并为 \(M'_h=M_h\cup E_h(s')\)，预算减一。若 \(q=1\) 且 \(s'\) 为未实测诊断节点，则用假定正确率 \(r=0.99\) 分成两个分支：

\[
\lambda_0=pr+(1-p)(1-r),\quad \lambda_1=1-\lambda_0,
\qquad p^{(0)}=\frac{pr}{\lambda_0},\quad
p^{(1)}=\frac{p(1-r)}{\lambda_1}.
\]

\[
Q_q(a)=
\begin{cases}
\sum_{y=0}^{1}\lambda_y V_0(s',b-1,M',p^{(y)}),&\text{触发诊断},\\
V_q(s',b-1,M',p),&\text{否则},
\end{cases}
\qquad V_q=\max\{Z,\max_a Q_q(a)\}.
\]

其中已实测姿态在每次规划入口固定排除；诊断节点由两公开模板互相比对的有符号证据分别达到 \(\pm\log99\) 判定。诊断后该预测分支不再展开新信息事件；任一诊断分支不可行，动作即不可行。所有状态若返航距离大于剩余预算，价值置为 \(-\infty\)。仅执行首动作并读取新实测后重新规划，预测权重不写入实际账本。

真实地图与模板曝光集合分别维护：地图只融合取得的深度，\(M_h\) 只表示若模板成立可望获得的曝光，不将模板表面补进网格。前进1 m或转向90°均消耗一个动作；前18步执行共同前缀并回到起始姿态，期间仍更新信念，后续最多24步才由当前权重决定动作。因此本算法评价的是共同观测后的主动决策。

实际执行仍须满足 \(1+d_{\rm return}(s')\le b_t\)。预测主动停止与碰撞、预算耗尽等强制终止分开记录，终止不自动表示任务合格。四模块分别完成状态登记、选向、守卫和反馈；当前执行粒度为原子动作，每次取得新观测后重新决策。

**算法1 付费观测驱动的滚动规划。**

```text
输入：共同安全图和双模板，预算 B=42，共同前缀 πpre，模式 G/S/X/Xnf
输出：实际动作与观测日志、实测地图、停止原因
初始化：Lg=Ls=0；曝光 M0=M1=∅；已访姿态 V=∅；t=0
循环：
  读取起点帧或刚执行动作所得帧；驱动器将该帧融合一次
  构造不含真实构型身份的观测，核验动作、步号和位姿
  OV-SDF：登记类别与地图摘要；IGCR：按首次姿态实测更新 Lg
  M0,M1 ← 分别并入当前姿态在双模板中的曝光；V ← V∪{s}
  若已碰撞或 t=B：记录强制终止原因并退出
  若 t<18：a ← πpre[t]
  否则：
    D ← 公开模板诊断节点集 \ V
    STGHP：求 Vq，其中 Xnf 取 q=0，其他模式取 q=1
    不可行或超过计算限制则报告失败；不将失败写成合格停止
    若停止值在最优值的 10^(-12) 容差内：记录主动停止并退出
    a ← 按公开图边固定顺序取容差内最优首动作
  RPN-UQ：核验 a 是合法边，且 1+dreturn(s')≤B-t
  若守卫拒绝：记录停止原因并退出
  执行 a；t ← t+1
封存输出；评价器独立计算覆盖、表面 F1、J5 和任务资格
```

X交换类别解释；Xnf还同时关闭实测几何更新及未来诊断，不能把X−Xnf写成单一反馈函数消融。单次规划固定上限为150万缓存状态、20秒，当前证据不用于证明大规模求解能力。

## 2 主稿与实现的一致性说明

1. [主稿](/root/NSO/docs/thesis/VIRTUAL_PAPER_DRAFT_20260928.md)采用本方法的分层决策与局部执行表述。当前CPU控制器直接选择下一原子动作，四接口表示具体实现职责；研究贡献围绕类别先验、几何反馈与预算观察规划展开。
2. 规划主动停止仅在起点且双模板预测覆盖合格时可选；实际碰撞、预算耗尽或守卫拒绝也会终止，合格性在封存后另判。
3. 类别登记要求单帧无另一标记颜色混入，并置入对数先验，不将总后验强制置为0.9。当前代码使用精确人工颜色，类别对照检验决策价值，不代表自然分类器准确率实验。
