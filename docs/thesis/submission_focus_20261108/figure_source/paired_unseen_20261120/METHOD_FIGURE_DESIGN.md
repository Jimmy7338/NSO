# Measured Structure

The diagram uses a restrained grid with equal box widths, short labels and generous internal space. Alignment communicates shared computation before differences between forecasts are introduced.

Blue identifies acquired measurements and executed observations. Teal marks hypothetical geometry and prediction. The palette separates these roles without assigning a favorable outcome to either forecast.

Arrows carry only documented data or decision flow. The execution feedback closes around the measured state; source-reference geometry has no arrow into the actor. The two forecast alternatives occupy one shared prediction box so that they cannot be mistaken for additive modules.

The finished figure is a reproducible vector schematic. Spacing and typography are checked at manuscript scale, and editable text and geometry are retained. Scientific fidelity takes precedence over decorative detail.
