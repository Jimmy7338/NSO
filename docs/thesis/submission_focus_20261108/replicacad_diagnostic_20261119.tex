\section{Textured-apartment exploration diagnostic}\label{sec:replicacad-diagnostic}

The unchanged observed-state joint policy, exploration\_joint\_v1/v10\_3\_1, was evaluated on the official ReplicaCAD v1.6 \texttt{apt\_0} apartment with its original furniture placements.\footnote{ReplicaCAD supplies authored reconstructions of scanned apartments; see A.~Szot et al., ``Habitat 2.0: Training Home Assistants to Rearrange their Habitat,'' NeurIPS, 2021, and \texttt{https://aihabitat.org/datasets/replica\_cad/}.} This is one inspected development layout with five paired arms, separate from the supplied-graph V35 study. Each arm starts from the same single RGB-D/laser observation and pose on an unknown map, with exact poses, noise-free $120\!\times\!90$ RGB-D, a $90^\circ$ field of view, 8~m range and 1.2~m camera height. The simulator retains the 0.2~m grid, 0.2~m circular radius, mesh-based collision and floor support, full forward sweeps, a 256-action cap and the original fixed-anchor return rule. Partial oracle labels identify only current first-hit surfaces of one verified open shelf and three opaque drawer fronts; other visible surfaces remain unknown. No hidden geometry or whole-scene labels enter the actor.

Coverage-only C attains higher coverage and surface F1 with fewer actions (Table~\ref{tab:s-replicacad}); G, S, reversed-cue X and S with absent labels have identical complete action/pose traces and native TSDF mesh hashes. Replay of all 31 joint-policy planning states locates the semantic failure at object grouping: labeled measured points join oversized wall/furniture components, which the original 2.2~m extent criterion rejects before class voting. Every retained scoring asset is unmarked, producing identical generic and category prior scores. Thus the tie is not evidence that the scene contains no semantic observations. Reconstruction uses 6~cm TSDF voxels and 12~cm truncation. Surface recall uses 36,766 source-mesh samples visible from a fixed 0.8~m reachable lattice and four cardinal camera headings; precision uses 12,000 reconstructed-surface samples and point-to-source-triangle distances, without per-run alignment. This controlled result supplies no semantic-planning advantage or physical accuracy claim. Separate RGB-only detector probes failed to establish reliable open/closed structural labels and are not the source of these oracle inputs; end-to-end visual-semantic exploration remains unvalidated.

An explicitly declared shared instance-support frontend was then evaluated with the same five arms and partial visible oracle support, giving ten runs across two frontends on one layout; it changes object grouping and is not equivalent to the original extractor. Each adapted arm exactly reproduces its original counterpart's action/pose trace and coverage, although S$-$G scores become nonzero in 17 of 31 planning states; the top two G candidates receive equal semantic increments in all 21 multi-candidate states. For the closed structure, all 1,606 recorded route-state occurrences fail the original rear-aperture condition (largest projection $-0.482$~m versus required $>0.15$~m), so its factor vanishes before the field-of-view test. Both frontend versions use an analytic prior from the observed axis-aligned bounding box (AABB), without invoking the complete two-template hidden-surface module; score activation supplies no trajectory or coverage benefit here.
