# 系统设计与实验协议（论文工作稿）

版本：2026-09-15。本稿衔接[问题定义与相关工作](/root/NSO/docs/thesis/PROBLEM_AND_RELATED_WORK_DRAFT_20260915.md)，区分系统设计、CPU 实现和本批实验；尚未收口的结果不写入正文，待验证部分不作为已完成贡献。

## 系统层次与实现边界

系统保留 ANS 全局—局部层次，以及 OV-SDF、STGHP、RPN-UQ、IGCR 四模块接口。全局层选择区域及观察位姿选项，局部层执行移动和转向，并逐步更新地图与反馈。模块名称及层次组合不作为创新依据。当前 `CPUFourModules` 及设施运行时以确定性观测算法验证接口和数据流，并不等于原 ANS 神经系统已经闭环运行。

| 模块 | CPU 原型的输入与输出 | 在线禁止输入及实现边界 |
|---|---|---|
| OV-SDF | 已付 RGB-D、观测点和标记支持→观测资产、类别票数、密度及方向支持 | 禁用 GT 实例 owner、隐藏类别；当前为人工标记线索，未实现自然开放词汇识别 |
| STGHP | 已观测地图、资产、候选路径和预算→连通区域图、位姿选项及排序 | 禁用真实全图、未付视点深度、未来 Q；区域图不等于已验证的房间语义分割 |
| RPN-UQ | 当前 belief、足迹、动作、剩余预算和锚点→动作许可、拒绝原因及已知返航路径 | 禁用 GT 可达图；当前为确定性守卫，无已校准的学习概率或不确定性 |
| IGCR | 实际动作、连续观测、到达与失败事件→付费账本、覆盖及观测收益反馈 | 禁用评价器真值收益；观测代理不等于设施外形 Q |

运行时核查观测顺序、身份和重复包，前缀历史按同一地图逐包更新。覆盖预算采用固定公共区域的已知格比例及实际净新增速率；障碍格也可计为已知，因此该代理不等于真可达覆盖率，不能保证终点达标。局部守卫要求当前已知安全图上的动作与返航可行，仍不能保证未知区域的实际安全。

拟研究的收益头以相同历史、类别线索、方向和预算预测付费观察后的外形净改善；未来评价差值只可用于离线标签。旧 V11 条件收益模型针对历史观测收益定义，不能据此宣称当前 Q 收益头已完成。共同外形后端已可处理实际深度历史；其观测证据与当前四模块规划闭环的整合仍待验证，评价器 Q 不得直接作为在线反馈。

## 共同表示与任务评价

所有方法使用相同感知和建图契约。本批沿用通用双目视差噪声、5 m 深度与扫描量程、精确离散位姿及 CPU TSDF。主表示从实际深度进行地面估计、组件关联和表面清理，禁用外壳推断；未测部分保持未知，不能按类别补出附件。原始 TSDF 固定旁报，不按成绩选择表示。

令 \(K_t\) 为已知格，\(R\) 为评价侧真实可达格，定义

\[
C_t=|K_t\cap R|/|R|,\qquad
Q_t=\frac1M\sum_{i=1}^{M}\frac13\sum_{p\in\{XY,XZ,YZ\}}
\min\{F_{i,p}^{5\mathrm{cm}},I_{i,p}\},\qquad J_t=C_tQ_t.
\]

其中 \(F\) 为投影边界 F1，\(I\) 为填充外形投影 IoU；全部任务设施等权，漏建记零。Q 衡量外轮廓与投影占用一致性，不称完整三维精度。C、Q、J 分别报告，尺寸、位置及其他容差结果旁报。终点须同时满足预算、零碰撞、返回规定位置和朝向、无执行失败及 \(C\ge0.8\)；中途高分和高 J 不能抵消资格失败。

## 首批成对采集与证据协议

V25 r1 首批仅在 P00 执行“复杂设施位于 A/B”与“补看 A/B”的四个组合。类别及对应外露结构成对交换，工位隔板保持相同，各臂跨排列使用同一冻结动作串。类别不能直接改变评分权重、评价窗口或在线几何输出。实例首先由实际 RGB 两色标记并集及真实深度种子建立；颜色代码另行记录，不能读取隐藏排列冒充语义识别。评价侧再核唯一关联，漏检、误关联和外来几何均保留。

每条独立执行 234 动作公共前缀，再补看并返航；预算上限 400，冻结 A/B 路线分别为 354/340 动作。移动、转向和取信息均真实计费，帧零不替代补看。两臂视点并非镜像、实际成本也不同，分析须检查位置和成本影响。本批路线来自评价侧 GT 设计目录，**没有调用完整自主策略**；该目录不得作为未来在线规划的合法输入。

公共前缀和返航终点均先保存观测表示，再进入 GT 评价。全部传感包、逐步状态、网格和来源哈希留存。每条随后由不同 PID 重新执行动作、核对新传感包，再用保存包独立更新地图和后端，逐项比对阶段几何与指标。回放属于一致性验证，不增加独立环境样本。完整非类别前缀、标记支持及关联均须核对；低 Q、覆盖不足和失败不删，不用最佳中途快照代替终点。

## 后续验证边界

收口时分别报告最佳固定臂、预声明复杂优先规则、反向类别规则及受限事后上限；固定选项参照不称强几何 G。后续自主G/S从相同初始状态出发，共享传感、行动能力、任务知识边界、后端、预算和安全规则，各自根据合法观测生成候选，允许主动探看与改选。只有“给定候选后的排序”消融共用最终几何候选池，不能用共用GT服务目录预先解决目标发现问题。另保留模板预测可见收益加实测纠错基线。只有类别条件增益超出这些解释，才支持进一步训练及留出环境验证。

## 2026-09-16补充：自主候选验证合同

V26将几何观测与语义提示在规划接口处分开。几何输入是已观测栅格、公开传感配置、当前位姿、返航锚点、剩余预算和实测表面支持，不含人工标记位置或类别。实测表面按共同规则采样，不依赖目标类别决定哪些表面可进入G。S另接实际RGB标记与同像素有效深度生成的位置、类别及颜色一致性，并给未见方向提出可被后续观测检验的假设。此人工标记前端不能描述成自然开放词汇网络。

全局规划可在继续覆盖和补看之间选择；局部执行每一步重算观测内安全路径和返航成本。主比较不强制234步公共前缀，候选不含GT附件视点。每次最多4个覆盖候选及8个其他候选，语义方法额外预筛选的查询数量和CPU时间均单独报告。GR排序消融在同一快照严格保留G最终候选集合，GP用于检验类别条件提议，S和去反馈用于后续机制归因；首批仅执行G/S。

当前原型的几何评分依赖可见实测patch的方向、距离和重复观测支持，语义项来自共用稀疏模板的类别条件权重、视野、观测遮挡和方向不足。这些是未校准的规划代理，不能写成真实未来Q、训练好的质量网络或论文已确认创新。IGCR只在实际到达被预测目标且存在足够共同实测支持时校正对应方向；采样集合出现新key不能直接当作新表面，不可判断也不记零收益。当前反馈并非整条选项的累计Q增益。

自主验证沿用P00、两个类别排列、400动作和原C/Q/J，共四条主任务。终点先冻结实测表示再接触评价真值，漏建保留固定位置并记零。独立回放使用不同进程的新世界和新runtime重新产生动作，再核对实际传感、全局候选、局部指令、模块调用、网格及分数；保存动作串不代替自主策略。来源协议为`V26_AUTONOMOUS_COMPARISON_PROTOCOL_20260916.md`及`V26_AUTONOMOUS_ANALYSIS_PROTOCOL_20260916.md`。该批四条主任务与四次成功独立自主回放现已封存；另一次容量故障回放的400动作单独保留。完整结果见 `V26_AUTONOMOUS_RESULT_20260916.md`。两排列的S相对G联合指标分别下降3.574%与1.548%，平均下降2.560%；四条均合格、返航、零碰撞且实例归因检查通过，当前没有整体语义净优势。

两条语义轨迹分别选中方向假设37和30次，各13次到达反馈均因共同支持不足而未更新。首条401份保存观测的全量诊断表明，原256样本仅有0–1个局部共同面片，完整实测几何实际有627–904个。独立V27-A已将反馈索引与规划抽样分离，保留最后一步窗口、原门槛和收益公式，8项小型测试及独立审查通过；固定历史影子验收中，同13事件旧版全拒绝、新版13更新、关闭反馈表为空。

V27随后完成两排列×S／关闭反馈四条新自主任务及四次成功独立回放，四条均合格、返航、零碰撞。第一排列13次反馈更新但轨迹和终点不变；第二排列11次更新，首次下一动作／实际动作在165／166步分叉，C、Q、J均提高，J相对关闭反馈增加4.752%。两排列平均反馈增量为2.404%，但第一排列为0，未通过预设“两排列均严格为正”门。修复后S相对已通过794包策略等价审计的历史G，在两排列的J差为−3.574%与+3.130%，均值相对差−0.217%，完整方案优势门仍未通过。第二排列中简单设施Q增加0.035106、复杂设施Q下降0.009569，不能写成反馈提高复杂设施精度。完整结果见`V27_AUTONOMOUS_EFFECT_RESULT_20260916.md`。

后置V28机制诊断对两条S轨迹的全部24次有效反馈建立选项级Q05标签。末步`/16`代理饱和54.17%，与Q变化的Spearman为−0.04894；整段改进面片比例为−0.14957。24条中11条Q上升、13条下降，且类别2/3反馈为23/1。该结果同时否定当前代理的最低校准证据和复杂类别反馈的可验证性，但不否定语义信息的一般价值。V28改为实例/方向重建债务、复杂类别候选覆盖、保守收益不确定性和完整选项残差；评价Q继续只作离线标签。详见`V28_OPTION_LEVEL_FEEDBACK_DIAGNOSTIC_RESULT_20260916.md`。

自然语义前端、含定位误差的 SLAM、大规模场景和 ROS 1 实车均待验证。实车拟接入 ZED 深度与位姿、单线雷达及 IMU，先核时间同步、坐标变换和安全返航；虚拟通用噪声不冒充 ZED 标定，人工标记结果不替代自然类别识别。
