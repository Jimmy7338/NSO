# 从实测几何到语义条件视角预测：方法补充稿

日期：2026-09-21。本文对应 V42 CPU 实现，可作为论文方法节修订材料。V42 的解析接口验证不替代已有 V39 性能实验，也不构成新开发场景或独立测试集的优势证据。

## 1. 要解决的具体问题

当机器人只看见设施的部分外表面时，几何可以指出已经测到的欠覆盖区域，但不能唯一确定尚未观测部分的结构。类别信息的作用，是为这些潜在结构提供条件先验，从而改变有限预算下候选观察方向的预期价值。语义不直接产生“重要设施奖励”，预测表面也不进入实际重建。

ANS 的全局—局部层次及 OV-SDF、STGHP、RPN-UQ、IGCR 接口保留。当前 CPU 实现的职责是：OV-SDF 保存实测地图与实例结构权重，IGCR 使用当前实测像素更新结构证据，STGHP 计算候选观察效用，RPN-UQ 的已实现部分检查原语运动与返航预算。后者尚无训练后的不确定性网络；这些接口部件尚未完成新的多设施自主闭环实验。

## 2. 观测与结构信念

第 t 步输入只含 RGB、轴向深度、相机内外参、帧号与付费步骤。可选平面扫描独立记录来源。实例首先通过可见人工标记初始化，其后用实测深度支持的唯一重叠关联；没有仿真 owner 或真实设施包围盒输入。

对已观测实例 i，结构候选 z 属于四种共有名义结构。V41 几何反馈得到有界累积评分 gᵢ(z)，V42 使用

\[
p_i(z\mid D_t,c_i)=\operatorname{softmax}_z\{\log\pi(z\mid c_i)+g_i(z)\}.
\]

匹配几何对照 G 使用同一观测、关联、反馈与原型，仅将类别条件先验替换为公共几何先验。语义必须通过多个合格支持观测后才激活；冲突或关联不确定时回退。这里的权重来自未校准设计先验与截断几何评分，不称为已校准贝叶斯概率。

## 3. 候选视角效用

共有原型库含四结构与三个预声明尺度。原型通过实测标记平面估计锚点和朝向，使用公共的标签安装约定；不读取实际场景设施中心、尺寸或隐藏结构。每个原型的实体并集外表面以确定性面积求积离散，内部重叠面不计入面积。

令 q 为原型表面样点，a_q 为对应面积权重，v 为公共候选视点，V(q,v) 表示相机视域、轴向深度范围、朝向与原型自身遮挡条件均满足。令 Sᵢ,t 为实例历史实测支持，尚未观测指示为

\[
U(q,S_{i,t})=\mathbf{1}\left[\min_{s\in S_{i,t}}\|q-s\|>0.08\ \mathrm m\right].
\]

令 E_t(v) 为新视角资格：若候选内参、外参及图像尺寸与任何已付观测的相机一致，则 E_t(v)=0，否则为 1。这里以 1e-9 的绝对数值容差识别同一相机；同位置转向仍是不同视角。这是防止原型失配导致原地重复观察的保守策略限制，不表示缺测像素对应的空间已被测得或已知为空。当前 STGHP 有效代理效用定义为

\[
\widehat{\Delta A}_i(v)
=E_t(v)\sum_z p_i(z\mid D_t,c_i)\frac{1}{3}\sum_{\sigma\in\{0.85,1,1.15\}}
\sum_{q\in\mathcal S_{z,\sigma}}a_q V(q,v)U(q,S_{i,t}).
\]

其单位为平方米。类别只通过结构权重进入该式；没有额外类别重要性系数。平坦类别先验应与 G 一致。置换类别先验可能改善或损害某次预测，不能预设其必然更差。收据同时保存资格限制之前的原始预测、限制原因与对应已付帧来源，以便审查这种策略近似。

目前这只是新表面完整性的代理：没有校准其与实际 TSDF F1 增量的关系；没有建模重复同视角的降噪收益、完整的环境遮挡、标记姿态不确定性积分或尺度后验。8 cm 最近支持阈值是计算近似，相邻平行表面可能互相抑制；它不是评价阈值，评价主阈值仍是预定的 5 cm。外部遮挡尚未建模意味着预测可偏乐观，实际开发验证必须检查这一误差。

原语路由层将预测效用除以到达和观察的动作成本，并要求余量足以返回起始位置及朝向。V42 接线检查只验证该输入连接；完整设施发现、跨设施探索—补看分配、观测障碍更新与运行时限仍需接入任务运行器。

## 4. 实测建图与评价隔离

新 mapper 使用 Open3D CPU TSDF，默认体素 4 cm、截断距离 12 cm。只融合合法付费 RGB-D 帧，轴向有效深度闭区间为 [0.1,4.0] m。原帧重传拒绝；新的合法付费静止帧允许融合一次。预测原型、语义完成面和真实场景几何均不进入 TSDF。

二维占据图接收实际扫描射线与深度障碍点。已占据原点不因“机器人在这里”而强行擦除。当前观测覆盖面积是触及格的并集，不自动等于可通行区域覆盖率；真实覆盖率需要离线冻结的公共评价定义和分母。本轮解析夹具没有扫描，也不计算 C_map 或 J₅。

论文必须区分三个层次：候选预测值发生变化、实际动作发生变化、实际重建质量发生改善。第一层的合同通过不能证明后两层。V42 图展示第一层及实测融合接线，已有 V39 表格保留其原始受控性能证据身份；新多设施主表仍等待真实闭环数据。

## 5. 下一项必须检验的假设

在满足持久存储门后，按已有 R2–R4 开发上限运行共同观测后端与完整任务驱动。记录每次预测的新增表面积、付费执行后新增实测支持、TSDF 完整性/精确率变化及路由成本，先检验代理是否有效，再检验 S−G 的最终 J₅ 差异。中性几何充分组和先验失配组保留；若语义只改变分数却不带来质量提升，应定位预测误差或预算分配问题，不能把分数差写成性能收益。
