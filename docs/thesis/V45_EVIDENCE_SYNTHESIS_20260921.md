# V45：语义构型规划的证据综合与论文结果、讨论补稿

日期：2026-09-21。本文是基于已保存结果的论文补稿，不替换 V39 原稿或 V40—V44 的冻结协议。对应机器可读证据为 `docs/research/V45_CLAIM_EVIDENCE_MATRIX_20260921.json`。本文重新读取 36 条主轨迹的结果与控制器记录，核对各自主任务封存和重放绑定，并从保存的精确率、召回率重算 F1 与联合指标；没有重算表面距离、执行策略、创建 World 或读取正式测试种子。

## 当前可以成立的中心论点

现有结果支持一个有明确适用条件的结论：在公开设施构型库、人工 RGB 类别观测和精确位姿的受控巡检任务中，类别信息可以改变对未观测结构的判断，使有限观测预算分配到更有价值的视角，改善最终表面重建质量，同时保持二维覆盖、预算和返航约束。这里的语义作用是改变构型信念和后续视角选择，并非在评价函数中给某个类别额外加分。

证据尚不能支持“完整原神经 ANS 已全面优于主流系统”“自然开放词汇感知已有效”或“大规模未知环境泛化已验证”。V35/V36 的四模块名称对应 CPU 机制接口；调用了四个接口不等于四个原始神经模块均已训练和验证。V43/V44 是新一代观测驱动实现的工程进展，不能把旧 CPU 策略的成绩自动移植给新控制器。

## 评价口径与样本单位

旧受控实验的主指标为无量纲终点联合得分

\[
J_5=C_{\mathrm{map}}F_{1,5},\qquad
F_{1,5}=\frac{2P_5R_5}{P_5+R_5}.
\]

其中二维覆盖率的分母是完整可达评价栅格；三维召回率的参考是固定的完整设施外部竖直表面，而不是机器人已经看见的表面子集。预测表面按公共设施联合 ROI 提交，因此旧协议不处罚 ROI 以外的错误表面。这是其适用边界，不能与 V40 后续扩大评价域的分数直接拼接。F1 同时体现几何精确率和表面完整度，不宜只称为“定位精度”或“误差降低”。下文相对改善均为两组均值之比减一，不是逐条件百分比的均值，也不是最终二维覆盖率提高了相同比例。

V35 包含一个已知布局 P00 的两种结构条件；V36 包含 P00/P01 两个已见布局及各两种结构条件，冻结策略后使用保留的噪声条件确认。P01 的理想几何此前已检查，因此“确认”不等于“未见几何泛化”。V39 在相同条件下增加外部对照。运行条数、结构条件、独立布局和重放次数须分别报告；重放不增加独立样本。本补稿不实施显著性检验或生成置信区间。

**错误语义与几何反馈。** 在 V35 的已知 P00 开发条件中，正确类别 S 的平均 J5 比交换类别 X 高 0.099011（相对 X 为 14.7283%）。在同样的错误类别输入下，保留反馈的 X 比 Xnf 高 0.017190（相对 Xnf 为 2.6241%）。两个主阈值配对差分别为 +0.016571 和 +0.017808。既有同状态干预审计在首次纠正的第 28 个付费观测处固定位置、历史与未来信息条件，仅替换后验；两种结构条件的下一动作均改变。该审计是两个保存状态的决策干预，不是两条新增实物或仿真终点轨迹。

反馈收益依赖误差容限：在 2 cm 阈值，h1 的 X−Xnf 为 −0.002159，不能表述为所有条件、所有精度要求均有改善。反馈只部分修复错误语义，X 的均值仍低于正确类别 S。V36 没有重新执行反馈开关消融，所以反馈结果须标注“开发消融”，不与确认集语义主效应混成同一证据层级。目前也没有四模块独立开关的完整因子消融，尤其没有证明当前 RPN-UQ 不确定性项的独立规划收益。

**共同 CPU 外部机制比较。** V39 的 G、S、SWAP-I、VISTA-I 共完成 16 条主轨迹及 16 次完整策略、传感、建图复现。方法间使用共同公共任务信息、付费观测和预算约束，全部达到相同的条件覆盖率。S 相对 SWAP-I、VISTA-I 的平均 J5 差分别约为 30.35% 与 16.37%。这些差值同时包含目标函数、结构预测和规划策略的差异；只有 S/G 的配对对照用于估计本系统内的类别条件构型增益，外部差值不全部归因于语义。

两个外部对照均实际启用了语义：从保存的候选评分记录重计，SWAP-I 与 VISTA-I 各有 96 次自主决策带正语义项；同状态去除语义评分会分别改变 9/96 和 12/96 次首动作。SWAP-I 实际作出 89 次巡检决策、7 次几何探索回退。这里的去语义结果是候选排序诊断，没有执行反事实轨迹，不能作为完整的外部方法消融终点性能。论文中应始终使用 “SWAP-inspection-inspired/CPU” 与 “VISTA-view-inspired/CPU” 全称或明确缩写，避免误写成原作者完整系统复现。

## 讨论与新协议的衔接

现有证据最清楚地回答“类别信息是否能在一个构型不确定的受控任务中产生可追踪的观测收益”，而不是“语义分割网络是否已经足够强”。两个无收益条件也有价值：当类别先验不改变最有价值的路线时，语义不会凭空提高重建质量。因此论文创新应落在**可被观测校正的类别条件构型信念及其观测分配机制**，避免将“高语义区域多看几次”作为缺少条件的普遍规律。

旧结果的主要局限是一个人工设施族、两个已见布局、公共构型与安全导航先验、人工类别标记、精确仿真里程计以及限定 ROI 的表面评价。它们保留了因果解释性，也限制了外推范围。自然感知网络性能与真实位姿漂移仍是不同问题，当前虚拟结论不能替代它们。

V40—V44 的作用是准备更严格的多实例和多场景验证：观测产生实例、预测只使用当前付费历史、几何安全检查使用实测占据、保存完整预测后独立重算与评价。V43 的 56 项合同测试与双固定帧接线、V44 的保存观测重算均属于实现验证；其保存结果明确记载实际开发 World 和新增自主性能轨迹为 0。六张静态导航图与 A/C 评价参考不等于六个场景的自主性能结果。当前不确定性惩罚默认值为 0，也不能写成已证实的不确定性规划创新。

论文可先将上述受控结果作为机制证据章节，V39 的 CPU 比较及 TARE 迁移作为不同层次的外部证据，把 V43/V44 放入可复现实现和评价方法章节。随后按冻结顺序执行往返诊断、A/C 开发语义对照、保存观测重算和完整表面评价，再决定是否进入正式多场景矩阵。DEV A/C 结果即使为正，也仍是开发结果；正式场景、无语义相关性场景、错误语义条件、不同预算及失败案例须保留预先声明的口径。禁止将旧得分与新评价域直接合并成持续上升的改进曲线。
