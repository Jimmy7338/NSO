## 实验回答什么

1. **类别信息的增量。** 原确认批两已见父布局×两构型的G/S比较，主指标均值相对提高6.1638%，两胜两平。双方共享主动几何规划与融合能力，区别为是否使用类别信息。
2. **错误类别的纠正。** 开发批X/Xnf的完整纠错政策比较，5 cm主指标均值相对提高2.6241%，保留2 cm的一个负例。该比较同时改变实际纠错和未来纠错预期。
3. **不同观察分配机制。** SWAP-I/VISTA-I在共同CPU条件下适配相关机制，后端相同；目标和规划细节不同，不构成原作者完整系统排名。
4. **预算、噪声与同族几何。** 固定128项任务已全部执行：96项完成且合格，32项B=30任务在共同前缀后因控制器规划不可行而失败。原布局B=42的S/G平均J5相对提高6.2505%，同族变体B=42提高4.2289%，均为4胜4平；原布局B=54为−0.6995%，0胜4平4负。全部资格与失败均已报告，合格配对分别解释质量差。结果见[独立扩展报告](../research/THESIS_EXPANSION_RESULT_20260928.md)和`audit_results/thesis_expansion_20260928/analysis_review/`，与旧确认批分开，不以种子数冒充独立布局数。

原“最多16条”的预算备选由本轮128项独立扩展替代。9月23日原冻结分支未完成项与收益门状态不变；后续共享可靠性分支的零/负结果继续在讨论中说明，旧J5与J_nav不混池。解析类别可靠度混合仅组合已运行的正确/错误类别结果，不增加任务数。

## 本地构建

```bash
python3 -B scripts/build_virtual_paper_review_20260928.py --render --export
python3 -B scripts/build_writing_deliverables_20260928.py english --render --export
```

脚本使用现有Pandoc、`tmp/thesis-tex-runtime_20260928/`中的缓存Tectonic、本机字体及`tmp/thesis-python_20260928/`中的渲染依赖。构建只排版，不导入模拟、规划或重建模块。中文日志和预览位于`tmp/virtual-paper-review_20260928/`；`--export`仅把本地审阅文件复制到`docs/thesis/`，不投稿。
