# Official Elsevier template snapshot

Retrieved on 2026-09-29 (Asia/Shanghai) for the NSO manuscript-formatting audit.

The archive was downloaded through the link on [Elsevier's official LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions):

[Original publisher-linked elsarticle.zip](https://assets.ctfassets.net/o78em1y1w4i4/4MpsJHO0MOJ2xZuwGTAbOZ/7bc64af36477c5d6cfce335a1f872363/elsarticle.zip).

`elsarticle_official.zip` and `upstream/` retain the downloaded bytes. The publisher's README, notices, example files, documentation, and manifest are preserved. The upstream README licenses the package under the LaTeX Project Public License, version 1.3 or later, with author-maintained status and Elsevier copyright. These files are third-party publication tools, not NSO scientific implementations.

The archive supplies `.dtx` and `.ins` sources. Its README describes `latex elsarticle.ins` to generate the class. No bundled build commands have been run here. Do not assume the archive contains a ready-made `elsarticle.cls`.

This is the publisher's general article template. It is not a verified journal-specific RAS template. The local default is its numerical-citation preprint example; the RAS guide could not be retrieved because its official current and legacy URLs returned HTTP 403. Those unresolved requirements are recorded in [the fit report](/root/NSO/docs/research/FINAL_JOURNAL_FIT_20260929.md).

Use a separate working directory for manuscript adaptation. Preserve upstream attribution and license notices. No author, institution, funding, review mode, or submission-approval information is inferred from these examples.
