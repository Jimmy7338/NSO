## 数据选择与实际范围

固定使用 `audit_results/v39_external_cpu_20260920` 的四条完整保存轨迹：

| 离线条件 | G 几何基线 | S 语义条件策略 | 选择含义 |
|---|---|---|---|
| P00 / h0 | case00 | case01 | 保存的零增益控制，两者动作和终点评价一致 |
| P00 / h1 | case04 | case05 | 此前公开过的正例；决策 18 首次选择不同的后继动作 |

每条包含初始观测及 42 个付费动作后的观测，共 172 帧。第一至第十八个动作是各方法共有的付费前缀，之后才由在线规划选动作。四条轨迹来自同一个父布局的两个条件，不能增加为四个独立场景样本，也不能证明自然设备或自然语义网络的优势。

输入图像为真实保存的原生 RGB 96×72、轴向深度 96×72；显示时仅放大。深度统一色标为 0–4 m，无效、缺失或范围外值用灰色。轨迹图展示已执行路径、当前相机朝向和当前帧每四像素抽取的实际深度投影；背景仅有坐标与公开任务范围，不读取 GT 设施几何或评价地图。

结构条形/时间线显示控制器保存的全局两个模板权重，明确标为未校准。它不是多设施实例概率，也不是训练完成的神经不确定性模块。候选条形使用保存的公共模板代理值，返航不可行的 -1e30 哨兵改为空值和“不可返航”，没有把代理改称实际 F1 或 Q 增量。

## 使用与时间边界

页面默认打开 P00/h1 的第 18 步，可立即对照 G 左转、S 右转的保存决策。提供条件选择、播放/暂停、时间拖动、回到第 0 步、首处分歧跳转及关键事件选择。1/2/4 步每秒仅表示展示速度，与传感仿真时间或 CPU 运行耗时无关。

关键事件由保存日志确定：首次语义权重更新为第 6 步，共同前缀完成为第 18 步，首次几何反馈更新为第 28 步，真实终点为第 42 步。h0 没有后继动作分歧，对应按钮禁用。决策时刻与执行时刻严格区分：第 t 步读入的观测对应决策 t，所选动作在第 t+1 步实际执行。

| 当前付费步数 | 显示的真实 TSDF | 可选离线评价 |
|---|---|---|
| 0–17 | 无保存快照，显示占位说明 | 无 |
| 18 | 第 18 步 prefix 保存网格 | 仅 prefix 保存评分 |
| 19–41 | 仍为第 18 步网格，明确标注当前步没有网格 | 仍为 prefix 评分，明确不是当前步新评分 |
| 42 | 第 42 步 final 保存网格 | final 保存评分 |

八个网格端点均以 Pillow 绘制全部保存三角形，提供三种全方法共享的正交相机预设。视图采用共同公开平移与坐标范围，没有网格配准、抽稀、补洞、预测表面或 GT 叠加。颜色仅区别 G/S，阴影仅辅助辨认形状，不是误差图。没有连续重积分或最终网格渐显动画。

“离线评分”默认关闭，打开后才显示当前已到达快照的 C_map、F1@5cm 和 J5。这些值直接摘取保存结果，完整外部垂直参考面作为召回分母；公开 ROI 外误差未计入。评分在独立 `evaluation` 数据层，不进入在线帧/候选/信念。单 HTML 在物理上包含完整保存记录以支持离线拖动；时间门控约束界面呈现，不是阻止使用者查看源代码的访问控制。

## 导出白名单与可复核性

在线帧仅含：付费步数、已执行/后继动作、观测位姿与时间戳、原始 RGB/深度的图像引用、当前帧深度投影、有效深度比例、选定的权重/残差摘要、实际人工类别线索、候选摘要及来源摘要。字段由 `FRAME_KEYS` 显式限定。

不会导出 packet metadata、语义真值数组、隐藏构型作为控制输入、evaluation_floor、GT 网格、控制器的完整 potential/mask 内部表或未来实际质量作为预测分数。页面上的 h0/h1 仅用于标记离线案例，在线控制器结果原样读取，导出器不重新决策。来源面板区别“NPZ 文件 SHA256”和“日志记录的逻辑包摘要”，两者原本不同，不互相冒充。

manifest 保存所有 202 个输入文件的路径、字节数和 SHA256；导出后再逐一检查未变化。记录渲染相机、原生像素、深度规则、网格可见时刻、源代码 SHA、Python/NumPy/Pillow 版本和 HTML 输出 SHA。输入包括四例 trace/controller/result、172 个 NPZ 包、八个网格和对应 crop、公共配置与导出脚本；不读取场景 GT 网格。

首次构建：目录合计 **2,864,219 字节**，125 个去重内嵌图像，低于 20,000,000 字节上限。每次构建前要求剩余空间大于 64 MiB 加输出上限，构建后保留至少 64 MiB。最终精确字节与 HTML SHA 以当前 manifest 为准；重复构建有意不加入变化的构建时间戳。
