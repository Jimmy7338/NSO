# 联合规划第二版：独立确认的预定判据

当前为开发阶段，尚未填写独立测试结果。所有参数只允许用开发种子 201—203 的结果决定；后端选择使用 115—118，不与后续规划确认种子重叠。

## 要分别检验的命题

1. 新完整规划比纯覆盖和旧几何补看有更高的固定预算联合 AUC。
2. 完整方法中的语义信息在新版无语义方法之上有额外收益。
3. 区域访问顺序相对相同质量奖励的局部选择有额外收益。
4. 更好的 F1 是否同时伴随更低表面误差，必须单独报告，不能自动推断。

## 统一实验条件

- 所有规划方法共享新后端，不将后端改进归功于规划器。后端独立因子实验选择 3 cm 体素、12 cm 截断距离，保留 6 cm／24 cm 结果。
- 主场景为 16×12 m，多房间和货架布置；这是程序化中等规模场景，不称工业大尺度真实场景。
- 同一几何种子的传感器噪声按动作时刻共享随机数，所有动作（前进／转向）统一计时；策略路径不同会得到不同视点的观测，不能复用不存在的帧。
- 主指标 `AUC(C2D×F1@5cm)`；同时报告覆盖 AUC、最终覆盖、P/R/F1@2/5/10cm、表面平均／95%误差、碰撞、路径、CPU时间。联合 AUC 为固定检查点的梯形近似。
- 固定参考表面与规划策略无关，包含未探索区域；评价按面积加权，不按语义类别加权。
- 对照包括纯覆盖、旧几何补看、旧语义补看、新版无语义、新完整方法、去除区域路线的新方法。旧对照同样使用新后端。
- 合成语义只在可见像素提供；标签变化不改变 RGB 材质、深度、雷达或真值。错误／缺失标签单独列结果。
- 位姿噪声试验是输入扰动，导航仍使用离散真实位姿；不能声称完成了 SLAM 定位估计器或实车验证。

## 统计与结论边界

使用独立的 301—308 八个种子块，每块包含两种布局与两种物体遮挡条件（开放货架／带背板），共 32 个场景。按种子块配对重采样，不能把同种子的多布局／噪声或每帧当作独立样本。

对完整方法相对纯覆盖、旧几何、新版无语义的三个联合 AUC 差异，报告 95% 区间，同时以 Bonferroni 校正的 98.333% 配对 bootstrap 区间作为这组三项优势的判据。完整方法优于新版无语义是“语义增量”所必需的条件；只超过较旧方法不能证明语义有效。区域路线作为单独消融报告，不宣称全局最优路线或完整 TARE 复现。

最终覆盖差异也应检查：均值不得下降超过 2 个百分点；若超过，必须说明覆盖／三维质量的代价，不能称为覆盖无损。三维“精度更高”需要表面误差或固定支持表面误差的独立证据，只有 F1 增长时使用“重建质量／完整性改善”。

开发结果不参与确认统计。确认结果一旦查看，若继续改算法，则当前确认集降为开发数据，重新冻结新种子后才可再次做独立确认。保留所有失败场景和消融，不按结果删场景、换主指标或挑选预算。

运行前以配置和源码哈希冻结最终参数、实验矩阵及上述判据。当前只建立判据，具体运行以冻结目录中的配置与源码快照为准。

## 2026-09-10 开发阶段修订：语义为必要贡献

用户明确要求可验证的语义创新。完整方案必须相对使用相同几何形状库的无语义版本有独立增量。加入去物体假设消融；其变化包含物体候选与形状推断，不能单独归因为类别信息。语义贡献由完整方法与相同候选预算的去语义版本比较。

主确认同时保留开放与带背板两类环境、两种布局，301—308 共 32 个场景，每方法统一 280 动作。不将开发中某个有利场景或某个局部指标改成整体主结论。正确标签为主确认，置换／缺失标签为单独鲁棒性测试。声明完整模块优势还要求路线、相机覆盖和物体假设消融的相应增量。

隐藏表面只影响规划，不进入 TSDF。所有方法使用相同可见观测与重建后端，最终按固定参考面积评价。当前尚未运行独立确认；开发数据无法证明这些判据已经通过。
