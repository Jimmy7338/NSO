RTAB optimized geometry / measured primitive feedback checkpoint
==============================================================

Each completed primitive is fused and scored once in its original prediction
epoch. Cached actual history is then reconstructed in the latest acquired RTAB
graph/map, preserving original Beta counts, source-time ledger events, failures
and arrivals. If corrected geometry invalidates a literal remaining route, an
explicitly declared execution adapter repairs the route to the same selected
fixed-map target with existing graph search. This physical adaptation is not
an original-method-equivalence or algorithm-efficacy claim. The macro and
bootstrap-frozen primitive options remain available.

The deployed I/O update uses uncompressed transient NPZ packets one at a time,
then discards only those derived archives after successful fusion. Original
source archives, actual prediction/after masks and reproduction matrices remain.
The atomic completed-records update repairs boundary metadata only. Neither
update was imported by the already-running completed S26 worker; its exact old
module bytes are retained under frozen_trial_source and source bindings.

The current source checkpoint matches the completed later exterior primitive
run. Supervisor summaries and worker terminal-feedback audits are both retained
when their final counts differ; no pending/uncaptured outcome is invented.
Neither primitive run completed unknown-space exploration or verified a full
macro arrival. The closed front glass and failed turns remain negative evidence.

Four actual recorded global plans and27 related score states all retain the
same G/S winner. Semantic terms change some asset scores, but no physical
semantic-efficiency benefit is established. Prequential mask-only prediction
checks compare the stored pre-action probability and fixed0.5 on the same real
events; they are not a no-feedback robot trajectory or exploration-efficiency
comparison. G3's adverse result, empty camera masks, failed turns and dependent
sample counts remain included. Versioned analysis provenance specifies the
chronology of later data rather than calling an overlapping episode prospective.

The22-page small paper,5-page supplement and85-page thesis and editable sources
are unchanged. All previously published integration paths remain. No raw RGB-D,
camera image, video, database, model weight, native binary, undeployed in-memory
prototype or failed native-clone proposal is included. The draft PR stays open
and unmerged. Portable verification uses only Python/NumPy and derived masks.
